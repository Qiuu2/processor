# 机制验证台账 —— 「一条没对 broken 输入失败过的护栏,不算护栏,是一段注释」

> **立台缘由**(critic 下岗前的自我怀疑,`W1P_critic_handoff_to_next.md §4.1`):
> **「本轮立了七条新机制。我验证的只是【这些文字写进了文件】。**
> **我没有验证过其中任何一条【跑过、并且能对 broken 输入 FAIL】。」**
>
> **⇒ 而 `r63` 当场证明它是对的**:同一条护栏,换一个计数器就恒绿 —— 而且 `n_notch` 那种写法
> 会把**臂 O 判得比臂 N 更像"NHS 在自选"(8 > 5)**,即**加强版的 B-1**。
>
> **⇒ 本台账的唯一作用:让「已立法」与「已验证」不再在读者眼里长得一样。**

## 1b 详情 —— **「已验」也可能验错了东西**(2026-08-03,adaptive-dsp 第 5 实例自查)

> **本条是本台账立台缘由的第二层**:立台时的判据是「有没有对 broken 输入失败过」。
> **1b 通过了那条判据(`r63` 3/3),但仍然是错的** —— 因为 **broken 版只证明了
> 「换成别的计数器更差」,没证明「现用的这个测的是不变量声称的那件事」。**

**旧判据**:臂 O(神谕预挂 8 陷、`T_low=999`)的 `ctr['N2_lvl'] == 0` ⇒ 判「分配被钉死」。
**代码事实(本轮读出)**:
```
nhs.py:396  cov = self._notch_covers(k*df)      ← 该 bin 是否落在【本层已挂陷波】覆盖内
nhs.py:399  if gr_ok or cov: gate = P.T_low_gr  ← = −65 dBFS,**不是 999**
nhs.py:711  _notch_covers: 槽非 FREE ∧ |slot.f − f| ≤ BW/2 ⇒ True
```
⇒ **臂 O 预挂的那 8 个频点 `cov` 恒 True ⇒ 它们的电平门是 −65,不是 999。**
  `T_low=999` 关掉的只有「**首次获取**」;「**维持**」路径一直开着。
⇒ **`N2_lvl == 0` 是【经验结果】** —— 它恒 0 只因被压 18 dB 的 bin 通常掉出 top-16 候选表。

**实测(`r65b_armO_breakdown_out.txt`,6 条种子 × Δ=+10/+12/+14 dB,共 18 格)**:
| 情形 | `N2_lvl > 0` 的格数 |
|---|---|
| 臂 O 构造**完好**(挂陷 8 ∧ 频点==picks) | **10** |
| 臂 O 构造**已散**(挂陷 8→2/4/5/6/7,频点≠picks) | **8** |
> **⇒ `N2_lvl>0` 在两种情形下都出现 ⇒ 旧判据对「分配到底发生了没有」【零分辨力】。**
> **不是"偏严",是"测的不是那件事"。** ——「拿掉被测物这个数应该等于多少」(D6-d)在这里的答案是:
> 拿掉"分配"这件事,`N2_lvl` 照样非零。

**新判据(1c)**:`挂陷 == 8 ∧ 8 个频点逐一 == picks`(= 「**没有发生新分配**」,
即 B-1 横幅真正断言的那件事)。**双向已验**:
- **正例(能失败)**:`r65b` 8 格判 FAIL,臂 O 实际掉到 2–7 个槽、频点被改写;
- **阴性对照(有分辨力)**:`r65` 中臂 N(自选)`频点==picks` 在 **30/30** 行上恒 False;
- **不误杀**:`r65` 在 `r57` 自己的读数点(Δ=6.00/6.00/7.50/3.50/6.50/4.50)上 **6/6 判 OK**,
  而旧判据在 Δ=+6/+8 dB 上已有 **7 例**把构造完好的数据判 FAIL。

> **⇒ 给本台账加一条纪律(见下 §纪律 4)。**

## 纪律

1. **新立任何机制,当场入本台账**,默认 `⚠ 未验`;
2. **⛔ 「未验·仅文本」的机制,不得在任何 verdict / 交接件 / 对外表述中被称作"护栏"或"已防住"**,只能称"已立规,未落机制";
3. **放行门(critic verdict)复核时,本台账是必查项** —— 一份 verdict 若引用了未验机制作为"已闭"的依据,该引用无效。
4. **⭐⭐「已验」须同时答两问,缺一即降回 ⚠**(2026-08-03,1b 事故后立):
   ① **能失败吗?**(broken 输入下确实 FAIL)—— 原判据,`r63` 答的是这一问;
   ② **⭐ 它测的是不变量声称的那件事吗?**(拿掉被断言的那个动作,这个量会不会照样变?)
      —— **1b 正是过了①而栽在②**:`N2_lvl` 在"分配发生"与"分配没发生"两种情形下**都**非零。
   **判别法(D6-d 的护栏版)**:写下「**若被断言的动作根本没发生,这个量应该等于多少**」,然后**真的去跑**。
5. **⭐ 护栏必须朝【两个方向】检查**(同日,A-1/B-2 事故后立):
   ①**它会不会放过错的?**(经典方向)②**它会不会挡掉对的?**
   > **第二个方向的失效更隐蔽,因为它长得像"严谨"** —— 实例:臂 N 自由槽位下 `N2_lvl==0`
   > 是**算法的真实输出**(「什么都没做,所以 ΔMSG=0」),按"护栏失败"剔除 = **把最差的样本
   > 从达标统计里删掉**;以及"任一臂失败即作废整行" = 因参照臂出问题而扔掉交付列。
   ⇒ 与「证据门槛不得随结论方向浮动」同族:那条管**举证力度**随方向浮动,本条管**样本被筛掉**。
