# V-34 · 房间冲激响应(RIR)实测 — 操作手册

> **为什么要做这件事(一句话)**:W1-P 闭环台架把声反馈路径带限到 **8 kHz**,
> 而那个前提目前只有 **[L3/CTO 领域判断]**(DEC-0020)。**本测量是唯一能把它升到 [L1] 的路径。**
>
> **它决定的不是精度,是【适用域】**:同一批种子,`f_cut=24k` 时实测 ΔMSG 是 **0.00–1.50 dB**,
> `f_cut=8k` 时是 **3.50–7.50 dB**。**真机落在两者之间的哪里,取决于真实电声链在哪里滚降。**

---

## 0. 这次要回答的只有三个问题

```
Q1  声反馈环路在 8 kHz 以上还有没有足以维持啸叫的能量?   ← 最要紧,定 f_cut 前提真假
Q2  真实房间的 T60 / 直混比是多少?                        ← 台架 F(z) 从合成换成真的
Q3  临界点数 N_crit 是多少?                               ← 架构侧那张 ΔMSG 表的自变量
```
**⇒ Q1 只需要一次粗测就能答。Q2/Q3 需要同一条数据,但精度要求更高。**

---

## 1. 器材(最低配,都不需要专业设备)

| 件 | 要求 | 说明 |
|---|---|---|
| 扬声器 | **就用目标部署的那一只** | 若无定型 ⇒ 用手边最接近会议场景的(吸顶/壁挂/桌面) |
| 麦克风 | 同上 | ⚠ **不要用手机麦** —— 多数手机在 8 kHz 以上有厂商滤波,会假造出我们要找的那个滚降 |
| 声卡 | 支持 **48 kHz、同时播放与录音** | USB 声卡即可;笔记本板载也行但要能同时播录 |
| 软件 | 能播 wav、能录 wav | Audacity / REW / 甚至 `ffmpeg` 都行 |

**⚠ 一条硬要求**:**播放与录音必须是同一个采样率 48 kHz,且不得开任何"增强/降噪/回声消除"。**
Windows 的"音频增强"、会议软件的 AEC、蓝牙链路 —— **任何一个都会毁掉这次测量**,而且毁得看不出来。

---

## 2. 摆位(决定测的是不是"反馈路径")

```
        ┌─────────┐
        │  扬声器  │  ← 正常安装位置、正常朝向
        └────┬────┘
             │  ⚠ 麦克风【不要】放在扬声器轴心上
             │     反馈路径走的是【离轴】,而高频离轴掉得比轴上快得多
             ↓
     ┌──────────────┐
     │   麦克风      │  ← 放在【真实使用位置】(会议桌上/发言人前方)
     └──────────────┘
```
**⇒ 这一条是本次测量的全部意义所在**:我们要的不是扬声器的规格书曲线(那是轴上的),
**是"扬声器→房间→麦克风"这条实际环路的响应**。

**记录下来(写进 `meta.txt`,脚本会读)**:房间大致尺寸、扬声器与麦克风的距离与夹角、房间是否有吸音处理、测量时是否有人在房间里。

---

## 3. 测量(三步,十分钟)

### 3.1 生成扫频信号
```bash
python3 04_platform/V34_RIR/make_sweep.py
# 产出 sweep.wav(指数扫频 20 Hz → 24 kHz,10 秒,48 kHz/单声道)
```

### 3.2 播放并录音
```
播放 sweep.wav 到【扬声器】,同时用【麦克风】录音,存成 rec.wav
⚠ 录音电平:峰值到 −12 ~ −6 dBFS 之间。削波(到 0 dBFS)= 本次作废,必须重录。
⚠ 录音要比播放长 2 秒(尾部留混响衰减)
```

### 3.3 ⭐ 必做的对照:**断开声学路径再录一次**
```
把麦克风移到远离扬声器处(或把音量关到最小),同样录一遍,存 rec_ref.wav
```
> **为什么必做**:它给出本底噪声与电学串扰。**没有它,你无法判断"8 kHz 以上没能量"
> 到底是【真的没有】还是【被本底噪声淹没了】** —— 而这两者对我们的结论方向完全相反。

## 4. 后处理

```bash
python3 04_platform/V34_RIR/analyze_rir.py rec.wav rec_ref.wav

```

## 附:这次测量【不能】回答什么

- **不能**回答"NHS 值几 dB" —— 那是 B-1 的活,与本测量无关;
- **不能**外推到别的房间 —— 一次测量 = 一个房间一个摆位。**要外推需要多组;**
- **不能**代替听感评价(SD)。
