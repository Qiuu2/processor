**设计决策(带量化理由)**:
- **RMS 检测器的功率状态必须用 Q8.54(int64)**:x² 的 dB 动态范围是信号的两倍,
  Q4.27 的 LSB(−162.6 dBFS)会让 −100 dBFS 信号的 x² 直接下溢到 0。
- **检测器功率底 = (1/α) LSB,与 release 耦合**:50 ms ⇒ −128.75 dB;**3000 ms ⇒ −110.97 dB**
  (比 PRD 的 >106 dB 只低 5 dB,但比门限量程下沿 −80 低 31 dB ⇒ 判据用途充分)。
- **非对称 attack/release 时读数不等于均值功率**,而介于均值与峰值之间(实测 −20.89 / −23.01 / −20.00);
  **对称时精确等于均值**(误差 0.013 dB)。⇒ ⛔ 不得称"RMS 值"而不带限定。
- **系数斜坡可用线性插值**:稳定三角 |a2|<1 ∧ |a1|<1+a2 是**凸集** ⇒ 两稳定点的插值仍稳定
  ⇒ 不需要双实例交叉淡入(省一半算力)。实测 480 步斜坡越出三角 0 次。

**算力自报(解析,⛔ 非实测)**:D3 ≈153 乘/样本/通道;D4 ≈154+N 乘(N=256 ⇒ 410);

⇒ 「+4 dBu ⇔ −20 dBFS」要求模拟前端净衰减 **−8.72 dB**;⚠ ADC 的 min 103 dB < PRD 的 >106 dB。

**每输出样本回写 80-bit = 3×32-bit 且须核心侧 decimate**,且**不支持 multi-iteration ⇒ ≤1024 taps**;

### 2026-08-04 · ⭐⭐⭐ 单记一条:**碰巧正确的实现,在扩展的那一刻变错**

> **lead 点名要求单独留痕。这是本项目目前最干净的一个该形态实例。**

**事实**:`chdsp_biquad.c` 的 `butter_q()` 原写
```c
1.0 / (2.0 * cos(M_PI * (2k+1) / (2n)))      /* ⛔ 应该是 sin */
```
- 对**偶数**阶:cos 式与 sin 式给出**同一个 Q 集合,只是顺序相反**
  (证:sin x = cos(π/2 − x),而 π/2 − π(2k+1)/(2n) = π(2k′+1)/(2n) 当 k′ = n/2 − k − 1;
   偶数 n 时 k′ 必落在 [0, n/2−1])⇒ 级联顺序不改变总传函
  ⇒ **它在当时是对的,而且是"逐位对的",任何测试都抓不到。**
- 对**奇数**阶:两式**不等**。n=3 时 cos 式给 **0.5774**,正确值是 **1.0**。

**⇒ 为什么这条值得单记(三层)**:
1. **它不是"写错了没被发现"** —— 在它被写下的那个作用域里,它**完全正确**。
2. **它只在有人去扩展作用域(加奇数阶)的那一刻才变错**,而那个人**没有理由去怀疑一个
   已经跑绿了几十轮的函数**。⇒ 缺陷的"出生时刻"和"写下时刻"**不是同一天**。
3. **⇒ 而它错的方式是【静默】的**:编译过、跑得动、滤波器能出声,只是频响不对。
   ⛔ 没有任何一条断言会红 —— 因为原来根本没有奇数阶的断言。

**⇒ 判别法(可推广)**:
> **凡"在当前参数域内正确"的实现,记下【它依赖域的哪个性质】。**
> 本例依赖的是「n 是偶数」⇒ 这个前提**没有写在任何地方**,只活在那个公式的对称性里。
> ⇒ **扩展参数域之前,先把"当前实现依赖域的什么"翻出来** —— 而不是扩展完再测。
