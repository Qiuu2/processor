### 2026-08-04 · 任务一(定点约定)收尾记录

**承重裁决**(全部 [L2/宿主] 或 [L3/解析],⛔ 无 L1):
- 样本 I/O `Q0.31` / 链内 `Q4.27`(+24.08 dB 余量);系数统一 `Q4.27`;累加器 ≥66 bit(SHARC+ MRF 80 bit)
- 溢出=饱和;舍入=就近;结构=DF1;**二阶误差反馈 EF 必选**(关掉最坏 −84.44 dBFS,连 PRD >106 dB 都不过)
- HPF/LPF 走**结构约束量化**(自由量化在 251/500 个 fc 上破坏 DC 零点,最坏 −59.26 dB)

**教训(本轮自己踩的,按事故记)**:
1. **⭐ 三条我自己写下的断言被自己的预注册当场证伪**,每一条都「听起来完全正确」:
   ①「0 dB 的 PEQ 节是 87 dB 噪声放大器」—— 实跑:G=0 时 b≡a ⇒ 累加器低位恒 0 ⇒ **逐位恒等,零误差**。
   ②「int64 不够,真实工况会溢出」—— 实测参数范围内占用 **58.005 bit < 63**。
   ③「S ≤ 1.0 保住了系数范围」—— 实扫:S 翻倍只动 +0.0144,**真正的驱动量是增益**(硬包络 +18.089 dB)。
   > **共同形状:一个正确的机理 + 一个我没验的作用域。** ③ 最险:若照原写法,
   > 保护会被归给一个几乎不起作用的常数,而真约束无人守(= D6-r「锁错字串的 lint 比没有 lint 更坏」)。
2. **⭐⭐ 我的一个检查本身没有分辨力,而它 PASS/FAIL 都不构成证据**:
   CHK-2 测「输出信号的样本均值」,判据 1e−7;8 个种子实测**标准差 1.226e−6** ⇒ 判据在噪声内。
   换被测量为「**算术误差**的均值」后才有分辨力(4.99e−12)。
   ⇒ **写判据时要先问「这个测量的分辨力是多少」**(LESSONS C-3 的正向用法)。
3. **⭐⭐ 变异测试的断言不能随构建翻转**。r1/r2 我让断言跟着 `BROKEN` 宏走,
   于是坏版本里检查 PASS ——「那不是检查杀死了变异,是检查换了题目」。
   r3 加 `FORCE_GOOD_ASSERT=1`(同一份好判据跑在坏模块上)才产出真杀伤矩阵:**3/3 杀,阴性对照零 FAIL**。
4. **⭐ 归档件里没有 deps 行的数不得进交付物**。系数上界 11.2148 与 DF2 的 135.13 dB 原先只在临时目录,
   已补 `scan_design_bounds.py` + `results_design_bounds.txt` 使其可复现。
   同一轮还发现:文档里的「EF 关」一列用的是临时脚本的数(−84.75…),
   与归档 C 轨实测(−84.44…)差最多 3 dB ⇒ **已全列换成有 deps 的那份**。
5. 读厂家原文的回报:**闭掉 W1-A 两条 [L4/待核]**(80-bit MRF 存在性、MAC 舍入模式),
   零工具链、约 20 分钟。⇒ 「必须实测才能定」之前先穷尽厂家已公布值(DEC-0014 同型第二次)。

**发现并上报 lead 的三条前提问题**(⛔ 我不处置,只报):
- EE-408「2.5 cyc/biquad」的工作点缺一维:**其基准代码是 `float` 数组 + CCES `biquad()`** ⇒ 是浮点数,定点值未测
- PRD §一.1 字面「24bit/32bit **浮点** DSP 运算」与 DEC-0006 锁定点冲突,库内未见 PRD 偏离留痕
- IF-v1.4 回执里「峰值参考 −128.19 / 正弦 RMS 参考 −119.2」的 9.0 dB 差,按定义应恒为 3.01 dB

**器件事实(入库备查)**:ADAU1979 满量程 4.5 V rms = +15.28 dBu(动态范围 min 103 / typ 109 dB A 计权);
ADAU1962A 满量程 2.00 V rms = +8.24 dBu(DNR 114 dB)。[L2/厂家 datasheet]
⇒ 「+4 dBu ⇔ −20 dBFS」要求模拟前端净衰减 **−8.72 dB**;⚠ ADC 的 min 103 dB < PRD 的 >106 dB。

**平台事实(D4 用,只记结构不估数)**:FIRA 有定点模式(FXD/TC/RND),但定点下
**每输出样本回写 80-bit = 3×32-bit 且须核心侧 decimate**,且**不支持 multi-iteration ⇒ ≤1024 taps**;
**IIRA 无 FXD 位,是浮点专用**(FORTYBIT 选的是 32/40-bit IEEE 浮点)。[L2/厂家 HW Ref §38 + EE-408]
