## B. 通用骨架(非本项目蒸馏,Claude 通识;框架/OS 未选,全部待校)
- **架构分层**:协议客户端(连接管理/重连/心跳)→ 设备模型(参数字典驱动,设备状态镜像+订阅)→ UI 层;多设备=设备模型×N+聚合视图。
- **矩阵路由 UI 要素**:交叉点网格(输入×输出)、拖拽+点选双操作、通道链路的复制/粘贴(← PRD §四.2)、当前路由与预设差异的可视提示。
- **EQ/频谱控件要素**:曲线=各段 biquad 响应叠加(公式与 DSP 参考实现同源);拖拽手柄改 F/Q/G;陷波点(AFC)只读显示层叠加;刷新率与协议查询频率解耦。
- **预设管理**:导入导出带 schema 版本;跨版本导入走迁移提示;批量备份。
- **多设备发现**:局域网广播/组播发现(与 platform-fw 定义)、设备列表/分组、固件版本矩阵视图(为 OTA 服务)。
- **OTA 界面**:版本校验显示、进度、失败恢复指引;禁"升级中"以外状态发起二次升级。
- **菜单层级方法**:按工作流组织(连接→路由→通道处理→会议功能→系统),对标上游软件后修订。
