## §A-B · 【护栏 B:动作计数】—— 运行时不变量,不是文本 lint(2026-08-03 蒸馏,independent critic 点名要求)

**规则**:**凡报告「某模块的性能」,必须附【该模块在该测量臂内实际发生的动作计数】。计数为 0 ⇒ 该数【不是该模块的性能】,不得以其名义呈报。**

| 属性 | 说明 |
|---|---|
| 形式 | **运行时不变量**,非文本 lint ⇒ 不受措辞、口径、术语变更影响 |
| 关键优势 | **不需要任何人事先想到某个限定词**(如「神谕选点」)就能自动抓住 |
| 双向可失败 | 计数 >0 而数值异常 ⇒ 查实现;计数 =0 而报为性能 ⇒ 当场违规 |
| 计数取什么 | 该模块**状态机的转移**(如 NHS:`engage` / 分类 / 分配),**不是**轮询次数、不是帧数(D-K:凡计数器须写明"每什么计一次") |

**来源实例**:`ΔMSG = 5.67 dB` 被报为「NHS 实测」,而该测量臂 `T_low=999` ⇒ **engage / 分类 / 分配三个计数全为 0** ⇒ 被测对象实为「8 个陷波器由解析式放在最优点上」= **NHS 的上界**。**文本护栏(要求同段出现某几个字串)完全通不过这道题;护栏 B 当场拦下。**

**⇒ 可迁移形态(任何模块、任何工单)**:`报告「X 的性能」 ⇒ 必须同时给出 X 在该臂内的状态机转移计数;为 0 即判该数不属于 X`。

## §A-C · 撤回的执行(2026-08-03;P-5 根因)

1. **撤回登记的作用域必须是【这一节 / 这个环路 / 这个来源】,不能是【这个数】。** —— 撤回 6 dB 后,复活时借走的是同一句话的**频段**。
2. **撤回条须带【无需重新论证即判违规】指针。** 只要还需要"重新论证一遍才知道违规",就会有下一次。
3. **⭐ 撤回的反扫特征串,必须取自【被撤回的那句话本身】,不能取自【发现问题的那个场景】。** 后者只会修好被指出的那几处 —— 这正是 P-5 的根因。
4. **撤回的执行者不能是撤回的作者。** 三次复活全部是自撤自复 ⇒ 必须落成机械物件(指针 / lint / 台账)。

## §A-D · 【L 标降级也是一次撤回】(2026-08-03;M-8 根因,critic 通则)

> **撤回一条【引用】⇒ 反扫【引用串】;降级一个【数值】⇒ 反扫【该数值的消费处】。**

**判据串(消费处特征)**:`过/不过` · `闭合` · `可取` · `不必` · `成立` · `无需`
—— 这些词标记的是**"这个数把某件事翻过去了"**的位置,而那正是降级后最先失效的地方。

| 层 | 反扫对象 | 本例 |
|---|---|---|
| 定义处 | 该数被赋值/被标 L 的行 | `C-8b-stat = 6.0 dB` 四处 ✓ 已改 |
| **消费处** | **用它做判定、并据此推出结论的行** | `:785`「三点全过 / 全不过」→ `:804`「并入 6.0 dB 总线」→ `:796`「**CTO 不必拍任何取舍**」⛔ 漏 |

**⇒ 实证教训**:消费链里还藏着**另一次撤回的漏网消费**(v0.17 作废 C-8f-for-AEC,而 v0.34 在其后又把它当现行约束用了一次)。
> **⇒ 【一次未完成的撤回,会让下一次撤回也不完整】** —— 因为第二次撤回的反扫,会在第一次留下的残骸上停下。

## §A-E · 写入类操作的断言位置(2026-08-03;D6-w)

> **凡"写入"类操作,断言写在【写入后重读】上,不是写在【写入调用的返回值】上。**
- `replace()` 静默失败正是返回值层的沉默:内容对、调用成功、**写入没发生**。
- **⇒ 且断言须双向**:既核**未发生**,也核**重复发生**(我同一段版本记录曾被插入两次)。
- **⇒ 索引层丢失的代价:连"丢了几轮"都数不准** —— 实际缺 v0.41–v0.49 九轮(非十轮),另有 v0.12/v0.13/v0.28 三个号不在,**而"是从未存在还是同一 bug 的更早发作",我自己不知道。**
