## 教训(候选蒸馏件,过门后进 skill §A)
- **双轨必须异法**(F1,2026-07-31):手算与 python 跑同一公式=同式重跑,同错不互检——35.7Hz 错数即此产。第二轨须换独立方法(如公式界 vs 数值解量化极点角)。铁律七的"独立工具"指独立**方法**,不是独立计算器。
- **接口共识必须落盘+版本化**(F-16,2026-07-31):W1-A/W1-B 曾在运行点/检测 tap/精度判据三项**互换立场**而双方均以为已对齐(消息流版本竞态,DEC-0008)。纪律见 team_config Interface contract discipline:合同独立成文件、两侧只引版本号禁转述规范值、先落合同后改文档。**收方义务:合同条款与自己论证冲突时,先据物理争一轮再接受**——我 v0.1 的出口 tap 被 adaptive-dsp 反推纠正,而他们 v0.95 曾反向"礼让"接受我的错误口径。
- **上界口径要按档全量、且声明无界档**(F2):只重定价一行的"上界"是假上界;T2 无板证上界必须显式说,否则"不构成风险"措辞越权。
- **"悲观"两字要有板证才配用**(F3):库内唯一同族规整短环板测=8.51 cyc/MAC(ITC 权重环,单 MAC 短环),2.0 只是规划值;敢写"悲观"= 敢背 ×4.3 敞口。
- **旁链设计要给"反应时间账",不只给"覆盖账"**(F4):检出覆盖≠反应达标;低速率扫描路径(看门狗 1.07s/通道)的最坏反应须显式预算并给补强机制。
