## 2026-08-01 晚 · v0.9 轮(AEC 实测打穿 C-8a 的裁定;`system-architect-2` 笔)
- **我 v0.8 写错了一处度量对象,被实测打穿**:§4.0.5 写"AEC 的 C-8a 按**最坏帧**峰-均核",算法侧照此测得 中位 25.33dB / 最坏帧 **129.56dB**(门 0.25dB)。**认账并修正**。
- **⭐ C-8a′(新定义)**:C-8 的度量对象 = **`D_sup(f) = sup_t D(f,t)`(时间上确界)**,不是瞬时、更不是"最坏帧峰-均"。**理由**:MSG 由环路响应的峰决定,而峰要**同时对频率和时间**取——元件某帧衰减得深**不会**让系统更不稳定,**只有它某时刻不衰减时环路才顶到那个值**。⇒ 纯衰减型元件 `D_sup` = **空闲响应**(**C-8 原文的"空闲"口径本来就对,是我画蛇添足加了"最坏帧"**);可增益型(AGC/makeup)`D_sup` = 最大增益。**这条同时简化了工作量**(不必逐帧核)。
- **⭐ 129.56dB 是度量对象错配的假象,不是 AEC 打穿了门**:AEC 是**加性**算子 `y = x − f(u)`,被减项**只是 u 的函数与 x 无关** ⇒ **`H_{x→y} ≡ 1`(0.00dB 平坦)** ⇒ **它没有一个 x→y 频响可供算纹波**。那 129dB 测的是**残差信号谱的谱平坦度**(或近端静默帧上的 Y/X 爆表),单位同、名字同、**物理对象不同**。**交叉验证**:算法侧同批实测 DTD 冻结/解冻的增益跳变 **≤0.014dB** —— 若真有 129dB 的 x→y 纹波,把自适应整体停掉不可能只跳 0.014dB。**同一批数据里一个量证伪了另一个量的读法。**
- **但不给豁免**,另立同预算线的两条:**C-8f 环路增益调制(MSG 限,`max ≤ +0.25dB`,计入同一 1.0dB 合计)**、**C-8g 电平依赖性(锚定限,`≤±1.0dB` 全量程;依据 = β_min 60dB/s × 128ms = 7.68dB 增长,±1.0dB ⇒ 斜率相对误差 13%,在 s_max 容差内)**。**度量 = 探针法**:向**本地环路**注持续探针音、元件正常自适应运行、测 tap 处探针幅度相对旁路基线——**用"它对本地环路做了什么"取代"它自己的残差长什么样"**。它也正好覆盖**通路 B**(NLMS 更新式里 e 含啸叫 ⇒ 啸叫经 ⟨e,u⟩ 泄漏进系数 ⇒ 零均值但方差 ∝ μ 的环路增益调制)——**静态纹波完全测不到这一条**。
- **⭐ 豁免判别式(三项合取,写死边界防"自适应元件一律豁免")**:①作用是**加性** `y=x−f(u)` 非乘性;②参考 u **不含本地扩声**;③内部**无任何乘性增益级**(含之则那段单独回 C-8a′,不得挂 AEC 名下搭便车)。**逐个代入验算:NLP/ANS/AGC/COMP/动态PEQ/噪声门 全部第 1 项即假 ⇒ 全项目只有 AEC 线性段适用。** **结构性印证:加性/乘性的分界恰好落在我 C10 子级裁定的 tap 位上**(线性滤波之后、NLP 之前)——两条独立推导的分界线重合。
- **C12(ii)×C-8×C10 合并决策(一次定)**:**AEC 参考 = 纯远端**。违反则三条**同时**失守(ADC 锚失效 / AEC 丧失加性资格回落静态门必挂 / tap 上游出现信号相关频选衰减压平臂2 证据)⇒ **须一次性走 C9,不得分三次**。
