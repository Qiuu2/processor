## 1. 检测旁链定案

### 1.1 前提(设计驱动量,均有出处)
- 啸叫主能量区 200Hz–8kHz(PRD 全频响 20Hz–20kHz [PRD §一.1];dbx 检测 HPF 30-500Hz [L4/dbx];GN 专利典型频段 1–6.5kHz [L4/专利文本];>8kHz 啸叫罕见但产品级不可裸奔 → 看门狗兜底,见 1.4)。
- 陷波对准精度需求:1/10 oct @100Hz 带宽 **6.93Hz**(公式 BW=f₀·(2^(oct/2)−2^(−oct/2)),代入 100×(2^0.05−2^−0.05)=6.93 [L3/双轨复算]);恒带宽下限 15Hz 后最窄仍 15Hz → **靠原始 bin 无法对准,Quinn 第二估计器 bin 内插为必需件**(非可选)[L3,结论承接 D0c §1.10-2]。
- 检测反应时间对标:Sabine "找到并消除一次啸叫典型 0.4s@1kHz" [L4/厂商]。

### 1.2 FFT 方案四联数对比(分辨率 / 分析窗 / 算力 / 内存)

算力口径:cyc/帧摊销,T2=2.0 cyc/op;**含抽取器**(B 组连续运行 72-tap ÷3 polyphase,9.216 MMAC/s,=12,288 MAC/帧 ×2.0 = 24,576 cyc/帧,见 §2 行2)。每次 FFT 总 op = 2.5N·log₂N + 窗 N + 幅度 N + 谱扫描 2N [L3/解析]。表中算力按各方案标注的每通道更新周期 T_u 摊销,FFT 项 ∝ 1/T_u 可线性换算。

| 方案 | fs_det / N / T_u(每通道) | 分辨率 | 分析窗 | 算力(cyc/帧摊销) | 内存(环形缓冲+工作区) |
|---|---|---|---|---|---|
| A1 | 48k / 2048 / 42.7ms | 23.44 Hz | 42.7 ms | 32,256(无抽取器) | 32KB(8×2048×2B)+ 24KB |
| A2 | 48k / 4096 / 42.7ms | 11.72 Hz | 85.3 ms | 69,632 | 64KB + 48KB |
| B1 | 16k / 1024 / 42.7ms | 15.63 Hz | 64 ms | 14,848 + 24,576 = 39,424 | 16KB + 12KB(+抽取态 2.25KB) |
| B2(高分辨率备选) | 16k / 2048 / 42.7ms | **7.81 Hz** | 128 ms | 32,256 + 24,576 = 56,832(4.26%) | 32KB + 24KB(+2.25KB) |
| **B3 ★V1 默认** | **16k / 1024 / 16ms(75% 重叠)** | 15.63 Hz | **64 ms** | **39,595 + 24,576 = 64,171(4.81%)** | **16KB + 12KB(+2.25KB)** |

样例算式:B2:FFT op = 2.5×2048×11 = 56,320;辅助 = 2048+2048+4096 = 8,192;合计 64,512 op ×2.0 = 129,024 cyc/次;每 4 帧 1 次 → 32,256 cyc/帧。B3:FFT op = 2.5×1024×10 = 25,600;辅助 = 4,096;合计 29,696 op ×2.0 = 59,392 cyc/次;系统 500 次/s(8ch × 每通道 62.5 次/s)→ 59,392×500/750 = 39,595 cyc/帧 [L3/双轨复算]。

**取舍与裁决(v0.2,并入 W1-B 反推)**:
1. **抽取到 16kHz 定案(A 组出局)**:同分辨率下算力/内存全面劣势(A2 对 B2:+23% 算力、双倍内存),且 >8kHz 盲区由看门狗兜底(1.4)后 A 组唯一优势消失;A1 低频最弱一票否决。
2. **B2 vs B3 是真正的运行点之争:谱分辨率 vs 时间密度**。W1-B 论证 IMSD(帧间幅度斜率——唯一必自研核心判据,D0c §1.8)吃 hop 密度:16ms hop 在啸叫建立期(百 ms 量级)可取 6-13 个 PAPR 轨迹样本做 LS 斜率+线性度检验,42.7ms hop 只有 2-5 个 [L3/W1-B 草稿];B2 的分辨率优势主要服务低频 PNPR 邻域分辨与 V2 预留窄档(1/20-1/80 oct,V1 不实现),V1 人声防线以 PHPR(谐波)承重,15.63Hz bin 足以分辨 ≥80Hz 间隔的语音谐波 [L3/W1-B 论证+本人复核];且 Quinn 内插在 1024pt Hann@16k 已有 L2 桌面数据(|f_err| 中值 1.4-1.6Hz、p95 2.8Hz@SNR 10-30dB [L2/W1-B 草稿 selfcheck,待其过门])支撑最窄陷波对准,B2 无对应实证。两者算力同量级(4.26% vs 4.81%)。
3. **裁决:检测引擎参数化**(N∈{1024,2048}、hop∈{16,21.3,32,42.7ms}、抽取 16k 固定、字段预留 24k/N2048 档),**V1 默认 = B3;B2 为高分辨率备选运行点**,对决以 L2 ROC 仿真收口(V-10),实现冻结前定案。板上预算吃紧时按 W1-B 降档梯子退:hop 16→32ms → 每 hop 1 通道 → N=512(分辨率 31Hz,低频对准劣化)→ 仅析 automixer 开门通道 [L3/W1-B 草稿]。

### 1.3 窗函数、重叠率、8 通道调度、更新率
- **窗 = Hann + Quinn 第二估计器内插**(PX4 实践组合,避开抛物线内插精度不足/Jacobsen 加窗有偏两坑 [L4/PX4 源码阅读,D0c §1.10];Hann+Quinn 组合偏差须 L2 仿真标定,验收判据见 §8)。
- **调度 = 轮流(round-robin),8 通道错峰,每 2ms 一个分析槽**(系统 500 FFT/s)→ 每通道谱更新周期 **16ms**(62.5 次/s),64ms 窗 75% 重叠(检测用途,无重构约束)[口径对齐 W1-B §8]。旁链为**最低优先级可抢占任务、非音频 ISR;错过槽位允许跳帧**(表现为降档,绝不阻塞音频帧回调)。
- 调度对比(为何不并行):每帧 8 路并行 = 8×59,392 = 475,136 cyc/帧 = **35.6%,荒谬且无收益**(反应时间由窗长与判据持续性主导,帧级 hop 无增益);错峰 500 次/s = 39,595 cyc/帧 = 2.97% [L3/解析]。
- B3 单次 FFT 59,392 cyc 在帧内空闲槽一次完成(峰值 4.5%);B2 备选运行点(129,024 cyc/次)须**按 radix 级切片跨 ≤2 帧**(11 级天然切点,帧内峰值 ≤65k cyc)。

### 1.4 高频看门狗(补 8-20kHz 盲区)——v0.3 含 F4 反应补强
每通道 ~1.07s 一次 N=1024@48k 直采 FFT(46.88Hz 分辨率;1/10 oct @10kHz=693Hz,粗 bin 足够),扫 5.5k–20kHz:单次 59,392 cyc,8 次/s → 摊销 **634 cyc/帧 = 0.05%**,环形缓冲 8×1024×2B=16KB [L3/双轨复算]。

**F4 修复——反应时间补强双机制**(v0.1-0.2 只论证了检出覆盖,未预算反应时间;若走常规 M=3 持续性判据,高频路径最坏 ~3×1.07s+斜坡 ≈ 3.4s,对高音单元不可接受):
1. **单命中强判据**:看门狗候选峰同时满足{PAPR 强阈值(高于主带阈值 +X dB)∧ 通道电平高于 fb_thr+Y dB}→ **单次命中即插浅陷(−3dB)**,不等持续性确认;X/Y [L4/待 ROC 标定,W1-B 定]。误插代价 = 高频 693Hz 宽 −3dB 浅陷,可听性低 [L3/定性],由缓抬回收自愈。
2. **触发式快速复扫**:看门狗报候选(未达强阈值)→ 主旁链临时将该通道切至 48k/N=1024 复扫 3 连拍(间隔 ~50ms,占用其正常槽位,无额外预算)→ 按正常判据流程确认,确认路径 ~0.2s。
**反应账(入 §6)**:典型 = 扫描相位期望 0.53s + 强判据即插 ≈ **0.6-1.1s**;最坏(候选走复扫确认)≈ **1.3-2.5s** [L3/手算]。**残余风险交 CTO**:0.6-2.5s 窗口内高音单元保护依赖输出链保护限幅器(PRD §三.5,D4 交付物)——AFC 高频路径不承诺替代扬声器保护;panic 阈值(默认 OFF,竞品惯例)标定期重议(m7),若产品定位要求更快高频反应,选项=看门狗提频(算力余量充足,0.05%→0.5% 即 10 倍频)。V-5 验证判据扩为**检出率+检出延迟**双指标。

## 3. 定/浮点口径裁决(本模块)

### 3.1 音频通路(陷波执行):**维持定点,DEC-0006 无例外**,但带四条强制实现规格
高 Q 低频陷波是定点最难场景(D0c §4.2:状态字长需比输入多 ~2·log₂(fs/fc) bit;代入 fs=48k、fc=100Hz → **17.8 bit**,fc=20Hz → 22.5 bit [L3/双轨复算,与 D0c "≈18bit" 吻合])。据此:

1. **系数 32-bit(a₁ 取 Q1.30,范围 ±2)——一票否决 16-bit 系数**(F1 全面重写,口径参数化):
   - **存储量与格式**:a₁=−2r·cosω₀ ∈ (−2,2),16-bit 存储 = Q1.14(LSB=2⁻¹⁴);32-bit = Q1.30(LSB=2⁻³⁰)。
   - **舍入约定**:就近舍入(round-to-nearest)→ 最坏误差 = 半 LSB;满 LSB 界仅作"无舍入保证"参考。
   - **误差口径**:检测到的啸叫频率是连续量 → 设计裁决用**连续频点上的最坏界**,非某一 f₀ 的实际舍入值。
   - **推导式**:δω=δa₁/(2r·sinω₀),δf=δω·fs/2π。代入 f₀=100Hz(ω₀=0.013090,r=0.999346@BW10):**Q1.14 半 LSB → 8.9Hz、满 LSB → 17.8Hz**;f₀=20Hz:半 LSB → 44.6Hz(灵敏度 ∝1/sinω₀);**Q1.30 半/满 LSB → 0.00014/0.00027Hz** [L3/解析]。
   - **第二轨(异法,F1 修复)**:直接量化系数后数值解极点角(numpy roots)——Q1.14@100Hz/BW10 实际偏移 3.4Hz、@20Hz 达 **18.5Hz**;Q1.30 → 0.0001Hz [L3/数值解,与界一致:实际值 ≤ 界]。
   - **判据对照**:精度契约 p95|Δf|≤BW/4=3.75Hz(IF-v1.0 条款C7)→ 16-bit 最坏界在 f₀≲237Hz 全线不过(20Hz 处连"实际值"18.5Hz 都不过)→ **否决**;Q1.30 余量 4 个数量级 → **采用**。
   - **v0.1-0.2 错误留痕**:曾发布"35.7Hz"= δa₁ 误取 2⁻¹³(格式假设错)且半/满未注明;手算与 python 同式同错——**"双轨"若同式即失效(铁律七教训),本轮第二轨已换独立方法**。三方错源收敛记录见 DEC-0008。
2. **32×32→64/80-bit 累加**(SHARC+ 定点 MR 累加器路径;FIRA 同款 32×32→80 已证硬件存在 [L1/ITC infocard],核心侧指令级确认待 sw_reference 精读 [L4/待核])。
3. **DF1 结构**(定点惯例,CMSIS 文档口径 [L4/CMSIS])+ **一阶误差反馈(EF)于递归状态回写**(m3 修正,量化模型重写):
   - **线性模型(闭式)**:单舍入源(递归回写)、就近舍入、RMS 口径:σ_out = (2⁻³¹/√12)·√NG,NG=Σh²(1/A(z))(冲激响应平方和)。代入:100Hz/BW10 → NG=2.23e6 → **−133.9 dBFS**;20Hz/BW15 → NG=3.72e7 → **−121.7 dBFS** [L3/闭式+数值双轨,critic-w1 第三轨 −134/−122 一致]。
   - **v0.2 错误留痕**:曾写 −79/−51dBFS——那是"最坏幅度界×2^(额外位数)"的另一模型且基准未注明,与 RMS 口径不可比,作废;V-6 仿真以 −134/−122 线性预测为对标值。
   - **EF 仍为必选,但理由重述**:线性模型下噪声已低于产品底噪规格(>106dB 动态范围 → 底噪 −106dBFS,余量 ≥16dB),EF 的承重理由是线性模型**覆盖不到**的两项:①定点 IIR 极限环/怠机音(Dattorro 动机本源)[L4/文献];②SHARC+ MAC 路径舍入模式(截断 vs 就近)未指令级确认,若为截断则 DC 偏置+噪声抬升 [L4/待 sw_reference 核]。成本已计入(§2.1 行1,9 op/biquad/样本),可按 fc<300Hz 条件启用,省出部分为上行不计入。
4. **恒带宽下限 15Hz 兼作精度护栏**(D0c §5a):BW≥15Hz 钳住极点半径 r≤0.99902,限制最坏噪声增益,与音质动机(dbx 8-11Hz/QSC 15Hz [L4/厂商])二合一。

**深度/频率变系数防爆音**:走 NHS 天然捷径(D0c §4.4)——新陷波从 −3dB 渐深、撤除按 3dB 缓抬、DF1 状态连续 + 小步系数切换,无需通用变系数机构 [L4/Shure"先浅后深"+dbx LIFT 佐证]。

### 3.2 检测旁链:**申请对 DEC-0006 的例外——旁链用原生 float32**(⚠ 显式例外申请,交 CTO)
理由:①旁链**不在音频通路**,无 bit-exact 承诺与逐样本实时约束;②SHARC+ 浮点 MAC 与定点同为单周期,**算力预算不变**(§2.1 T2 口径同额)[L4/架构特性,待 cycle 实测佐证];③免去定点 FFT 的块浮点定标工程与其假绿面(定标错→谱幅错→判据错,且纯正弦自测照样绿);④PX4 结构迁移时全部定标坑消失(CMSIS q15 FFT 是 ARM 件,本就须重写 [D0c §1.6])。
**对 DEC-0006 的影响**:锁定点的动机是"MCPS 效率"[DEC-0006 原文],旁链 float 不触碰该动机(无算力代价 [L3]);音频通路仍全定点。**验证纪律代价**:检测器 L2 仿真对比改用容差判据+固定种子素材(非 bit-exact),此口径写入 D14 [L3/自定]。
**若 CTO 驳回**:退路 = 定点 FFT + 块浮点,算力 +~10-20%(定标/规格化开销 [L4/粗估]),工期 +(定标验证),功能无损。

### 3.3 谱缓冲 16-bit 存储(附带裁决;m5 修正——按字典实际下限重写)
环形缓冲按 Q15 存(内存减半,§2.2)。**论证按字典 fb_thr 实际下限 −80dBFS**(v0.2 用 −60dBFS 系松写):Q15 量化底噪 σ=2⁻¹⁵/√12 → **−101.1dBFS/样本**;正弦对噪声的 FFT 处理增益 10log₁₀(N/2)=**27.1dB**(N=1024)→ 谱域有效底噪 ≈ **−128.2dBFS**;对 −80dBFS 检测下限的余量 = **48.2dB**,检测用途充分 [L3/解析双轨复算]。分析时转 float 入窗(转换开销已计入窗步 op 数)。

## 4. AFC 在信号链中的位置(关联 A9)

A9 口径:链序由 adaptive-dsp(W1-B)重推、本人定稿。**本节给 NHS 硬约束,W1-B 提案必须满足,链序定稿在收到提案后出**:

| # | 约束 | 理由 |
|---|---|---|
| C-1 | **NHS 陷波必须位于 AEC 之后** | 陷波是时变 IIR;置于 AEC 前 = 回声路径(参考→麦估计路径)随陷波动作持续时变,迫使 AEC 反复重收敛 [L3/解析] |
| C-2 | **NHS 位于 ANS/AGC 之前(automixer 门控判决之前)** | 啸叫是高能窄带信号:先杀,否则污染 ANS 噪声谱估计、AGC 电平估计、automixer 门控 [L3/解析] |
| C-3 | **检测 tap = 陷波器组入口(AEC 之后、陷波之前)**(v0.2 修正,采 W1-B 反推) | 陷波器在扩声环路**内**,其压制效果在麦克风信号(=陷波入口)已可观测——入口 tap 不损失"是否仍反馈"信息;而**出口 tap 的陷波裙边会偏置同频复发峰的 Quinn 重估,且深度足够时残余低于门限而环路仍可能临界** [L3/解析];PX4 同构架构即"原始传感器 tap 检测 + 下游陷波执行" [L4/PX4 源码阅读];"同频持续检出且该频点已有陷波 → 加深"由状态机槽位关联实现,行为对齐竞品"若仍反馈则继续加深" [L4/竞品手册 §2.3];tap 在 AEC 后 → 远端单讲回声不伪装成持续窄带峰 [L3]。**诚实留痕:v0.1 曾定"出口 tap 闭环",系本人错误,被 W1-B 反推纠正。** |
| C-4 | **panic / 兜底增益动作与 AGC 互斥** | 恐慌阈值触发的临时增益回落 [L4/竞品] 与耗尽兜底增益(C-6)若被后级 AGC 反向补偿 = 失效;定义控制面信号 `NHS_GAIN_OVERRIDE(PANIC|EXHAUSTED)` → AGC hold(进参数字典遥测段) [L3/自定] |
| C-5 | 输出链 FIR 群延迟(DEC-0007.4)加长扩声环路延迟 → 啸叫候选频率梳更密、建立更慢 | 对 NHS 检测无碍,记为背景;不构成 FIR 的反对意见 [L3/定性] |
| C-6 | **宽带兜底增益节点位于 AFC 模块出口**(陷波器耗尽 EXHAUSTED 时启动,可编程恢复) | Rane"耗尽时宽带减益+可编程恢复时间"+Espressif"全局增益回落"+dbx 架构三源同构 [L4/D0c §1.2];挂 C-4 互斥信号 [L3];W1-B 状态机含此节点 [L3/W1-B 草稿] |

推定链位(供 W1-B 对齐,非定稿;m6 修正):`前放/增益/相位 → AEC → 噪声门 → **NHS(AFC)** → ANS → AGC → automixer(全局)`。v0.2 曾把噪声门画在 AEC 前,与 C-1 自身逻辑相悖(门是时变增益环节,置于 AEC 前同样扰动回声路径估计)——已改;**噪声门确切位置由 W1-B 链序提案论证、本人定稿,此推定不作锚定**。NHS 仅部署于 8 路输入链(PRD §二.5),输出链无 NHS。
