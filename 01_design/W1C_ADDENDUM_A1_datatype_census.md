## §1 ⛔⛔ 顶格结论(按 lead 要求,不缓和措辞)

> 我在 v0.2 §5 写的那句「**先跑 T1b/T2/T3,它们本来就是定点/标量**」——
> **其中 T3 那一项是错的。T3 是【浮点】内核,从头到尾。**

```
T1b  ✅ 定点(Q15 系数 × Q31 状态)
T2   ✅ 定点(Q1.31 复数,int64 中间积 >>31)

T1a  ⛔ **浮点** —— 而且不止库函数:它自己的 input/output/state/coeffs **四个数组全是 float**
                   (⇒ 回答 lead 的 ③:同一形状确实不止一处,只是方向与他猜的不同)
```

**⇒ 而后果不是"少一个内核",要放到 DEC-0009 自己的三档上看才看得见:**

## §5 B-4 地址闸(G3)完整设计 —— 含两极值代入与两段 L2

### 5.1 区间定义(逐字取自 `system/startup_ldf/app.ldf`)

```
L1  : 0x00090000 … 0x0039BFFF   (mem_iv_code / mem_block0_bw … mem_block3_bw)
L2  : mem_L2_bw    START(0x20000000) END(0x200f9fff)   ⇒ **cached**   (#define MY_L2_CACHED_MEM)
      mem_L2UC_bw  START(0x200fa000) END(0x200fdfff)   ⇒ **uncached** (#define MY_L2_UNCACHED_MEM)
      mem_L2BC_bw  START(0x200fe000) END(0x200fffff)   ⇒ **引导码工作区**
                   (LDF 注释:"The boot code claims the last 8KB of L2 SRAM, as working space")
```

### 5.2 三条断言

```
A 分离性:每一对 (L1臂, L2臂) 缓冲,region(&l1) == L1 ∧ region(&l2) ∈ {L2_cached, L2_uncached}
B 一致性:全部 L2 臂必须落在**同一段** —— 否则「L2 臂」内部就是一名多量,跨内核不可比
C 回填  :把实测段名写回 v0.2 §1 的板级参数槽「L2 臂落在哪一段」
做法    printf("%s @ %08X", name, (unsigned)&buf);  ⛔ 不需要任何 API、不依赖板型
```

### 5.3 两极值代入(⭐ 含第三次代入 —— 按我上一轮立的"相反还不够,得看是哪两个方向")

```
真该过    &l2 = 0x20001000 ⇒ L2_cached;&l1 = 0x00240500 ⇒ L1  ⇒ 分离 ⇒ **过**
真该不过① &l2 = 0x00241000 ⇒ 落 L1 ⇒ 两臂同区 ⇒ **不过**(= 假绿分类②:两臂被构造成相同) ✓ 相反
⭐ 真该不过② &l2 = 0x200FE100 ⇒ 落 **mem_L2BC_bw(引导码工作区)** ⇒ **不过**
   ⇒ 为什么这一侧也必须能失败:若判据写成「地址以 0x2 开头 ⇒ 算 L2 ⇒ 过」,
     这一格会**静默通过**,而它意味着我们把测量缓冲放进了引导码的工作区
   ⇒ 那是"看起来更像 L2 所以放过"——**方向对我们有利的那一侧没有闸** = 上一轮那条的同型
⇒ ∴ 判据必须是**枚举区间**,⛔ 不得写成"是不是 0x2 开头"
```

### 5.4 这条闸失败时阻止什么

```
A 失败 ⇒ 阻止「L1/L2 对照其实是同一种内存」的整臂假绿
B 失败 ⇒ 阻止「一个内核的 L2 是 cached、另一个是 uncached,而两个数被并排比较」
C 缺失 ⇒ 阻止「板级参数槽空着就出数」(v0.2 §1 已定空槽不跑)
⇒ 三条都是**中止条件**,不是输出行。
```
