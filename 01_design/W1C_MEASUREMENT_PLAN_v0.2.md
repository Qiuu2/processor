## §2 前提自检闸 G0–G5(⛔ 全是**中止条件**,不是输出行)

> **每条都按同一格式写:断言 / 怎么算 / 失败时阻止什么 / 两极值代入。**
> **⇒ 判据若代入两个极值给出相同答案 ⇒ 该判据作废重写。**

### G0 尺子闸(修回审 B-2)

```
断言  a) 背靠背 clock() 差 > 0
      b) 1000/2000/4000 次 volatile 加法的周期比 ∈ (1.7,2.3) 与 (3.4,4.6)   ← v0.1 已有,保留
      c) ⭐ 新增:用 §1 的 CCLK 槽把量级判据收紧 —— 4000 次循环的实测周期数
         必须落在 [4000×1, 4000×20](= 1–20 cyc/iter)
怎么算 同 v0.1 的 C1/C2/C3,只把 C3 的 [2e3, 2e6] 换成上面的 [4e3, 8e4]
失败阻止 ⛔ **立即 return,不跑任何内核**(v0.1 是只打印一行字然后照跑 —— 那是输出不是检查)
        ⛔ 且 CSV **每一行**都带 `RULER=PASS|FAIL` 列(v0.1 的尺子判定与它作废的数据是分离的)
两极值  真该过:d[2]=24000(6 cyc/iter)⇒ 落区间 ⇒ **过**
        真该不过:clock() 返回毫秒 ⇒ d[2]=0 ⇒ 比值 0、量级 0 ⇒ **不过并中止**  ✓ 相反
        ⚠ 旧 C3 的 [2e3,2e6] 对应 0.5–500 cyc/iter ⇒ 对 2–10× 的偏差**无分辨力**,故收紧
```

### G1 载荷闸 ⭐(派单点名的那条:**先断言被测量真的动过**)

```
断言  a) 极值比:C(window=1024,biquads=12) / C(window=1,biquads=4) ≥ 100
         (真实负载比 = 1024×12 / 1×4 = 3072 ⇒ 若周期数只涨不到 100×,测的多半是调用开销)
      b) 边际线性:固定 biquads=8,对 window ∈ {1,8,32,64,256,512,1024} 做最小二乘
         C = a + b·window ⇒ 要求 **b > 0** 且 **R² ≥ 0.99**
      c) 第二轴:固定 window=64,对 biquads ∈ {4,6,8,10,12} 同样回归 ⇒ b' > 0 且 R² ≥ 0.99
怎么算 复用 v0.1 现成的 35 组 ParamList.dat(⛔ 不重新设计扫描表 —— 它本来就是对的)
      离线在宿主上拟合;⛔ 不在板上算(省事且不引入新的板上代码)
失败阻止 ⛔ 阻止「把每调用固定开销 a 当成每 biquad 边际成本 b 报出去」——
        而 v0.1 的报法(cycles/8)**正是把 a 摊进了 b**
两极值  真该过:a≈120, b≈2.5·8 ⇒ C(1024,12) ≈ 30000+, C(1,4)≈130 ⇒ 比 230 ≥100,R²≈1 ⇒ **过**
        真该不过:C 恒 ≈ 200(与 window 无关)⇒ 极值比 ≈1 < 100,b≈0 ⇒ **不过**  ✓ 相反
```

### G2 活性闸 + ⭐**阳性对照**(修回审 B-1,并给守卫本身一次证伪)

```
断言  a) 每个内核的 checksum **非零**
      b) 同一内核换参数后 checksum **至少取到 2 个不同值**
      c) ⭐ **阳性对照**:额外跑一行【故意把系数清零】的 T1a ⇒ 断言该行 checksum **== 0**
         且 a) 在该行**确实报 FAIL**
怎么算 a)b) 逐内核统计;c) 一次额外调用,tag = `POSCTRL_zeroed`
失败阻止 a)b) 阻止「代码被 DCE / 参数没真的传进去 / 数据是常量」这三类
        ⭐ c) 阻止的是**守卫自己变成装饰品**:若清零后 checksum 仍非零 ⇒ 说明 checksum
        根本没依赖被测数据 ⇒ **整个活性闸无效** ⇒ 中止
两极值  真该过:正常行 chk 取到多个非零值 ∧ 清零行 chk==0 且报 FAIL ⇒ **过**
        真该不过:清零行 chk 仍 ≠0 ⇒ 守卫不依赖被测物 ⇒ **不过并中止**  ✓ 相反
⚠ 而 v0.1 的现状:系数从未初始化 ⇒ **正常行与阳性对照行完全一样**(都是 0)
  ⇒ 该闸在 v0.1 上恒假,且无法与"被 DCE"区分 —— 这正是本闸要修的东西
```

### G3 内存臂闸(修回审 B-4;成本 ≈0,一次性关掉假绿分类 ②)

```
断言  运行时打印并断言两臂缓冲的地址落在**不同**物理区间:
        L1 臂 ∈ [0x00090000, 0x0039BFFF]      (LDF: mem_iv_code … mem_block3_bw)
        L2 臂 ∈ [0x20000000, 0x200FFFFF]      (LDF: mem_L2_bw / L2UC / L2BC)
      并打印 L2 臂落在 cached 段还是 uncached 段 ⇒ 回填 §1 的槽
怎么算 printf("%08X", (unsigned)&buf) —— 不需要任何 API
失败阻止 ⛔ 阻止「L1/L2 两臂其实是同一种内存」这个**两臂被构造成相同**的假绿
        ⚠ 这在 v0.1 上是**未关的真实风险**:那些 L2 数组是无初始化列表的静态数组,
          而 LDF 另有 `seg_l2_bsz_data`/`seg_l2_noinit_data` 两个分开的段名
两极值  真该过:L2 臂地址 0x20001234 ⇒ 在 L2 区间 ⇒ **过**
        真该不过:L2 臂地址 0x00245678(静默落回 L1)⇒ **不过,该臂对照作废**  ✓ 相反
```

### G4 计时纯净闸(修回审 B-5)

```
断言  为每个含"热循环"的内核加一条**对照臂**:循环体内**只做非被测工作**(T2 = 只 fill;
      T3 = 只 init),不调被测物 ⇒ 得 C_ctrl
      要求 C_ctrl / C_raw ≤ 0.25;并**同时报** C_raw 与 C_corrected = C_raw − C_ctrl
失败阻止 ⛔ 阻止「把 setup 成本算进内核成本」——T3 的数要去回填 20k cyc/槽 包络,
        污染会直接吃掉余量(方向:高估 ⇒ 会造出"装不下"的假象)
两极值  真该过:C_ctrl/C_raw = 0.08 ⇒ ≤0.25 ⇒ **过**,并报两个数
        真该不过:0.60 ⇒ **不过** ⇒ 须改测量结构(把 setup 移出计时区或换重置手法)  ✓ 相反
```

### G5 构建配置闸

```
断言  `NDEBUG` 已定义(Release)。⛔ Debug 下产出的数不得与任何锚点比较
失败阻止 阻止「拿关优化的数去对表」
两极值  真该过:Release ⇒ **过**;真该不过:Debug ⇒ **不过**(可跑,但全部行强制标 `BUILD=Debug`)  ✓
```

## §3 各内核的判据 + 两极值代入

### 3.1 T1a-float —— **改判为「尺子标定」**(保留,降级,重写判据)

```
定位变更:主口径点 ⇒ **用一个【已知答案】验证我们的测量方法**(LESSONS A-3)
被测量  b_fit = G1(b) 拟合出的**边际**成本,单位 cyc /(样本·biquad)
对照    EE-408 公布值 **2.5 cyc/biquad** [L2/厂家],⚠ 该值是**浮点**的 —— 而本内核也是浮点
        ⇒ ∴ 二者**同口径,可比**(这正是它还能留下来的唯一理由)
判据    **双侧**:0.5 ≤ b_fit / 2.5 ≤ 2.0
```
**两极值代入**:
```
真该过(厂家锚点在我方形态下成立):b_fit = 2.5 ⇒ 比值 1.00 ⇒ 落区间 ⇒ **过**
真该不过(不成立):b_fit = 42.6(= 8.51 cyc/MAC × 5 MAC/biquad)⇒ 比值 17.0 ⇒ **不过**  ✓ 相反
⭐ 第三次代入(另一侧,⛔ 不许省):b_fit = 0.5 ⇒ 比值 0.20 ⇒ **不过**
   ⇒ 为什么这一侧也必须能失败:我们跑的是 **ADI 自己的库函数、在 ADI 自己的条件下**
     ⇒ 「比厂家还好 4 倍」不是本事,是**测量出错**的信号(多半是计时没包住被测物)
   ⇒ 若写成单侧「b_fit ≤ 2.5 ⇒ 过」,尺子少数时它会静默通过 = 证据门槛随结论方向浮动
```
**⇒ 本内核 FAIL 时改什么**:⛔ 不改设计,改**我们对自己测量的信任** —— 尺子不准,其余内核的数全部存疑。

### 3.2 ⭐⭐ T1a-fx —— **新增,这才是"第一个定点锚点"**

```
被测物  **我方将要落地的那份定点 biquad**,⛔ 不调 ADI 库:
        · 结构 = **DF2T**(与 `nhs.py` 文件头写死的结构一致;DF1 与 DF2T 在此不等价)
        · 系数 Q2.30、累加 64/80 bit、带误差反馈(架构侧 IF 数制条款)
        · 8 级 × 64 样本为主口径点,**扫描表复用 v0.1 的 35 组**(与 3.1 逐格可比)
输出    b_fit_fx(cyc /(样本·biquad))+ 截距 a + R² + 95% 区间
```
**⛔ 而本内核【没有达标判据】—— 它只有有效性判据。这一条要专门说明:**
```
派单要求把「厂家锚点成立 / 不成立」两个值代进来。⇒ 我照做了一次,结果是这条判据【不能用】:
  假设判据 =「b_fit_fx ≤ 厂家锚点 2.5 ⇒ 过」
    代入 2.5 ⇒ 过 ｜ 代入 42.6 ⇒ 不过    —— 表面上两次答案相反 ✓
  ⛔ **而它判的不是它声称判的那件事**:厂家锚点是**浮点**通路的值(DEC-0023 已判定),
     定点通路过不过与"厂家浮点锚点成不成立"**无关**
  ⇒ ∴ 这是「能双向失败、却测错了对象」= 假绿分类 ⑤ 的镜像 ⇒ **判据作废**
⇒ ⭐ 正确形态:**取锚点的内核不该有达标判据**。给它编一个,不是恒真就是恒假。
   它的判据是【有效性】:G0–G5 全过 ⇒ 该值可用;任一不过 ⇒ 该值作废。
   而"这个值够不够好"是**下游决策**,归 adaptive-dsp/架构侧,不是本测量的通过条件。
```
**⇒ 本内核跑出什么数会改设计**(= 下游决策规则,⛔ 不是本内核的判据):
```
b_fit_fx 折成 cyc/MAC ≳ **7.4** ⇒ AFC 旁链越 20k cyc/槽 包络 ⇒ 触发降档旋钮(候选峰 16→8)
   [L3/由算法侧已声明的两点(2.0⇒5–6k / 8.51⇒21–25k)线性内插,⛔ 未经算法侧确认]
```

### 3.3 T1b / T2 / T3

```
共同    ⭐ 一律先跑 G1 载荷闸的同构版本(**这三个在 v0.1 里连载荷轴都没有,只有 1–2 个点**):
        T1b:probe 长度 ∈ {64, 256, 1024, 4096} 四点回归
        T2 :N ∈ {256, 512, 1024, 2048} 四点 —— 断言 C 随 **N·log₂N** 线性(不是随 N)
        T3 :轨数 NT ∈ {4, 8, 16, 32} 四点回归
判据    有效性判据(G0–G5 + 上面的回归),⛔ 无达标判据(同 3.2 的理由)
两极值  真该过:T2 的 C 对 N·log₂N 回归 R² = 0.999,b>0 ⇒ **过**
        真该不过:C 对 N·log₂N 无关(R²≈0)⇒ **不过** —— 那说明测的不是 FFT 本身  ✓ 相反
⭐ T2 的那条特别值得写死:**断言 C ∝ N·log₂N 而不是 ∝ N**
   ⇒ 若它其实 ∝ N,说明蝶形循环没按级数跑(例如 log2n 传错)——
     而**只测两个点(v0.1 的 1024/2048)时,∝N 与 ∝N·log₂N 几乎分不开**(比 2.0 vs 2.2)
   ⇒ 这是"工作点落在无差别区"的教科书形态,四点才拆得开
```

## §5 执行顺序(工具链到位后)

```
0. 填 §1 的板级参数槽                                    ⛔ 空槽不跑
1. G0 尺子闸 ⇒ 不过则**中止**
2. G2 阳性对照(清零系数行)⇒ 守卫若不响则**中止**
3. G3 地址回读 ⇒ 落错区间的臂**当场作废**(其余臂继续)
4. ⭐ **先跑 T1b / T2 / T3**(它们本来就是定点/标量,是现成可用的第一个定点锚点来源)
5. 再跑 T1a-fx(须先写,v0.1 里不存在)
6. 最后跑 T1a-float(尺子标定;它现在是**验证方法**,不是产出锚点)
7. mem_sizeof 差异表
⇒ 4 排在 5/6 之前,是因为**它们不依赖任何新代码,且已经能回答"我们有没有定点数"**
```
