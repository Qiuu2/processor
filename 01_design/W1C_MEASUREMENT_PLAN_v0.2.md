### G1 载荷闸 ⭐(派单点名的那条:**先断言被测量真的动过**)

```

```

### 3.1 T1a-float —— **改判为「尺子标定」**(保留,降级,重写判据)

```
定位变更:主口径点 ⇒ **用一个【已知答案】验证我们的测量方法**(LESSONS A-3)
被测量  b_fit = G1(b) 拟合出的**边际**成本,单位 cyc /(样本·biquad)
对照    EE-408 公布值 **2.5 cyc/biquad** [L2/厂家],⚠ 该值是**浮点**的 —— 而本内核也是浮点
        ⇒ ∴ 二者**同口径,可比**(这正是它还能留下来的唯一理由)
判据    **双侧**:0.5 ≤ b_fit / 2.5 ≤ 2.0
```
**两极值代入**:
```
真该过(厂家锚点在我方形态下成立):b_fit = 2.5 ⇒ 比值 1.00 ⇒ 落区间 ⇒ **过**
真该不过(不成立):b_fit = 42.6(= 8.51 cyc/MAC × 5 MAC/biquad)⇒ 比值 17.0 ⇒ **不过**  ✓ 相反

   ⇒ 为什么这一侧也必须能失败:我们跑的是 **ADI 自己的库函数、在 ADI 自己的条件下**
     ⇒ 「比厂家还好 4 倍」不是本事,是**测量出错**的信号(多半是计时没包住被测物)
   ⇒ 若写成单侧「b_fit ≤ 2.5 ⇒ 过」,尺子少数时它会静默通过 = 证据门槛随结论方向浮动
```
**⇒ 本内核 FAIL 时改什么**:⛔ 不改设计,改**我们对自己测量的信任** —— 尺子不准,其余内核的数全部存疑。

### 5b.1 P1 · 解析下界(ISA 层)—— 单侧硬闸,零成本

```
定点 DF2T biquad,每 biquad·每样本的必需算术 = **5 乘 + 4 加**
   (y = b0·x + s1 ; s1 = b1·x − a1·y + s2 ; s2 = b2·x − a2·y)
SHARC+ 核心 = **2 个 MAC 单元**(CLAUDE.md §0 架构必读,源自 DEC-0014 / SHARC+ Core Programming
   Reference,件在 knowledge_base/adsp21569/bsp/sw_reference/)
⇒ 理论下界 = 5 MAC / 2 MAC-per-cycle = **2.5 cyc/biquad**(⛔ 不含 load/store、循环、饱和/移位)
判据  实测 b_fit_fx **< 2.5 cyc/biquad ⇒ 测量错**(代码没真跑 / 计时没包住 / 被优化掉)
```
**⚠⚠ 而这里有一个必须当场拆掉的同名陷阱(否则又是一次"同名不同物"):**
```
我算出的下界 = **2.5**,EE-408 公布的浮点实测 = **2.5** —— **数值相同,而【不是同一个量】**
  我的 2.5   = 定点 DF2T 的**理论下界**(由 MAC 数 ÷ MAC 单元数 算出)[L3/解析]
  ADI 的 2.5 = 浮点 biquad 的**实测吞吐**                              [L2/厂家]
⇒ 二者数值相同这件事本身有信息量:说明 **ADI 的浮点实现已经跑到了理论下界**(完美双发射)
⇒ ⛔ 而**不得**据此说"定点也该是 2.5":定点多出饱和/移位/舍入指令,实际只会更高
⇒ ⭐ 报告里这两个 2.5 **必须分行写、分别挂 L 标**,⛔ 不得出现在同一个句子里当作一个数
```

### 5b.2 P2 · 反汇编清点 —— 与 `clock()` **完全独立**的第二条路(铁律七 双轨)

```
做法  CCES 出内循环的汇编列表 ⇒ 数指令条数 × 迭代次数 ⇒ cycles_predicted
性质  静态清点**不含停顿**(访存等待/cache miss/流水线)⇒ 它是**下界**,不是等值
判据  measured ≥ predicted            ⇒ 正常(差值 = 停顿,本身是有用的数)
      measured **<** predicted        ⇒ ⛔ **测量错**(计时没包住 / 循环被展开合并 / 代码被删)
      measured / predicted **> 3×**   ⇒ ⚠ 停顿主导 ⇒ 该数不能代表算术成本,须查内存放置
⇒ 这一条**不依赖计时器**,因此它能抓到 `clock()` 本身的错 —— P1/P3 抓不到的那一类
```

**⇒ 这把问题从"判据对不对"变成了"仪器有没有分辨力" —— 而那是可以直接测的。**

```
决策相关的档距(取最小的那个):
  包络越线点 ≈ ~~**7.4**~~ → **5.24** cyc/MAC  [L3/内插,⛔ 未经算法侧确认]  ｜  同族板测 **8.51** cyc/MAC [L1/ITC]
  ⇒ 最小需分辨的档距 = 8.51 − ~~7.4 = 1.11~~ → **5.24 = 3.27 cyc/MAC**

  (= 档距的一半;⛔ 半宽大于半档距 ⇒ 两档区间重叠 ⇒ 分不开)
```
