§1  EXP-7  把系数界从【经验扫描界】换成【解析界】
--------------------------------------------------------------------------------
缘起  : 架构侧意见(经 lead 转)——`11.2148` 是经验扫描界,**其完备性依赖我扫了哪些量程**;
        若 PRD §二.4「频率/Q/增益独立可调」的实际量程比我扫的宽,界就变了。
        ⇒ 要求换成由 PRD 参数量程直接推出的解析界。**该意见成立,本轮执行。**

推导(RBJ Audio EQ Cookbook 归一化式,A = 10^(G/40),α = sin ω₀/(2Q) ≥ 0,c = cos ω₀ ∈ [−1,1]):

  ① 峰型 PEQ:令 β = α/A ≥ 0,则
       b0/a0 = (1+βA²)/(1+β)      ∈ [min(1,A²), max(1,A²)]      ⇒ |b0| ≤ max(1, A²)
       b2/a0 = (1−βA²)/(1+β)                                     ⇒ |b2| ≤ max(1, A²)
       b1/a0 = −2c/(1+β)                                         ⇒ |b1| ≤ 2
     ⇒ **max|b| ≤ max(2, A²)**   —— **与 Q、与频率无关**

  ② 架式(高架/低架):a0 = (A+1) ∓ (A−1)c + 2√A·α
       |b1|/a0 = 2A|(A−1) ± (A+1)c| / a0,在 c = ±1(⇒ α = 0)取到
                 分子 4A²、分母 2 ⇒ **|b1| ≤ 2A²**
       |b0|,|b2| ≤ A²(同处取到)
     ⇒ **max|b| ≤ 2A²**   —— **与 S、与频率无关**

  ③ HPF / LPF(Butterworth / LR):b = [(1±c)/2, ±(1±c), (1±c)/2]/(1+α)
       |b1| = (1±c)/(1+α) ≤ 2/(1+α) ≤ 2 ⇒ **max|b| ≤ 2** —— **与 Q、与频率无关**

  ④ a 系数:稳定三角 |a1| < 1+a2 < 2、|a2| < 1(构造上不可超越,任务一已立)

  ⇒ **全族解析界  max|b| ≤ 2 · 10^(G_max/20)**(G_max = PEQ/架式的最大 |增益|,dB;G_max ≥ 0 时)
  ⇒ **它只依赖 G_max 一个量,不依赖 Q 量程、S 量程、频率量程。**
  ⇒ Q4.27(|c| < 16)的**解析硬包络**:2·10^(G/20) < 16 ⇒ **G_max < 20·log₁₀8 = 18.0618 dB**

预期  : ①对 G_max = 15 dB,解析界 = 2·10^0.75 = **11.2468**;
          r3 的数值扫描最大值 **11.2148 ≤ 11.2468** ⇒ 扫描不越界;
        ②界要**紧**(否则无用):架式扫描最大值 / 解析界 ≥ **0.99**;
        ③在 G ∈ {6, 12, 15, 18} 上逐一复核 ①②;
        ④解析硬包络 18.0618 dB **略严于** r3 的扫描包络 18.089 dB(扫描取不到 c=±1 与 α=0)。
证伪条件: **任一数值扫描值 > 解析界** ⇒ 推导有错,§1 整段作废,退回经验界并说明;
          或 ②的比值 < 0.90 ⇒ 界太松,不足以替代扫描,须重推。

§2  EXP-8  延迟逐项表(我这一侧)+ ⚠ 一条给架构侧配平表的更正
--------------------------------------------------------------------------------
背景  : lead 已把三条线的延迟并起来看,得 ≈27 ms vs 预算 12 ms(超 2.3×),
        并路由架构侧出【组合可行性表】。我这一侧要交的是**逐项 + 可否降**。

⚠ **但我必须先注册一条对那个加法的更正**:
  **群延迟是频率的函数。把各项的【最大值】相加,是把发生在【不同频率】上的峰硬凑到一起
  ⇒ 系统性高估。** 正确的量是「**各项群延迟曲线逐频相加后的最大值**」。
  ⇒ 本组同时报两个数,并显式标注它们是**两个不同的量**(LESSONS B-3:先核量的类别)。

被测量:
  (a) 我这一侧每个模块的**最大群延迟**(20 Hz–20 kHz)及其发生频率;
  (b) 同一配置下,**逐频相加**后的合计曲线的最大值,及其发生频率;
  (c) 每项的**可降档位**与省下的 ms。
预期  : **(a) 的和 > (b)**(严格大于),差值 ≥ 1 ms —— 即"各自最大值相加"确实高估。
证伪条件: (a) 的和 − (b) < 0.1 ms ⇒ 各峰其实落在同一频率附近,那条更正**不成立**,
          须撤回并告知 lead 按简单相加处理。
分辨力  : 解析/确定性计算,无随机项;两轨(逐节 group_delay 求和 vs 相位差分)已在 EXP-4 立。
