§0  本预注册之前已经发生的事(诚实分段,防「事后限定」误读)
--------------------------------------------------------------------------------
探索阶段(scratchpad,非归档)已跑过 A–E 五组,用于**形成设计论证**,不作验收证据。
其中**两件必须原样记下来,因为它们改变了我要注册的东西**:

[X-1] 探索 B 首版用 `scipy.signal.group_delay` 作用在**卷积后的 9 阶多项式**上,
      给出「LR8 高通 fc=120Hz 群延迟 18.59 ms @ **1426.8 Hz**」——
      **对一个 120 Hz 高通,1.4 kHz 处不可能有 18 ms 群延迟**(D6-ab:先问这个数意味着什么)。
      工具同时报了 "denominator is extremely small" 警告。
      ⇒ 判为**数值失效**,不是物理。改为「逐节群延迟求和」(级联可加)并加第二轨(相位差分)。
      ⇒ 本轮 EXP-4 因此**强制两轨**。

[X-2] 探索 E 我的假设是「分频在 PEQ 之前更省链内余量」。
      **实测:两种顺序的链内峰值增益完全相同(12.95 dB vs 12.95 dB,差 0.00 dB)⇒ 假设被证伪。**
      事后看原因清楚:我量的是「max over 频率的 |H_partial|」,这是**宽带最坏频点**测度,
      而两种顺序的**最后一个节点就是输出**,输出相同 ⇒ 最大值必然相同。
      ⇒ **⚠ 我不在此处补写「其实我想说的是窄带」然后宣布论证成立。**
      ⇒ 合规动作:在 EXP-1 里**重新注册一个不同的被测量**(窄带激励下的逐节电平),
        并**预先写死**:若它也测不出差异,则「分频在前更安全」这条论证**整条删除**,
        D4 的顺序改用别的理由或改为「二者等价,按界面语义选」。

§1  EXP-1  D4 顺序:PEQ 在分频【前】 vs 【后】(重新注册被测量)
--------------------------------------------------------------------------------
背景  : 二者均为 LTI ⇒ 总传函严格相等(探索实测差 2.8e−14 dB)⇒ 顺序**不能**用传函来选。
被测量: **窄带激励下的逐节峰值电平**。激励 = 单频正弦 @ 40 Hz,幅度 = 标称 −20 dBFS;
        配置 = PEQ 在 40 Hz 提升 +12 dB;分频 = LR4 高通 fc = 120 Hz(⇒ 40 Hz 在阻带)。
        报「每个 biquad 节输出的稳态峰值(dBFS)」两条曲线。
混淆面: 若激励频率落在分频器通带内,两种顺序**本来就该相同** ⇒ 该测量只在阻带内有分辨力。
        ⇒ 故同时报一个**通带内**的对照点(1 kHz),预期两者相同。

预期  : ①阻带激励(40 Hz):PEQ 在前的**最大节点电平 ≥ −8 dBFS**(= −20+12);
          分频在前的最大节点电平 ≤ **−20 dBFS**(分频先衰减,PEQ 提升作用在已衰减信号上)
          ⇒ **两者差 ≥ 10 dB**。
        ②通带对照(1 kHz):两者最大节点电平之差 ≤ 0.1 dB。
证伪条件: **①的差 < 3 dB** ⇒ 「分频在前更省链内余量」不成立
          ⇒ **整条论证删除**,D4 顺序改用其它理由,并在设计文档里写明这条被删过。
分辨力  : 本测量为解析计算(非蒙特卡洛),分辨力 = 双精度舍入 ≈ 1e−12 dB ⇒ 3 dB 判据远在其上。

--------------------------------------------------------------------------------
§2  EXP-2  D3 顺序:HPF 在动态处理【之前】的理由
--------------------------------------------------------------------------------
背景  : 工程惯例说「low-cut 要在门/压限之前,否则隆隆声驱动侧链」。**惯例不是证据。**
被测量: 侧链电平检测器(RMS,时间常数按参数表)的输出,在两种链序下的差;
        以及噪声门在同一素材上的**开合次数**。
素材  : 合成 = 语音级突发(1 kHz 猝发串,−30 dBFS,占空比 20%)+ 隆隆声(45 Hz 正弦,−20 dBFS)。
        HPF = 二阶 Butterworth,fc = 80 Hz。
预期  : ①HPF 在前 ⇒ 侧链检测器在「静默段」的读数比 HPF 在后**低 ≥ 15 dB**;
        ②HPF 在后 ⇒ 门被隆隆声顶开(静默段门增益 > −6 dB),HPF 在前 ⇒ 门正常关闭(≤ −20 dB)。
证伪条件: ①的差 < 6 dB **或** ②两种链序下门的开合行为无可判差异
          ⇒ 「HPF 必须在动态之前」不成立,该理由删除或换。
分辨力  : 同上,解析/确定性仿真,无随机项 ⇒ 分辨力远小于判据。

--------------------------------------------------------------------------------
§3  EXP-3  D-4 级联:LR 分频器(⭐ lead 点名的那条)
--------------------------------------------------------------------------------
被测量: LR2/LR4/LR8 的 LP+HP 求和在 20 Hz–20 kHz 内偏离 0 dB 的最大值,
        分**同相**与**反相**两种;并报每支的 **DC 增益**与 **Nyquist 增益**;
        系数按 Q4.27 量化(用 chdsp 约定)与理想双精度**各跑一遍**。
预期  : ①LR2 与 LR6 需**反相**求和才平坦;LR4 与 LR8 需**同相**(阶数 mod 4:2 ⇒ 反相,0 ⇒ 同相);
        ②正确极性下,理想系数的求和偏离 ≤ 1e−6 dB;
        ③Q4.27 量化后求和偏离 ≤ 0.01 dB(远小于 PRD 的 ±0.3 dB);
        ④高通支的 DC 增益 ≤ −180 dB(用结构约束量化);低通支的 Nyquist 增益 ≤ −180 dB。
证伪条件: ③ > 0.05 dB,或 ④ > −120 dB ⇒ Q4.27 对分频级联不足,须加宽系数格式。
⚠ 假绿  : 本组必须附**坏版本**——把极性规则写反(LR4 用反相)⇒ 求和必须出现深谷;
          若坏版本仍平坦 ⇒ 本检查不依赖被测物,作废。

--------------------------------------------------------------------------------
§4  EXP-4  群延迟与延迟预算(⚠ 强制两轨,因 X-1)
--------------------------------------------------------------------------------
被测量: ①LR2/4/8 高通在各 fc 下的 20 Hz–20 kHz 内**最大群延迟**(样本与 ms);
        ②线性相位 FIR 的抽头 → 群延迟 → 对 12 ms 预算的占用(三联数);
        ③全链延迟预算表(ADC + 块 I/O + IIR + FIR + DAC)。
两轨  : 轨A = 逐节 `group_delay` 求和(级联可加);轨B = 整体相位 unwrap 后差分。
预期  : 两轨最大差 ≤ 0.05 样本;峰值位置落在 fc 附近(**不得出现在远离 fc 的频率**)。
证伪条件: 两轨差 > 0.5 样本,或峰值位置离 fc 超过 3 倍频程
          ⇒ 数值仍不可信,结论不得报出(X-1 的复发)。
锚点  : ADC 群延迟 **22.9844/fS**、DAC 传播延迟 **25/fS** [L2/厂家 datasheet],
        48 kHz 下合计 47.9844 样本 = **0.99968 ms**。

§5  EXP-5  D3/D4 全链量化噪声底(D-4:不许只验单级)
--------------------------------------------------------------------------------
被测量: 按 D34 定点约定(Q4.27 + DF1 + 二阶 EF)统计各链的量化器个数,
        给出 −173.35 + 10·log₁₀(N) 的链级噪声底,并与 PRD >106 dB 对表。
预期  : D3 与 D4 单链均 ≤ −160 dBFS,合计 ≤ −158 dBFS。
证伪条件: 任一链 > −140 dBFS ⇒ 与任务一的单节实测不自洽,须回查。
⚠ 本组依赖任务一的 [L2/宿主实测] 单节值 −173.35 dBFS,**其本身尚未过门**
  ⇒ 本组结论继承同一门禁状态,⛔ 不得独立引用。
