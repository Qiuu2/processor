### 1.2 各判据公式

输入=合同供给(架构侧,IF-v1.0 C4):幅度谱 `M[j]` float[512](B3 运行点:N=1024@16kHz,Hann,15.625Hz 网格,**每通道每 16ms 更新**;B2 备选运行点经 `AFC.det.cfg` 适配,**判据代码不得硬编码 bin 宽**——合同原文条款)、看门狗谱(§3.6)、候选峰列表 ≤16/通道 {Quinn 内插 f, P_peak, 全带均值, 邻域均值, 上次配对 id}。判据组合与阈值逻辑=本文自研层。Quinn 式与 PX4 `GyroFFT.cpp EstimatePeakFrequencyBin` 同构,浮点重写已双验(CHECK B@B3:|f_err| 中值 1.4-1.6Hz、p95 2.8Hz,SNR 30/10dB [L2/桌面数值]);合同精度语义(IF-v1.0 C7)= **p95|Δf| ≤ BW/4**,CHECK B 为其可实现性旁证(⚠ 余量仅 25%,且纯音+白噪是最友好条件——V-3 正式标定须用劣化素材:AM 展宽+有色干扰,critic INFO③ 已入 §7.3 标定清单),正式标定归架构侧 L2(V-3)。

**PAPR**(PX4 :514 同构式,直接取用):
```
PAPR(k) = 10*log10( (Nbins-1) * M[k] / (Σ_j M[j] - M[k]) )   [dB]
```
其中 Nbins=N/2,Σ 在检测频带内取(合同供给的"全带均值"即此式分母的等价原料)。候选门:`PAPR ≥ T_papr`,初值 **T_papr = 15dB [L4/待标定]**(PX4 MIN_SNR=1dB 为陀螺域值,不可用;音频域按"语音共振峰帧也可达 10dB+"的保守起点设 15,待 ROC 标定)。

**PNPR**:
```
邻域定义(Hz 表述,与运行点解耦——判据定义不依赖 bin 宽):
  U(f) = [f-K_hz .. f-E_hz] ∪ [f+E_hz .. f+K_hz]
  E_hz = 3*Δf_bin(排除主瓣:Hann 主瓣 4 bin 宽,与 N 无关;Δf_bin 由 AFC.det.cfg 取)
  K_hz = max(187Hz, f*(2^(1/3)-1))(+1/3 oct 上边界;低频 ±1/3 oct 窄于主瓣 → 固定 Hz 下限)
PNPR(f) = 20*log10( M(f) / mean(M[U(f)]) )   [dB]
```
- B3 换算参考:E=±3bin=±46.9Hz,K 下限 187Hz=12bin(仅为阅读便利,实现按 Hz 式)。
- **接口状态**:合同供给的"邻域均值"按本 Hz 语义在旁链侧实现(architect 2026-07-31 已确认采纳,含"改用 Hz 表述"的修正建议——正是判据与运行点解耦原则,与 IMSD 的 dB/s 定义同理)。
- 门:`PNPR ≥ T_pnpr`,初值 **T_pnpr = 8dB [L4/待标定]**(zapline-plus 论文 +4dB 为 EEG 尺度 [L4/D0c §1.7];音频动态范围大,取 2 倍起点,待标定)。

**PTPR 双阈值**(语义对齐竞品 [L4/竞品手册 §2.3]):
```
level(k) = 20*log10(M[k]) + cal_offset   [dBFS,校准到通道满幅]
反馈阈值 T_low:level < T_low → 绝对不判啸叫(防柔和乐段/低电平嗡声误触发)
恐慌阈值 T_panic:level ≥ T_panic 且 PAPR≥T_papr → 立即判定(§3.4),0=关闭
```
初值:T_low = -45dBFS,T_panic = -6dBFS **[L4/待标定]**(QSC Feedback Threshold 量程 -70~-20dB [L4/QSC 手册] 作 T_low 的可调范围参考;竞品恐慌阈值语义:高于此"绝对是反馈")。
**⚠ T_panic 有效性前提(critic B-F1,v1.1 补)**:"冲顶啸叫必触 PANIC"仅在**增益结构担保**下成立——被下游压缩/限幅钉住的环路,其在检测 tap 参考点的平台电平必须 ≥ T_panic + 裕度,否则 PANIC 恒不触发(v1.0 无任何文档担保此前提,即 B-F1 三路脱靶的一环)。该担保属架构侧:链序约束(COMP/限幅不得在检测 tap 前,architect 拟 C-7)+ T_panic 默认值与通道限幅器阈值的参数字典联动校验;**落点条款号待 IF-v1.1 / W1-A 修订(在议,§8.1-C9),落盘前本前提记为未担保开洞**,连锁后果见 §3.2 可达性表 case (b)。

**IPMP(跟踪门)**:帧间关联由合同供给的"上次配对 id"承载(架构侧按最近频率配对,PX4 :525 的 0.25bin 豁免同构);本层在其上维持(T_hop=每通道更新周期,IF-v1.0 C1;B3 下 16ms):
```
连续性:进入"跟踪态"须 命中 ≥3/4 hop(B3:48-64ms)
中值:首挂用 3 点中值(与跟踪门同步,B3:≈48ms),后续补满 7 点持续精修(受重调迟滞限制)
老化:6 hop 未命中 → 删轨(B3:≈96ms,PX4 100ms 老化的直接映射 [L3])
重调迟滞:|Δf| > max(0.25*Δf_bin, 0.01*f) 才发 retune(≥IF-v1.0 C6 下限 max(0.5Hz, 0.25bin);
          B3:0.25bin=3.9Hz)
```

**PHPR(反向否决)**:见 §3.2。
**IMSD(分类主判据)**:见 §2。

### 1.3 组合规则:分级流水线,非"几中几"投票

```
G0 门(全过才进):检测频带 [F_det_lo, F_det_hi] ∧ level≥T_low ∧ 通道未 bypass
候选:PAPR≥T_papr ∧ PNPR≥T_pnpr             → 进入/维持跟踪(IPMP 配对)
跟踪:≥3/4 hop 命中 → TRACKED;6 hop(B3:≈96ms)失踪 → 删
分类(TRACKED 上,三路任一命中 → HOWL,详见 §3):
  PANIC 路:level≥T_panic                       (最快,1 hop;前提担保 §1.2/§3.3)
  GROWTH 路:(IMSD 命中 ∨ 等效命中(§3.2 臂2))∧ 非谐波族(PHPR 否决,削波豁免 §3.2)
  PERSIST 路:长时持续 ∧ 高 PAPR ∧ 非谐波族(同受 §3.2 豁免)  (慢,秒级,兜稳态啸叫)
```
**不做扁平"几中几"的理由**:六判据信息维度不同(电平/形状/时间),扁平投票会让三个"形状类"判据(PAPR/PNPR/PHPR)在一帧内互相凑票,把持续元音投成啸叫;分级流水线强制"先是窄带峰、再是持续峰、最后才谈是不是啸叫",每级淘汰各自的假阳性(设计论证 [L3])。检测频带初值 `F_det_lo=120Hz`(可调 30-500Hz,对齐 dbx 检测 HPF [L4/dbx AFS2])、`F_det_hi=8kHz`(主旁链 Nyquist 上限);**8-20kHz 由合同看门狗谱补盲,仅粗判(§3.6)**。

## 2. ★ IMSD 判据自研(帧间幅度斜率)

D0c §1.8 已确认全域无同构实现:振动/工频域的目标全是稳态窄带,从不需要区分"正在长起来的啸叫"与"稳态存在的合法窄带信号"。这是本设计的核心自研件。

### 2.1 物理机理:为什么斜率是啸叫的"身份证"

闭环电声系统在频点 f 处环路增益 G(f)(含相位对齐)超过 1 时,幅度每经一次环路乘 |G|:
```
a(t) = a0 * |G|^(t/τ)  →  L(t)[dB] = L0 + β*t,  β = 20*log10|G| / τ   [dB/s]
```
τ=环路延迟(声程+处理链)。**即:啸叫在 dB 域随时间线性增长,斜率恒定**——这是环路物理决定的签名,人声/乐音没有义务遵守它。
桌面自验(CHECK C,结论域按 B-m5 限定):闭环差分方程仿真(脉冲种子,g=1.05/τ=10ms 与 g=1.02/τ=25ms),用本设计旁链参数(1024 Hann/hop 256)提取 STFT 峰值轨迹,LS 拟合斜率与解析值 20log10(g)/τ 偏差 **0.0% / 0.1%**——证明**轨迹提取管线对指数增长无斜率偏置**(IMSD 的测量链可信);dB 域线性模型本身属反馈物理常识 [L3],不赖此"证明" [L2/桌面数值,`selfcheck_W1B` CHECK C]。**结论限定(critic B-m5)**:CHECK C 的被测物是理想线性差分环路,它只证明"本设计的 STFT 轨迹提取管线能无偏还原 dB 域线性增长",**不证明真实房间的啸叫必呈该形态**——RT60 混响尾、多路径梳状、环内非线性都会给真实斜率叠加噪声与弯折,IMSD 对真实啸叫的判别力由 ROC 素材(§7.3)另证。

量级(会议室,[L3/手算]):τ ≈ 5-50ms(声程 3-30ms + 处理 ~2ms + 换能),超额增益 0.5-3dB/圈 → β ≈ 10-600 dB/s → 每 hop(T_hop=16ms@B3,IF-v1.0 C1)**0.16-9.6 dB**。快端由 PANIC 路兜——**仅限输入侧钉住(ADC 满幅)场景有担保(IF-v1.1 C10-2);输出侧限幅器钉住时 tap 电平无下界担保,PANIC 降为机会快路径,覆盖转由 pinned-howl 路径承接(§3.2 E_pin/§3.5-#11,B-F1 修法)**;慢端(<β_min)由 PERSIST 路兜(终将饱和为稳态高峰);IMSD 主攻中段——**在啸叫可闻爆发前抓住它**。

### 2.2 数学定义

对跟踪峰 k,维护其 **PAPR 轨迹** P_k[n](dB,n=hop 序号,T_hop=IF-v1.0 C1 每通道更新周期,B3=16ms)长度 W 的环形历史。**用 PAPR(相对量)而非绝对幅度**——这是抗误判设计的核心(§2.4 ①)。

```
窗内 LS 线性拟合:P_k[n-W+1..n] ≈ b_k*x + c_k
  b_k  = 斜率 [dB/hop]
  s_k  = 拟合残差 RMS [dB]           (线性度)
  ΔP_k = P_k[n] - P_k[n-W+1] [dB]    (总升幅)

IMSD 命中 ⟺ 轨迹当前为 TRACKED ∧ hist_n ≥ W_used
            (轨迹历史自诞生起累积、含 TRACKED 前的 hop——窗填充与跟踪门并行计数,
             非串行相加;起算点=轨迹诞生(首个候选命中 hop)。B-m4 同参口径,已发
             architect 对表,W1-A 反应时间行须同此参数化)
          ∧ β_min ≤ b_k ≤ β_max
          ∧ s_k ≤ s_max
          ∧ ΔP_k ≥ ΔP_min
双窗:W_long=8(B3:128ms,主判);W_short=4(B3:64ms,快判,仅当 b_k ≥ β_fast)
```

**初值(阈值以 dB/s 定义、按 T_hop 换算,与运行点解耦——B3/B2 切换只改换算列;全部 [L4/待标定],标定方法见 §7.3)**:
| 参数 | 初值(dB/s) | @B3(16ms)换算 | 论证 |
|---|---|---|---|
| β_min | 60 dB/s | 0.96 dB/hop | τ=10ms 时对应超额增益仅 0.6dB/圈 [L3];再低的边际啸叫交 PERSIST 路,压误触发。70dB/s 附近为设计灵敏度下缘(CHECK D 慢啸例对 β_min/ΔP_min 均边际通过,如实记录) |

### 2.3 窗长选择论证(B3 口径;含 B2 对比的如实记录)

- **反应时间(B-m4:与 W1-A §6 同参——起算点=啸叫起振,含分析窗填充,串行保守合成,两文档互引)**:T_react ≈ 窗填充 64ms + 判据持续(W_short 4 hop=64ms / W_long 8 hop=128ms)+ 执行器挂入斜坡 ~50ms → **快路 ≈0.18s、主路 ≈0.24s [L3/手算,保守口径]**,对 Sabine"典型 0.4s"[L4/对标不承诺] 余量 1.7-2.2×。**如实对比**(同一保守口径重算):42.7ms 槽率下为 128ms 填充+171/341ms+50ms ≈ 0.35-0.52s——B3 使反应余量真实改善约 2 倍,这正是架构侧采 B3 的理由(IMSD 吃时间密度);改善为算术推导,闭环验证归 V-4。
- **判别力(代价,如实记录)**:窗须长于语音的准平稳段。音节率 4-8Hz → 周期 125-250ms;W_long=8×16ms=**128ms 只覆盖音节弧前段**(起音+平台),不如 B2 的 341ms 全弧覆盖——**B3 以拒收余量换反应速度**。缓解:s_max 对起音+平台形态仍有效(CHECK D 元音例 s=4.45dB 被拒);PHPR/预设收紧承担更多人声防线。**B3 vs B2 的检出延迟/误检率真实权衡由 V-10 ROC 定案(合同 §1.2 裁决,共任务)**,两侧论证均为 [L3],不预判胜者。
- 大房间预设 W_long=10(B3:160ms;RT60 长,混响尾拖慢表观增长,见 §6)。

### 2.4 抗误判设计(四条,全部自研)

1. **相对量抵共模**:P_k 用 PAPR(峰对谱均值)而非绝对电平 → 推子/AGC/整体渐强(crescendo)是共模,斜率≈0(CHECK D:crescendo 例 b=0.14dB/hop 被拒)。⚠ 出生先验"共模抵消只抵消共模":**独奏乐器单线渐强不是共模**——由 PHPR 否决与预设收紧兜(§3.2/§6),残余风险如实列入 §3.5。
2. **线性度门 s_max**:语音有韵律/颤抖(jitter/shimmer),幅度轨迹粗糙;环路增长平滑。CHECK D 中元音例(起音+平台游走,128ms 窗形态)b=+1.77dB/hop 落入增长区间但 s=4.45dB 被线性度拒 [L2/构造轨迹自洽,非检出率结论]。**"s_max 是 128ms 窗下人声防线的承重件"这一承重声明本身定级 [L3/设计推断]**(critic B-m5:证据仅为单条构造轨迹旁证,真实语音的 s 分布未测,承重与否由 ROC 定,§2.3 代价条)。
3. **跟踪连续性前置**:斜率只在 TRACKED(已连续 ≥3/4 hop 的窄带峰)上计算;缺帧即中止,防瞬态(掌声/敲击)的谱溅射伪装成"增长"。
4. **饱和啸叫不漏(v1.1 按 critic B-F1 改写——原文即被坐实的无担保"另一路兜住"声明)**:已冲顶/被限幅器压住的啸叫斜率≈0,IMSD 不命中,须由 PANIC/PERSIST 兜——但 v1.0 的两条兜底路在该场景各有未担保前提:PANIC 要 tap 电平 ≥T_panic(增益结构担保缺失,§1.2)、PERSIST 会被削波谐波触发的 PHPR 否决且旧豁免恒 False(§3.2)。v1.1 闭环:PERSIST 经 §3.2 三臂豁免恢复可达;PANIC 前提待架构侧担保落盘;**残余开洞按 §3.2 可达性表 case (b) 如实列示,不再声称无条件全覆盖**。

### 3.3 三路分类的分工(§1.3 的展开)

- **PANIC 路**(1 hop,B3:≤16ms 判定延迟):level≥T_panic ∧ 窄带门(PAPR≥T_papr)的峰,不经 PHPR/持续性判据。**覆盖担保限输入侧钉住场景(§1.2 前提/IF-v1.1 C10-2 在议);输出侧钉住时为机会快路径,不承诺覆盖**。响应:①挂陷波 -9dB(经执行器斜坡 ≤3dB/50ms → ~150ms 达标,合同硬约束)②通道宽带临时回落(5ms 起,§4.4)**先行兜住斜坡期间的增长** ③临时提升检测灵敏度(T_papr/T_pnpr 各降 3dB,持续 5s)④断言 `NHS_PANIC_ACTIVE` → AGC hold(链序 C-4(W1-A §4),防 AGC 把回落的增益拉回来)。①-③对齐竞品恐慌阈值语义 [L4/竞品手册 §2.3] 与 Espressif 全局增益回落结构 [L4/README_HOWL]。
- **GROWTH 路**(64-128ms):IMSD ∧ PHPR 非否决。抓"正在长"的啸叫,主力路。
- **PERSIST 路**(秒级):TRACKED 连续 ≥ P_persist ∧ PAPR ≥ T_papr_high(=T_papr+6dB)∧ PHPR 非否决。兜"已饱和/缓慢爬升"啸叫。P_persist 初值:语音预设 1.0s、音乐预设 2.5s [L4/待标定]。**已知代价**:超过 P_persist 的合法纯音(测试信号/HVAC 风鸣/提示音)会被浅陷(-3dB)——列入误触发清单 §3.5,由浅起步+快回收把损伤控制在轻微。

### 3.4 分类输出

`HOWL(ch, f_median, class∈{PANIC,GROWTH,PERSIST}, PAPR, level)` → 交状态机(§5)。同 hop 多峰命中按 (PANIC 优先, 次按 b_k 降序) 排序,每 hop 每通道**至多执行 1 个新挂/加深动作**(防一帧内连锁误动作;PANIC 不受限)[L3/设计]。

### 3.6 高频看门狗带(8-20kHz;消费合同的 float[512]@46.875Hz 谱,每通道 ~1.07s)

主旁链上限 8kHz 的盲区由看门狗谱补,但其网格粗(46.9Hz)、更新慢(1.07s),**IMSD/GROWTH 不适用**(采样周期 ≫ 啸叫增长时标)。处理规则:
- 仅两路:**PANIC**(level≥T_panic 的窄带峰,单次确认即动作)与 **PERSIST-粗**(连续 ≥3 个看门狗周期 ≈3.2s 的高 PAPR 窄带峰)。
- 挂陷用**宽档**(≥1/5 oct;10kHz 处 1/5 oct ≈1.4kHz ≫ 46.9Hz 网格,定频精度要求天然放松 [L3/手算]);占用同一 8 槽池。
- PHPR 否决在此带仅下查(f/2 落主带,及时可用)。
- 预期负担极低:会议场景 8kHz 以上啸叫罕见(GN 专利典型带 1-6.5kHz 旁证 [L4]),看门狗是保险不是主战场。
- **⚠ 反应时间联动(W1-A verdict F4,DEC-0008)**:本带反应下限 = 扫描周期(~1.07s)+ 判据持续性 + 斜坡——PANIC 路(单次确认)最快 ≈1.1-1.2s,PERSIST-粗 ≈3.2s+;期间 10kHz 级啸叫持续,高音单元承压。**本层无法快于扫描周期**,该预算与后果论证归 W1-A F4 修正(扫描率是否上调 / T_panic 本带默认值是否强制启用),本层跟随其结论调整 §3.6 参数;T_panic 在看门狗带的默认启用状态 = 产品决策 [L4/待定,联动 F4]。

## 4. ★ 深度策略:先浅→复发递进→缓抬试探→宽带兜底

### 4.1 深度可控陷波器(修补 PX4 缺口)

PX4 `NotchFilter::setParameters` 仅三参数、全深无深度控制(D0c §1.6 已核)——**弃其系数公式,保留其 DF1 结构与更新纪律**。系数改用 **RBJ peaking-EQ 负增益式**(RBJ Cookbook [W0 已核])。**双轨口径(B-m3 勘正)**:已做的双轨 = CHECK A 的闭式|H| vs 复数求值 **+ 半深点带宽功能核**(功能核按"设定 BW ↔ 数值求得 BW"闭环,能抓系数公式转写错);v1.0 曾写"pareq.m 交叉核"**实际未做,系虚账,照直改正**——pareq.m(KU Leuven,BSD)对照列为待做项(C 实现阶段第三路,非本设计稿门槛):
```
A=10^(G/40)(G<0);alpha=sin(w0)*sinh(ln2/2 * BW_oct * w0/sin(w0))
b=[1+αA, -2cosw0, 1-αA]/(1+α/A);a=[1, -2cosw0, 1-α/A]/(1+α/A)
带宽:BW_hz = max(BW_oct*f, BW_floor);BW_floor 取参数字典默认 15Hz [L4/QSC](量程 5-30,合同 §5 字典);
      我方原提 12Hz [L4/dbx 8-11Hz 折中] 作 ROC 标定候选,标定后若胜改字典默认值(非结构分歧,双方已确认)
```
桌面双轨核:闭式 |H| vs freqz,5 组 (f0,深度,BW) 两轨差 ≤1e-5dB、@f0 深度=设定值、半深点带宽=设定 BW、极点全稳 [L2/桌面数值,CHECK A]。

### 4.2 深度状态转移(每陷波)

```
动作接口(合同执行器):notch_request(f,bw,target)/deepen(Δ)/release;
      斜坡由执行器实施,≤3dB/50ms 硬约束(防爆音,D0c §4.4)——本层只发目标,不管逐样本
挂入:target=-3dB [L4/Rane"单陷波目标仅2-3dB"] → 斜坡 ~50ms 达标
      PANIC 挂入:target=-9dB → ~150ms 达标,斜坡期间由宽带回落(5ms 起)先行兜住(§3.3)
复发(TRACKED 再分类命中且 |Δf|≤BW_hz/2):deepen(-3dB)(步长 [L4/dbx 对称步进])
      直至 MaxDepth(预设参数,默认 -18dB,量程 -3..-40dB
      [L4:Rane">20dB 说明有问题"→默认远离之;Sabine 最深 -50dB 为业界外包络;留 -40 给极端房间])

      第一次:带宽升档一次(1/10→1/5 oct)[L4/竞品"语音环境建议1/5"]
      仍复发:标记 NOTCH_INSUFFICIENT → 宽带兜底(§4.4)+ 上报 host 事件
```

### 4.3 回收(LIFT,dbx 语义 [L4/dbx AFS2 手册])

```
HOLD 中静默(该轨无任何再命中)≥ LIFT_AFTER(预设,§6)→ 进 LIFT:
      +3dB / lift_step(5s)[L4/dbx 3dB 步进;dbx LIFT AFTER 量程 5s-60min]
      抬升中复发 → 立即回挂 pre-lift 深度并重置计时(dbx 语义);若复发为 PANIC 级 → 回挂并再加深 -3dB
      抬至 0dB 无复发 → STANDBY(§5.3)
老化:AUTO 陷波连续挂 ≥ AutoClear(默认 OFF,量程 1-99h [L4/Shure DFR22])→ 强制进 LIFT
```

### 4.4 宽带减益兜底(8 点耗尽/陷波不足;Rane + 乐鑫结构佐证 [L4])

```
触发:①分类命中但无可分配陷波(§5.5 分配失败) ②NOTCH_INSUFFICIENT ③PANIC 路(临时回落)
动作(作用于本通道 AFC 模块出口的宽带增益 g_duck):
  attack:-1dB/100ms 递减,直到该通道无 HOWL 分类,下限 -6dB [L4/待标定]
  PANIC 变体:一步 -6dB(5ms 斜坡),恐慌解除后并入通用恢复

  互斥:g_duck 生效期间断言 NHS_PANIC_ACTIVE / NHS_DUCK_ACTIVE → AGC hold(链序 C-4(W1-A §4),
        否则 AGC 会把回落增益拉回,两环对打)
  事件:FILTERS_EXHAUSTED / PANIC_DUCK 上报 host(PRD §六 可视化)
```
执行侧需求:g_duck 是 AFC 出口的宽带增益节点,须支持逐样本斜坡(已列 §8.3-④,执行器归架构侧)。
兜底放通道内不放主输出:只降罪魁通道,不伤全系统(与 automixer NOM 限制天然叠加)[L3/设计]。

## 5. 状态机完整定义

### 5.1 每陷波槽:模式 × 状态

**模式**(对齐 PRD §二.5"三种工作模式"与竞品口径 [L4/竞品手册 §2.3],DEC 已确认吻合):
- **AUTO**:参与自动分配/加深/回收/老化/循环复用。
- **MANUAL**:用户直设 f/BW/深度;分配器不可占用、不自动变化。
- **FIXED**:频率钉死(用户手动钉或将 AUTO 陷波"固化"),重启/调预设仍有效,不被新啸叫占用;自动加深仍作用(复发时),LIFT 只回到**固化基线深度**而非 0dB。[L3/产品语义推断:竞品仅明言"不被占用且重启有效",基线深度语义待 host-software/CTO 确认]

**状态**(AUTO 槽;MANUAL/FIXED 仅 ENGAGED 恒驻):
```
        分配(§5.5)                目标深度到达
 FREE ────────────► ENGAGE ────────────────► HOLD ◄──┐
  ▲                (渐深中)                    │      │复发:加深/回挂(§4.2/4.3)
  │                                 静默≥LIFT_AFTER   │
  │ reclaim 窗到期                      ▼             │
  └────────────── STANDBY ◄───────── LIFT ───────────┘
                (0dB 驻留,记频率)   (+3dB/5s 缓抬)
                     │同频复发(≤reclaim 窗)
                     └──────► ENGAGE(直接 -3dB 挂回,不耗新槽)
```
- **STANDBY/reclaim 防抖**:抬到 0dB 后驻留 `reclaim = 30s`(量程 5-120s [L4/QSC Q-SYS]),防"弹进弹出";窗内同频(|Δf|≤BW_hz/2)复发直接回挂;到期 → FREE。
- 系数更新纪律(PX4 防抖思想 + IF-v1.0 C6 硬约束):重调迟滞 `|Δf| > max(0.25*Δf_bin, 0.01*f)`(≥合同下限;B3:0.25bin=3.9Hz)才发 retune [L4/待标定];深度斜坡由执行器保证(IF-v1.0 C6);**系数重算全局 ≤1 次/帧(IF-v1.0 C6)→ 本层动作进重算队列串行下发,最坏 64 滤波器全更新 ≈85ms(64 帧)排空 [L3/手算],状态机时序对此不敏感(时间常数均 ≥秒级,唯 PANIC 例外——其首动作是宽带回落 g_duck,增益通路不进系数重算队列,architect 2026-07-31 已确认)。**

### 5.2 全局语义

- **Lock(锁定)**:通道级开关。冻结所有槽的状态转移与系数变化(演出锁定,竞品同语义);检测旁链继续跑,仅记 log。
- **Clear(清除)**:两级。`Clear-Auto`=复位全部 AUTO 槽(含 STANDBY)→ FREE;`Clear-All`=另含 MANUAL/FIXED(host 二次确认)。[L3/竞品仅"一键复位全部",两级细分为本设计补强,待产品确认]
- 预设切换:AUTO 槽全清;FIXED/MANUAL 随预设文件载入(与 D6 预设模型、参数字典对接)。

### 5.3 分配策略(§5.5 伪代码)与循环复用

新 HOWL 分类到达,按序取槽:
1. **STANDBY 同频槽**(reclaim 命中)→ 直接回挂;
2. **FREE 槽** → ENGAGE;
3. 无 FREE:**round-robin 复用**——候选=全部 AUTO 槽中 `当前深度最浅` 者(损失最小);同深取 `最久未复发` 者(Shure"替换最旧动态"的保守化:替换最旧可能放虎归山,替浅优先把回归风险压到最小 [L3/设计,偏离 Shure 有意为之,留痕]);被复用槽旧频率记入 STANDBY 影子表(仅记频,不占槽),reclaim 窗内旧频复发 → 走宽带兜底而非再抢槽;
4. 3 也无(全部 MANUAL/FIXED 或 LOCK)→ 宽带兜底(§4.4)。

### 5.4 老化超时:§4.3 AutoClear;跟踪表老化:§1.2 IPMP(6 hop,B3:≈96ms)。两者语义不同(陷波器寿命 vs 检测轨寿命),实现分开。

### 5.5 伪代码(可实现;C 风格,定/浮点中立)

```c
// ===== 每通道状态(静态分配,无堆)=====
#define NN 8            // 陷波槽数(DEC-0007.3)
#define NT 12           // 跟踪轨上限(>NN 留余量)
#define W_MAX 10        // IMSD 窗缓冲上限(B-m2:预设 W_long 最大 10,§6;W_used ≤ W_MAX)

typedef enum { M_AUTO, M_MANUAL, M_FIXED } NotchMode;
typedef enum { S_FREE, S_ENGAGE, S_HOLD, S_LIFT, S_STANDBY } NotchState;
typedef struct {            // 陷波槽(滤波器本体归执行器,本层只持句柄与元数据)
  NotchMode mode; NotchState st;
  u8    exec_id;            // 执行器滤波器句柄(notch_request 返回)
  float f_hz, bw_oct, depth_db, target_db, base_db; // base_db: FIXED 基线
  u32   t_last_hit, t_lift_start, t_engage;         // 分析槽计数戳
} NotchSlot;
typedef struct {            // 检测轨
  bool  active; float f_hz; medfilt7_t fmed;        // 首挂 3 点、补满 7 点(§1.2)
  u16   pair_id;            // 合同供给的帧间配对 id(关联归架构侧)
  float papr_hist[W_MAX]; u8 hist_n; u32 t_born, t_last_seen;
  u8    hits4;              // 近 4 hop 命中位图
  u32   t_growth_start;     // 增长/跳升起点(§3.2 因果时序用)
  u32   t_veto_start;       // PHPR 否决条件首次成立时刻(§3.2 因果时序另一端)
  bool  rapid_onset; u32 t_rapid;  // 臂2 sticky 签名 + 保鲜期计时(T_exempt=10s)
} Track;
typedef struct {
  NotchSlot slot[NN]; Track trk[NT];
  float g_duck_db; u32 t_duck_quiet;      // 宽带兜底
  StandbyShadow shadow[NN];               // 复用槽的影子频率表
  bool lock; PresetParams P;              // §6 预设参数包
} AfcChannel;

// ===== 合同供给(架构侧产出,本层只读)=====
typedef struct {
  float f_hz, p_peak, band_mean, nbr_mean;  // Quinn 内插频率 + PAPR/PNPR 原料
  u16   pair_id;                            // 上次配对 id(IPMP 关联)
} PeakInfo;
typedef struct {
  const float *M; u16 nbins; float df_bin;  // 幅度谱+网格参数(AFC.det.cfg;B3=512/15.625Hz。
                                            //  判据代码不得硬编码 bin 宽——IF-v1.0 C4)
  const float *M_wd;      // float[512] 看门狗谱,46.875Hz 网格(~1.07s 更新)
  PeakInfo pk[16]; u8 np; // 候选峰 ≤16(含 opt-in 的 2f 看门狗值,§3.2)
  const GrTelem *gr;      // IF-v1.1 C10-3(在议):{out_lim[8],comp_in[8]}{active,GR_dB},
                          //  帧级+有效位;invalid → 臂3 自禁用+记事件,禁静默当零
} SidechainSupply;

// ===== 每通道 hop(IF-v1.0 C1;B3=16ms)一次,轮询到本通道时执行;包络 C2(对账 §8.2)=====
void afc_slot(AfcChannel *c, const SidechainSupply *sp, u32 slot_now) {
  // 1) 判据:对 sp->pk 逐个算 PAPR/PNPR/level,过 G0 门(§1.2-1.3)
  // 2) 跟踪:按 pair_id 挂到 Track,维持 3/4 hop 连续性 + 6 hop 老化 + 中值(§1.2)
  update_tracks(c->trk, sp, slot_now);
  // 3) 分类:三路(§3.3),输出至多 1 个非 PANIC 动作;看门狗带走 §3.6 粗判
  Howl h; int nh = classify(c, sp, slot_now, &h);
  //    classify 内部:PANIC: level>=P.t_panic(→断言 NHS_PANIC_ACTIVE,链序 C-4(W1-A §4))
  //                  GROWTH: (imsd_fit(trk) ∨ rapid_onset等效命中) ∧ !phpr_veto(trk,sp)
  //                  PERSIST: age>=P.persist ∧ papr>=P.t_papr+6 ∧ !phpr_veto(trk,sp)
  //                  phpr_veto 内含 §3.2 三臂豁免(臂1 IMSD/臂2 RAPID_ONSET/臂3 sp->gr,
  //                    臂3 仅 PERSIST;GR 证据另使 P.persist 减半 [L4/待标定])+因果时序
  // 4) 状态机 → 动作经执行器 API(notch_request/deepen/release,斜坡归执行器)
  if (!c->lock && nh) allocate_or_deepen(c, &h, slot_now);  // §5.3/§4.2
  slots_tick(c, slot_now);       // ENGAGE 等斜坡 / LIFT 缓抬 / STANDBY 到期 / 老化
  duck_tick(c, nh, slot_now);    // §4.4 宽带兜底攻击/保持/恢复
  publish_dict(c);               // 参数字典回写:每槽 {mode,st,f,bw,depth} → host 频谱图
}

bool imsd_fit(const Track *t, const PresetParams *P, float *b_out) {
  // 预设加载时校验 P->W_used ≤ W_MAX(B-m2:大房间 W_long=10 恰为上限)
  if (t->hist_n < P->W_used) return false;
  float b, c0, s; ls_fit(t->papr_hist, P->W_used, &b, &c0, &s);   // O(W) 闭式
  float dP = t->papr_hist[P->W_used-1] - t->papr_hist[0];
  bool long_ok  = (b>=P->beta_min && b<=P->beta_max && s<=P->s_max && dP>=P->dP_min);
  bool short_ok = imsd_short(t, P);                // W_short=4, b>=beta_fast
  *b_out = b; return long_ok || short_ok;
}

void slots_tick(AfcChannel *c, u32 now) {
  for (int i = 0; i < NN; i++) { NotchSlot *s = &c->slot[i];
    if (s->mode == M_MANUAL) { retune_if_needed(s); continue; }  // §5.1:MANUAL 不自动转移
    switch (s->st) {
    case S_ENGAGE: // 斜坡由执行器实施(≤3dB/50ms);本层按时长推进状态
                   if (elapsed(now, s->t_engage) >= ramp_slots(s->target_db))
                     s->st = S_HOLD;                                     break;
    case S_HOLD:   if (elapsed(now, s->t_last_hit) >= c->P.lift_after)
                     { s->st = S_LIFT; s->t_lift_start = now; }          break;
    case S_LIFT: { float floor_db = (s->mode==M_FIXED) ? s->base_db : 0;
                   if (every(now, c->P.lift_step))
                     s->depth_db = fminf(s->depth_db + 3, floor_db); // B-m2:clamp,任意基线不越界
                   if (s->depth_db >= floor_db)
                     s->st = (s->mode==M_AUTO) ? S_STANDBY : S_HOLD; }   break;
    case S_STANDBY:if (elapsed(now, s->t_last_hit) >= c->P.reclaim) free_slot(s); break;
    default: break; }
    retune_if_needed(s);   // Δf 迟滞 §5.1;经执行器 retune,全局 ≤1 次系数重算/帧
  }
}
```

音频通路侧(每 64 样本帧最坏 8 级 DF1 串联)与系数斜坡/双缓冲**归执行器(架构侧,合同)**;本层不触碰样本域,只发 notch_request/deepen/release 与 retune。

### 5.6 跨通道协调(自研;多麦系统必需)

同一物理啸叫环路的频点会同时出现在多支开麦上;8 通道各自独立挂陷 = 同频最多 8×深度,音质无谓受损。
```
全局频率登记表(共享,单写者=旁链调度器):
  通道 j 挂入/加深 f 时登记 (j, f, hop)
  通道 i(i≠j)对 |f_i - f| ≤ BW_hz/2 的分类命中:延迟 2 hop(32ms)执行
    → 若 j 的动作已让环路回稳,i 的轨在延迟期内自然衰减,不挂
    → 若仍命中(多麦共环/另一环)→ i 正常挂入
  优先执行者:同 hop 多通道命中同频时,取 level 最高者先动
```
[L3/设计,待闭环多麦仿真验证;PANIC 不延迟。]

### 7.1 它真在工作(正面判据;测量仪器只看**输出信号**,不信内部旗标——假绿纪律)
