## C1 帧结构与旁链调度
- 音频:48kHz / 64 样本/帧 / 750 fps(平台硬底,DEC-0006 [L1/ITC])。
- 旁链分析槽:每 2ms 一个(系统 500 FFT/s,8 通道错峰,每通道更新周期 16ms)。
- 旁链任务属性:最低优先级、可抢占、非音频 ISR;**错过槽位允许跳帧**(降档,不阻塞音频帧回调)。

## C5 PNPR 邻域均值定义(本条款自足;计算=提供方)
> v1.1 结构修法:定义全文内联,权威方向 = **本条款定义、W1-B §1.2 引用**(v1.0/v1.0a 的「语义=接收方 §1.2」指针已删——合同是唯一权威源,不得把语义外包给受方文档,DEC-0010)。
- **邻域(线性 Hz 域,两侧对称)**:`U(f) = [f−K_hz, f−E_hz] ∪ [f+E_hz, f+K_hz]`。
- **主瓣排除半宽**:`E_hz = 3·Δf_bin`,即**每侧 3 bin**(Hann 主瓣全宽 4 bin,与 N 无关;Δf_bin 按当前 `AFC.det.cfg` 运行点取值,B3 = 15.625Hz)。
- **邻域外边界半宽**:`K_hz = max(187 Hz, f·(2^(1/3)−1) ≈ 0.26f)`,**此为每侧(单边)值**(度量约定显式化,DEC-0010 同族二义性通则:187Hz 下限与 0.26f 均指单边半宽,勿作全宽解读);换算到 bin 由提供方按当前 `AFC.det.cfg` 执行。
- **邻域均值** = `mean(M[U(f)])`;供给字段「邻域均值」即此量(PNPR 组合式 `20·log10(M(f)/邻域均值)` 属接收方判据层)。
- 值属 [L4/待 ROC 标定];若标定倾向更窄邻域(接收方回执提示强混响场景可能性),走 C9 → 下一版本。
- 变更史:v1.0 误写「±1/6 oct」(2× 同族二义偏差);v1.0a 勘误为接收方原式;v1.1 自足化 + 补「每侧」字样 + 删指针(结构修法)。

## C6 执行器接口(提供方实现,接收方调用)
- API:`notch_request(ch, f0, bw, depth)` / `notch_deepen(ch, slot, Δ)` / `notch_release(ch, slot)` / `g_duck(ch, gain, ramp)`(宽带兜底/PANIC 增益,逐样本斜坡)。
- 系数**双缓冲、帧边界切换**。
- 硬约束:深度斜坡 ≤ **3dB/50ms**(防爆音,D0c §4.4 [L4/厂商佐证]);频率重调迟滞 ≥ **max(0.5Hz, 0.25bin)**(防抖,PX4 惯例 [L4]);陷波系数重算全局 ≤ **1 次/帧**(队列串行;最坏 64 滤波器 85ms 排空)。
- **PANIC / g_duck 旁路系数重算队列**(增益通路,不进队列,帧级生效)。

## C7 陷波中心频精度语义
- Quinn 内插后 **p95 |Δf| ≤ BW/4**(恒带宽下限 15Hz → 3.75Hz)。
- 依据:需求正向推导(W1-A §3.4:真频点初咬 ≥2dB ⇒ BW/4 达标、BW/2 不达);失谐 BW/4 处陷波仍有 ≈7dB 咬合(窄带近似+精确 RBJ 双轨,W1-A 附录)、BW/2 处仅 3dB;Rane 单陷波环路余量目标 2-3dB [L4/文献]。
- 现状:W1-B selfcheck L2 桌面数据 p95 2.8Hz@1024pt Hann/SNR10dB,满足 [L2/W1-B,待其过门];接收方判据设计不得假设优于此语义。

## C10 检测 tap 上游增益结构担保 + 动态增益(GR)遥测(v1.1 新增,B-F1 架构侧)
> 背景(critic-w1 B-F1):被输出限幅器钉住的啸叫可使三路分类全脱靶——IMSD(斜坡被压平)、PANIC(tap 电平被钳在 T_panic 下,冲顶前提无人担保)、PHPR 豁免(削波谐波触发否决而旧豁免条件恒 False)。本条款给出接收方**可依赖**的结构担保与新增供给;与接收方豁免条件修法(W1-B §3.2 轨迹历史版)联合闭洞,**不是只堵豁免条件**。

1. **上游纯净担保(提供方担保;执行机制 = W1-A §4 C-7 链序约束,A9 定稿承接)**:检测 tap(陷波器组入口)上游的输入通路内,**不存在压缩器/限幅器/AGC 等「高电平衰减型」时变增益处理**;tap 上游唯一可能的饱和机制 = 模拟前端/ADC 满幅削波(物理饱和,≈0dBFS)。噪声门/扩展器(低电平衰减型)不在禁止之列(不销毁高电平增长段证据 [L3/解析]),其开启阶跃对轨迹线性度的影响列入接收方 s_max 标定注意项。AEC 位于 tap 前但非增益型处理;其与啸叫分量的耦合取决于 AEC 参考路径定义(D1/G2 未决项),不在本担保范围,A9/D1 定稿时显式检查(W1-A §4.1)。
2. **增益结构二分(覆盖责任划分,双方文档各自承接)**:
   - **输入侧钉住**(ADC 满幅):担保 1 成立时 tap 电平 ≈0dBFS(满幅),显著高于任何合理 T_panic 设置 ⇒ **PANIC 路担保覆盖**(接收方 PANIC 路仅按电平判定、不经 PHPR,W1-B §1.3/§3.3)。
   - **输出侧钉住**(输出链保护限幅器 PRD §三.5 / 功放 / 扬声器压缩——均在环路内且不可移除):tap 电平 = 限幅天花板 + 回程增益(声学+前端),**无下界担保,PANIC/IMSD 均不担保命中** [L3/解析,论证 W1-A §4.1] ⇒ 覆盖责任 = 接收方 pinned-howl 路径(轨迹历史豁免 + 本条款 GR 遥测证据)。
   - **T_panic 语义修订**:输入侧饱和快路径 + 高电平机会快判,**不承诺输出侧钉住场景的覆盖**;两侧文档中与此冲突的旧表述(如「快端由 PANIC 路兜」的无条件式)一律按本款收窄。
3. **GR 遥测供给(提供方产出,帧级更新)**:
   - 结构(字段细目待接收方回执确认):`gr_telemetry = { out_lim[n_out]: {active: bool, GR_dB: float} /* 输出链保护限幅器,逐输出母线 */, comp_in[n_ch]: {active: bool, GR_dB: float} /* 输入链 COMP(位于 tap 后,仍在环路内)*/ }`。
   - 用途(接收方自研层,判据归接收方):持续 GR active + TRACKED 高 PAPR 峰 → pinned-howl 证据 / PHPR 豁免条件 / PERSIST 加速;v1 不提供「路由→环路归属」映射,接收方按「任一相关 GR active」粗判,细化走 C9。
   - 实现归属:输出限幅器 GR 导出 = **D4(输出链)工单新增需求**;输入 COMP GR 导出 = D3 需求;由提供方在相应派单/评审中承接 [L3/架构定义,待 D3/D4 实现]。
   - **降级可见性(假绿防线)**:gr_telemetry 带有效位/心跳;遥测源未实现或失效时字段显式标 invalid 并上报 host 事件,**禁止静默置零**(静默零 = 检测器在"看不见限幅器"状态下无人知晓地降级)。
4. **验证钩子**:pinned-howl 闭环场景(输出限幅器入环、构造 tap 电平 < T_panic 的钉住啸叫)列入 W1-A §8 V-12 与 W1-B §7.2 broken 版矩阵;**对「禁用 GR 遥测 ∧ 禁用轨迹历史豁免」的 broken 版,测试必须 FAIL**(假绿纪律:能证伪才算数)。
