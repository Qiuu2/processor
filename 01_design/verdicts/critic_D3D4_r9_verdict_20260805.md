## 1.2 ⛔ 而同一张表里还有**第三、第四个同病实例**,它们没被抓到

```
EXP-3a  判据 ≤1e−6 dB  实测 6.34e-11  ⇒ 表记「距离 +9.999e-07 dB」
        ⛔ 那个"距离"到四位有效数字**就是判据线本身**(1e-6)——
           因为实测比线低 4 个数量级 ⇒ 线减去它 ≈ 线
        ⇒ 真实比值 = 1e-6 / 6.34e-11 = **15,773×** ⇒ **全表最厚的一条**
EXP-5b  判据 <0.01 dB   实测 **0.00**(表自注「|−163.81 − (−163.81)| = 0.00」,逐位相等)
        ⇒ 距离 0.01 = 判据线本身;比值 = **∞**
```
**⇒ 而 B 单是按距离升序排的,而表头写着「余量最薄的那几条 —— 下一次任何小改动【最先被推过线】的」:**
```
B 单实际顺序:① EXP-5c(已越线) ② **EXP-3a** ③ **EXP-5b** ④ EXP-7c ⑤ EXP-3b ⑥ EXP-1b …
⇒ ⇒ ∴ 一个自上而下读的人,会把**全表最厚的两条**当成仅次于已越线者的高危项。
```

## 1.3 ⇒ ⭐ 而最值得记的是:**表自己那条正确的规则,正是把它们藏住的东西**

```
表立的规则:「⛔ dB 量不给倍数 —— dB 的『一个单位』在不同量上不等价」
⇒ ✅ 该规则**是对的**(跨量比较 dB 距离确实无意义)
⇒ ⛔ 而"不算倍数"恰恰使 15,773× 与 ∞ 这两个数**没有被算出来** ——
   而它们正是唯一能一眼看出这两条不该在薄单前列的东西。
⇒ ⇒ **一条为防止 A 类错误而立的规则,制造了 B 类错误。**
⭐ 与今天已命名的都不同:这不是限定脱落,是【正确的规则有它自己的盲区,而盲区没被登记】。
```

## 1.4 修法 —— **一个不需要解释倍数的机械判别式**

```
⭐ 判别式:若 |距离 − 判据线| / 判据线 < 5% ⇒ **该余量已退化为判据线本身**
          ⇒ 它不携带关于【实测值】的任何信息 ⇒ 标【余量退化】,⛔ 不参与薄厚排序
⇒ 逐条代入(⛔ 按我给自己立的规矩,不只给族名与总数):
     EXP-3a  9.999e-07 / 1e-6  = 0.9999  ⇒ ✅ 退化
     EXP-5b  0.01      / 0.01   = 1.000   ⇒ ✅ 退化
     EXP-4a  0.0495    / 0.05   = 0.990   ⇒ ✅ 退化 —— ⚠ 而**无害**,见 §二 m-1
     其余各条 ⇒ 未退化
⇒ ⭐ 它不需要"给 dB 量算倍数",只需要拿距离与线比一比 ⇒ **不违反表自己那条规则**
```
**⇒ 而 B 单还须改一件事**:要么**不排序**(既然拒绝给可比的量,排序就没有意义),
要么排序前先剔除退化行。⛔ **现状是"拒绝给倍数,却给了一个按距离的名次"** —— 两者不能并存。

## 1.5 ⇒ 若不修,下游会怎么错

```
这张表的**唯一交付物**就是那两张单子("下一次改动最先被推过线的是哪几条")。
⇒ 照 B 单前列去盯 ⇒ 盯的是**最不可能出事的两条**;
⇒ 而真正薄的 dB 条目(EXP-7c / EXP-3b / EXP-1b)被挤到它们**下面** ⇒ 名次是反的。
```
