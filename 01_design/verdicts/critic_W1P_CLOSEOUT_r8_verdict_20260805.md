## 2.2 ⛔ 而「在另一个量上互相印证」这句,**两条都不成立**

```
(a) ⛔ 不是「另一个量」——两者是同一个测量的两种写法
    检测器偏差 = 实测 dO − 解析 dO,而解析 dO 是**窗长无关的常数**
    ⇒ 偏差的窗长依赖 = 实测 dO 的窗长依赖,**逐位相同,相关系数为 1(按构造)**
    ⇒ 而 ΔMSG 就是实测 dO。⇒ ∴「两个量都出现」= **同一个量出现了一次,被写了两遍**
    ⇒ ⇒ 它**不区分**「台架性质」与「ΔMSG 性质」—— 两个假设预测的东西一模一样

(b) ⛔⛔ 更要紧:S-3 的原文**否认**收敛这个框架
    S-3 逐字:「r64 实测 T60=0.5 三条在 48 s 仍未收敛,且赢家频率逐档迁移
              7580→1034→22 Hz ⇒ **不是在收敛,是在换被测对象**」
    ⇒ 而 r91 的整个框架就是收敛(自洽区间三分:漏检/已收敛/过检)
    ⇒ ⇒ 拿 S-3 印证一个收敛结论,与 S-3 自己那句话**正面冲突**
    ⚠ 我**不主张**它们是两回事 —— 二者可能是同一物理的两个阶段
      (临界点建立时间 ∝ 1/裕度,而低频高 Q 模式建立最慢 ⇒ 长窗下赢家迁到 22 Hz)
    ⛔ 而那条链子**没有被论证**,且引用时把 S-3 的否定句略掉了。
```

## 2.3 ✅ 而结论本身**有更强的支持,就在 r91 自己的数据里**

```
r91 逐格测的是 **m(闭环扫描给出的临界增益)落不落在自洽区间内** —— 那是**对 m 本身的直接测量**,
⛔ 不是通过某个派生量推的。
⇒ ∴ 可以直接说:**在测过的三个 T60=0.5 种子上,`m` 在 T=12 均未收敛;其中一个 48 s 仍未收敛。**
⇒ 而 ΔMSG / 检测器偏差 / f_trig / HOP / TRI **全部由 m 派生** ⇒ 它们在那些格上一律继承该缺陷。
⇒ ⇒ ⭐ 这个说法【更强、更直接、且不需要 S-3】,而它已经足以支撑那个大后果
   (那三格上这台架产出的每一个数都待查)。
⇒ ∴ 我的建议:**把论证换成这一条,⛔ 别用"两个量都出现"和 S-3 印证。**
```

## 2.4 ⚠ 而无论换不换论证,**量化范围仍须收窄**

```
「台架在 T60=0.5 上的性质」= 对**所有** T60=0.5 配置的断言;
```

## 2.5 ⭐ 而有一条机制 + 一个便宜的实验,能把这个推广【挣到手】
