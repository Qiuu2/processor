# 一、⛔ MAJOR-1 · `T_conv(0.35) = 24` **证不了它被记为证明的那件事** —— 而问题不是限定

## 1.1 先答 lead 的问:那条限定写得对,而它挡的是**另一条**威胁

```
它写的:「⛔ n = 1 个种子 ⇒ 无论结果如何,不得外推到该 T60 的其它种子」
⇒ ✅ 这条本身**正确**,而它限制的是【同层内的泛化】。
⛔ 而承重的推断不是"0.35 的其它种子如何",是【层与层之间的次序】——
  那条限定**一个字都没碰它**。
```

## 1.2 ⛔ 而真正的问题:**24 不在 12 与 0.5 层"之间",它就是 0.5 层自己的最小值**

```
PREREG_r92 §2 的 H1 逐字:
  「H1 ✅ 支持(且可预测):T_conv(0.35) = 24
     ⇒ **严格落在** 0.2 的 12 与 0.5 的 **24–∞** 之间 ⇒ 单调关系被此格检验且通过」
⛔ 而 "24–∞" 这个区间**闭在 24**。⇒ 24 ∈ T60=0.5 层的取值集合 {24, 48, ∞}。
⇒ ⇒ ∴ 该观测**不能区分**:
     假设甲「0.35 介于两层之间」  与  假设乙「0.35 与 0.5 同层」
   —— 从 0.5 层随机抽一格,有 1/3 的机会正好给出 24。
⇒ 即:**一个被预先标为"支持"的结果,同时是"无差异"假设的一个常见输出。**
```

## 1.3 ⛔⛔ 而更深一层:那个判据**在被写下的那一刻就不可能兑现**

```
档位网格是 T_OBS ∈ {12, 24, 48} ⇒ T_conv 只能取 {12, 24, 48, ∞}。
⇒ 「严格落在 12 与 24 之间」在这个网格上**不是一个可表示的结果**。
⇒ 三个非证伪出口只有两个:

     = 24 ⇒ 与 0.5 层最小值相等 ⇒ 见 1.2,同样不构成检验
⇒ ⇒ ∴ **H1 与 H2 穷尽了所有非证伪出口,而两者都证不了严格单调。**
⭐ 形态:**量具的分度值大于它要分辨的差** —— 与我今天两次自勘误同族
```

# 二、⛔ MAJOR-2 · `+nan` —— **"写明"不够,而证据就在这一跑里**

**⇒ lead 问"一个不适用项和一个失败项在输出里能不能【结构上】分开"。⇒ 答:必须,而现在没有,已经出错了两处。**

## 2.1 已经发生的两处错标(⛔ 不是隐患,是这一跑的实际输出)

```
背景:PREREG_r92 明写「⛔ **不跑冻结 Na**」⇒ Na 列**按设计不适用**,⛔ 不是测失败。

错标①  `缺口偏差` 列三行全写 **[未收敛]**
        ⛔ 而真相是「本轮未跑 Na ⇒ 不适用」。
        ⚠ 尤其 T=24 / T=48 两行:**臂 O 明明已收敛** ——
          该格没数的唯一原因是 Na 压根没跑。
        ⇒ ⇒ 而 `[未收敛]` 这个标签在 r91 里是**有实义的**(0.5/2 是真的不收敛)
          ⇒ **同一个记号在同族表里指了两件事** ⇒ 后来取数的人无从分辨。

错标②  `Hs2 复现闸门:T=12 缺口偏差 = +nan(须复现 r89 已报值)`
        ⛔ 这是一条**闸门**,而它既没 PASS 也没 FAIL —— 它印了一个 nan 就过去了。
        ⇒ 按本项目假绿纪律:**一个不能 FAIL 的检查不是检查**。
```

## 2.2 ⇒ 结构性理由(这才是"写明不够"的原因,⛔ 不是纪律问题)

```
⭐ `nan` 是一个**数**,而它的全部比较都返回 False:
     nan < x   ⇒ False        nan > x   ⇒ False        nan == nan ⇒ False
⇒ ∴ 任何判据只要碰到 nan,**两侧分支都不成立** ⇒ 它不报 PASS 也不报 FAIL,**它消失**。
⇒ ⇒ 用 nan 表示"不适用",**在构造上保证了每一个碰到它的闸门都会静音**。
⇒ 这不是"忘了写明",是【选了一个会让闸门蒸发的值】。
⭐ 而它与 channel-dsp-2 那条「诬告对的」是同一枚硬币的两面:
     那条:一个正常项长得像故障 ⇒ 有人去修没坏的东西
     这条:一个不适用项长得像**数据** ⇒ 没人去修,因为它看起来已经有值了
```

## 2.3 修法(⛔ 必须是结构的,不是标注的)

```
① **不适用 ≠ 一个数** ⇒ 该列的取值域改为四个**互斥记号**:
     `<数值>` | `未收敛` | `不适用(本轮未跑)` | `闸门未执行`
   ⛔ nan 不得作为其中任何一个的载体。
② **聚合护栏**:任何 max / 中位 / 闸门在遇到后两个记号时 ⇒ **中止并报 FAIL**,
   ⛔ 不得跳过、不得静默返回。
   ⇒ 理由:PREREG_r91 §2-② 已经为「未收敛」立过这条规矩(该档 max 整体不可用);
     现在只是把同一条规矩扩到「不适用」——⭐ 而"不适用"比"未收敛"更该拦,
     因为它连一次测量都没发生过。
③ **闸门自证**:`Hs2` 这类"须复现某已报值"的闸门,若其输入不可得 ⇒
   必须显式打印 `⛔ 闸门未执行(输入不适用)`,⛔ 不许只印一个值。
   ⇒ 与 `check_gates_fire.sh` 那条元检查同型:**闸门在不在,不能由闸门自己回答。**
```
