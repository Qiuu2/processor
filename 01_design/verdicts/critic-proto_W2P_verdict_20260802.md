1. 直接命中 critic/skill §4.6 **假绿门**与 D6-b 判别提示①(「被测物被禁用时仍有非零读数 ⇒ 它测的多半不是你以为的那个东西」)——这里不是"非零",是**大一个数量级**。
2. `probe.py` 的分析窗 `W = 2*BLK = 256` 是**硬编码且未申报的工作点维度**,它单独就能翻门(D6 的第 4 个实例)。
3. `20log10|X[k]|` 是**幅度**统计量,而 `tap` 在该 bin 上是"探针 + 远端回声"的**复数矢量和**;当两者幅度可比(实测远端干扰/探针 = −10.3 dB 中位、p90 −5.4 dB)时,矢量相消会制造任意大的 dB 跳变 —— 这正是"median≈0、std 大、max 随 T_obs 单调增"的成因,而这三个特征在 r13 §方法学限制里被如实记录了,却被解释成"零均值抖动"而非"测量伪影"。

### ⛔ BLOCKER-2 · r13「零假设对照」是**恒等自比**,构造上不可能失败,却被用来排除竞争解释
**位置**:`run_w2_r13b.py:14-17`
```python
def frozen_pair(mu, dur=40.0):
    a=probe.probe_run(V(delta=1.0,mu_max=mu), adapt=False, dur=dur, far_gate=(1.0,1.0))
    b=probe.probe_run(V(delta=1.0,mu_max=mu), adapt=False, dur=dur, far_gate=(1.0,1.0))
    m=min(len(a),len(b)); return a[:m]-b[:m]
```
**事实**:两次调用**参数完全相同**,`probe_run` 内部远端用固定种子 `default_rng(1)`、RIR 固定、初值固定 ⇒ 全程确定性 ⇒ `a - b ≡ 0`。归档输出正是 `E[g]=0.00000 SE=0.00000 t=0.0 斜率=nan`。
而 `results_w2_r13.txt` 用它得出:「⇒ 若零假设行 ≈0 而实验行显著 ⇒ **漂移为真,须计入 C-8b**」。

**为什么是问题**:critic/skill §4.6 点名的 **「A/B 同实现自比 = 恒等假绿」**。这个对照检验的是"程序是否确定性",不是"漂移是否伪影"。**它提供的信息量为零,却被当作排除测量伪影的证据。**

**critic 补做的、能失败的零假设**(两边都冻结,只差冻结时刻 1 块 = 8ms ⇒ 两个不同但都**静止**的系统):
```
   μ                                条件       E[g]        SE       t     D斜率      max
0.10               adapt − frozen(原件量)    0.00851   0.00243     3.5   1.057    2.779
0.10            frozen − frozen(原件零假设)    0.00000   0.00000     0.0     nan    0.000
0.10  frozen(t0) − frozen(t0+8ms) [critic]    0.00000   0.00002     0.0   0.893    0.011
0.40               adapt − frozen(原件量)    0.02556   0.00609     4.2   0.987    6.060
0.40            frozen − frozen(原件零假设)    0.00000   0.00000     0.0     nan    0.000
0.40  frozen(t0) − frozen(t0+8ms) [critic]   -0.00015   0.00014    -1.0   0.885    0.080
```
**结果分两半,必须分开讲**:
- **`D` 标度律判据不成立**:`run_w2_r13.py:48-50` 定 `slope>0.85 ⇒ **线性(有漂移)**`。我的**无自适应**对照给出 slope = **0.893 / 0.885**,同样落在"有漂移"侧。⇒ r13 §① 的三行「**线性(有漂移)**」判定**不具备区分力**。

**建议方向**:零假设对照必须引入一个**与被测机理无关的独立扰动**(不同随机种子 / 不同冻结时刻 / 不同 RIR 实现),否则它不是对照。**凡写下「零假设」三个字的地方,先问"这个对照有没有可能给出非零"。**

### ⛔ BLOCKER-3 · 参考谱否决(DEC-0018 的**替代方案本体**)的判据只实现了一半,且其验收在**每一个它自己声明的维度上**都不可证伪
**位置**:`run_w2_r20.py:47-91`;消费方 `DEC-0018`、`W1A v0.17/v0.18`、`W1A V-31`。

DEC-0018 规定的机制:「候选峰频点若在远端参考谱上同时存在**且显著度可比** ⇒ 判远端来源 ⇒ 否决」。

**实测事实**:

**(a) 「显著度可比」根本没实现**。`run_w2_r20.py:83-84`:
```python
rp,mp = ref_veto(mc,fr,k,align)
v = rp>=T_REF                      # ← mp(mic PNPR)计算了、打印了,从未参与判定
```
机械证明(本实例实跑):**把 mic 信号整个换成全零**,三个场景的否决判定**一个都不变**:
```
A: 原 mic -> 否决=True (refPNPR=99.0) | mic 置零 -> 否决=True (refPNPR=99.0)  判定不变
B: 原 mic -> 否决=False(refPNPR= 5.6) | mic 置零 -> 否决=False(refPNPR= 5.6)  判定不变
C: 原 mic -> 否决=True (refPNPR=34.5) | mic 置零 -> 否决=True (refPNPR=34.5)  判定不变
```
⇒ 实现的规则实际是「**只要远端参考谱在该 bin 上有突出峰,就否决**」,与麦克风侧证据无关。

**(b) 「须时间对齐」的声称由一个对对齐**结构性不敏感**的用例支撑**。原件 `align = argmax|h| = 127 样本`,并写「**须时间对齐**(补偿 R→扬声器→声学→麦 传播延迟)」;W1A 据此立 V-31「时间对齐鲁棒性」。本实例把 `align` 从 0 扫到 60000 样本(3.75 秒,远超任何物理传播延迟):
```
align=     0  3/3 正确      align=   500  3/3 正确      align=  8000  3/3 正确
align=     1  3/3 正确      align=  2000  3/3 正确      align= 20000  3/3 正确
align=   127  3/3 正确(原件)                            align= 60000  3/3 正确
```
**全部 3/3。** 成因:三个场景都是**平稳信号**,而判据是**幅度谱局部突出度**,对时移不变。⇒ 「须时间对齐」这条设计要求在本用例上**没有被验证过一次**。

**(c) 标题写「ROC」,文件里没有 ROC**。判据门 `T_ref=8.0 dB` 的全部证据是三个点:99.0 / 5.6 / 34.5 dB。**任何落在 (5.6, 34.5) 区间的门都给出 3/3。** 唯一从下方约束该门的是场景 B,余量 **2.4 dB** —— 而 W1A v0.18 把它转述为「场景 B(本地啸叫时 ref 显著度仅 5.6dB **≪** 门 8.0)证实了 §4.8 裁定的核心论据」。**2.4 dB 不是「≪」。**

## 12. 给作者的一条元观察(不计入分级)

W1 的 B-2 是「**自验件不依赖被测物**」。W2 把这一条守住了(§2,记功)。W2 失守的是**下一层**:
> **自验件真的调用了被测物,但读出来的**不是**被测物的那个物理量。**

`import` 是可以 grep 的,「这个数到底是什么」不行。团队已经为此立了 **D6-b**(报数前先声明被测对象与混淆面),而 D6-b 的四个实例**全部**是本工单产出的 —— 说明这个病在本工单里是**主症**而非偶发。本轮新增的三个实例(C-8f 探针 bin、恒等零假设、参考谱否决只用一半判据)有一个共同的、可机械执行的判别法,建议入 D6-b:

> **对每一个度量,写下"把被测对象从台架里拿掉后,这个数应该等于多少",然后真的去跑一次。**
> 拿掉探针 → 应为 0,实测 13–42 dB;拿掉 mic 证据 → 判定应改变,实测三例全不变;两次跑之差 → 应可非零,实测恒等于 0。
> **三条都是一次实跑就能戳穿的,三条都过了二十轮没被跑过。**
