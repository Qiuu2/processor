# 一、MAJOR-3 已闭 —— 而它的解法比我要求的好

## ⭐ 一手原文自带校验例,常数当场定死(这是本轮最漂亮的一处方法)

执行者取到 Schroeder 1964 p.1723 逐字原文,**并用同页 Fig.7 图注做自校验**:

```
Fig.7 图注:booth 体积 14 m³,T60 = 0.34 s     正文:该 booth 的极限 "is about 600 cps"
  k=4000 ⇒ 4000·√(0.34/14) = 623 Hz ≈ "about 600"  ✅   我复算 623.4 ✓
  k=2000 ⇒ 312 Hz                                  ⛔ 与原文自己的话矛盾
⇒ 在这篇论文里常数只能是 4000,且 V 只能是 m³
```
**⇒ 论文自己验证了自己的常数,不需要外部权威。⇒ 这个方法值得进纪律:

# 二、新增 MINOR(MAJOR-3 整改本身带出来的)

## m-4 · 「孤立模态区 ≈ 54–110 Hz」的两个端点用了**不同的 V 范围** —— 而这正是 §5.0 刚修好的那个病

**位置**:`01_NHS_numbers.md` §5.2「⇒ 建议因此改写」块。

```
文档给的三点(我全部复算相符):
   V=100 / T60=0.5 ⇒ ≈85 Hz      V=100 / T60=0.2 ⇒ ≈54 Hz      V=60 / T60=0.5 ⇒ ≈110 Hz
⇒ 然后写「孤立模态区 ≈ 54–110 Hz」
   ⇒ 下沿 54 取自 V=100,上沿 110 取自 V=60
```
**而 §5.0 同一节自己声明的 V 范围是 60–300 m³。按它自己的范围全网格:**

| V | T60=0.2 | T60=0.5 |
|---|---|---|
| 60 | 69.8 | **110.3** |
| 100 | 54.0 | 85.4 |
| 300 | **31.2** | 49.3 |

**⇒ 全网格是 31.2 – 110.3 Hz,不是 54–110。**

> **⇒ 这与 §5.0 刚刚修掉的病是同一个**:§5.0 的开头写着
> 「**⛔ 这一节的频带边界【不是测出来的】,是两个借用输入的函数 —— 标题不得写成一个固定频带**」,
> 而两小节之后,`54–110 Hz` 又被写成了一个固定频带,且两端取自不同的 V。
> **⇒ D6-l:一个病被立法修过之后,下一次它会以「我们已经修过了」的形式回来。**

**⚠ 而结论本身不受影响,但余量比读起来小**:
```
「整段落在检测带下沿 120 Hz 之下」——
   在 §5.0 声明的 V 下限(60 m³)上,f(M=1) = 110.3 Hz ⇒ 距 120 只剩 9.7 Hz
   而临界值:V < 50.7 m³(T60=0.5)⇒ 孤立模态区上沿越过 120 Hz ⇒ 与检测带【重叠】
```

**修法**:①写成 `f(M≈1) ≈ 31 – 110 Hz(V 60–300 m³ × T60 0.2–0.5)`,与 §5.0 同格式;
②补一句「**V ≲ 51 m³ 时该段上沿越过 120 Hz,与检测带重叠 ⇒ 两段分离在小房间不成立**」。
