## §1 一句话结论

> **在标称输入电平上,NHS 自己选点、8 个陷波、12 秒观测窗、环路 8 kHz 带限的条件下,
> 实测反馈余量改善 `ΔMSG ≥ 2.00 – 6.00 dB`(六条种子,中位 ≥2.50 dB)。
> 六条中 2 条 ≥4 dB、1 条 ≥5 dB。**

> **而这条线的杠杆已经用尽:天花板不是实现缺陷,是 `ΔMSG ≈ top1 − top(NN+1)` 这个序统计量的数学形状(§4)。**

⚠ **为什么写「≥」**:ΔMSG = (有陷波的起振增益) − (无陷波的起振增益);而**无陷波臂(m0)在其读数点上仍在增长**
⇒ m0 被高估 ⇒ 差值被**低估**。量级已实测 = 恰好一个扫描步长 **0.50 dB**(4/6 条可判,2/6 条本方法无分辨力)。
出处 F76.3 / F77.4;r87 在六条上独立复现该形态(m0 臂 6/6 末秒−首秒 RMS 在长,+0.19 … +3.22 dB)。

## §4 ⭐⭐ 天花板的来源(CTO 做路线决定的依据)

**结论先写**:ΔMSG 不是"实现得好就能涨"的量。它是**顶部几个峰之间的序统计量**:

```
ΔMSG ≈ top1 − top(NN+1)      ← 完美陷掉前 NN 个峰后,第 NN+1 个峰接管
⛔ 不是 峰-均比(max − mean)
实测判别(六条种子,NN=8):|假说「峰-均比」误差| 中位 **6.88 dB**
                          |假说「序统计量」误差| 中位 **1.57 dB**
```
出处 F71。⇒ **Schroeder 的「≈10 dB」确实存在、也确实是峰-均比(一手原文 p.1719 已核),
但那是把【全部 223–475 个临界点】压平才够得着的量;用 8 个陷波能拿到的是【第 1 峰与第 9 峰之差】。**

### 逐条堵死四个方向

| 方向 | 实测 | 判 |
|---|---|---|
| **加陷波数**(⚠ **等预算**:总带宽钉死 ≡1.00 oct,用 `NN` 换 `bw_oct`) | 神谕臂 `NN` 8→16 有可判改善,**16→24 中位 +0.00 = 饱和**;而自选臂**填不满**(利用率 0.81→0.25) | 序统计量增长本就极慢 ⇒ **饱和不是实现缺陷,是这个量的数学形状**。⚠ 台架实测 `top1−top(NN+1)`:NN=8 ⇒ 1.92–3.15;16 ⇒ 2.51–4.18;24 ⇒ 3.21–5.26 |
| **开更窄的陷波** | 旁链 bin 宽 **15.625 Hz**;`bw_oct ≤ 1/8` 起陷波比一个 bin 还窄(1/24 @120 Hz = **3.47 Hz = 0.22 bin**);Quinn 选点误差 p95 **1.4 Hz** ⇒ 1/24 在 120 Hz 处实得深度损失 **−7.53 dB(42%)** | **低频物理墙**,与算法无关,改 `_allocate`、改排序键都修不掉 |
| **压得更深** | `recheck_free` 使六条种子的陷波**全部达到 `max_depth`**(基线下有两条卡在 −15.00 / −16.50)—— **而 ΔMSG 一格未涨:0/6 变好、1/6 变差 −0.50、4/6 不可判** | **公式里没有深度这一项**(r87 实证,F79) |
| **压得更深(旁证,⚠ 不同量)** | r21:深度设定 −3 → −18(多 15 dB),**陷波点残余电平**总落差只有 **−0.4 / +0.9 dB**,末三步不再下降 | ⚠ **方向一致,但不是同一个量**:r21 测的是**残余电平**不是 ΔMSG,且其 `depth` 是**输入参数**、并刻意 `T_low=999` 关掉自适应 ⇒ **只作旁证,⛔ 不得当作 ΔMSG 的实测** |

> **⚠ 这两句必须挨在一起读:「六条种子的陷波全部达到 max_depth」是真的;「它换不来任何可判的 ΔMSG」也是真的。**
> **⇒ 代理量达标 ≠ 交付量改善。**

### ⇒ 剩下的唯一杠杆:**选点**

本报告 §2 的「选点缺口」列 = 神谕选点臂 − 自选臂,**逐种子 0.00 / 4.00 / 3.50 / 0.50 / 4.50 / 2.00,中位 2.75 dB**。

```
✅ 空间存在:4/6 条种子上缺口 ≥ 2.00 dB
⛔ 但只在【部分种子】上:0.2/sd0 缺口 = **0.00**(自选已追平神谕),0.5/sd0 = 0.50(不足两格)
⛔ 且这张表是在 `bw_oct = 1/5` 上测的,而 1/5 **超文献带宽预算 1.3–2×**(1.60 oct vs 0.8–1.2)
⛔ 而在合规带宽(1/8)上,神谕选点臂**自己**退化(6/6 种子下降 0.50–2.50 dB),
   且出现 5/30 格倒挂 ⇒ **"把选点做到神谕水平"这个目标本身在窄带宽上定义不清**
```

**⇒ 给 CTO 的净判断**:靠继续修 NHS(选点/分配/判据)拿到的,乐观上限是**中位 2.75 dB 的一部分**,
而**四条判据层修法已实测全部无效**(`growth_and_gate` 无从评估 / `R_RISE` 下调 δ≡0 / `prefer_unnotched` 证伪不提交 / `recheck_free` 0/6 变好)。
⇒ **若目标是 4–5 dB,本线的证据不支持"再修实现就能到"。**

## §5 ⭐⭐ `120 – 280 Hz`:五条互相独立的限制指向同一频段

> **这一节单列,因为它不是"低频差一点",而是【五个机制各不相同的限制刚好落在同一段】。**

| # | 限制 | 数 | 类型 | 出处 / L 标 |
|---|---|---|---|---|
| ① | **Schroeder 统计理论的适用下限**`f = 4000·(T60/V)^{1/2}` | V=100 m³:T60=0.2 ⇒ **179 Hz**;T60=0.5 ⇒ **283 Hz**。而 NHS 检测带下沿 = **120 Hz** | 理论适用域 | Schroeder 1964 脚注 4,一手原文;代入为 [L3/公式代入],`V` 借用架构侧算例 |
| ② | **窄陷波挂偏的物理墙** | 1/24 @120 Hz:陷波 3 dB 带宽 3.47 Hz = **0.22 个分析 bin**;Quinn p95 误差 1.4 Hz ⇒ 深度损失 **−7.53 dB(42%)**;1/16 −5.00;1/8 −1.92;1/5 −0.86。300 Hz 处 1/24 仍损 −2.56;**1 kHz 处各档 <0.35 ⇒ 高频不受影响** | 物理(做不到) | F72,[L2/桌面数值] |
| ③ | **架构侧 C7 精度契约的约束点在低频端** | `BW/4 = 1 bin` 的对应点 = **1351 Hz**,越往低越紧 | 契约(做不到) | 架构侧 W1A v0.33 |
| ④ | **Hilbert/SSB 频移的镜像抑制在低频劣化** | 我方唯一实测 = 镜像 **−64 dB @1 kHz**(513 taps);**低频端劣化量本线未测** | 物理(做不到) | r80 守卫①;低频端归架构侧 |
| ⑤ | **`Hilb1025` 在延迟预算下可行组合 = 0** | 同一声学区内输出必须延迟对齐 ⇒ 全机延迟 = 区内 `max`;LR8@80 分频 21.04 ms 已占满 12 ms 预算 | **资源(买不起)** | 架构侧 W1A v0.58 |

> **⇒ 前四条说「做不到」,第五条说「买不起」。⇒ 而它们的机制彼此独立。**

### 5.1 ⛔ 而我们自己的台架在这一段的有效性也存疑(必须先说这一条)

```
台架 plant = **噪声 RIR**,其文档明写:选它正是因为检测带"几乎全在【统计区】"
⇒ 而 120–280 Hz 恰恰是【统计区之外】(限制 ①)
⇒ ⇒ **本线所有低频数字都悬在一个在该频段不自称有效的模型上**
⇒ 这不是"我们测得不够准",是"我们这把尺子在这一段没声称过能用"
```

### 5.2 ⭐ 建议(**待验推论,⛔ 不是结论**)

> **lead 的读法**:低频模态**少、尖、稳** ⇒ 那正是【装机时一次性固定陷波】最擅长的形态,
> 而不是自适应算法擅长的形态。
> 而 **PRD §五.2 已经写了这个功能**:「开机自动扫描房间频响、一键修正驻波」。
> ⇒ ∴ 建议把 `120–280 Hz` 从**自适应 AFC 的作用域**里划出去,交给**装机/开机时的固定陷波**。

**⚠ 这条要成立,还缺三件(全部未测)**:
```
① 「低频模态少、尖、稳」在**真实会议室**里成立吗 —— 我方无 RIR 实测、且台架模型在该段不适用(§5.1)

```
**⇒ 故:作为【路线建议】提交,⛔ 不得写进任何规格、不得对外承诺。**

## §7 已知的两条真实设计缺陷(**已定位,但修它们不改善 ΔMSG**)

```
① `_allocate` 是**开环下令**:加深 = 每个 howl 一步 −3 dB **无速率限制**,而执行以 60 dB/s 爬
   (一步需 50 ms),分析槽 16 ms ⇒ **下令速率 3.1× 于执行速率**;下令时上一步平均还差 4.08 dB 未执行
   ⇒ 诊断性反事实(加最小生效守卫):`DEPTH_EXHAUSTED` 6/6 全消失(因果链坐实),
     **但挂陷数 3 条变差、1 条变好 ⇒ 该"自然修法"净负** ⇒ 「少做一点」不等于「温和一点」
② **供给恒为 1**:`nhs.py:891` 硬截断 ⇒ 每个分析槽只有一个 howl 名额,一次复检就吃掉它
   ⇒ r86/r87 修的正是它 ⇒ **深度确实被补足,ΔMSG 不动**(§4)
```
**⇒ 这两条是真实的、可复现的设计缺陷,应当记入设计件;⛔ 但不得作为"还能再拿几 dB"的依据。**
