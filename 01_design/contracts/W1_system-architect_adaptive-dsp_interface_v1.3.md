## C10 链序约束(沿承 v1.2 泛化版;critic B-F1 + lead 常识审)
- **约束(泛化)**:NHS 检测 tap 的同通道上游**不得存在任何快时变「高电平衰减型」增益环节**,含:
  - **宽带动态**:压缩器/限幅器;
  - **频段选择性动态**:**8 段动态 PEQ(PRD §二.4)**、多带动态类处理——动态 EQ 恰在啸叫频段做增益衰减 = 单频段限幅器,压平增长斜坡机理与宽带限幅同型;
  - "快时变"判据:增益调制时间常数(攻击/释放)< IMSD 轨迹窗量级(128ms [L3/设计定义,与 W1-B §2.2 轨迹窗同源,随 C13 主路判定窗联动])。
- **分类注记(并入 -2 草案)**:噪声门/扩展器属「低电平衰减型」,不销毁高电平增长段证据,不在禁止之列 [L3/解析]——本链位仍将其置于 tap 之后(更强姿态:tap 见未门控信号,PNPR 背景估计不受门控畸变);**门位=A9 定稿项**,若定稿移至 tap 前,其开启阶跃对轨迹线性度的影响列入接收方 s_max 标定注意项。
- **机理**(违反后果):上游动态压平啸叫增长斜坡 → IMSD/RAPID_ONSET(臂2)失效;电平被钳 → T_panic 语义失效;削波/调制产物先于 tap 生成 → PHPR 反向否决。**臂2 的有效性以本条款为前提。**双重理由:动态 PEQ 前置于 AEC 亦违 W1-A §4 C-1。
- **担保推论(供 C12 引用)**:本条款成立时,tap 上游唯一可能的饱和机制 = 模拟前端/ADC 满幅削波(物理饱和)。AEC 位于 tap 前但非增益型处理;其与啸叫分量的耦合取决于 AEC 参考路径定义(D1/G2 未决),不在本担保范围,A9/D1 定稿时显式检查。
- **提供方 A9 推定链位(定稿仍走 W1-B 提案→architect 定稿流程)**:
  `前放/增益/相位 → AEC → [NHS 检测 tap + 陷波器组] → 噪声门(EXP) → 8段动态PEQ → 压缩器/限幅 → ANS → AGC(含语音闪避) → automixer`
- **PRD §二 逐条差集表(链位完备性证据;提供方固定自查步骤,链位变更必重跑)**:

| PRD §二 | 模块 | 链位 | 备注 |
|---|---|---|---|
| .1 | 前放/增益/相位 | 位1 | tap 上游,静态/慢变,允许 |
| .2 | 噪声门(扩展器) | 位4 | tap 下游 ✓(低电平衰减型,分类注记见上) |
| .3 | 压缩器/限幅器 | 位6 | tap 下游 ✓(C10 硬约束) |
| .4 | **8 段动态 PEQ** | **位5** | **tap 下游 ✓(v1.2 补,C10 硬约束)** |
| .5 | AFC(NHS) | 位3(tap+陷波) | 本模块 |
| .6 | ANC 降噪(项目术语 ANS) | 位7 | tap 下游 ✓ |
| .7 | AEC | 位2 | tap 上游——非增益动态,系自适应线性滤波;耦合检查项见担保推论 |
| .8 | AGC + 语音闪避 | 位8 | tap 下游 ✓(慢时变,另受 C-4 互斥) |

  **差集 = ∅**(8/8 覆盖,0 缺失 0 多出)。
- 反例显式排除:竞品链序 EXP→COMP→AGC→EQ→AFC(动态处理前置)。
- 输出链元件(分频/10段EQ/FIR/延时/两级限幅)物理上必在环路内,不受本条款约束——限幅级可观测性由 C11 承接;**输出链 10 段 EQ 为静态(PRD §三.2 未标"动态"),若日后升级为动态须重开 C11 作用域(变更钩子)**。

## C11 动态处理 GR 遥测(v1.3 合并版 + 粒度裁定增补;**case (b) 输出侧钉住检出的担保主体**)

## C12 T_panic 增益结构二分(v1.3 合并版;输入侧担保 + 输出侧非担保)
- T_panic 语义 = 检测 tap 点电平(dBFS)。
- **输入侧钉住(ADC 满幅)= 担保覆盖(并入 -2 草案,ADC 参考电平表述)**:C10 担保推论成立时,tap 上游唯一饱和机制 = ADC 满幅 ⇒ 钉住平台电平在 **ADC 参考系 ≈ 满幅**,经**已知**数字增益链(前放数字 trim 等 DSP 内量)折算至 tap,可精确补偿 ⇒ **PANIC 路对输入侧钉住构成担保**(接收方 PANIC 路判定 = **电平 ∧ 窄带门(PAPR)**、不经 PHPR——措辞按接收方回执勘正,原"仅电平"系表述二义 [每侧/全宽同族];钉住啸叫天然满足窄带门,担保范围不变)。担保条件(缺一降级为软,须显式重开本条):(i) ADC→tap 数字增益链为 DSP 已知量(trim 补偿);(ii) **AEC 参考路径不含本地扩声分量**(D1/G2 未决项;若定稿含之,AEC 可部分抵消 tap 处啸叫分量,平台电平失去 ADC 锚)——**A9/D1 定稿时显式检查,检查项挂 W1-A §4.1**。
- **输出侧钉住(输出链限幅/功放/音箱)= 非担保**:平台电平@tap = L_限幅阈 + G(限幅点→扬声器) + **G_声学(未知时变)** + G(麦→tap),含不可知项 ⇒ 静态担保不可能 [L3/物理论证];覆盖责任 = 接收方 pinned-howl 路径(臂2 轨迹历史 + 臂3 GR 遥测,担保主体=C11)。
- **T_panic 语义修订(并入 -2 草案)**:PANIC = 输入侧饱和快路径 + 高电平机会快判,**不承诺输出侧钉住覆盖**;两侧文档中"快端由 PANIC 兜"的无条件旧表述一律按本款收窄。
- **字典软校验(沿承)**:panic 启用时 host 依可知项 {输出链限幅阈值, 矩阵/输出增益, 输入增益} 算平台电平@tap 可知下界分量,T_panic 高于其 −X dB(X 默认 12 [L4/待标定])→ 配置告警(不自动改值)。
- 接收方表述模板:"PANIC 前提担保仅限**输入侧(ADC 满幅)钉住**且受 C12 两条件约束;输出侧钉住检出由 IF-v1.3 C11(GR 遥测)担保;T_panic 配置合理性由 C12 软校验提示"。

## C13 检测反应时间同参口径(沿承 v1.1/v1.2,critic B-m4 收敛)
- **算法级参考点 = 轨迹诞生**(该峰首次跨候选门的 hop);轨迹历史自诞生起累积(含 TRACKED 前 hop);IMSD 于 TRACKED ∧ hist_n≥W_used 判定 ⇒ 主路判定 = 诞生 + 8 hop(128ms@B3)、快路 = 诞生 + 4 hop(64ms@B3);执行器首挡斜坡 50ms 另计。
- **对外/延迟账参考点 = 啸叫起始(onset)**:总反应 = Δfill(0~64ms,窗内能量爬升至跨候选门,随增长率变)+ 上述诞生参考值。**两参考点并存、不得混用**;W1-A §6 与 W1-B 反应时间表述统一按本条款(两侧文档在各自合并轮按此改写)。
