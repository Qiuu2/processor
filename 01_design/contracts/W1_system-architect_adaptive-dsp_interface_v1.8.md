## C2 接收方算力包络(**v1.6:T3 记账分两档**;包络值 20,000 未变)
- ≤ **20,000 cyc/分析槽**(**规范值,本版未变**)。
- **⭐ 记账口径分两档(v1.6 新增;原「一律 2.0 cyc/op」已不足)**:
  - **T3a 普通标量 op**(比较、加减乘、分支、访存):按 W1-A §0 T3 计入值;
  - **T3b 超越函数 op**(`log10` / `log` / 除法 / `sqrt` / `sin`·`cos` / 幂):**不得按 1 op 计**。SHARC+ 上无单周期实现,典型代价为普通标量 op 的**一个数量级**;真值由 **W1-C 第 4 内核**实测回填 [L4/粗估待实测]。
  - **报数义务**:接收方的每槽算力自报**须分列 T3a/T3b 两项计数**;只报总 op 数**不构成对本包络的合规证明**。
  - **缘由**:评审实测每分析槽含 **≥32 次 log10、≥17 次除法、1 次 LS 拟合**,而原记账把它们按 1 op 计 ⇒ 隐藏成本量级为**每槽千级 cyc**。**包络 20,000 未破,余量下降**;数值不变、口径必须改。
- **GR 遥测消费逻辑(C11)计入本包络**(量级:每槽数十 op,可忽略 [L3/解析])。
- **口径注(v1.5,DEC-0014)**:T1 档已获厂家锚点 [L2/ADI EE-408:SHARC+ 核心 2.5 cyc/biquad = 0.5 cyc/MAC],**T3(分支密集标量码)无对应锚点**——EE-408 的值只覆盖规整 biquad 链。**本包络的适用性风险不因 DEC-0014 减轻**,仍以 W1-C 第 4 内核收口。
- 超出须与提供方重议(C9),不得静默占用。

## C3 接收方内存包络(**v1.6:仅加重算注记**;16 KB / 112 KB 规范值未变)
- 检测状态机 ≤ **16 KB**(**规范值,本版未变**);AFC 全模块包络 ≤ **112 KB**(W1-A §2.2 承载,知会值)。
- **⚠ 注记(v1.6,critic 原型评审)**:接收方的内存第二轨 `mem_sizeof.c` 与其权威源**不同源**(缺两个承重字段)⇒ 其自报值**须重算**,重算前一律标 **[L2/待重算]**。已知方向:**字节打包档的配额占用上升、余量变薄**(**配额未破**);**WORD32 下行档仍越配额,仍走 C9**。**在重算完成前,接收方不得新增任何字段而不先对账。**
  **⚠ 增补期变动留痕(D3 两向自验抓获)**:本版初稿曾写 **120 KB**(= v1.4 的 112 + C4 排序供给前缀和 4.0KB + `gr_telemetry` 0.5KB);**增补3 把 `n_pnpr_quota` 默认改 0 后前缀和成为条件项** ⇒ 回落至 94.28+16 = 110.28 → **圆整 112 KB,与 v1.4 同值**。**条件值**:若 ROC 开启配额,回到 ≤120 KB。
- **⭐ 性质澄清(DEC-0014-⑤补,[L2/厂家 .ldf `app.ldf`:`5 Mbit L1 RAM` = 640 KB])**:**16 KB 是提供方分给 NHS 检测状态机的配额,不是芯片能力**。W1-B v1.2 曾报 19.00 KB,越的是**配额**,占 L1 仅约 3%。⇒ **越 C3 = 配额谈判(走 C9),不是物理越界**;重议时提供方按全局内存分配(D13)裁,不得以"硬件放不下"为由拒绝。
- **存储宽度假设 = 双方共同 V 项(critic X-2)**:两侧承重预算(接收方 16 KB / 提供方 112 KB)**同时**建立在"16-bit 标量按 2 B 存储"上。
  - 现有证据:`app.ldf` 载明 `mem_block0_bw { TYPE(BW RAM) … WIDTH(8) }` ⇒ **L1 按 8 位宽字节寻址** [L2/厂家链接文件];厂家系统优化文档明述存在 8/16-bit 访问 [L2/厂家]。**WORD32 末日档概率显著下调**。
  - **但不删该档**:终证 = SHARC 工具链 `sizeof` 实算(提供方 V-13 / 接收方 §8.2.2 同一钩子,**一次装工具链同时收口 W1-C 算力口径与本项**)。
  - WORD32 档成立时的后果(两侧同步声明,重议**一次性**走 C9):接收方 ≈20.5 KB(越配额);提供方环形缓冲 48 KB→96 KB、总包络 →≈168 KB(占 L1 26%,仍在物理内)。
- **放置约束(v1.5 新增,DEC-0014-⑤)**:**热状态与逐样本写缓冲优先置 L1**。理由:L2 SRAM 有 ECC,**任何 <32-bit 写 = 读改写 3 周期**,且 L2 跑 SYSCLK 而 L1 跑 CCLK [L2/厂家系统优化文档]。若 D13 全局分配迫使落 L2,三选一(保持 32-bit 对齐放弃减半 / 接受读改写 / 关该 bank ECC ——**末项是可靠性决策,须 CTO**),并按 W1-A §2.2 的敞口行计入算力。

## C4 旁链供给数据(**v1.6:增远端参考谱 `ref_spec` 与时间对齐量 `ref_delay`**)

- **高频看门狗谱**:float32,512 bin @ 46.875Hz(N=1024@48k),扫 5.5k-20kHz。
  **扫描周期规范值(⑩,v1.5 消歧)**:**每通道 1.07 s ⟺ 系统率 7.48 次/s(8 通道错峰)——两者互为定义,任一侧做摊销/反应时间计算必须同参**。(v1.4 前提供方文档内部曾并存"1.07s"与"8 次/s",互差 7%;1.07s 为规范值。)
- **候选峰列表** ≤16/通道 :{f_interp(Quinn), P_peak, 全带均值, 邻域均值(定义=C5), 上次配对 id}。
  - **提取口径写死(⑩,防 T_low 洞搬进供给层)**:候选提取 = **相对选择 + 频带门(det_hpf/主带范围),无任何绝对电平门**;唯一物理下限 = 谱域数值底噪(Q15 存储 + 27.1dB 处理增益 ≈ **−128 dBFS(峰值参考约定)** [L3/解析],系物理量非判据门)。绝对电平判定(T_low/T_low_gr/fb_thr/panic)**全部属接收方判据层**。
  - **⭐ 排序度量(v1.5 新增,回执 P1;D3/D4 实现派单的前置定案)**:候选表名额按**混合配额**分配——
    1. **PNPR 组**:`N_pnpr` 个名额,按 **PNPR 等价比值 `M[k] / 邻域均值(C5)` 降序**取(局部统计,不受带外能量抬高全带均值影响);
    2. **P_peak 组**:其余 `16 − N_pnpr` 个名额,按 `P_peak` 降序取;
    3. 两组**去重**(同一 bin 只占一个名额,去重后从对应组顺延补足);
    4. **确定性要求**:排序必须是**稳定全序**——比较值相等时按 bin 序号升序;禁止实现相关的不确定顺序(否则回归测试与 bit-exact 对账失效)。

### C6-② ⭐ 回收计时器的刷新条件(v1.8 四次增补;评审 C9,**独立缺陷,不只是弃权的副作用**)

**缺陷**:LIFT 的启动条件是 `t_wall − t_last_hit ≥ LIFT_AFTER`,而**复检到同频**这一事件**无条件刷新 `t_last_hit`** ⇒ **对内容反复出现的素材,陷波不是回收得慢,而是回收根本不启动**。实测:6 s 末挂陷 0.30 → 100 s 稳态 4.40(**gap 扩大 16 倍,不收敛**),8 槽中 4.4 个被长期占住。
> **⭐ 缺陷的形状:一个回收机制的启动条件,被「被回收对象持续出现」这件事一直复位。** 而在会议室里"同一说话人 / 同一段背景音乐 / 同一台空调持续出现"**几乎是常态**。**与 C11-① 的 `T_low_gr` 自熄灭同族:机制与其作用对象之间形成自指环。**

**⭐ 根因比"弃权刷新"更靠上,而且来自本合同自己的 tap 位裁定**:**tap 在陷波器组入口(C10),陷波在 tap 下游**。
| 情形 | tap 上还看得见该峰吗 | 复检 | 刷新是否正当 |
|---|---|---|---|
| 真啸叫 + 陷波已足够 | **看不见**(环路被打断) | 不复检 | — ⇒ LIFT 正常启动 ✓ |
| 真啸叫 + 陷波不足 | **看得见** | 复检 → **加深** | **正当**(在积极对抗) |
| **外部持续源** | **永远看得见**(陷波在 tap 下游,对它在 tap 上零衰减) | **永远复检** | **不正当 —— 复检不携带"陷波仍被需要"的信息** |
> **⇒ 「该峰仍被检出」不是「该陷波仍被需要」的证据。C8-② 的探针用的正是这条不对称性,而 `t_last_hit` 的刷新逻辑恰恰忽略了它。**

**⇒ 裁定(取代接收方提的特例版,规则更窄且更普适)**
```
t_last_hit 刷新  ⟺  本次复检【导致了加深动作】 ∧ 探针未判「外部」且未【弃权】
```
- **① 只在"导致加深"时刷新** —— 而加深受 `AFC.max_depth` 封顶 ⇒ **推迟量被加深步数上界钉死**:`init_depth −3 / depth_step 3 / max_depth −18` ⇒ **≤6 步** ⇒ **由"无限推迟"变为"有界推迟"**。这是本裁定最重要的性质。
- **② 弃权不刷新** —— **弃权不是"陷波仍被需要"的正向断言**(与 C8-④ 的"弃权不得登记保鲜期"同一原则)。
- **③ 判「外部」不刷新** —— 该分支本就要撤陷。
- **⚠ 对「复发→加深」的影响(必须写明)**:**加深路径不受损** —— 真啸叫在陷波不足时仍会复检、仍会加深、仍会刷新。**受影响的只有"复检但不加深"的情形**,而那恰恰是"陷波已到最大深度仍压不住"或"根本不是啸叫"两类;前者应当交 EXHAUSTED/宽带兜底而非无限占槽,后者应当被回收。
- **⚠ 残余**:真啸叫在**已达 `max_depth`** 后仍存在时,不再刷新 ⇒ LIFT 会去释放 ⇒ **啸叫短暂回来**。**这是已声明行为**:该情形本就应触发 EXHAUSTED 路径(C6/§4.4 宽带兜底),**不应靠"永久占槽"来掩盖**。
- **④ 回收优先序 ⇒ 升级为「可抢占」(v1.8 五次增补)**:槽位紧张时,**由弃权产生的占用不仅优先被回收,而且可被正向分类的真啸叫直接抢占**。
  **⭐ 为什么这比排序更重要**:"弃权占槽"这一害的度量 `W` 究竟取「HELD 口径」还是「到 FREE」,取决于**槽何时能重新给真啸叫用**;**做成可抢占后,对"真啸叫拿不到槽"这一害 `W_eff ≈ 0` ⇒ 该害直接消失**,只剩「多挂一个浅陷」的音质害。**⇒ 口径之争因此不必再打。**
- **⑤ 「加深是否发生」必须由状态判定,不由代码路径判定(v1.8 五次增补;接收方实现期发现)**:实现上**即使已达 `max_depth` 仍会进入 deepen 分支** ⇒ **若按"是否进入分支"判定,`t_last_hit` 照旧刷新,本裁定等于没做**。
  > **⇒ 条款判据固定为:`target` 深度**实际变小**才算"导致了加深"。**
  > **通则(与 D-J 互为镜像)**:**D-J 说"分支必须被触达";本条说"触达分支 ≠ 动作发生了"。凡以"动作是否发生"为条件的判据,一律由**状态变化**判定,不由代码路径判定。**
- **⑥ ⭐ 加深动作**本身**也须受同一合取门(v1.8 六次增补;我上一轮的漏洞)**:v1.8 四次增补只门控了 `t_last_hit` 的**刷新**,**没有门控加深动作本身** ⇒ 阶梯照旧被爬到底。
  ```
  加深  ⟺  复检到同频 ∧ 探针未判「外部」 ∧ 未【弃权】
  ```
  **⭐ 为什么必须门控加深**:**tap 在陷波上游** ⇒ **外部持续源的峰不因陷波加深而下降** ⇒ **"峰仍在"不携带"陷波还不够深"的信息** ⇒ 未门控时,**任何外部持续源都会把阶梯一路爬到 `max_depth`**。**这是同一条 tap 上游不对称性的第三次命中**(C8-② 用了它 / `t_last_hit` 漏了它 / 加深动作也漏了它)。
  **⇒ 在本门加上之前,`EXHAUSTED` 计数不构成对 `max_depth` 取值的任何证据** —— 它测的是"外部源爬满阶梯"的次数,不是"18 dB 不够"的次数。

**⭐ 强制证伪测试(D-F + D-J 触达断言)**:
- **构造**:内容反复出现的素材,试次长度 ≫ `LIFT_AFTER`;
- **判据**:①**窗末累积占用数不得随试次长度继续增长**(现状是 6 s→100 s 扩大 16 倍);②**触达断言**:须报告"因加深而刷新"与"因复检而未刷新"两类事件的**实际计数**,**任一为 0 则测试无效**;
- **反向对照**:关掉本裁定 ⇒ 窗末累积占用数**必须**回到增长态。**若不回到增长态,说明归因错。**
- **⭐ 判据必须比对瞬态解,不得比对稳态值(v1.8 五次增补)**:占用是一个 M/G/∞ 型排队,`L(t) = λW(1 − e^(−t/W))`。以实测 `λ ≈ 0.0425 /s` 代入:**`W=65 s` 时 `L_ss=2.76` 而 `L(100 s)=2.17`(仅达稳态 79%);`W=95 s` 时 `L_ss=4.04` 而 `L(100 s)=2.63`(65%)**。
  > **⇒ 100 s 试次本身也没到稳态(仅 1.1–1.5 个 `W`)。拿单点 `L(100)` 去比 `λW` 会系统性高估,从而把一个正确的修法误判为"仍有第二条占用来源"。**
  > **⇒ 判据形式固定为:取多个试次长度 `(t, L)`,拟合 `λ`、`W`,再与独立测得的 `λ`、`W` 比对。** 单点比对不构成对本款的验证。

- **⭐ 附带得到一条架构事实(值得单记)**:`λ = f(W)` 意味着**占用具有自限性** —— 驻留越长,新到达越少。**这既是好消息(占用不会随 `W` 线性发散),也是限制(占用实测值【不可迁移】到另一个 `λ` 区制,例如更换素材或更换会场)。**

**⇒ 取代方案(比 lead 提的更强,且不需要外推):`offered load` 在本系统里【是可直接观测的】。**

Erlang-B 是为「看不见被拒绝者」的世界发明的 —— 电话网里被阻塞的呼叫方挂机走了,你只能靠模型反推 offered load。**我们是软件,拒绝发生在我们自己的代码里(`if not free:` 那一支),被拒者是谁、几次、哪个频点,全部可以直接记。**

| 量 | 定义 | 观测点 |
|---|---|---|
| `n_carried` | 提名并**获得**槽位的次数 | `ENGAGE` 事件 |
| `n_blocked` | 提名但**因无槽未获得**槽位的次数(含抢占失败后) | `if not free` 分支 |
| **阻塞率 `B_obs`** | `n_blocked / (n_carried + n_blocked)` | **直接算,无需任何模型、无需平稳性假设** |

- **⚠ 按 D-K 定计数单位**:`n_blocked` **每候选每次提名计一次**,不是每帧计一次;并**另报去重后的不同频点数** `n_blocked_bins`。现实现的 `duck` 事件是**每候选每帧**发一条 ⇒ **口径必须先明确再取数,否则是 EXHAUSTED 放大 11× 的同型第二例。**
- **⇒ 外推需求消失**:8 槽下若不饱和,`n_blocked = 0`,结论直接是「够用」,本就不需要模型去证;若饱和,`B_obs` 直接测得。**两种情形都不需要 Erlang-B。**
- **低槽数实验的定位不变**(定性验证机制),**但其结论不得再经由任何模型折算回 8 槽**;`c=2/3` 仍须写进工作点向量。

### C6-③ ⭐ 占用度量的模型口径:**这是有限槽损失系统,不是无限服务台**(v1.8 六次增补)

**缺陷(我 v0.26 写的模型形式错)**:我给的判据形式 `L(t) = λW(1 − e^(−t/W))` 是 **M/G/∞(无限服务台)**。**本系统只有 8 个陷波槽且无排队 ⇒ 是 M/G/c/c 损失系统(Erlang-B)**,且 v0.26 起**还带抢占**。
- **后果**:**观测到的"到达率"不是需求率,是被占用状态节流后的接受率** ⇒ **槽越满,测到的 λ 越小** ⇒ **λ 必然随窗长变化,而这不是"λ 不平稳",是模型选错了**。
- **实测形态**:25 s 窗 λ=0.0950/s vs 100 s 窗 λ=0.0425/s(2.2×)。**Erlang-B 代入**(c=8):λ_off=0.095、W=65 s ⇒ `a=6.17 erlang, B=0.132`;W=95 s ⇒ `a=9.03, B=0.290` ⇒ **阻塞确实随占用升高而显著**。
- **⚠ 而且这两个 λ 本来就不可比**:`0.0425` 取自**修法前**(占用永不回收 ⇒ 槽长期满 ⇒ 重度节流),`0.0950` 取自**修法后 + 短窗**(槽初始全空 ⇒ 接近未阻塞)。**它们来自两个不同的系统。**

**⚠⚠ v1.8 七次增补:我上面这段 Erlang-B 归因被同一批数据否掉了。**
实测占用 **2.6–4.6 / 8 槽 ⇒ 始终有空槽 ⇒ `B ≈ 0`** ⇒ **阻塞不可能是 `λ` 下降的机制**;**抢占实际发生 = 0/0/0 是同一事实的另一面**。⇒ **上文的 Erlang-B 诊断作废(保留为过程证据)。真实机制 = 保鲜期(`ext_ttl_s`)登记累积 ⇒ 可产生弃权的频点被暂时移出池子。**

**⚠⚠ v1.8 八次增补:以下「走平」判断已被 200 s 点证伪(瞬时 λ 续降至 0.0050 /s,再降 5.4×)。保留为过程证据,不得引用。**

**⭐ 但「λW 不适用」这个结论也走得太远了 —— 报出的 `λ` 是【累积平均】,差分它就得到瞬时率:**

|---|---|---|---|
| [0, 25] s | 2.375 | 25 | **0.0950 /s** |

> **⇒ 我的框架没有死,是被套在了错的 `λ` 上(累积平均 vs 渐近瞬时)。** [L3/由已有三点差分,弱证据:后两段仅差 10%,须更多点确认]

**⇒ 裁定(四条)**
0. **⭐ 直接测占用时长分布 = 正确方向,确认,且算法侧不等我裁是对的** —— 它严格比模型反推更直接,**不存在"裁下来会推翻它"的可能**;排队模型本就是"没法直接测 `W`"时的替代品。**更强的形式 = 在此之上再加一条:`λ` 也直接测,且报【瞬时(差分)】而非【累积平均】。两者都直接测,就不再需要任何排队模型。**
1. **`λ` 的独立测量 = 「弃权判决次数」,不是「弃权占用创建次数」。** 前者是**内容的属性**(offered rate),与槽位状态无关;后者是**系统状态的函数**(accepted rate)。**成本为零:在弃权判决处计数即可。**
2. **模型形式改 Erlang-B / 抢占型损失系统**;`W` 由生存数据拟合,`λ_off` 由 (1) 独立测得,**二者不得互相反推**。
3. **⚠ 右删失必须处理**:试次 25–200 s 而 `W ≈ 65–95 s` ⇒ **大比例占用在试次结束时仍未释放**(粗估 100 s 试次下 ≳58%)。**⇒ 占用时长与释放路径的统计一律用生存分析(Kaplan–Meier),并报删失率;直接除法得到的"回收比例"无效。**

**⚠ v1.8 八次增补(直接测量首批数据到手,口径规则)**:实测驻留 **50 s 截尾 24/24 = 100%、100 s 35/35 = 100%、200 s 34/39 = 87%**;200 s 窗内仅 5 段真正释放,`p50 = 120.1 s`、`max = 136.9 s`。

> **⇒ 「实测比理论长 1.26×」是【比值的下界】,不是比值。真值 ≥ 120.1 s,上界未知。**
> **⇒ 定为口径规则:事件率 < 50% 时【不得报中位数】。须报 KM `S(t)` 在固定 `t` 的值 + 该 `t` 的在险数(at-risk),或明确标为下界。**

**⇒ 连带撤回(我的):`λW` 拟合出的 `W_fit = 30 s` 比真值小 ≥ 4.0×,而【偏小方向 = `a` 偏小 = 余量偏大 = 朝"8 槽够用"】** —— 我的第一号失效模式第四次命中。**据 `W_fit` 做的「8 槽尚有 3.25 槽余量、加槽不是瓶颈」折算,重算方向确定是【余量更少】** ⇒ **撤回期间不得沿用其乐观方向作为任何决定的依据**(「待重算」不等于可以中性挂着)。

### C6-④ ⭐「回收比例」的口径:抢占是**第二条释放路径**(v1.8 六次增补)
v1.8 五次增补引入的**可抢占**,本身就是一条**独立于 LIFT 的释放路径**。而「回收比例 = 经 LIFT / 总占用」**只数了 LIFT 一条** ⇒ **该指标在抢占实现后已不再等于"占用是否被释放"**。
> **⇒ 指标改为「占用是否被释放(任意路径)」,并按路径分解:LIFT / 抢占 / 改派 / 试次截断(删失)。**
**⭐ v1.8 七次增补:删失是首要嫌疑,且可直接算出来。** `LIFT_AFTER = 60 s`,而占用须**连续 60 s 无复检**才达 LIFT ⇒

| 试次 | 可达 LIFT 的建立窗 | 占试次比例 |
|---|---|---|
| **25 s** | **无** | **0%(结构上不可能)** |
| **50 s** | **无** | **0%(结构上不可能)** |
| 100 s | t < 40 s | 40% |
| 400 s | t < 340 s | 85% |

> **⇒ 25 s 与 50 s 试次里,没有任何一次占用可能达到 LIFT。「43.5% 等不到 LIFT」几乎必然是右删失,不是第二条阻断路径。**

### C6-⑥ ⭐⭐ 素材频点预算:`λ` 衰减是系统的性质还是素材的性质(v1.8 八次增补;lead 判为最重一条)

**问题**:`λ` 从 25 s 到 200 s 降 3.9×,机制是「保鲜期 20 s 累积 ⇒ 越来越多频点被登记 ⇒ 新挂陷减少」。**但保鲜期在一个【频点集】上累积,而钢琴的频点集是有限的(离散音高 + 谐波)。** ⇒ 衰减可能是**素材把频点用光了**,不是**系统会自然趋于安静**。

**⇒ 判据形式裁定:不比较跨素材的 `λ` 衰减曲线,改测【比值】。** 理由:跨素材比速率会把「素材频点集大小」「素材触发检测的强度」「素材是否根本不触发」三件事混在一起;**而且它只能给出排序预测(钢琴应最快),排序预测是弱预测。**

| 量 | 定义 | 取法 |
|---|---|---|
| `U(t)` | 累计**登记过**的**不同**频点数 | 注册表,累计去重 |
| `N_mat(t)` | 同一次运行内**被提名过**的**不同**频点数,**含因「已登记」而被拒的提名** | 检测前端,**在注册表查表之前**打点 |
| **判别量** | `R = U(T) / N_mat(T)` | 单次运行内即可得,**不需消融、不需跨素材、无轨迹发散** |

| 结论 | 条件 | 备注 |
|---|---|---|
| **素材主导** | `R ≥ 0.8` **且** U 已平台(末 25% 窗增量 ≤ 5%·U(T)) | 登记追平了素材能提供的全部频点 ⇒ 是素材没料了 |
| **系统主导** | `R ≤ 0.5` **且** U 已平台 | 素材还有料而登记停了 ⇒ 是系统的登记逻辑在限流 |
| **未判定** | 0.5 < R < 0.8,**或 U 未平台** | **⚠ D-J 陷阱:U 仍在爬时 `R` 天然偏小,看起来像「系统主导」,实为【未触达】。必须先断言平台,再读 `R`。** |

- **⛔⛔ 前置门(由算法侧 r19 分箱 bug 触发,我判为【本判据的结构性弱点】,必须在取任何 `R` 之前封住)**:
  - **事实**:算法侧写 `round(f / max(f*0.2, 15.0))`,`f > 75 Hz` 时 `f/(f*0.2) ≡ 5` ⇒ **所有频点落进同一箱**,输出"不同频点数 = 1.0"。**一个看起来是"自适应带宽"的表达式,化简后是常数。**
  - **⭐ 而这个 bug 对我的 `R = U/N_mat` 判据是【致命且隐形】的:分子分母共用同一个分箱函数 ⇒ 分箱塌缩时 `U = N_mat = 1` ⇒ `R ≡ 1` ⇒ 判据会【干净地输出"素材主导"】,不报任何异常。** 我设计比值判据本是为了消掉共模误差,**结果连"仪表坏了"这个共模也一起消掉了。**
  - **⇒ 通则(我的,补在 lead 给的通则之后):【凡分子与分母共用同一个可疑函数的比值判据,对该函数的错误免疫,免疫方向通常是 `R → 1`】⇒ 比值判据必须配一个【绝对量前置门】,否则它无法自证仪表是好的。**
  - **⇒ 前置门三条(全部通过才允许读 `R`)**:①**分箱函数取值范围检验** —— 对 `f ∈ [100, 8000] Hz` 扫描,箱号必须**严格随 `f` 不减且总箱数 > 1**;②**已知输入检验** —— 合成 `N` 个已知间隔正弦,箱数须 `= N`(可失败,D-F);③**绝对量下限** —— **`N_mat(T) ≤ 2` 一律判为【仪表故障】,不得读作"素材枯竭"**。
  - **⇒ r19 首批作废、改对数分箱重跑,判断正确;`N_mat ≥ 3 × 槽数 = 24` 的准入门须在【前置门通过之后】才生效。**
- **⚠ 门限 0.8 / 0.5 为 [L4/工程取值]。按 lead 本轮立的「弱证据配套」自问:若这两个数是错的,本裁定改不改?** ——**判别式的结构(测比值、要平台、留未判定带)不改;只有落入中间带的样本归属会变。** ⇒ **可进裁定段,但门限须随首批数据复核。**
- **预注册(D-I,在发起测量之前):若素材主导成立,则 `R ≈ 1` 【跨素材不变】—— 不变量是比值,不是速率。** 这是强预测:三类素材(钢琴 = 离散音高、多人交谈 = 宽带持续更新、空调 = 稳态窄带)的 `λ` 曲线差异可以很大,但 `R` 都应趋近 1。**任一素材出现 `R ≤ 0.5` 且已平台,即证伪「素材主导」。**
- **若改用消融法(关注册表测 `N_mat`)作后备:关表后增益持续上升 ⇒ 提名更多 ⇒ `N_mat` 高估 ⇒ `R` 偏小 ⇒ 偏向「系统主导」。⇒ 若消融法仍得出「素材主导」,结论更硬;若得出「系统主导」,不得据此定论。** 首选仍是单跑打点法。

**(2) `ext_ttl_s = 20 s` 是否需重新论证 —— 是,但不是「重新标定」,是【拆分】。**

它现在同时承担 **(a) 抑制重复误判** 与 **(b) 事实上限制占用增长**,而 (b) **从未被设计为它的职责**。两职责的最优值由**不同物理量**驱动:(a) 由误判的时间相关性定,倾向短;(b) 由占用预算定,倾向长。⇒ **一个旋钮两个职责 ⇒ 调其一必然静默地动另一个,且当前仪表看不见 (b)。**
> **⇒ 立即动作(不等 (1) 的结论):把职责 (b) 显式化并单独观测 —— 报 `U(t)`,并报「因【已登记】而被抑制的提名数」。参数拆分待 (1) 结论。**
> **⇒ 这是「同族二义」在参数层的实例:以前的例子是一个名字两个语义,这次是一个数值两个职责。**

**(3)「8 槽够不够」的最终判据基于哪类素材 —— 不基于任何单一素材,且【不是随手取最坏素材】。**

- **约束工况 = 频点不枯竭的素材**(多人交谈、变化的音乐);钢琴/空调只用于验证机制,**不得用于容量判定**。
- **⚠ 但若 (1) 判为「素材主导」,则「8 槽够不够」在【任何有限素材】上都不可判** —— 因为占用峰值 = `min(素材频点预算, 槽数)`,测出来的永远是前者。
- **⇒ 那时唯一合法的容量判据 = 构造一个 `N_mat ≫ 8` 且【新频点到达率恒定】的素材。** ⇒ **「甲(加密素材)」的规格由此改写:目标不是「更密」,是「`N_mat` 可控且远大于槽数、且新频点到达率不随时间衰减」**(可合成:宽带成分 + 缓慢扫频/随机跳频)。
- **⇒ 容量结论的准入门(挂在 ④ 抢占的 8 槽长窗上)**:该运行**必须同时报 `U(T)` 与 `N_mat(T)`,且 `N_mat(T) ≥ 3 × 槽数 = 24`,才允许把「未触达饱和」读作「够用」。** 否则「没撞满」只说明素材没料。
  - **`3×` 为 [L4/工程留量]。两端论证(D-H)**:**下端** —— `N_mat` 只略大于槽数时占用被素材钳住,「未撞满」不携带信息,**≥2× 是信息存在的最低要求**;**上端** —— 取得过大则素材偏离真实会场,结论偏保守且可能根本达不到。**取 3× = 2× 的信息底线加一档留量。若该数为假,本裁定改不改?——「必须给出 `N_mat` 且必须 > 槽数」不改,只有具体倍数改。**

### C6-⑦ ⭐⭐ 两个不同的「耗尽」共用了一个名字,而兜底只挂在其中一个上(v1.8 八次增补;`max_depth` 立项裁定)

> **⇒ 深度撞顶时槽还占着、`free` 不空(实测尚余约 3.4 槽)⇒ `g_duck` 【不会被触发】。**
> **⇒ 「撞顶后的宽带兜底路径」的答案是:【未定义】。更准确地说 —— 存在一个叫「兜底」的机制,但它挂在另一个触发条件上;撞顶只发事件、不改行为。**
> **⇒ 那 1.1 次/试次的 EXHAUSTED,全部是【报了警但不作为】的静默失效** —— 违反 DEC-0017「告警不静默劣化」的精神(此处是「告警而不劣化也不处置」,更坏:上位机以为兜底在动)。

**⚠ 而且这条缺陷有我的一份**:我的参数字典把 `AFC.exh_gain / exh_attack / exh_hold / exh_rate` 四个参数和 `AFC.status` 的 `FILTERS_EXHAUSTED` 位都写成「兜底」族,**而 `EXHAUSTED` 事件由深度撞顶发出、兜底由槽位耗尽驱动 ⇒ 事件与参数不同源。** 上位机按字典理解「收到 EXHAUSTED ⇒ 兜底已介入」,**是错的**。⇒ **字典侧本轮起区分 `SLOTS_EXHAUSTED`(驱动 duck)与 `DEPTH_EXHAUSTED`(不驱动 duck)两个位,事件同步改名。**

**⇒ `max_depth` 阶梯裁定(lead ①):【不动阶梯】,补触发条件。**

| 选项 | 判 | 理由 |
|---|---|---|
| **加步**(更多级到更深总量) | **否决** | **主理由(不受下述修正影响)**:啸叫增长是指数的,**阶梯太慢本就控不住** —— 这是反应速度问题,与占用无关。**次理由**:`W` 中位不可估 ⇒ 在未知量上加载 |
| **加深每步**(每步 > 3 dB) | **不首选** | 量化更粗 ⇒ 单次误判挖掉更多好声音,且易过冲/振荡;`1.1 次/试次` 不足以支撑这个代价 |
| **补兜底触发** | **✓ 采纳** | 真正的缺口不是「压不够深」,是「压不下去之后没有行为」 |

**⇒ 但改阶梯之前必须先做一步判别(复用已有器械,不新增)**:**撞顶后残余 PNPR/PHPR 是否随最后几个加深步单调下降?**
- **单调下降但未过门 ⇒ (a) 深度确实不够** ⇒ 那时才谈加深/加步(且须先有 `W`)。
- **最后几步残余不再下降 ⇒ (b) 陷波没对准**(频率估计误差 / Q 太窄 / 频率在漂)⇒ **加多少深度都无效,兜底是唯一正解,改阶梯是错的解。**

  > **⚠⚠ v0.33 证伪注(原文保留不改,按 D-N)**:上面这一支的【分支结构成立,但我挂在它上面的【因果假设】被证伪】。实测:残余确实不再下降(+0.9/+1.5/+1.6 dB)⇒ 分支判对;**但陷波【对得很准】** —— 对准 vs 偏移一个带宽差 **7.1–14.5 dB** ⇒ **「陷波没对准 / 频估误差 / Q 太窄 / 频率在漂」全部不成立**。真实机制是**邻近成分的谱泄漏地板**:on-bin 分量拿掉后即触底。
  > **⇒ 结论(兜底是正解)存活,但理由是另一个 —— 而理由才是可复用的部分。** 按 D-F/D-I,被证伪的预注册假设**记为证伪,不得静默替换**。
  > **⇒ 且「无效」按 v0.33 措辞规范改读为【约 10:1 收益递减】(15 dB 买约 1 dB,效率 6–11%)。**
- **这条判别可失败(D-F)**:若残余序列既非单调下降也非平台(震荡),则两假设都不成立,须另立。**这与 C8-② 的「挂陷后残余」是同一器械,不新增仪表。**

**⚠ v1.8 八次增补 · 自我修正**:我上表原写「加步 = 直接加长 `W` ⇒ 占用线性增长」,并据此把加步判为**硬否决**。**`λ = f(W)` 这条新事实使该论证不成立** —— 负反馈下占用随 `W` **次线性**增长(有限源结构,被频点总数封顶),不会线性发散。**⇒ 该条论证撤回,否决降为普通否决,理由改挂"反应速度"。** 结论不变,但**理由变了,而理由才是可复用的部分**。

**⇒ 优先级:按 lead 的 `1.1 次/试次` ⇒ 「要处理」不是「要紧急处理」。但【兜底未定义】这一条与发生率无关 —— 哪怕 0.1 次/试次,静默失效路径也必须封。**

### C6-⑨ ⭐⭐ 兜底触发须先过泄漏判别 + 弃权驻留按来源分档(v1.8 十次增补;取代 C6-⑦ 的"直接接 duck")

### C6-⑩ ⭐⭐ C7 的约束点在低频端(v1.8 十一次增补;由"对照量随频率塌缩"反查得到)

`bw_oct = 1/5` 倍频程 = **常 Q** ⇒ `BW = 0.13874·f`;检测 `NFFT = 1024 @ 48 k` ⇒ **bin 宽恒 = 46.875 Hz**:

| f0 | 陷波 BW | = 几个 bin | 实测对照量(偏移−对准) |
|---|---|---|---|
| 1047 Hz | 145.3 Hz | 3.10 | 14.5 dB |
| 520 Hz | 72.1 Hz | 1.54 | 14.4 dB |
| 329 Hz | 45.6 Hz | 0.97 | **8.7 dB** |
| 263 Hz | 36.5 Hz | 0.78 | **7.1 dB** |

> **⇒ 塌缩点正好在「BW ≈ 1.5 bin」。「偏移一个带宽」在低频 < 1 bin ⇒ 与「对准」落进同一分析 bin,差别被平均掉。⇒ 这是【测量分辨力伪影】,不是低频陷波变弱 ⇒ 该趋势不得用来改低频带宽或判据设定。**

**⇒ 但它暴露了 C7 的一个结构性成立域边界:**
- `BW/4 = 1 bin` ⇒ **f = 1351 Hz**。**f < 1351 Hz 全段,C7 的 `p95 ≤ BW/4` 要求【优于一个分析 bin】的精度;f = 263 Hz 处要求 ≤ 9.1 Hz = 0.19 bin。**
- **⇒ 裸 bin 峰值在整个低频段【结构上不可能满足 C7】** —— 必须靠 Quinn 子 bin 插值。**这条现在有了定量边界,不再是一句"用 Quinn"。**
- **⇒ V-35(新)**:**Quinn 的 `p95|Δf|` 必须在【≤500 Hz】实测。只验中高频等于没验 —— C7 的约束点在低频端。**
- **⇒ `bw_floor = 15 Hz` 复核**:`f < 108 Hz` 时陷波由常 Q 转为**常 Hz** ⇒ 该段 `BW/4 = 3.75 Hz = 0.08 bin`,**精度要求再紧 4 倍且不再随 f 放松** ⇒ `CFG_WARN_PRECISION` 的成立域须按此重述。

### C6-⑰ ⭐⭐⭐ 极值侧检验(`F(z)` 真实性第 6 条)+ KS 超门的处置(v1.8 十七次增补)

**(1) ⭐ 顶部间距分布【完全不依赖 `N`】** —— Rényi:`n` 个 iid Exp(1) 的降序序统计量,间距 `D_i = X(i)−X(i+1)` 相互独立且 `i·D_i ~ Exp(1)`,**与 `n` 无关**(80k MC:`N=100/455/988/5000` 全落 0.994–1.008)。

> **⇒ `N_crit` 只通过 `X(1) ≈ ln N` 进入 `ΔMSG` ⇒ 对 `N` 的敏感性是【对数】的(故 988→455 只差 0.29 dB);且【极值侧检验对 `N_crit` 的定义之争完全免疫】⇒ 可在定义之争未决时先做。**

**(2) ⭐⭐ 已有四条检验(σ_dB / 偏度 / 峰度 / KS)全是【体分布】性质,而 `ΔMSG` 只吃【顶部序统计量】**
> **⇒ 体分布全对不保证极值侧对。⇒ 四条降为【必要条件 / 背景检查】,第 6 条为把关项。**
> **⇒ 这是「所选观测量下不含区分信息」一族在【正确性检验侧】的第一例**(此前实例全在判据侧:C14-② 同频 / C8-② 持续纯音 / 56.5% 指标)。**⇒ 检查项:每写一条检验,问一句「被检验的那个结论,数学上依赖这个量吗?」**

**(2) ⭐ 但配对预测确有一处【结构】假设(非分布),须消掉**
> 推导默认:挂 `k` 个陷波后**临界点集不变**。而**陷波器自身有相位** ⇒ `∠(F·N₁···N_k) ≠ ∠F` ⇒ **临界点会移动、也可能新增。**
> **⇒ 改【迭代式预测】**:挂第 1 个 → **重算 `F·N₁` 的临界点集** → 取新最大 → 挂第 2 个 → …… 共 `k` 次。**`k=8` 仅 8 次重算 ⇒ 代价可忽略,而消掉全部不变性假设。**
> **⇒ 一次式与迭代式之差 = 陷波相位扰动的量度,两式都出、差值入报告;差 <0.1 dB 则以后只用一次式。**

**(4) ⛔ 群延迟机制的检验统计量:两方提的都会给【假阴性】**
> 该机制说的是**两端(峰与谷)都被过采样**。而线性相关系数是**单调/位置**统计量 ⇒ **两端对称过采样给出 `corr ≈ 0`** ⇒ **机制成立却报"被否"。**
> **⇒ `corr(\|F\|², τ_g)`(我提)与 `corr(τ_g, \|log\|F\|\|)`(lead 提)同病,均作废。**
> **⇒ 正解:按 `τ_g` 分位分档(低/中/高),报各档内 `log\|F\|²` 的【均值】与【方差】。预测:高档【方差更大 ∧ 均值更低】。高档方差不大于低档 ⇒ 机制被否。** 这才是能失败的对照。

- **⇒ 相位条件是【实质约束】⇒ 解析式不可简化,`max\|F\|` 不得代替临界点上的最大值(系统性低估 MSG ≈1.4 dB)。**

- **⭐ `Δ` 离散度 0.09–3.31 dB ⇒ 单条上"临界点抓没抓到全局峰"基本是运气 ⇒ 【这是配对对照的首要理由:有效性,而非效率】。** 与 `k=1` 最吵同形 —— **顶端量由变异系数=1 的间隙决定 ⇒ 顶端量一律不得用单条实现解读。**

> **⇒ 与 DEC-0007 不冲突** —— 8 点是**个数**约束,总带宽是**频谱面积**约束;**二者联合钉死 `bw_oct ≤ 1/8` ⇒ 现值 1/5 须改。**
> **⇒ 「8 槽从来不是约束」这条结论【存活,理由更换】**:误报侧 `B_obs=0`/加槽零增益仍成立,**但真正的产品约束是【频谱面积】不是槽数** ⇒ **加槽更没意义(加到 12/16 只会让 `Σ` 更超,除非同步收窄 `bw`)。**
- **⇒ 补全 C6-⑳(2b)**:「带宽对 MSG 是纯收益」仍对,**但此前未给上界** —— 上界即本条。**C6-⑳ 预注册的「`BW` 减半扫描」目标值现已确定:`1/5 → 1/8`。**

**(6) 陷波器级联:维持 RBJ,不换**
实测 8 级串联:零极点配置法 **DC −37.2 dB / Nyquist +4.40 dB**;RBJ **0.000 / 0.000**。

> **⇒ 记档备选:Orfanidis 1997 prescribed-gain。**
> **⇒ 通则:【单级设计正确 ≠ 级联正确】。凡"要串 N 级"的滤波器,必须给出 N 级串联后的 DC/Nyquist 增益,而不是只给单级响应。**

## C7 陷波中心频精度语义(v1.5:增成立域声明)
- Quinn 内插后 **p95 |Δf| ≤ BW/4**(恒带宽下限 15Hz → 3.75Hz)。
- 推导锚:初咬须在真啸叫频点交付 ≥2dB(Rane 2-3dB 下缘)→ BW/4 偏移交付 −2.40dB 达标、BW/2 偏移 −1.52dB 不达 [L3/双轨]。
- **⭐ 成立域(v1.5 新增,提供方参数量程自查发现)**:本款的 3.75 Hz 由 **`AFC.bw_floor = 15 Hz`** 导出。字典量程允许 `bw_floor` 低至 5 Hz,此时 BW/4 = **1.25 Hz**,而 Quinn 内插实证 p95 = 2.8 Hz@SNR10-30dB [L2/接收方 selfcheck,待其过门] ⇒ **精度契约在量程下端不成立**。
  ⇒ **本款承诺的成立域 = `AFC.bw_floor ≥ 15 Hz`**;设为更小值时 host 须出配置告警(事件 `CFG_WARN_PRECISION`,与 C12 软校验告警同族),且该配置下 C7 降级为"尽力而为,不构成契约"。**不因量程存在而默认承诺。**

## C8 判据语义约束(沿承 v1.4,逐字无变更)
- IMSD 阈值以 dB/s 定义(运行点无关);IPMP 类频率稳定性不得做唯一主判据(R-AFC-1 FTO 前)。

### C8-② ⭐ 「持续纯音 vs 啸叫」原理性盲区,与其**事后**甄别机制(v1.8-④)

**事实**:PERSIST 侧的误报**不是 PHPR 失职** —— 纯正弦注入、长笛(高次比基频低数十 dB)、空调单叶片线谱,**本来就没有谐波族可查**。
⇒ **在「单帧谱 + 谐波族」这一观测集下,「持续纯音」与「啸叫」不可分,是原理层面的**(与 **C14-②** 同族:**同一观测量下不含区分信息**)。

**⭐ 裁定:不新增频率稳定性类判据,改用「对干预的响应」做事后甄别。**

**⚠ 观测点勘正(v1.8 增补;评审 C9-②,我写错了)**:本表初稿写外部音 `ΔL ≈ d`,那是**观测点在陷波之后**的假设。**但 NHS tap 在陷波器组入口(C10),陷波在 tap 下游、不影响 tap 读数** ⇒ **外部音在 tap 处的预期是 `ΔL ≈ 0`**;而**啸叫在 tap 处仍会掉**,因为陷波在环路内、打断环路会降低麦克风处的循环能量(**这正是 C-3 选入口 tap 的原始理由**)。
> **⇒ 按初稿字面取门(`d + X`)会把门抬高约一个 `d`,代价落在漏检一侧。已改。** **成因:我在同一版里既定了 tap 位、又写了这张表,却没有把两处放在一起核** —— 与 D-G 同形,只是对象从「豁免 vs 入选」换成了「观测点 vs 判据」。

| | 啸叫 | 外部持续音 |
|---|---|---|
| **tap 处**(= 陷波**上游**)挂陷 `d` dB 后该 bin 的能量下降 `ΔL_f` | **大** —— 环路被打断,稳态振幅从临界跌回本底 | **≈ 0** —— 陷波在 tap 下游,**tap 读数不受其影响,源仍在** |

- **判据(v1.8 勘正)**:`ΔL_f > X` ⇒ 啸叫(保留);`ΔL_f ≈ 0` ⇒ 外部持续音 ⇒ 撤陷 + 登记该频点、带保鲜期抑制再次挂陷。**`X` [L4/待标定,建议 6 dB 起];门中不含 `d`。**

### C8-③ ⭐ 探针必须带共模对照 —— 否则它自己就没有区分信息(v1.8 增补;评审 C9-①)

**缺陷**:`ΔL_f` 大有**两个**原因:①**陷波打断了环路** ②**外部源自己停了**。**探针只测 `ΔL_f`,不含区分这两者的信息。**
实测坐实:开环钢琴素材(**根本没有环路**)出现判「啸叫」31/200,其 `ΔL` 中位 25.21 dB、max **506.39 dB** —— **506 dB 是该 bin 掉到数值底,即被跟踪的音符在窗内整个结束**(钢琴音符自身 256 ms 内自然衰减仅数 dB)。**调 `probe_thr_db` 动不了 —— 源停了给数百 dB,任何门都拦不住。**
> **⚠ 这与 C8-② 本要治的病同型,只是换了一层。** 记为**同族第三例**(C14-② / C8-② / 本条),见 §同族登记。

**⇒ 裁定:共模参照取 C5 邻域 ⇒ 判据量塌缩为 `ΔPNPR`(v1.8 二次增补,取代初稿的宽带差分)。**
```
判据 = ΔPNPR(f) = PNPR_挂陷前(f) − PNPR_挂陷后(f)   >  X   ⇒ 啸叫(保留)
                                                  ≈ 0   ⇒ 外部/源停(撤陷 + 登记 + 保鲜期)
```
- **⭐ 为什么是 PNPR 而不是新造一个差分量**:`PNPR = 峰 − C5 邻域均值` —— **它本身就是共模抵消后的量**。⇒ **不需要新数据、新字段、新定义:C4 已随候选峰交付邻域均值,C5 已定义邻域。** **这是"把已有的量用对",不是"加一个机制"。**
- **逐场景代入(判据的可分性,`X = 6 dB`)**:

| 场景 | `ΔL_f` | `ΔL_邻域` | **`ΔPNPR`** | 判定 |
|---|---|---|---|---|
| 环路被打断(真啸叫) | 大 | **≈0**(邻域=房间噪声,不随陷波变) | **大** | **啸叫 ✓** |
| 源自己停:钢琴音符结束 | 大 | **同步大**(同源其余成分一起消失) | **≈0** | **外部 ✓** |
| 源自己停:单人说话停顿 | 大 | **同步大**(该说话人宽带一起塌) | **≈0** | **外部 ✓** |
| 源自己停:**多人交谈,他人仍在说** | 大 | **仅部分塌**(邻域含他人能量) | **中等** | **⚠ 残余,可能仍判啸叫** |

- **⚠ 初稿的宽带形式为何被取代**:`ΔL_rest` 取**全带**时,**多人交谈中一人停顿而他人继续 ⇒ 宽带几乎不变 ⇒ 共模抵不掉** —— 而多人交谈恰是实测最差的一类。**C5 邻域是频谱局部的,对"同一声源的其余成分"敏感、对"另一个声源"不敏感,正是这里需要的选择性。**
- **门 `X` 的两端论证(按 D-H)**:**下界** —— 须高于 PNPR 估计噪声(弱峰/噪声邻域下估计方差大);**上界** —— 须显著低于真啸叫的 `ΔPNPR`(环路打断后峰落至本底,`ΔPNPR` 与原 PNPR 同量级,数十 dB)。⇒ **`X` [L4/待 ROC 标定],建议 6 dB 起**;**两端机制不同,标定须分别取证。**
- **物理**:陷波只改变 **f 处**的环路增益 ⇒ **环路被打断时 `ΔL_rest ≈ 0`**;**源停了时该源的其余成分同步消失 ⇒ `ΔL_rest` 同步大** ⇒ **共模被抵掉**。
- **成本零**:所需数据(主谱)已有;**不动陷波 ⇒ 零音质代价**。
### C8-④ ⭐ 判据的**定义域**与三态输出(v1.8 三次增补;评审机制 B)

**缺陷**:`10·log10(e + ε)` 在**近静音 bin** 上给出 ≈ **−300 dB**(ε=1e-30)⇒ `ΔL` 出现数百 dB。**这不是物理量,判据在该区域无定义。**
- **物理可达上限的独立核算**:Q15 谱域有效底噪 ≈ **−128 dBFS**(C4 数值底噪同源)⇒ 峰即便自 0 dBFS 掉到本底,`ΔL` 也**只有约 128 dB**。⇒ **500–570 dB 物理不可达,只能来自 log 的 ε 地板。**
- **⚠ 定点移植下形态由「趋 −300 dB」变为「饱和」,同样无定义** ⇒ **这不是浮点实现瑕疵,是判据缺一个定义域。**

**⇒ 裁定:判据改三态,并立有效性前提。**
```
有效性前提: L0 > 底噪 + M  ∧  L1 > 底噪 + M        (M [L4/待标定])
不满足     ⇒ 探针【弃权】:不产出判决
```
- **⭐ 弃权 ≠ 判啸叫,也 ≠ 判外部** —— 三态,不是二态。**弃权时的处置 = 保留陷波**(按 C8-③ 的偏置原则:判「外部」须正向干净证据),**但不得登记入保鲜期**(登记是对「这是外部源」的正向断言,弃权没有作出该断言)。
- **⭐ 报数义务**:**弃权率必须与判决率一起报**。**一个高弃权率的探针,其判决准确率再高也不构成覆盖证明** —— 否则"少判少错"会被读成"判得准"。
- **`M` 按 D-H 两端论证**:**下界** = 高于本底估计的不确定度;**上界** = 不得高到把真啸叫的低电平早期段排除在定义域外(那会造成漏检)。**两端机制不同,须分别取证。**

- **⚠ 它修不掉什么(必须写明,两类)**:①**裸纯音停掉**(无其他频谱成分)⇒ 邻域不塌 ⇒ 仍判啸叫;②**多人交谈中一人停顿而他人继续** ⇒ 邻域仅部分塌 ⇒ 可能仍判啸叫。**共模抵消的是「同一声源的其余成分同步消失」那一类,不是全部。**
### C8-⑤ ⭐ 共模对照必须**单边钳位**(v1.8 三次增补;评审机制 A)

**缺陷**:共模参考与被测量**共享同一批时变源**,不满足对照的独立性前提。若 `rest` **上升**(新音符/新说话人进入 ⇒ `ΔL_rest < 0`),则 `|diff| > |ΔL_f|` ⇒ **比单量判据更容易判啸叫**。实测:`|diff|>|ΔL_f|` 在多人交谈 4/4、钢琴 3/6、长笛 1/1;**长笛由 0 → 3 的全部来源**即"单量本不会判啸叫、被对照推过门"。

**⇒ 裁定:对照量单边钳位。**
```
diff = ΔL_f − max(ΔL_rest, 0)          (ΔPNPR 形式下同理:参照项只许减、不许加)
```
- **物理理由**:`rest` **上升**这件事,**不携带任何关于「环路是否被打断」的信息** ⇒ **不得允许它增加"判啸叫"的证据**。`rest` **下降**才携带信息(同源其余成分同步消失)。
- **⭐ 结构性后果**:钳位后 **C8-③ 在该维度上单调不劣于 C8-②** —— 参照项**只能移除**假啸叫证据,**永不增加**。`rest` 上升时自动退化为单量判据。
- **⭐ 同型第二次**:与 **C14-①「显著度可比」改单边** 是同一个失效模式 —— **一个双边修正项,其中只有一侧携带信息**。⇒ **立通用检查:凡引入修正/对照项,须逐侧问「这一侧的变化携带我要的信息吗?」;不携带的一侧必须钳掉。**
- **⭐ 预注册预测(按 D-I,写在钳位版实测之前)**:钳位后 **长笛回归(0→3)应完全消失**;钢琴与多人交谈**应 ≥ C8-② 水平**(不劣化),其中 `rest` 下降的用例保留共模收益。**证伪条件**:①长笛仍有回归 ⇒ 归因错;②钢琴/多人交谈仍劣于 C8-② ⇒ 尚有第三条机制未识别。

- **⭐ 预注册预测(按 D-I,写在 `ΔPNPR` 版实测之前)**:改用 `ΔPNPR` 后,**钢琴与单人停顿类应显著归零;多人交谈应改善但残余最大**(因其邻域只部分塌)。**若多人交谈毫无改善 ⇒ 共模假说被证伪,须另寻观测量;若改善但仍高于钢琴 ⇒ 与本预测一致。** 本预测随本版落盘,时间戳即本文件的版本记录。
- **⭐ 但残余的方向是良性的,这决定了探针的偏置**:
  | 误判 | 后果 |
  |---|---|
  | 源停了 → 判啸叫 → **保留陷波** | **良性** —— 一个挂在空频点上的浅陷,由 LIFT/老化正常回收 |
  | 真啸叫 → 判外部 → **撤陷 + 保鲜期抑制** | **有害** —— 漏检,且被抑制期内不再挂 |
  ⇒ **探针必须偏向"保留":判「外部」须有正向且干净的证据(`ΔL_f−ΔL_rest ≈ 0`),判「啸叫」是默认分支。** **这是设计原则,不是门限取值。**
- **⇒ 相应地,"探针判为啸叫"不得被用作任何其他机制的正向证据** —— 它在上述残余情形下不携带信息。

**方案②(短暂放开陷波看回弹)—— v1.8 三次增补的裁定:不新增快节拍探针,但把 LIFT 已有的释放变成一次带记录的实验。**
- **接收方的理由成立**:②测的是**对本层干预的响应**,**不依赖外部源的平稳性** —— 而那正是机制 A 的病根。**这是唯一结构上独立于外部源的证据来源。**
- **我原先的理由同样成立**:②在**探针节拍(数百 ms)**上运行会产生**每事件一次的可闻回啸**;而 **LIFT 已经在 60–600 s 的正确节拍上做同一件事**。
- **⇒ 二者不冲突,冲突来自把②理解成"新增一个探针"**:
  > **LIFT 的周期性释放本身就是方案② —— 只是它现在不记录结果。** ⇒ **裁定:不新增探针;要求 LIFT 每次释放时记录「该频点是否回来」,并把该记录作为独立证据回灌探针的模糊带用例。**
  - **成本零、新增伪影零**(释放动作本来就会发生);
  - **证据独立性正是接收方要的那一条**(对本层干预的响应);
  - **代价是时标**:结论在 `LIFT_AFTER` 之后才到 ⇒ **仅适用于模糊带/弃权带的事后裁决,不适用于实时分类**。而模糊带的默认处置是**保留陷波**,**等待期内是安全的**。
- ⇒ **方案② 以"LIFT 带记录"的形式采纳;快节拍探针形式否决。**
- **成本近乎零**:陷波已挂,所需数据(主谱该 bin)已有;**代价 = 每个不同外部音一次浅陷(−3dB 起步)+ 快撤**,与既有「先浅后深」姿态一致 —— **不是每次误报一次,是每个频点一次**。
- **⭐ 它是物理实验,不是统计推断** —— 与 C11-① 的 LIFT 探针同一范式(**真把深度还回去、真改变环路增益,再看结果**)。
- **⭐ FTO 有利(须记)**:本机制的签名是**「对本层干预的响应」**,**不是频率稳定性签名** ⇒ **与 US9794695B2 的 IPMP 类权利要求不同域**(R-AFC-1,DEC-0007 / CTO 议程第 6 项)。**这是选它而不选「新增频率稳定性判据」的第二个理由。**
- **⚠ 诚实边界**:它**不能在动作之前**区分二者 —— **「先验不可分」这一盲区依然成立**,改变的是**它在事后以有界代价可分**。**任何文档不得据本机制宣称该盲区已消除。**
- **⚠ 残余**:啸叫与外部音**同频共存**时 `ΔL` 介于两者之间 ⇒ 模糊(与 C14-② 场景 D 同型)。列残余,**不调门**。
- **强制证伪测试(D-F)**:注入**外部纯音** ⇒ 必须判为外部并撤陷;构造**真啸叫** ⇒ 必须判为啸叫并保留。**两者结果相同即本款未实现。**
- **⭐ 探针窗长的两端论证(v1.8 增补;实测,并据此立 D-H)**:

| probe 窗 | 啸叫 ΔL | 外部音 ΔL max | 判定 |
|---|---|---|---|
| 128 ms | 2.43(中位) | 4.01 | ⛔ 重叠 —— **环路尚未衰落**(下界机制) |
| **256 ms** | **18.22** | **3.77** | ✔ 间隔 14.5 dB |
| 1024 ms | 24.74 | **29.37** | ⛔ 重叠 —— **外部素材自身变了**(上界机制) |

  **⇒ 窗长取 256 ms**;**下界由「环路衰落时间」定,上界由「外部素材的自身变化时标」定 —— 两端是两个不同的物理机制。**
  **⚠ 首版取 128 ms,真啸叫被判「外部」6/6 并撤陷 ⇒ 漏检方向。只论证一端(够长以便衰落)会漏掉另一端(够短以免素材变了)。**

## C9 变更流程(**v1.7:增起草纪律 D-F**)
- 条款变更 = **新文件**递增版本号 + 双方回执 + decisions_log 台账行;旧版文件不得原地改(证据保全)。
- 谈判结论先落本文件、后改两侧文档;僵局上报 lead。

- **⭐ 起草纪律 D-F(v1.7 新增;lead 立 D6-d 的合同侧落点)**:**本合同中凡采用「须 X 可比 / 须 Y 对齐 / 须 Z 一致 / 须 W 有效」形式的规范要求,必须在同一条款内写明「把该要求拿掉后,哪一个可观测量应当改变」,以及据此构造的证伪测试。**
  - **不满足本纪律的条款视为未完成起草** —— 因为实现可以**合规地把它省掉而无人能发现**(v1.6 的 C14「显著度可比」即此形态:实现只用了 `ref_PNPR ≥ T_ref`,mic 证据从不参与判定)。
  - **口诀(lead 语)**:**能失败的对照才是对照。** 恒等自比、时移不变量、无区分力阈值,一律不计为证据。
  - **⭐ D-F 细化(v1.8;起因是我自己写的测试恒真)**:**对单边(不等式)判据,消融必须朝「更不满足」的方向做。** 通用形式「把被测对象拿掉,该数应当改变」在单边判据上会把量推向**更满足**的一侧 ⇒ **恒真、无区分力**。正确形式 = **把被测量推过边界,双向各一次**。
  - **⭐ 起草纪律 D-G(v1.8-①;豁免与入选不得同源)**:**任一豁免/例外条件,不得是其所豁免路径的入选条件的子式。** 若豁免臂 A ⊆ 路径 P 的入选条件,则 A 对 P 恒成立 ⇒ **P 上的否决被结构性作废,且从各自条款文本上看不出来**(实测形态:GROWTH 入选含 `imsd_hit`,而 PHPR 豁免臂1 = `imsd_hit`)。
    - **检查法**:对每条「P 成立 ∧ 否决未触发」的路径,把 P 的入选条件与全部豁免臂做**子式包含检查**;有包含即为短路。
    - **追溯适用**:C11 全部豁免臂 × 全部分类路径,**须在回执中逐格给出检查结果**。
  - **⭐ 起草纪律 D-H(v1.8;窗长/阈值的两端论证)**:**凡为参数选取值,必须对其取值区间的两端各给出独立的物理论证;只论证一端者视为未完成起草。** 实测形态:C8-② 探针窗长的**下界**由「环路衰落时间」定、**上界**由「外部素材自身变化时标」定,**是两个不同机制**;首版只论证了下界(取 128 ms),结果真啸叫 6/6 被判为外部并撤陷 —— **漏检方向**。
    - **自查已命中一处**:**C-8f″ 的 250 ms 窗,我当时只写了下界论证**(环路 e 倍时标 / AFC 反应时间)。**上界论证补于此**:窗若长于「一次偏移能产生可闻增长的时长」,则真实的持续偏移会被稀释 ⇒ **上界与下界收敛到同一时标** ⇒ 250 ms 是**被两侧钉住**而非仅有下界。**结论未变,但当时的推导是不完整的。**
  - **⭐ 起草纪律 D-I(v1.8;预注册)**:**凡条款要求「预期值 / 强制证伪测试」,其预期必须在测量启动之前落盘**(或先落哈希),**并记录所针对的依赖件 sha16**(与 W1-A §4.11 的 `deps:` 同机制)。**事后写下的预期一律按非盲测折价,不得作为该条款已被验证的证据。**
    - **缘由(实测)**:一次"数据到达前写预测"的尝试,**被文件 mtime 自证否**(数据件早于预测件 17 秒)⇒ 该批预测按非盲测折价。**"我还没看"不是证据,时间戳才是。**
    - **⇒ 适用于本合同全部 D-F 强制测试**(C11-⑤、C14-①、C8-②/③)。
    - **⭐ D-I 细化 ①(v1.8;多条预期的相容性)**:**凡预注册多于一条预期,须给出各自的量化形式并检查相容性**;不相容者必须**指明哪一条是判据、哪一条是描述**。**定性表述之间的不相容在写下时看不出来,只有代进数才暴露。**
    - **⭐ D-I 细化 ②(v1.8;诊断指标 ≠ 验收指标)**:**揭示缺陷的那个指标,通常不能直接用作修复的验收指标。** 实测形态:「6 s vs 100 s 挂陷数的 gap」是**缺陷的诊断信号**(gap 扩大 16× ⇒ 无界累积),但**修复后 6 s 远低于混合时间**(6 s 窗内期望到达仅 0.255)⇒ 该比较**在修复后没有意义**。**⇒ 写验收指标时须独立地问:这个量在"已修好"的世界里取什么值、以及它取得到吗。**
  - **⭐ 起草纪律 D-K(v1.8;「复检」是观测不是事件)**:**「复检到同频」是一次【观测】,不是一次【事件】。凡以复检为触发或计数单位的逻辑,必须问一句:它计的是「状态变了」还是「我又看了一眼」?**
    - **实测形态,同一根因已四次命中**:①`t_last_hit` **每次复检都刷新** ⇒ 回收永不启动;②**加深动作每次复检都执行** ⇒ 阶梯被外部源爬满;③`EXHAUSTED` **每次复检都计数** ⇒ **放大 11×**(20 s 试次 12 次挂陷记成 132 次);④`LIFT观测` 逐槽逐分析槽计数 ⇒ 与占用事件数不可相除。
    - **⇒ 一律改为【状态转移计数】**;确需轮询计数的,**另立字段单记、不得与事件计数混用**。
  - **⭐ 起草纪律 D-J(v1.8;触达断言)**:**强制证伪测试必须自带「触达断言」—— 测试须报告被测分支的实际执行次数;次数为 0 时,测试判为「无效」,不得判为「通过」。**
    - **缘由(实测)**:一个专为"共模修不掉裸纯音停止"而造的构造**没触达要测的失效面** —— 纯音在响时即被判外部并登记进保鲜期(20 s > 试次 6 s),**停止时该频点根本不会再挂陷,探针从未启动**。**造这个构造正是为了找自己的下限,而构造本身踩了同一个坑。**
    - **⇒ 本合同全部 D-F 测试(C11-⑤ / C14-① / C8-②③④⑤)均须补触达断言**;**「预期结果」与「触达次数」必须一起报**。
    - **⭐ D-J 细化(v1.8;标记/状态驱动判据的两段覆盖)**:**凡判据由「标记 / 状态位」驱动,测试必须覆盖两段 ——「标记会不会被设上」与「标记设上后是否生效」。只测后者是自证式测试。** 实测形态:一个变异体(弃权来源标记失效)**存活**,因为原检查**手工把标记设好再测"标记生效"**,从未测"标记会不会被设上";补端到端后杀死。
  - **⭐ 换观测量时的通用陷阱(v1.8;同族第三例后总结)**:**当一个判据被判为「所选观测量下不含区分信息」而改换观测量时,必须同时检查新观测量是否引入了新的混淆项** —— 三次实例(C14-② 同频 / C8-② 持续纯音 / C8-③ 源自己停)都是**验证了新观测量能分开原来那一对,却没验证它自身干净**。**检查法 = 对新观测量再问一次「这个量变大,有几个原因?」**
  - 本纪律**追溯适用**:C7 的「p95 精度」、C11 的「验证钩子」、C12 的「担保三条件」、C14 全款,**均须在下一次修订时逐条补齐证伪语句**(本版已补 C14)。


  - **⭐ 起草纪律 D-L(v1.8;标签不阻断影响)**:**「标注为弱证据 / [L4/待验证] / 『不据此翻案』」并不能阻止该数影响结论 —— 标签是给读者的,不是给推理的。**
    - **⇒ 凡被标为弱证据的数,若出现在【裁定段 / 结论段】,须显式写明「若该数为假,本裁定是否改变」;答不出即不得进裁定段。**
    - **来源**:我 v0.28 把「瞬时 λ 走平」标了 `[L3/弱证据,后两段仅差 10%]`,**然后还是让它进了裁定段并支撑了整个框架** —— 标签一个字没少写,影响一点没减。**该条由 lead 判为「比它所修的那个错更值钱」并入库。**
    - **⚠ 本轮起草已自我执行**:C6-⑥ 的 `0.8/0.5` 门限与 `3×` 留量各自附了「若为假,本裁定改不改」。


  - **⭐ 起草纪律 D-M(v1.8;归一化式须验取值范围 + 比值判据须配绝对量门)**:**凡形如 `f(x)/g(x)`、`max(a·x, b)`、"自适应带宽/自适应门限"的表达式,必须先在其【实际取值范围】上扫描一遍输出,确认它没有化简成常数、没有塌缩、没有在定义域某段失去单调性。**
    - **来源(算法侧)**:`round(f / max(f*0.2, 15.0))` 在 `f > 75 Hz` 时恒等于 5。**"看起来自适应"不等于"是自适应的"。**
    - **⭐ 推论(我的,更普适)**:**比值判据对分子分母共用函数的错误【免疫】,免疫方向通常是比值 → 1** ⇒ **凡比值判据必配【绝对量前置门】**,否则它连"仪表坏了"都会读成一个漂亮的结论。**C6-⑥ 的 `R = U/N_mat` 差点就是这样过关的。**
  - **⭐ D-M 细化(v1.8 九次增补;"干净定律"须数值复核)**:**凡化简出形式干净的定律(整数系数、`+3 dB`、`×2` 一类),必须数值复核后才允许使用 —— 漂亮本身就是一个该起疑的信号。**
    - **来源(我的)**:推「挂 `k` 个陷波可提增益」时把**指数序统计量的对数之差**当成**功率比的对数**(量纲层级错一层),得 `ΔG = 4.343·ln(k)` ⇒「每翻倍陷波数 = +3.01 dB」。**形式干净、可直接进 D13、且与行业宣称的 6–9 dB 吻合 —— 而它错 4.7×**(MC 实为 1.91 dB)。
    - **⭐ 附带一条更值钱的教训:「与外部权威数字吻合」在本例中是【错误的证据】** —— 我的错误恰恰把 1.91 放大到 9.03,才撞进 6–9 的区间。**自洽性检验与外部一致性检验【会同时给一条错误定律放行】。⇒ 干净定律的唯一可靠拦截手段是独立数值复核。**

  - **⭐ D-J 细化(v1.8 十次增补):「未触达」与「构造上不可达」是两回事。** **未触达** = 可达但没跑到 ⇒ 结论待定,加长/换工况可解;**构造上不可达** = 该台架跑多久都不会有 ⇒ **这本身就是结论,不是数据缺失,且它使该台架对该问题【永久沉默】**。⇒ 报成"未触达"会诱导再跑一轮无效实验。
  - **⭐ D6-e 并入项 + 族命名【共用即失效】(v1.8 十次增补)**:**两个本应互相检验的量,一旦共用同一构造/函数/数据,检验关系就退化成恒等关系。**

    | 纪律 | 共用了什么 | 后果 |
    |---|---|---|
    | **D-G** | 豁免判据与入选判据同源 | 豁免恒成立 |
    | **D-M** | 比值的分子与分母共用可疑函数 | 对该函数的错误免疫,`R → 1` |
    | **D6-e** | 对照与被测共用被判别量 | **只能朝一个方向通过** |

  - **⭐ 检查项(v1.8 十次增补;「披着谨慎外衣的错误」)**:**凡一条判据/对照/标注的输出是「无结论 / 待验证 / 保守起见」,必须问一句:它有没有可能【永远】输出这个?**
    - **同族三例**:我拒绝的「降为保守上界法」= 假保证;**D-L** 标签不阻断影响;算法侧的错误对照恒输出"需要更多证据"。
    - **⇒ 输出"谨慎"的错误比输出"结论"的错误更难被发现,因为它看起来像美德。**

  - **⭐ 检查项(v1.8 十一次增补;「把小数说成零」)**:**凡把某个量写成「无效 / 不起作用 / 可忽略」,必须同时写出它的实际数值与效率。**
    - **来源(我的)**:我 v0.32 写「加深无效」,实测是 **+0.9/+1.5/+1.6 dB**。数值上只错 1 dB,**决策上却是把一个选项从视野里删除,而删除是不可见的。**
    - **⇒ 与「披着谨慎外衣的错误」互为镜像**:那一条把"不知道"说成美德;这一条把"很小"说成"没有"。
  - **⭐ D6-e 维度扩写(v1.8 十一次增补)**:由「两条独立判据不得共用同一**条件**」扩为「**不得共用同一【量】**」。**来源**:阴性对照拿"深度台阶间落差跨度"作对照量,而那正是被判别的量本身 ⇒ **只能朝一个方向通过**。**比前几例更隐蔽:mic 置零恒真、裸停无分辨力至少还是两个不同的量,这次共用了同一量纲、同一条数据。**
  - **⭐ D6-j 同族补充(v1.8 十一次增补;操作事故伪装成物理现象)**:交错输出文件里的**空白段可以被解释成「某阶段无事件」** ⇒ **凡一个异常结果读起来"像是一个可解释的物理现象",先排除操作事故再解释。** 输出路径须唯一且带轮次后缀。

  - **⭐ 起草纪律 D-O(v1.8;推翻模型不得连坐模型里的量)**:**【结论 / 理由 / 量】是三个独立对象。推翻其一,必须逐项裁定其余两个,不得自动作废。**
    - **正例**:Erlang-B 整族被否,而 `λ·W` 作为量级粗估存活并被实测证实(2.91 估 vs 3.55 实测)。
    - **反例(我的)**:v0.30 否 Erlang-B 时几乎把 `λW` 一起扔掉;v0.33 改「加深无效」措辞时几乎只改措辞而放过被证伪的因果假设。
    - **⇒ 收尾检查项:凡本轮推翻了什么,逐项问「结论、理由、量,哪几个真的倒了」。**
  - **⭐ 检查项(v1.8 十二次增补;响亮的失败 vs 沉默的错误)**:**在"数据结构会扩展"的地方,【裸元组 + 位置解包】是安全特性,不是坏味道。** 带默认值的字典取值会把**响亮的崩溃**转成**沉默的错误值**。
    - **来源(算法侧)**:`store` 元组由 3 项扩到 6 项、汇总层未跟上 ⇒ **崩在打印处,数据未受影响**。**这是 D6-i 同族里运气好的那一半。**
    - **⇒ 凡消费方须与结构同步的地方,优先选择"不同步就崩"的写法。**

  - **⭐ 起草纪律 D-P(v1.8;结构可能性 ↔ 发生率,两个方向都要证据)**:**「代码里存在这条路径」推不出「这条路径常被走到」;反过来,「这条路径很少被走到」也推不出「它不重要」。两个方向的推断都需要独立证据。**
    - **拦截工具极便宜:一行占空比除法。** 例:探针窗 256 ms / 占用寿命 120 s ≈ **0.21%**,85 次探针期望命中 **0.18 次** ⇒ 实测 `B=0` 完全相符。
    - **两个方向各有实例**:lead「占用久 ⇒ 改派频繁 ⇒ 探针常被作废」(结构 ⇒ 发生率);**我 v0.30 用 `1.1 次/试次` 给 `max_depth` 定优先级,v0.32 发现那是台架的性质**(发生率 ⇒ 结构重要性)。
    - **⇒ 检查项:凡"这条路径会不会常被走到"的断言,先做一次量级估算,再决定要不要当架构问题。**
  - **⭐ D-Q(v1.8;"恰好相等"不是定义)**:**两个定义不同的量在某工况下数值相等,不得合并为一个量或共用一个计数器。** 相等是**实测结果**,不是**定义保证**;工况一变即分叉,而那时已无人记得它们本是两个量。**例**:「弃权率」与「无判决率」本轮恰好相等。**⇒ 同族二义的标准形态。**

  - **⭐ D-Q 命名细化(v1.8 十四次增补;采用 lead 的命名对)**:「命名与量的错配」有**两个方向**,须分别检查 ——
    - **一名多量**:一个名字盖了多个量(`稳态 ERLE` / `稳态占用`,E-01);
    - **多名一值**:多个定义不同的量被压成一个值(`弃权率` / `无判决率`,本轮实测恰好相等)。
    - **⇒ 统一检查形式:【每个名字必须能写出它的定义式;两个定义式不同的量,不得共用名字或计数器,哪怕当前数值相等。】**
  - **⭐ D-M 统一检测形式(v1.8 十四次增补;按签名而非按值/按机制)**:**「化简成常数」(D-M 原例)与「ε 底饱和成常数」机制完全不同,但可观测签名相同 —— 分布退化。**
    - **⚠ 且值法必漏**:同一个 `ε=1e-30` 在**幅度口径**给 `−600 dB`、在**功率口径**给 `−300 dB`(10log/20log 二义,本身就是已登记的同族二义)⇒ **检测不得依赖具体底值。**
    - **⇒ 机械检查:扫全部输出量的分位数,凡出现【方差 ≈ 0 / 多个分位数全等 / 恰等于某个参数值】,先证明它是物理量,再拿它做任何归因。**
    - **⇒ 源头修法**:`ε` 同时承担「防 `log(0)`」与「信号下界」两个职责 —— **又一个数值两个职责**(同 `ext_ttl_s`)⇒ 正解是 `if x < x_floor: return SENTINEL`(显式哨兵,下游必须显式处理),**而不是静默滑到 −600 dB 被当电平读**。同「响亮的失败优于沉默的错误」。
  - **⭐ D-J 细化(v1.8 十四次增补;阴性结果须配阳性对照)**:**「测到 0」只有在「该方法在同一条件下能测到非 0」被证明之后,才是结论。**
    - **正例**:探针出口守恒式(`启动 − 判决 = A+B+D`)与插桩**互不依赖**,且若 `B>0` 则判决数必 <85 ⇒ **具备阳性检出能力** ⇒ `B=0` 可采信。**⚠ 但其分辨力只到「和」,不能分辨 A/B/D。**
    - **⇒ 这是 D-J 在【仪器】维度的镜像**:D-J 说「分支必须被触达」,本条说「**仪器必须被证明能看见**」。

  - **⭐ 起草纪律 D-R(v1.8;「解释」须按其物理前提结算)**:**凡提出「若参数取 X 则冲突消解」,必须同时给出【X 对应的物理条件】,并检查它是否落在产品的适用域内。**
    - **来源(我的)**:v0.31 提「`N_eff` 取 20–30 即落进行业 6–9 dB 区间」时,**只检查了它数值上能否圆场,没检查它对应什么** —— 一算是 `T60 ≈ 0.01 s`,即**消声室**。
    - **⇒ 那不是一条解释,是一句「如果这不是会议室的话就说得通了」。⇒ 未按物理前提结算的"解释",只是把矛盾搬到一个没人看的地方。**
  - **⭐ 零共享的边界(v1.8 十五次增补)**:**「不复用代码」不等于「不共享信号路径」。** 独立判据若取自被判对象**下游**的信号,仍会被对方的动作污染(例:起振判据取宽带 RMS,而 NHS 的 `g_duck` 正压低它)。**⇒ 零共享须同时声明:不共享代码、不共享信号取数点、不共享参数。**

  - **⭐ D-Q 第三形态(v1.8 十六次增补;定义对、取值来源错)**:**「一名多量」还有第三种形态 —— 名字定对了、定义写清了,【实际填进去的数却从别处来】。**
    - **来源(我的)**:我把表的自变量定名为「相位临界点数」(定义正确),同一份文件里却用 `1975·T60` 去填它 —— **而那个公式算的是 `\|H\|` 极大值数,差 2.17 倍,且两个量的名字、单位、量级全都一样。**
    - **⇒ 前两种形态(一名多量 / 多名一值)在【文档】层可查;这一种只在【数据流】层可查。**
    - **⇒ 检查项:凡一个量有正式定义,须再问一句「实际填进去的那个数,是按这个定义算出来的吗?」**

  - **⭐ 起草纪律 D-N(v1.8;勘误传播不得改写预注册原文)**:**术语勘误的全库传播【必须绕开预注册段落】。预注册文本的价值全部来自"它写下时就是那样"** —— 一旦被事后编辑,无论改动多么无害,它都不再能证明任何事。
    - **来源**:E-01「稳态」勘误扫过 W1-A §4.16(3) 的预注册原文(`稳态挂陷占用数` → `窗末累积占用数`),**且只扫了正文没扫同段的证伪条款,留下了内部不一致**。
    - **⇒ 正确做法:预注册段保留原文不动,在其【下方】加勘误注(「本段"稳态"一词按 E-01 应读作『窗末累积』;原文保留不改」)。**
    - **⚠ 本例的实害为零**(两种读法指向同一个被测数,预注册的判断内容未变),**且原文未曾 commit,git 无法回滚** ⇒ **本条按"下不为例"处理,不追改已发生的一处,只封住机制。**

## C10 链序约束(**v1.6:AEC 移出本地扩声支;tap 位改写;担保推论升为无条件**)
- **约束(泛化)**:NHS 检测 tap 的同通道上游**不得存在任何快时变「高电平衰减型」增益环节**,含:
  - **宽带动态**:压缩器/限幅器;
  - **频段选择性动态**:**8 段动态 PEQ(PRD §二.4)**、多带动态类处理——动态 EQ 恰在啸叫频段做增益衰减 = 单频段限幅器,压平增长斜坡机理与宽带限幅同型;
  - **⭐ 输入级保护类(v1.5 新增,提供方子级自查发现)**:**输入通道 clip limiter / 软削波器 / 自动 PAD 切换 / 模拟 AGC**。商用前放常内含此类环节且**位于 ADC 之前**——它们是**主动衰减**,与 C12 依赖的**物理饱和**性质完全不同:物理饱和把电平钉在**可知**的 ADC 满幅(C12 输入侧担保的锚),主动衰减把电平钉在**可编程且不可观测**的阈值上,**直接摧毁 C12 输入侧担保**。⇒ **硬件设计约束:输入链 ADC 之前不得存在主动衰减环节**;若产品形态必须含之,其阈值与状态须作为已知量登记入字典并纳入 C12 可知项集,否则 C12 输入侧担保降级为软条件。
  - "快时变"判据(参数化):增益调制时间常数(攻击/释放)< **配置内最大 IMSD 轨迹窗**(= W_long_max × hop;现行预设最大 = 10×16ms = **160ms**@大房间档)[L3/推导,与 W1-B W_long 预设表联动]。
- **分类注记**:噪声门/扩展器属「低电平衰减型」,不销毁高电平增长段证据,不在禁止之列 [L3/解析]——本链位仍将其置于 tap 之后(更强姿态:tap 见未门控信号,PNPR 背景估计不受门控畸变);**门位=A9 定稿项**,若定稿移至 tap 前,其开启阶跃对轨迹线性度的影响列入接收方 s_max 标定注意项。
- **机理**(违反后果):上游动态压平啸叫增长斜坡 → IMSD/RAPID_ONSET(臂2)失效;电平被钳 → T_panic 语义失效;削波/调制产物先于 tap 生成 → PHPR 反向否决。**臂2 的有效性以本条款为前提。**
- **担保推论(供 C12 引用;v1.6 加强)**:本条款成立时,tap 上游唯一可能的饱和机制 = 模拟前端/ADC 满幅削波(**物理**饱和)。**v1.6:AEC 已移出本地扩声支 ⇒ tap 上游只剩前放 ⇒ 本推论成为无条件结论**,v1.5 中「AEC 位于 tap 前…其与啸叫分量的耦合取决于 AEC 参考路径定义(D1/G2 未决),不在本担保范围」一句**随之删除,不再是软点**。
- **提供方 A9 推定链位**(定稿仍走 W1-B 提案→architect 定稿流程):

  **⭐ tap 位定义(v1.6 改写,取代原 W1-A §4 C-3)**:**NHS 检测 tap = 前放之后、陷波器组入口**。**其上游不再有 AEC** ⇒ **C10 担保推论成为无条件结论**(tap 上游唯一饱和机制 = ADC 满幅,不再有「AEC 与啸叫分量的耦合取决于参考路径定义」这一软点)。

### C11-⑤ ⭐ 豁免结构的逻辑短路修正(v1.8-①;评审 C9-① 坐实)

**事实**:GROWTH 入选 = `imsd_hit ∨ rapid_onset`;而 PHPR 豁免**臂1 = `imsd_hit`**。
⇒ **GROWTH 经 `imsd_hit` 入选 ⟹ 臂1 成立 ⟹ 豁免成立 ⟹ PHPR 对 GROWTH 路完全空转。** 实测 **1:1 恒等、六类全中、残余为零**;而 **PHPR 本身在干活**(触发数万次、否决率 98.5%)⇒ **是豁免结构把它作废了,不是判据不灵。**

**⇒ 裁定(结构性,非参数)**
1. **臂1(`imsd_hit`)对 GROWTH 路失效,必须移除。** 它保留在 **PERSIST 路**(B-F1 的钉住场景走 PERSIST,**故本改动不削弱 B-F1**)。
2. **GROWTH 路的 PHPR 豁免改用「谐波因果先后」**,与 `imsd_hit` **不同源**:
   > **豁免 ⟺ 谐波族成员(2f/3f…)的出现时刻,晚于候选峰自身增长起点。**
   - **物理**:削波谐波由候选**自己长大后**产生 ⇒ 族成员**后到**;乐音的族成员与基频**同时到** ⇒ 无先后。
   - **⚠ 现行 `causal_ok` 实测几乎恒真 ⇒ 它测的不是这件事**(测的是候选轨龄相对否决起点,而非**族成员**的出现时刻)⇒ **须按本款重新定义,不得沿用**。
3. **⭐ 强制证伪测试(按 C9 起草纪律 D-F)**:
   - **乐音**(基频与谐波同时出现)⇒ **豁免必须不成立**;
   - **渐长后削波的单音**(谐波后到)⇒ **豁免必须成立**;
   - **两者给出相同结果即本款未实现**(该测试是本款存在的唯一证据)。

### C11-⑥ 三臂在误报测试集中未被触达 —— 正确解读(v1.8-②)
实测:**arm2/arm3 在四类误报素材中恒为 0**。**这不是「三臂退化成单臂」**:
- **arm3 需要限幅器 active**,而音乐/交谈素材不产生 GR ⇒ 恒 0 **是预期行为**;
- **arm2(快升入台)是钉住场景的签名**,音乐素材不产生 ⇒ 恒 0 **亦是预期**;

### C11-⑦ PANIC 路绕过 PHPR(v1.8-②;声明,不改机制)
**PANIC = 电平 ∧ 窄带门,不经 PHPR**(C12 明文)⇒ **高于 `T_panic` 的持续乐音可直接触发 PANIC,无任何谐波否决。**

- **T_panic 语义**:PANIC = 输入侧饱和快路径 + 高电平机会快判,**不承诺输出侧钉住覆盖**;两侧文档中"快端由 PANIC 兜"的无条件旧表述一律按本款收窄。
- **⭐ 担保的参数前提(v1.5 新增;提供方参数默认值自查产出)**:本款一切"担保"表述以 **`AFC.panic_thr` 处于启用状态(非 OFF)且 `AFC.enable = 1`** 为前提。
  **出厂默认值是产品决策,不在本合同定值** —— 但**依赖关系在此写明**:若出厂默认 `panic_thr = OFF`(W1-A v0.6 §5 字典现状)或 `AFC.enable = 0`,则**出厂配置下本款输入侧担保不存在**,两侧文档所有"输入侧担保"表述须加"**仅在 panic 启用且模块使能时**"限定。**已上 CTO 第三关议程**(W1-A v0.7 §5 记录依赖表)。
  **通则(critic 蒸馏,双方采纳)**:**凡"X 担保 Y",必问"X 出厂开着吗"。**
- **字典软校验(2026-08-01 晚增补:可知项集 + 折算域,P13/P18)**:panic 启用时 host 依**可知项集**算平台电平@tap 的可知下界分量,T_panic 高于其 −X dB(X 默认 12 [L4/待标定])→ 配置告警(不自动改值);同一机器对 **T_low** 一并出告警(C11-③)。
  - **可知项集** = {输出链限幅阈值, 矩阵/输出增益, 输入增益, `AFE.clip_headroom_db`, **⭐ 环路内各元件的空闲插入损耗 `<module>.idle_loss_db`(新增,见 W1-A §4 C-8)**}。**遗漏最后一项 = 公式里有一个未登记的数字增益**,直接违反本款"可知"的定义。
  - **⚠⚠ 折算域增补【挂起】(v1.6;critic 原型评审 M-1)**:v1.5 曾据「实测失效临界比算术早约 6 dB」增补「软校验必须按 **bin 域**折算」。
    **该实测已被判为原型标定缺陷** —— 其电平计算**未补偿 Hann 窗相干增益**,全频段系统性低读。**理论值 `20log10(0.5) = −6.02 dB`,与频率无关**,与评审实测的偏差量逐位相符 ⇒ **归因可信**;加回后**实测与设计件算术之差降至零点几 dB ⇒ 设计件的算术是对的**。
    **⇒ 处置**:①**本增补挂起**;②**软校验回退按 v1.4 的总电平口径执行**;③待接收方修复电平标定后**重测**(W1-A **V-32**),再定该增补是**保留、修改还是撤销**。
    - **⭐ 但通则不倒,且这次错误正是它的实例**:通则是「**电平在一种约定下算出、却拿去比另一种约定下定义的门**」;**相干增益漏补与 bin/总电平混用属同一族**。⇒ **通则保留并加强(入 DEC-0010 度量约定清单),数值实例全部作废。**
    - **真正的 bin 效应上界(理论,不依赖任何实测)**:剔除相干增益后,单 bin 与真峰之差只剩 **Hann 扇贝损失 ≤ 1.42 dB**(`20log10(0.8488)`,[L3/窗函数理论])—— **不是此前所称的 5–6 dB**。软校验是否仍须 bin 域折算,取决于该项与「总电平 vs 单 bin」能量分布项的合计,**待重测。**

  - **⇒ 折算的执行方 = 提供方**(与 (i) 的 trim 补偿同理):偏移量取决于当前 `AFC.det.cfg` 的 N / 窗 / 泄漏与场景,**接收方与 host 都无法用一个常数补偿**;提供方须在电平供给侧交付**与门同域**的量。**禁止在两侧各自加常数修正**——那是 C5 老病(一个量两个真值源)。
- 接收方表述模板:"PANIC 前提担保仅限**输入侧(ADC 满幅)**钉住,受 C12 三条件 + 参数启用前提约束;输出侧钉住检出由 C11(GR 遥测)担保;T_panic 配置合理性由 C12 软校验提示"。

## C13 检测反应时间同参口径(v1.5:示例数按档位全量给出)

## C14 远端参考谱否决:使用约束与残余盲区(v1.6 新增)

> **定位**:C4 供**事实**(参考谱、对齐量);本条款载**使用约束与不可协商的边界**(与 C11 的「T_low 使用注记」同型)。**判据与门限归接收方判据层**,但**下列四条不属判据自由度,任何实现或文档不得偏离。**

### C14-① 机制
**判据(v1.7 改为可证伪的单边形式)**:
```
veto  ⟺  ref_PNPR(f) ≥ T_ref            (远端在该频点确有显著窄带内容)
       ∧  mic_PNPR(f) ≤ ref_PNPR(f) + Δ  (mic 侧的显著度未明显超出远端可解释的量)
```
- **为什么是单边**:PNPR 是**相对**量,广义的 ERL 衰减在峰与邻域上同时作用、基本对消 ⇒ **若 mic 峰纯由远端而来,`mic_PNPR ≈ ref_PNPR`**;**若另有本地啸叫叠加,`mic_PNPR` 会明显高出** ⇒ **超出即不否决**。反向(mic 低于 ref)属掩蔽/部分抵消,不应阻止否决,故只设上边界。
- `Δ` **[L4/待 ROC 标定]**,须吸收 PNPR 估计噪声(弱峰、噪声邻域时估计方差大)。
- **⚠ v1.7 立此形式的直接原因**:v1.6 的「显著度可比」在实现上被写成 `veto = (ref_PNPR ≥ T_ref)`,**mic 侧证据算了、打印了,从不参与判定** —— 把 mic 谱整体置零,判定一例不变。**条款文本没错,但它没有规定"可比"如何进入判定,也没有规定如何证伪 ⇒ 实现可以合规地把它省掉。** 本版把它写成**判定式的一个合取项**,并加下方强制测试。
- **⭐ 强制证伪测试(不做即视为本款未实现)**:固定 `ref`,在**同一频点**注入递增的本地窄带分量 ⇒ **`mic_PNPR` 上升越过 `ref_PNPR + Δ` 时,否决必须释放**。**若否决在整个注入区间内不变,本款未实现。**
  - **⚠ v1.8-③ 删除原第二条测试并记教训**:v1.7 曾要求「**把 mic 谱置零,否决判定必须改变**」。**该测试对单边判据恒真** —— mic 项是**上界**,置零把 `mic_PNPR` 推低,只会让否决**更**成立 ⇒ 实测正常 1/1、置零 1/1,**无区分力**。
    > **这条为「强制可证伪」而写的测试,自身不可证伪 —— 恰好犯了它要治的病。**
    - **⇒ 改为方向正确的反向对照**:把 `mic_PNPR` **人为抬到 `ref_PNPR + Δ` 之上** ⇒ **否决必须不触发**。与上方的注入测试构成双向。
    - **⇒ 据此细化起草纪律 D-F(见 C9)**:**对单边(不等式)判据,消融必须朝「更不满足」的方向做**。
- 显著度度量:**PNPR(局部统计)**,与候选峰侧同度量、同 dB 约定(C4:`20·log10` 幅度比);
- 门 `T_ref` **初值 8.0 dB [L4/待 ROC 标定]**;
- **本机制不依赖 ERL/ERLE** —— 这是它相对「靠 AEC 抵消远端音」的**结构性优势**:后者的防护强度随 ERL/ERLE 漂移,前者不随 [L3/解析]。

### C14-⓪ ⚠ 增量价值待重新量化(v1.8 二次增补)
开环台架实测:**C8-② 单独就把「远端重放」类的误挂率压到 0.000**(该类此前卡在 0.300)。⇒ **在开环台架上,C14 的增量价值被 C8-② 覆盖,目前无实测支持。**
- **C14 不撤**:其**唯一未被 C8-② 覆盖**的价值主张在 **C14-② 的场景 D(本地啸叫与远端内容同频共存,闭环)**,而**该场景本轮完全没测** ⇒ **不得据开环结果外推,也不得据开环结果撤销**。
- **⭐ D4 收口条件(先写死,防事后解释)**:**在场景 D 上量化 C14 的增量**。若场景 D 上 C14 相对「仅 C8-②」**无可测增量**,则 **C14 成为删除候选**(其成本 = `ref_spec`/`ref_delay` 两个供给字段 + 对齐机构);若有增量,按增量重述其价值主张。**在该测量完成前,任何文档不得宣称 C14 已被验证有效。**

### C14-② ⭐ 残余盲区:**同频不可分是原理性的**(不可协商)
本地啸叫与远端内容落在**同一 bin** 时,参考谱与主谱的显著度**相等** ⇒ **任何纯谱域显著度比较都不含区分二者的信息**。
> **⇒ 这是信息论层面的边界,不是参数层面的不足。**
> **⭐ v1.8-⑤:与 C8-② 的「持续纯音 vs 啸叫」同族** —— 两者都是「**在所选观测量下不含区分信息**」。**同族的正确处置也相同:不调门、不新增同域判据,而是换一个含区分信息的观测量**(C8-② 用「对干预的响应」,C14 用 mic/ref 的单边差与三层兜底)。
> **⇒ 禁止以调整 `T_ref`(或任何单一谱域门限)作为其修法。任何声称"调门可解"的实现、文档或验收表述,视为对本条款的误读,应予退回。**
- 该场景的**发生概率未测**(需真实远端语料 + 房间模式分布)⇒ **不得外推,不得据以判定风险等级**;
- **不得在可达性表中把该场景写成"已覆盖"。**

### C14-③ ⭐ 作用域:**仅 PERSIST 路,不作用于 GROWTH 路**(不可协商)
**理由(物理,非取舍)**:远端内容是**本地环路之外的外生输入**,不是环路谐振 ⇒ **不具备指数增长段**;其起音是**电平阶跃**,已由 `s_max` 的线性度检验拒收。
⇒ **GROWTH 路本来就不需要这道否决**;而把否决施加于 GROWTH 路,会在盲区 ②(同频)下**否掉正在增长的真啸叫** —— 那是**漏检**,代价远高于误检。
- 结构上与 **C11「臂3 仅 PERSIST 路启用」同型**;
- ⇒ **盲区 ② 的"正在增长"那一大部分由本条零成本关闭。**

### C14-④ 三层兜底的归属与代价(分层,不默认全开)
| 层 | 机制 | 归属 | 代价/边界 |
|---|---|---|---|
| **①(必做,零成本)** | **C14-③ 的 PERSIST 路限定** | 接收方判据层 | 无。**不新增误检面**:远端渐强类误触发本就由 PHPR/预设承担,与本层无关 |
| **②(建议)** | **ERL 参照的电平超出检验**:远端可解释的 mic 分量 = `ref_bin − ERL[ch][o][band]`;**mic_bin 显著超出该值时,超出部分必为本地 ⇒ 不否决** | 接收方判据层;`ERL` 由提供方按 C4/ERL 矩阵供给 | **⚠ 重新引入 ERL 依赖** —— 但 ERL 已**逐台逐频段实测**,是**已知量而非假设**。**这是明码的取舍,须在文档中如实标注,不得含糊** |
| **③(可选)** | `R` 与 mic 在候选 bin 上的**相干性/互相关** | 接收方 | 成本较高;盲区 ② 下二者共存 ⇒ **相干度居中,退化平缓而非干净失败** |

**三层之后的残余** = **「已钉住(无增长段)∧ 与远端持续内容同频 ∧ mic 电平未超出 ERL 可解释量」的交集** —— **窄,但必须显式声明,不得宣称已覆盖。**

### C14-⑤ 降级语义
`ref_spec` 或 `ref_delay` 为 `invalid` 时:**停用否决并上报 host 事件**,**不得带错对齐运行**(错帧比对会同时产生误否决与漏否决,方向不可预期)。停用期间远端内容的误检面由 PHPR/持续性/预设承担,**如实计入残余风险**。

### C14-⑥ 验证钩子(假绿纪律)
- **broken 版**:禁用否决后,**远端持续纯音必须导致误挂陷**(否则说明测试没依赖被测物);
- **正例**:本地真啸叫 + 远端语音并存时,**否决必须不触发**(该场景是本机制成立的支点);
- **盲区组**:同频场景的预期结果 = **否决触发(即漏检)且这是已声明边界** —— 与 C11-④ 的「真盲区组」处置同构;
- 判定量取**输出信号**,不看内部旗标。


### C14-⑦ 时间对齐:必要性条件、以及为什么平稳素材上测不出来(v1.7 新增)

**事实(W2 评审)**:对齐量扫 0 → 3.75 s,否决判定**全部 3/3 正确** ⇒ 表面看"对齐无所谓"。
**成因**:**幅度谱对平稳信号的时移不变** ⇒ 在平稳素材上,任何对齐量都给同一个谱 ⇒ **该扫描按构造就没有区分力**,不是"对齐不必要"的证据(**这正是 D6-d 所指的"不能失败的对照"**)。

**⇒ 对齐的必要性条件(量化,取代"一律须对齐"的无条件表述)**
- 参考谱与主谱各在长度 `T_win` 的分析窗内取(B3:`T_win = 64 ms`);
- 语音的谱内容在**音素时标(20–50 ms)**上变化 ⇒ **当 `ref_delay` 相对 `T_win` 不可忽略时,不对齐就会比对到不同的音素上**;
- **门(工程取法)**:`ref_delay > 0.25 × T_win` 时**必须对齐**;B3 下 = **16 ms**,对应声程 **≈5.5 m** [L3/解析]。
- **参照**:实测的 `ref_delay ≈ 7.9 ms`(声程 ≈2.7 m)= **12% 窗** ⇒ 该房间下对齐收益本就小;而 **10 m 声程 = 29 ms = 46% 窗**、15 m = 68% 窗 ⇒ **大房间下对齐是必需的**。
- ⇒ **本款不因一次小房间实验而降级,但其表述由"一律须对齐"改为"按 `ref_delay / T_win` 判定必要性",并强制标注该比值。**

**⭐ 证伪测试(必须用非平稳参考内容)**
- **素材**:含清晰音素边界的语音(禁用平稳纯音/稳态噪声 —— 在其上本测试**按构造不可能失败**);
- **构造**:`ref_delay` 取真值 vs 取 0(或 ±0.5 `T_win`),**在 `ref_delay > 0.25 T_win` 的配置下**;
- **判据**:两者的否决判定序列**必须出现差异**。**若不出现,先检查素材是否平稳,再检查对齐是否真的被消费** —— **不得据此结论"对齐不必要"**。
- **若在非平稳素材 + 大延迟下仍无差异**:则本款降级为「对齐量仅供 ERL/回声路径机构使用,不构成否决判据的一部分」,**并须显式改写 C4 中对 `ref_delay` 的义务描述**。
