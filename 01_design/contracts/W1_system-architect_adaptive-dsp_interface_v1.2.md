## C1 帧结构与旁链调度(沿承)
- 音频:48kHz / 64 样本/帧 / 750 fps(平台硬底,DEC-0006 [L1/ITC])。
- 旁链分析槽:每 2ms 一个(系统 500 FFT/s,8 通道错峰,每通道更新周期 16ms)。
- 旁链任务属性:最低优先级、可抢占、非音频 ISR;错过槽位允许跳帧(降档,不阻塞音频帧回调)。

## C2 接收方算力包络(沿承)

## C4 旁链供给数据(沿承)

- **2f 看门狗字段(接收方已点单)**:候选峰附带 2f 处看门狗 bin 值(仅 PERSIST 路否决用,秒级陈旧度可接受)。

## C6 执行器接口(沿承)

## C10 链序约束(v1.2 泛化重写;关联 A9;critic B-F1 + lead 常识审 2026-08-01)
- **约束(泛化)**:NHS 检测 tap 的同通道上游**不得存在任何快时变增益环节**,含:
  - **宽带动态**:压缩器/限幅器(v1.1 原条款);
  - **频段选择性动态**:**8 段动态 PEQ(PRD §二.4)**、多带动态类处理(v1.2 新增)——动态 EQ 恰在啸叫频段做增益衰减 = 单频段限幅器,压平增长斜坡的机理与宽带限幅完全同型;
  - "快时变"判据:增益调制时间常数(攻击/释放)< IMSD 轨迹窗量级(128ms)。
- **机理**(违反后果):上游动态压平啸叫增长斜坡 → IMSD/RAPID_ONSET(臂2)失效;电平被钳 → T_panic 语义失效;削波/调制产物先于 tap 生成 → PHPR 反向否决。**臂2 的有效性以本条款为前提。**双重理由:动态 PEQ 前置于 AEC 亦违 W1-A §4 C-1(时变环节扰动回声路径估计)。
- **提供方 A9 推定链位(v1.2 补齐 PEQ;定稿仍走 W1-B 提案→architect 定稿流程)**:
  `前放/增益/相位 → AEC → [NHS 检测 tap + 陷波器组] → 噪声门(EXP) → 8段动态PEQ → 压缩器/限幅 → ANS → AGC(含语音闪避) → automixer`
  噪声门置于 tap 之后 → tap 见未门控信号,PNPR 背景估计不受门控畸变,增长段斜坡完整 [L3]。
- **PRD §二 逐条差集表(链位完备性证据;此核对为提供方固定自查步骤,每次链位变更重跑)**:

| PRD §二 | 模块 | 链位 | 备注 |
|---|---|---|---|
| .1 | 前放/增益/相位 | 位1 | tap 上游,静态/慢变,允许 |
| .2 | 噪声门(扩展器) | 位4 | tap 下游 ✓ |
| .3 | 压缩器/限幅器 | 位6 | tap 下游 ✓(C10 硬约束) |
| .4 | **8 段动态 PEQ** | **位5** | **tap 下游 ✓(v1.2 补,C10 硬约束)** |
| .5 | AFC(NHS) | 位3(tap+陷波) | 本模块 |
| .6 | ANC 降噪(项目术语 ANS) | 位7 | tap 下游 ✓ |
| .7 | AEC | 位2 | tap 上游——非增益动态,系自适应线性滤波,不属 C10 约束对象;其前置由 W1-A §4 C-1 论证 |
| .8 | AGC + 语音闪避 | 位8 | tap 下游 ✓(慢时变,另受 C-4 互斥) |

  **差集 = ∅**(8/8 覆盖,0 缺失 0 多出)。
- 反例显式排除:竞品链序 EXP→COMP→AGC→EQ→AFC(动态处理前置)。
- 输出链元件(分频/10段EQ/FIR/延时/两级限幅)物理上必在环路内,不受本条款约束——限幅级可观测性由 C11 承接;**输出链 10 段 EQ 为静态(PRD §三.2 未标"动态"),若产品日后升级其为动态,必须重开 C11 作用域(变更钩子)**。

## C11 动态处理 GR 遥测(v1.2 作用域修正;**case (b) 钉住场景检出的担保主体**)
- **供给字段(每输入通道 ch,随旁链数据交付)**:
  - `dyn_active(ch)`:bool,通道内 tap 下游任一快时变增益环节(COMP/限幅/**动态 PEQ 各频段**)处于增益衰减态;
  - `gr_ch_db(ch)`:float,上述环节 GR 平滑包络(~10ms 时间常数;动态 PEQ 取各频段 GR 最大值);
  - `out_active(ch)` / `gr_out_db(ch)`:bool/float,**经激活路由映射的输出链限幅聚合** = max{GR(o,级) : 矩阵路由 ch→o 增益 > −40dB,级 ∈ {**输出限幅(PRD §三.4)**, **音箱保护限幅(PRD §三.5)**}}(v1.2 修正:两级全入,v1.1 漏 §三.4 级);聚合由提供方按当前矩阵状态逐帧计算。
- **更新率/陈旧度**:标志 ≤1 帧(1.333ms);GR 包络平滑 ~10ms。
- **作用域**:通道内快时变增益环节(含动态 PEQ)+ 输出链两级限幅(路由映射)。**不含**:AGC/闪避(慢时变,不构成钉住;互斥由 C6/W1-A §4 C-4 承接)、输出链静态 EQ/分频/FIR/延时(非增益动态)。
- **担保边界(显式)**:本遥测只覆盖 **DSP 内可观测**的动态节点。**DSP 外部限幅(功放内置限幅/音箱热压缩)钉住的环路不在担保内** —— 运维前提(写入 D14 调试 SOP + 用户手册):**DSP 输出链限幅阈值必须设置低于功放限幅点**,使环路钉住点落回 DSP 可观测域 [L3/标准调试实践,竞品 SOP 六步同向佐证 [L4]];违反此前提的场景列 CTO 残余风险清单。
- 接收方使用约束(双方同意记录):臂3 仅 PERSIST 路启用(秒级+浅陷 −3dB+快回收),GROWTH 路不用。

## C12 T_panic 增益结构(沿承 v1.1;**声明:非担保机制**)
- T_panic 语义 = 检测 tap 点电平(dBFS)。
- **静态担保不可能之论证**:钉住平台电平@tap = L_限幅阈 + G(限幅点→扬声器) + **G_声学(扬声器→麦,未知且时变)** + G(麦→tap);含不可知项 ⇒ 任何"T_panic 必低于平台电平"的静态字典规则**不构成担保** [L3/物理论证]。case (b) 的担保主体 = C11 臂3。
- **字典软校验(联动规则,提供方 owner,host-software 实现告警)**:panic 启用时,host 依可知项 {输出链限幅阈值, 矩阵/输出增益, 输入增益} 计算平台电平@tap 的**可知下界分量**,若 T_panic > 该值 − X dB(X 默认 12 [L4/待标定])→ 配置告警(不自动改值,V1 口径)。
- 接收方文档表述模板:"PANIC 前提(tap 电平 ≥ T_panic)不作静态担保,钉住场景检出由 IF-v1.2 C11(GR 遥测臂3)担保;T_panic 配置合理性由 C12 软校验提示"。

## C13 检测反应时间同参口径(沿承 v1.1,critic B-m4 收敛)
- **算法级参考点 = 轨迹诞生**(该峰首次跨候选门的 hop);轨迹历史自诞生起累积(含 TRACKED 前 hop);IMSD 于 TRACKED ∧ hist_n≥W_used 判定 ⇒ 主路判定 = 诞生 + 8 hop(128ms@B3)、快路 = 诞生 + 4 hop(64ms@B3);执行器首挡斜坡 50ms 另计。
- **对外/延迟账参考点 = 啸叫起始(onset)**:总反应 = Δfill(0~64ms,窗内能量爬升至跨候选门,随增长率变)+ 上述诞生参考值。**两参考点并存、不得混用**;W1-A §6 与 W1-B 反应时间表述统一按本条款(W1-A v0.4 §6 表述在合并轮按本条款改写)。
