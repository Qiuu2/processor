## §0 ⛔⛔ 先报一条会**推翻选型理由**的(lead 令:发现即顶格报)

> **lead 已把「算力结构性有界」当作选 automixer 的理由报给 CTO。⇒ 而它成立**有条件**,
> 条件不满足时**它就是假的**。⇒ 故先写在最前,⛔ 不埋在 §2。**

```
风险 A ⭐⭐ **NOM ↔ 门判决之间存在【隐式反馈】**
   NOM 衰减改变通道电平 ⇒ 改变门开关判定 ⇒ 改变 NOM ⇒ 改变衰减 …
   ⇒ 若门的旁链取在 **NOM 增益之后**,该式是**隐式方程**:
     ⛔ 可能无唯一不动点 · 可能振荡 · 求解可能需要**迭代**
   ⇒ ⇒ **而迭代次数是数据相关的** ⇒ **「op 数是通道数的函数」当场不成立**
风险 B ⭐ **「设定最大开启麦数量 M」(PRD §二.1 明写)是一个【选择问题】**
   N 路里选电平最高的 M 路 ⇒ 朴素实现 = 排序 ⇒ **O(N log N) 且比较次数数据相关**
```
**⇒ ✅ 两条都可解,而解法是【结构约束】,⛔ 不是"注意实现"**:
```
约束 C-1(破环):**门判决的旁链必须取在 NOM 增益【之前】**
   ⇒ 环被构造性打断 ⇒ 该式变显式 ⇒ 单遍 O(N),⛔ 无迭代
   ⚠ 同族先例:W1-A 裁定「AFC 检测 tap 取在陷波器组入口」、我方裁定「AEC tap 取在 NLP 之前」
     ⇒ **本项目第三次遇到同一形状:判据的取点位置决定它是不是隐式方程**
约束 C-2(定选择的代价):top-M 必须实现为**固定代价的插入网络**
   ⇒ 每通道对 M 个槽做**固定 M 次**比较-替换(⛔ 不提前退出、⛔ 不排序)
   ⇒ 代价 = **N×M 次比较,与数据无关**;N=12 / M≤8 ⇒ ≤ 96 次/帧 [L3/解析]
```
**⇒ ⇒ ∴ 正确表述:「算力结构性有界」**在 C-1 ∧ C-2 下成立**;⛔ 而它不是无条件的。**
**⇒ 若架构侧或 PRD 要求门旁链取在 NOM 之后 ⇒ **该选型理由失效**,须回报 CTO。**

## §2 ⭐ 算力结构性有界的**证明**(⛔ 不是假定)

### 2.1 op 数关于通道数 N 的函数

| 环节 | 每帧 op(逐通道) | 关于 N | 数据相关分支? |
|---|---|---|---|
| 电平检测(每通道包络) | 平方累加 + 一阶平滑 ≈ `2·L + 3` | **O(N)** | ⛔ 无 |
| 门判决(迟滞 + 计时) | 2 次比较 + 1 次计数 | **O(N)** | ⛔ 无(迟滞是两个固定比较) |
| NOM 计数 | N 次累加 | **O(N)** | ⛔ 无 |
| NOM 增益(查表 / `−k·log2(NOM)`) | 1 次(母线级) | **O(1)** | ⛔ 无 |
| **top-M 选择**(PRD 的"最大开启麦数") | **N×M 次比较-替换**(固定插入网络) | **O(N·M)** | ⛔ 无 —— **前提 C-2** |
| 优先级/分组 | 优先级折进比较键 | **O(N)** | ⛔ 无(静态键) |
| 增益平滑(每通道斜坡) | 1 次乘加 | **O(N)** | ⛔ 无 |
| 语音闪避(检测 + 母线增益) | 检测 O(N) + 施加 O(1) | **O(N)** | ⛔ 无 |
| AGC(慢包络 + 增益) | 每通道 O(1) | **O(N)** | ⛔ 无 |

**⇒ 合计 = `a·N + b·N·M + c`,而 `M ≤ N` ⇒ **上界 O(N²)**,且 N=12 / M≤8 ⇒ **N·M ≤ 96**。**
**⇒ ⭐ 而全部环节【无数据相关分支】⇒ 每帧 op 数是【常数】,不是随信号变化的量。**

### 2.2 ⛔ 而这个结论**依赖两条结构约束**,⛔ 不是无条件的

```
C-1 门判决的旁链取在 **NOM 增益之前** ⇒ 破掉隐式环 ⇒ **单遍,⛔ 无迭代**
C-2 top-M 用**固定代价插入网络** ⇒ ⛔ 不排序、⛔ 不提前退出 ⇒ 比较次数与数据无关
⇒ ⇒ **任一条不成立 ⇒ §2.1 那张表【失效】,而"结构性有界"这个选型理由随之失效**
```
**⇒ ⭐ 而 C-1 是【链位裁定】,归架构侧 ⇒ 已请 lead 转:**
**⛔ 在它落定之前,「算力结构性有界」只能写成【条件成立】,不得当作已证。**

### 2.3 ⚠ L 标与它的边界

```
上表全部 **[L3/解析]**(手数 op,⛔ 未在任何目标上测)
⛔ 而按 **DEC-0025**:开发板已寄出 ⇒ **本条无限期不可 [L1] 验证**
⇒ ⭐ 最容易犯的错是**把"不可验证"读成"已验证"** —— 时间一久就会
⇒ ∴ 本件所有算力数字**永久带 [L3/解析]**,⛔ 直到有 [L2/模拟器] 或 [L1] 之前不得升级
⚠ 而"结构性有界"这句**不依赖**那个不可验证的锚点:
  它断言的是 **op 数不随数据变**,⛔ 不是"op 数是多少" —— 两者是不同的断言
  ⇒ ⭐ 这正是选它的理由所在,而**也正因如此,C-1/C-2 才是承重的**
```
