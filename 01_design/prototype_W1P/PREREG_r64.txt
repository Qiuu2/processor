4. ⭐ `T_OBS` 自适应阶梯与【收敛判据】—— 跑前落盘(本轮最核心的方法学)
═══════════════════════════════════════════════════════════════════════
**为什么必须自适应**:F36 已证 `T_OBS` 不是全局常数 —— 22.3 Hz 的临界点在 6s 下
**根本不是赢家**,要 24s 才收敛(mk 残差 0.42 → 0.12 dB)。`r61` 用固定 12/30s
⇒ 凡 `f_trig < 120 Hz` 的读数在其上不可信(M-6 未闭)。

**阶梯**:`T_OBS ∈ {6, 12, 24, 48} s`(×2 几何阶梯)。
  上限 `T_MAX = 48 s`。**硬约束 `T_MAX < P.lift_after_s = 60 s`**,否则臂 O 的预挂槽会
  在窗内进入 LIFT ⇒ 被测对象在窗内改变(`nhs.py:1003`)。脚本内以断言强制。

**停止条件(两条【都】要满足,任一不满足即进下一档)**:
  C1  1/f 充分性:`T_final ≥ T_req(f_min)`,
      `T_req(f) = 6.0 × max(1, 120.0 / f)`,
      `f_min` = 该档 **基线 + 全部臂** 实测 `f_trig` 的最小值。
      **锚点与保守性**:`120 Hz = nhs.py:69 的 f_det_lo`(项目自己的检测带下沿);
      代入 r60 实证点 `f = 22.5 Hz` 得 `T_req = 32.0 s`,而 r60 实测 24 s 已够
      ⇒ **本式偏保守(要求更长),不偏乐观**。
  C2  相邻档稳定:对**每一个要报的臂**,`|ΔMSG(T_k) − ΔMSG(T_{k−1})| < STEP/2 = 0.25 dB`。
      ⚠ **量化事实必须同时写明**:m0 与各臂扫描**同锚同栅格**(均为 `anchor + 0.5×整数`)
        ⇒ `ΔMSG` 恒为 0.5 的整数倍 ⇒ **C2 在数值上等价于「相邻两档 ΔMSG 完全相等」**。
        这是一条**可以失败**的判据(不是恒真):r60 实测 12s→24s 的 `ΔMSG` 由 6.70 变 6.40。
        (B-2 教训:同锚同栅格的差值恒为 STEP 整数倍 —— 这次**跑前**写出来,不等被指出。)

**未收敛处置**:`T = T_MAX` 仍不满足 C1∧C2 ⇒ 该行标 `⛔未收敛@48s`,
  **其数不进达标统计**,并在文末单列。**不得取"最后一档"当收敛值。**

**算力优化(方法留痕,免得被当成口径漂移)**:第 2 档起,各臂扫描起点取
`lo = m_prev − 1.5 dB`(而非 `anchor − 1`)。理由:窗变长只会让起振**更早**被抓到
⇒ `m` 单调不增,起点下移 1.5 dB 有余量。**若某档返回 NaN(起点处已起振)**,
自动回落 `anchor − 3` 全程重扫,**且该回落必须在输出行内留痕**(不得静默)。
⚠ 起点平移**不改栅格**(`m_prev` 本身在 `anchor + 0.5×整数` 上)。

**触发**:用**阶梯之外**的配置(`T_OBS ∈ {2, 4} s`,两条种子)做机制烟测,

──────────────────────────────────────────────────────────────────
修订 A-1 · **INV-N 原样会把【对我不利】的数据丢掉**(严重,必须改)
──────────────────────────────────────────────────────────────────
**观测**:`T_OBS=4 s / 0.5-seed1` 上臂 N 的 `N2_lvl = 0`、`n_notch = 0`、
`ΔMSG = 0.00` ⇒ 按 §3 原文判 `⛔INV-FAIL` ⇒ 该行被剔出达标统计。

**⛔ 这是错的,而且错的方向很危险**:
`N2_lvl = 0` 在臂 O 上是**构造应然**(`T_low=999` 钉死);
但在臂 N 上(默认 `T_low=−45`、槽全空)它是**算法的真实输出** ——
「NHS 全程什么都没做,所以 ΔMSG = 0」**本身就是一个合法的、不利的测量结果**。
把它当"护栏失败"剔除 = **把最差的那些条从达标统计里删掉** =
「证据门槛随结论方向浮动」的教科书形态(team_config 该节 + DEC-0011)。

**⇒ INV-N 改为三分(仍双向可失败,且不再丢数据)**:
```
(a) N2_lvl > 0 且 n_notch > 0                 ⇒ ✅ 该数可称『NHS 自选』
(b) N2_lvl == 0 且 |ΔMSG| ≤ STEP(0.5 dB)     ⇒ ✅ 该数可称『NHS 自选』,
    但必须同段打出「**NHS 全程零动作**」;**计入达标统计(记为未达标)**,
    ⛔ 不得剔除
(c) N2_lvl == 0 且 ΔMSG > STEP               ⇒ ⛔ INV-FAIL
    —— **这正是 B-1 的形状**:被测机制零动作却有收益 ⇒ 收益来自别处
    ⇒ 该数不得称『NHS 自选』,剔出统计并单列
```
臂 O 的 `INV-O`(`N2_lvl == 0`)**不变**。
**⇒ 护栏仍能失败**:(c) 是真实可达的判 FAIL 路径;烟测已证 (b) 也真实可达。

──────────────────────────────────────────────────────────────────
修订 A-2 · **Hp2 写反了方向 —— 对自适应臂不成立**
──────────────────────────────────────────────────────────────────
**观测**:`0.2-seed0` 臂 N/Na 的 `ΔMSG` 由 `T=2s` 的 **0.00** 升到 `T=4s` 的 **1.50**
⇒ 触发 §5 Hp2 的证伪条件。

**成因(机械可查,非事后合理化)**:`T_OBS` 变长对**自适应**臂有两个方向相反的作用 ——
  (i) 窗越长越容易抓到起振 ⇒ `m` 下降(这是 F36 说的那一条);
  (ii) 窗越长 NHS 越有时间**检测→分配→加深**(`depth0=−3` 起,`depth_step=−3`,
       `ramp=60 dB/s`,`hit_need=3`)⇒ 陷波更深更多 ⇒ `m` 上升。
**Hp2 原文只写了 (i),把 (ii) 漏了** —— 而 (ii) 对臂 O 不存在(它一上来就钉死在 −18 dB),
所以 Hp2 对臂 O 成立、对臂 N/Na 不成立。**这是我写 Hp2 时没想到的一维。**

**⇒ Hp2 拆成两条**:
```
Hp2a(臂 O,固定滤波器):ΔMSG 随 T_OBS 单调不增。
     证伪:上升 ≥1 阶梯 ⇒ 阶梯法或起点上移有问题
     ⇒ **唯一合规动作 = 对该条回落 anchor−3 全程重扫做独立观测**(C-4),不是补解释。
Hp2b(臂 N/Na,自适应):**不预测方向**,只预测**最终收敛**(C2 会兜住)。
     记录项:ΔMSG 随 T_OBS 的**完整轨迹**逐档打出(已在输出里),
```

**§1 第 2 条与 §8 的 `E-3` 行写着「M-1 已由 r61 结算,本轮不重复结算」——【该判断现已知不成立】。**
成因(lead 转 SD 工具实测):**M-1 的"等代价"用的是【功率代价】,而这是错的对齐口径。**
`sd_meter` 实测同一陷波(1kHz/BW100/−20dB):按**同等功率**对齐 ⇒ 陷波是平坦的 36.2× 更差;

机理:SD 是**对数谱偏差**的加权均方根,不是功率度量;窄陷波功率代价近乎为零却造成 20 dB 对数偏差
⇒ **按功率对齐时它必然更贵。** 文献选陷波的理由是「**同等 MSG 收益下更便宜**」。
⇒ **`r61` 的三口径(中位/dB均/功率均)全部是功率侧 ⇒ 它们回答不了 M-1。**
⇒ **本轮据此写下的「M-1 已结算」是错的;正确状态 = M-1 未结算,且其判据须重写为
  【固定 ΔMSG,比 SD】(不是固定代价、比 ΔMSG)。** 详见 `FINDINGS.md` F47。
