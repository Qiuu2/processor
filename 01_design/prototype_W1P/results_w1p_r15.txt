【§0.1】⛔ 对裁定①的一处反对(实测支持,写在实现之前)
--------------------------------------------------------------------------------
裁定①称:钳位 `diff = ΔL_f − max(ΔL_rest, 0)` 后
「**长笛 0→3 的全部来源被堵**」「C8-③ 在该维度上单调不劣于 C8-②」。

**实测复核(60 试次,长笛全部假啸叫样本 n=1):**
    dL = **−1.89**   dR = **+9.34**   |dL − dR| = 11.24
    ⇒ `max(dR, 0) = dR` ⇒ **钳位不触发**
    ⇒ 钳位 + 保留绝对值:diff = −11.24,|diff| = 11.24 > X=8 ⇒ **仍判啸叫**
    ⇒ 钳位 + **去绝对值**(`判外部 ⟺ diff ≤ X`):−11.24 ≤ 8 ⇒ **改判外部** ✔

⇒ **该样本的 rest 是「下降」(dR>0),不是「上升」** ⇒ 钳位管的是 dR<0 的情形,**管不到它**。
⇒ **真正堵住它的是去掉绝对值**:`dL < 0` 表示 f 处电平**上升**,
  而"环路被打断"只能使 f 处电平**下降** ⇒ **电平上升不可能是啸叫证据**,
  现式却因取绝对值把它当成了强证据。
⇒ **单调不劣的结论,只有在「钳位 ∧ 去绝对值」同时成立时才成立**;仅钳位不成立。

**我要实现的形式**:
    diff   = ΔL_f − max(ΔL_rest, 0)        ← 钳位(裁定①)
    判外部 ⟺ diff ≤ X                       ← **单边**(本层增补;去掉绝对值)
    判啸叫 ⟺ 否则(默认分支)
  · rest 上升 ⇒ max(·,0)=0 ⇒ diff = ΔL_f ⇒ **精确退化为 C8-② 单量判据**(单调性成立)
  · f 处电平上升(ΔL_f<0)⇒ diff<0 ≤ X ⇒ 判外部(**不再被绝对值误当作啸叫证据**)

**⚠ 为使该反对可判,本轮同批产出两套判决**(同一次跑批、同一组 dL/dR 后处理,零额外成本):
    (甲) 钳位 + 保留绝对值 —— 裁定①字面
    (乙) 钳位 + 去绝对值   —— 本层主张
  **两者并列报出。若(甲)的长笛假啸叫 = 0,则我错。**

【§0.2】D-H:机制 B 的 `M`(弃权门)两端各须**不同机制**的论证
--------------------------------------------------------------------------------
弃权条件:`L0` 与 `L1` **均须** > 底噪 + `M`,否则探针弃权、不产出判决。
**下界(太小会怎样)**:机制 = **本底估计不确定度**。1024 点 Hann、单 bin 噪声功率
  服从 2 自由度 χ²,单次估计标准差 ≈ **5.6dB** ⇒ M ≲6dB 时,纯噪声起伏即可
  被当作"有效读数" ⇒ ε 地板附近的伪值仍会进入判定 ⇒ **机制 B 没修干净**。⇒ M > 6dB。
**上界(太大会怎样)**:机制 = **真啸叫早期低电平段被逐出定义域**(与上界完全不同的机制)。
  候选峰能入选的前提已是 `PAPR ≥ T_papr = 15.0dB`(峰高出邻域 15dB)。
  若 M ≥ 15dB,则**凡合法候选都可能被判弃权** ⇒ 探针在它该工作的场景里恒弃权
  ⇒ **漏检方向**(弃权保留陷波虽安全,但"永不判决"= 机制空转)。⇒ M < 15dB。
⇒ **取 M = 10.0 dB**:距下界 4.4dB、距上界 5.0dB,近似居中。[L4/待 ROC 标定]
