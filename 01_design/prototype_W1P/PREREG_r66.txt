§0  先答 lead 的收敛问:**接受未收敛,但【换掉被比较的量】**
════════════════════════════════════════════════════════════════════════
**结论:不做 96 s,接受"未收敛"这个限定 —— 但不是"接受一个暂定值",而是把主统计从
【绝对值】换成【同档配对差】。理由三条,第一条是硬约束:**

1. **96 s 结构上做不了。** `nhs.py:94 lift_after_s = 60 s`:超过 60 s,
   臂 O 的预挂槽进入 LIFT(`:1003`),**臂 N 自己挂的陷波也会开始 LIFT**
   ⇒ 两个臂都在窗内换了工作机制 ⇒ 与 r64 **不再是同一个测量**,
   直接违反 lead 要求 2(「任何一处不同,就不能与 r64 相减」)。
   要跑 96 s,必须先改 `lift_after_s` = **改被测算法本身**,那是另一个工单。

2. **但"接受并读 48 s 那个值"也不安全。** `0.5/sd1` 的 ΔMSG 在阶梯上跨 0.5–4.0 dB
   ⇒ 残余不确定度 ±1.75 dB,**与我们要判的效应量同量级**。lead 说"要判的是 1.0 还是 3.0",
   而这条的不确定度就有 1.75 ⇒ **绝对值不能用**。

3. **⇒ 正解:本轮问的是【同一条种子上,修完比修前好多少】,那是一个配对差。**
   把阶梯**钉死**(不再自适应停机),对每一档算
   `δ(T) = ΔMSG_修后(T) − ΔMSG_基线(T)`,**T_OBS 逐档对齐**。
   非收敛是**被控对象(plant)的性质**(赢家在 7580→1034→22 Hz 之间迁移,r64 直接观测),
   基线与修后臂**共有** ⇒ 在配对差里大部分抵消。
   **⇒ 收敛与否从【门】降级为【报告项】:C1/C2 照算照打印,但不再决定哪条数可用。**


### ①(AND 门)—— 描述基本属实,但有一条**必须同时说出来的**附加事实
原文 Table 2(PD=95% 时的 PFA):`PHPR ∧ PNPR ∧ IMSD` = **PFA 3%**(全表最优);
`PNPR ∧ IMSD` = 5%;`PHPR ∧ PNPR` = 15%;**`PAPR` 单独 = 63%**。
⇒ 「最优组合是三项 AND」属实。
**⚠ 但:原文那三个特征里的 `IMSD` 是【谱距离,QM 帧、T_IMSD = 0.5 dB】;
我方 `_imsd` 是【自研构型:PAPR 轨迹上的 LS 斜率,dB/s 定义】(D0c §1.8,全域无同构)。
⇒ 把原文的【组合规则】套到我方的【不同特征】上,不等于复现原文结果。**
⇒ 本轮 ① 只做一件可判定的事:**把 GROWTH 入选式的 OR 旁路关掉**
   (`nhs.py:860` `(imsd_hit or tr.rapid_onset)` → `imsd_hit`),**不宣称"复现了原文最优组合"。**
**⚠ 且 `rapid_onset` 还在 `:818 arm2`(PHPR 否决豁免臂 2)上被用**
   ⇒ **只能改 `:860` 那一处**;全局把 `rapid_onset` 置假会连带关掉豁免臂 2 = 两处一起改,
   违反 lead 要求 1。**这正是本轮唯一需要碰 `nhs.py` 的原因(§6)。**

### ②(PAPR 门)—— ⛔ **「15.0 → 16.7」不成立,三条独立理由**
```
原文式(6)(7):PAPR = 10·log10( |Y(ω̆i)|² / (M·P̂y) ),P̂y = 全 M 个 bin 的平均功率
              ⇒ 实为【峰值功率 / 平均 bin 功率】,上限 = 10·log10(M)
我方 nhs.py `_papr`:20·log10( (len(M)−1)·|Y_k| / Σ_{j≠k}|Y_j| )
              ⇒ 513 个【单边】bin、**幅度**均值、剔除峰值 bin
```
**(a) 两者不是同一个量**(功率均值 vs 幅度均值差 ~1.05 dB;M=1024 双边 vs 513 单边;含/不含峰值 bin)
    ⇒ **把原文的门值直接搬进我方公式,是同族二义的第 6 例**(前 5 例:每侧/全宽、半/满步、
      峰值/RMS、单边/双边、10log10/20log10 —— **而 PAPR 这一个量上已经栽过一次**)。
**(b) `20·log10(M/150)` 不是原文的结论,是原文【引用的他人提案】([19][20])。**
    原文自己的 ROC 最优(Table 2)在 **M=4096 时是 `T_PAPR = 35 dB`**,
    而该式在 M=4096 给 28.7 dB ⇒ **原文自己的配置下,式与实测差 6.3 dB。**
**(c) PAPR 是原文里第二差的特征**:AUC 0.89 但 **PAUC(PFA≤5%)= 0.19**,PD=95% 时 **PFA = 63%**;
    **原文最优组合根本不含 PAPR。**
⇒ **② 改写为**:先按式(6)(7)**逐字重实现** `PAPR`(记 `_papr_jaes`),
   再取门 `T = 10·log10(M) − 1.1 dB`(= 原文 M=4096 时 35 dB 相对上限 36.1 的同一相对位置)
   ⇒ M=1024 时 **28.9 dB**;**同时报旧式旧门的读数**,两列并排,差异可审。
   **⛔ 不报"我们按原文把门从 15 提到 16.7"** —— 那句话四个部分有三个不对。

### ③(PNPR 邻元)—— 描述属实,但**漏了更重的一半:聚合方式也不同**
```
原文式(9)+判据(§3.1-4):PNPR(ω̆i,t,m) = 10·log10( |Y(ω̆i)|² / |Y(ω̆i+2πm/M)|² )
                        判据 = **∧_{m∈M_PNPR}** [ PNPR(·,m) ≥ T_PNPR ]  ← 对每个邻元【逐个】比,再取 AND
我方 nhs.py:324:      20·log10( |Y_k| / mean(|Y_j|, |j−k|>3, 外沿到 1/3 倍频程) )  ← 【对一个宽带求均值】的单一比值
```
⇒ **不只是"邻元集选得不同",是"判据结构不同"**:逐邻元 AND vs 对宽带均值的单比值。
⇒ **只改集合、不改聚合,仍然不是原文那个判据,AUC 0.77 照样不能引。**
⇒ 量化差距:`FS_SC=16000 / NFFT=1024 ⇒ df = 15.625 Hz`;原文 ±4 bin = **±62.5 Hz**;
   我方下限 187 Hz = ±12 bin,5 kHz 处 `f·0.26 = 1300 Hz` = **±83 bin** ⇒ **宽 3–20 倍**。
⇒ **③ 改写为**:实现 `_pnpr_jaes`(逐邻元 AND,`M_PNPR = {±2,±3,±4}`,`T_PNPR = 8 dB`
   —— 原文 Table 1 该集合 AUC 0.77 最高、Table 2 三项 AND 里正是这两个值),
   **旧式读数同时报**。⚠ 我方现行 `T_pnpr = 8.0` 与原文巧合相同,**但它作用在不同的量上**,
   **不得因为"数一样"就认为已经对齐**。

§4  ⭐ 第二条轴:选点准确度(直测,不依赖起振扫描,零额外算力)
════════════════════════════════════════════════════════════════════════
**为什么加**:①②③ 改的是**检测/分类**,即**选哪些频点**;而 ΔMSG 是**下游结果**。
若只看 ΔMSG,「没变好」会有两种完全不同的成因而无法区分。本轴把它们分开。
```
top1_hit  : 最高的那个神谕临界点,是否落在某个 NHS 陷波的 BW/2 内   ← **最承重**(MSG 由 max 决定)
hit@BW/2  : NHS 所挂陷波中,落在任一神谕 pick 的 BW/2 内的比例      (准确率)
cover@BW/2: 神谕 top-8 picks 中,被任一 NHS 陷波覆盖的比例          (召回率;NHS 可能挂不满 8 个)
|Δf|_min  : 每个 NHS 陷波到最近神谕 pick 的距离(Hz),逐条报
```
全部由 r64 已有的 `fr` 与 `picks` 直接算出,**不需要额外仿真**。
