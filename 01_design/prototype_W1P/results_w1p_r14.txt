【§0.1】⛔ 先提一条**对转来公式的反对**(写在实现之前,不是事后解释)
--------------------------------------------------------------------------------
转来的判据:
    判外部  ⟺  (ΔL_f − ΔL_rest) > X
**我认为这个方向是反的**,理由是它会产出硬要求①明令要避免的那个残余:

  情形                      ΔL_f      ΔL_rest    差分      按转来式判   物理上应判
  ① 真啸叫(我的陷波打断环路)  大(p10 18.2dB)  ≈0      **大**    **外部** ⛔   啸叫
  ② 外部持续音(源没停)       ≈0            ≈0       ≈0        啸叫  ⛔    外部
  ③ 外部源自己停了            大            大        ≈0        啸叫  ⛔    外部

⇒ 按字面式,**真啸叫会被判外部并撤陷 = 漏检** —— 而硬要求①正是写着
  「真啸叫被判外部 = 漏检」要避免。**字面式直接产出被禁止的残余。**
⇒ 我判断是转述/符号方向出错(与 C8-② 表把观测点写错同族)。

**我要实现的形式(同时满足硬要求①的"正向证据 + 啸叫为默认分支"):**
    判外部  ⟺  |ΔL_f − ΔL_rest| ≤ X        ← **正向的有界断言**(声称二者接近,非"缺证据")
    判啸叫  ⟺  否则(**默认分支**)
  · 情形① 差分大 ⇒ 判啸叫 ✔       · 情形② 差分≈0 ⇒ 判外部 ✔
  · 情形③ 差分≈0 ⇒ 判外部 ✔(这正是 F25 要修的)
  · 测量含噪/歧义 ⇒ 差分大 ⇒ **默认判啸叫 ⇒ 保留浅陷 ⇒ 良性残余** ✔
⚠ **若架构侧确认字面式才是本意,我请求先复核再实现** —— 但为不阻塞,本轮按上式实现,
  并把该反对与两式的差异实测报出。

【§0.2】D-H:`X` 的取值两端各须**不同机制**的独立论证
--------------------------------------------------------------------------------
**下界(太小会怎样)**:机制 = **估计方差**。ΔL_f 与 ΔL_rest 都是 bin/带级电平估计,
  r13 实测外部持续音的 ΔL 波动 max 达 **3.77dB**(256ms 窗)。X 若 ≲4dB,
  纯粹的估计噪声就会把**真外部音**推过门 ⇒ 判啸叫 ⇒ **陷波留在乐音上**
  ⇒ **已归零的四类(长笛/弓弦/空调/远端重放)会劣化**。⇒ X 须 > 4dB。

**上界(太大会怎样)**:机制 = **环路打断幅度的上限**(与上面完全不同的机制)。
  真啸叫的差分 ≈ ΔL_f(因 ΔL_rest≈0),r13 实测啸叫 ΔL **p10 = 18.22dB**。
  X 若 ≳18dB,**真啸叫的差分反而进不了"判啸叫"分支**…… 等价地,在 |·| ≤ X 形式下
  真啸叫会落进"判外部"区 ⇒ **撤掉真啸叫 = 漏检**。⇒ X 须 < 18dB。

⇒ **取 X = 8.0 dB**:距下界(噪声 3.77)余量 4.2dB,距上界(啸叫 p10 18.22)余量 10.2dB。
  偏向下界一侧,因**代价不对称**(漏检 ≫ 多留一个陷波),与 r13 的 `probe_thr_db` 同理。
  [L4/待 ROC 标定]

`ΔL_rest` 的定义与其自身两端(同样按 D-H):
  定义 = 剔除 f 的 ±1 个陷波带宽后,检测带(120–7800Hz)内的**能量和**电平变化。
  **邻域剔除太窄** ⇒ 陷波/啸叫自身的裙边漏进 rest ⇒ 共模被"自己"污染 ⇒ 差分被压小
    ⇒ 真啸叫被误判外部(漏检方向)。
  **邻域剔除太宽** ⇒ rest 的统计基底变小、方差变大,且会剔掉同源的邻近谐波
    ⇒ 共模抵消能力下降 ⇒ 源停时差分变大 ⇒ 假啸叫回升(F25 修不干净)。
  ⇒ 取 **±1 个陷波带宽**(bw_oct=1/5 ⇒ 在 220Hz 处约 ±31Hz;两端各有上述不同机制)。

仪器 B 的"存活挂陷"口径写错了,**r13 与 r14 同源同错**:

    base = 稳定段结束时的挂陷数
    n6   = 全程挂陷数 − base           ← **只算稳定段之后**的挂陷
    surv = n6 − count(c8-ext-retract)  ← **却减掉了全程(含稳定段)的撤陷数**

⇒ **稳定段内发生的撤陷,被从稳定段之后的挂陷里扣掉** ⇒ **存活数被低估**
⇒ **p̂ 系统性偏低。** 稳定段 = 1s / 6s = 试次的 17%,偏差量级非零。

  —— 这些都不经过 surv 这条路。
**仍然可用的是**:r13 ↔ r14 的**相对比较**(同一个有偏估计量,偏差同向)。
**不可用的是**:任何 p̂ 的**绝对值**,以及"归零"这一表述 ——
  p̂ = 0.000 可能是偏差造成的,**不得读作「零误报」**。

  **修正口径后须重跑,并把两套数并列报出**;在此之前
  **r13/r14 的 p̂ 绝对值一律标 [偏低/待重测],不得对外引用。**

【§3】为什么变差 —— 两个机制,第二个更严重
================================================================================
**机制 A:「对照」本身会动,而且会把差分**放大**而不是抵消。**
  diff = ΔL_f − ΔL_rest。若 rest **上升**(ΔL_rest < 0,如新音符/新说话人进入),
  则 |diff| > |ΔL_f| ⇒ **比单量判据更容易判啸叫**。实测:
    钢琴   ΔL_rest 为负 5/6;**|diff| > |ΔL_f| 3/6**
    多人交谈 ΔL_rest 为负 3/4;**|diff| > |ΔL_f| 4/4**
    长笛                     **|diff| > |ΔL_f| 1/1**
  且其中「|ΔL_f| < 8dB(**单量判据本不会判啸叫**)、被对照推过门」的:钢琴 1/6、多人 1/4、长笛 1/1。
  ⇒ **这就是长笛 0→3 的来源:C8-③ 制造了 C8-② 没有的假啸叫。**
  ⇒ **共模参考不是干净对照**:它与被测量共享同一批时变源,**不满足对照的独立性前提**。

**机制 B(更严重,且 C8-②/③ 都有):数值底病理。**
  `_level` / `_rest_level` 用 `10·log10(e + 1e-30)`;近静音 bin 给出 ≈ −300dB。
  实测钢琴 |ΔL| 分位:**p50 = 2.91dB,p90 = 325.68dB,max = 572.19dB**,
  |ΔL| > 100dB 占 **6/44**。
  ⇒ **数百 dB 不是物理量,是数值底的产物** ⇒ **判据在近静音 bin 上无定义**,
    拿它与 8dB 门比较**没有意义**。
  ⇒ 这也解释了钢琴恶化最重:钢琴的 bin 最容易在探针窗内跌到数值底(音符整个结束)。
  ⇒ **必须先立"有效性前提"**(如 L0 与 L1 都须高于底噪 + M dB,否则**探针弃权**,
    不产出任何判决),再谈门限。**弃权 ≠ 判啸叫,也 ≠ 判外部。**
  ⚠ 定点移植下该病理形态不同(饱和而非 −300dB),但**同样无定义** ⇒ 属可迁移性问题。

⇒ **「假啸率 0%」不是"共模救得了裸纯音停止",而是"这条路这次没跑到"。**
⇒ 按我自己在 r12 立的形态:**未触达的路上,通过和不通过都无效。**
⇒ 修法:构造须让纯音**停止后再以不同频率重来**,或把 `ext_ttl_s` 短于停止时刻,
  **下一轮重造并重跑**;在此之前**不得**声称该失效面已验证。
