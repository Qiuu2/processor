0. 为什么是这条线(lead 2026-08-04 收回 r78 的设计并重设)
═══════════════════════════════════════════════════════════════════
```
总陷波带宽 = **NN × bw_oct**,文献预算 0.8–1.2 倍频程
  现状        8 × 1/5  = 1.60 oct   ⛔ 超预算 1.3–2×
  只加 NN     24 × 1/5 = 4.80 oct   ⛔ 荒谬,数不能当产品用
  只收 bw_oct(= r78 跑的那条)      ⇒ 总带宽 1.60 → 1.00 → 0.80 **往下走**
⇒ **单独扫任一个都会走出预算 ⇒ 得到的数无法用**
```
**⇒ 正确设计 = 把总带宽钉在预算内(≡ 1.00 oct),用 `NN` 换 `bw_oct`:**
```
N08  NN=8  × 1/8  = 1.00 oct  ✅      N16  NN=16 × 1/16 = 1.00 oct  ✅
N10  NN=10 × 1/10 = 1.00 oct  ✅      N24  NN=24 × 1/24 = 1.00 oct  ✅
参照 R05  NN=8 × 1/5 = 1.60 oct  ⛔ 超预算,**只作对照,不作结论**
       ⇒ 直接复用 r78 的 C1 逐格 json(同工作点,已跑完)⇒ **不重跑**
⇒ 这条线上**音质代价恒定** ⇒ 差异全部来自【多而窄 vs 少而宽】⇒ 结论直接可用
```

**⇒ 这个实验决定一件架构级的事**(lead 原话,已含他自己的撤回):
```
lead 曾对 CTO 说「T60=0.5 层就算完美也到不了 5 dB ⇒ 需要 AFC」
⇒ 该句已撤回并立纪律 D6-af:**把【某配置的上界】说成了【方法的上界】**
⇒ 本扫描判定它:上界随 NN **显著上涨** ⇒ 天花板是「8」的性质 ⇒ AFC 结论不成立
                上界很快**饱和**       ⇒ 才是方法的性质 ⇒ AFC 回到桌面
```
⚠ 算力不是约束:24 陷波 × 8 路 × 2.5 cyc/biquad @48k ≈ 23 MHz / 1 GHz = **2.3%**
  `[L2/厂家锚点推算,EE-408]` ⇒ ⛔ 不得拿算力当限制 NN 的理由。

3. ⭐⭐ 预注册假设 —— 含 lead 点名要写死的那个【不对称】
═══════════════════════════════════════════════════════════════════
**物理依据**:模态带宽 ≈ `2.2 / T60`(Schroeder 相干带宽)
```
T60 = 0.2 ⇒ 模态带宽 **11.0 Hz**       T60 = 0.5 ⇒ 模态带宽 **4.4 Hz**
1/24 oct 的绝对带宽:200 Hz 处 ≈ 5.8 Hz ｜ 1 kHz 处 ≈ 28.9 Hz
⇒ 陷波比模态还窄 ⇒ 削不干净 ⇒ 收益应在那里转平或下降
```
**Hc1(lead 的不对称,写死)**
```
T60=0.5(模态窄 4.4 Hz)⇒ 窄陷波仍够用 ⇒ 应【明显受益】于多而窄
T60=0.2(模态宽 11 Hz)⇒ 低频段窄陷波已不够 ⇒ 受益应【更早饱和】
⛔ 若实测反过来(0.5 层不受益、0.2 层受益)⇒ **lead 这条推理错,当场记 F 条,⛔ 不替他圆。**
```
**Hc2(本轮的判定量,⛔ 报法已写死)**
```
⛔ 不报「NN 越大越好」
✅ 报【**在哪一档饱和**】—— 那个饱和点才是答案
   饱和判据:相邻两档的 `臂O 达标数`(或 ΔMSG 中位)之差 **< 仪器底 0.354 dB** ⇒ 视为已饱和
   在 8–10 就饱和 ⇒ 天花板是【方法】的性质 ⇒ AFC 那条路回到桌面
   一路涨到 24   ⇒ 天花板是【「8」这个数】的性质 ⇒ ⛔ AFC 结论撤销
```
**Hc3** · `臂O@神谕选点` 随 NN 单调不减(更多陷波不应更差)。
      证伪:出现可判的下降 ⇒ **臂 O 的构造在高 NN 上有问题**(接 r78 的「上界名不成立」),
      须与 INV-O 一起查,⛔ 不得直接当作"多而窄更差"的证据。
**Hc4** · 自选臂随 NN 的变化**不预测方向** —— 更多槽 ⇒ 更多机会,但也更多误挂。只记录。
**Hc5** · `n_cand` 单独效应(r79-N08 vs r78-C2,同 NN 同 bw,只差 16→48):
      **不预测方向**,如实报。⚠ 它是"从被砍到 16 的名单里挑"这条上游链的直接测量。
