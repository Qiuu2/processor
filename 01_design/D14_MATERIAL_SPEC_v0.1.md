### 3.2 ⭐ 数量怎么来的(⛔ 不是"3–5 段",是算出来的)

**依据一:零事件时能断言多强的上界(Wilson 95%,[L3/解析,我方计算])**

| N | 0/N 时 95% 上界 |
|---|---|
| 50(**现行**) | **7.13%** |
| 73 | 5.00% |
| 189 | 2.00% |
| 381 | 1.00% |

```
⇒ 现行 N=50 只能说「掌声/咳嗽/键盘 的误报率 < 7.13%」,⛔ 说不了"不误报"
⇒ 要断言 ≤5% 需 N ≥ 73;要 ≤2% 需 N ≥ 189;要 ≤1% 需 N ≥ 381
⇒ ∴ **N 直接由 CTO 在 §1 定的目标数决定** —— 这就是为什么 §1 必须先答
```

**依据二:要能分辨"修法有没有用"(= ROC 标定的真正用途)**

⚠ 两种设计的成本差一个量级,**必须选对**:

```
【非配对】两组独立试次比较(α=0.05 双侧,power=0.80,[L3/解析]):
   p 1.00 → 0.90  需 N/组 ≥ 74
   p 0.94 → 0.80  需 N/组 ≥ 90
   p 0.72 → 0.50  需 N/组 ≥ 76
   p 0.40 → 0.20  需 N/组 ≥ 82
   ⇒ 反过来:**N=50 时最小可分辨降幅 ≈ 20–27 个百分点**
   ⇒ ⛔ 也就是说:现行仪器**看不见**"钢琴 1.00 → 0.90"这种真实改善

【配对】同一批试次跑两个判据变体 ⇒ 只数【结果不同的试次】(符号检验/McNemar)
   单侧精确 p = 0.5^k(k = 不一致试次数,且全部朝一个方向)
   k=5 ⇒ p=0.031 ｜ k=7 ⇒ p=0.0078 ｜ k=10 ⇒ p=0.001
   ⇒ 要看见 10 个百分点的改善,期望不一致数 = 0.10·N ⇒ **N ≈ 50–70 即够**
```
**⇒ ∴ 规格硬性要求:ROC 标定一律用【配对设计】(同一批试次,变体间只比不一致的那些)。**
**⇒ 而这条要成立,素材必须【可精确重放、逐样本可复现】—— 见 3.4 格式要求。**

**依据三:试次必须互不重叠(否则不独立)**

> ⚠ **这条是从一次事故来的,不是纪律条文**:r10 之前的套件用**单条 10 s 连续片段**计次,
> 而一次 engage 占槽 ≈105 s ⇒ 后续误报被**自己已挂的陷波挡住** ⇒ **计数天然封顶在 1**。
> **那个"1 次"不是低误报率,是计数器饱和。** 连带 B5 的"1→8"等一切比较全部作废。

```
⇒ 每试次:6 s(现行) · 全新 NHS 状态 · 与其他试次【不重叠】的音频段
⇒ 每类所需【互不重叠】音频时长 = N × 6 s
     N=50  ⇒ 5.0 min/类 ｜ N=73 ⇒ 7.3 min/类 ｜ N=150 ⇒ 15.0 min/类
   10 类合计:N=73 ⇒ **约 1.2 h** ｜ N=150 ⇒ 约 2.5 h(⛔ 均指**净音频**,不含静音/切换)
```

⚠ **而 6 s 这个试次长本身只覆盖"检出路"**(GROWTH 反应 0.11–0.18 s、IMSD W_long=128 ms)。
**槽位占用/回收(LIFT 60 s + reclaim 30 s)在 6 s 试次里【永远测不到】。**
⇒ ∴ 另立 **A-长**:每类 **1 段 ≥ 300 s 连续**(≥ 105 s 的 2.85 倍),N=3 段,只测占用/回收/抖动,
  ⛔ 不进误报率统计(它就是那个会饱和的量)。

### 3.4 格式与可复现要求(⛔ 配对设计的前提)


## §5 C 类:真实房间 RIR —— **它是唯一能解 B-3 的东西**

> `03_open_questions B-3`:台架 plant 按构造就是统计模型 ⇒ 在它上面数临界点**只会复现自己的假设**
> ⇒ **不是"待验证",是「验证手段本身缺失」** ⇒ 资源决定,归 CTO。

**规格(⛔ 每条都由已知问题反推,不是通用最佳实践)**:

| 项 | 要求 | 为什么是这个数 |
|---|---|---|
| 房间数 | **≥3**,体积覆盖 **V ≈ 60 / 100 / 300 m³** | 收口件 §5.0:`f_c ∝ 1/√V`,V 在 60–300 间 `f_c` 跨度 **3.5×** ⇒ 单一房间答不了 |
| ⭐ 小房间 | **另加 1 间 V ≲ 51 m³** | `03_open_questions C-2`:解 `f(M=1)=120` 得 **V≈51 m³**,该值以下"两段分离"结论**失效** ⇒ 必须有一个证伪点 |
| T60 | 覆盖 **0.2 与 0.5 s** 附近各 ≥1 间 | 与全线六条种子同档,便于与 [L2] 结果对表 |
| **低频下限** | RIR 在 **≥20 Hz** 处须有效 | 真正"模态少"的段 = **31–110 Hz**,整段在 NHS 检测带下沿之下;而 F35 实测该盲区会成为封顶(f_trig 52.2 / 22.3 Hz)⇒ **测不到 20–120 Hz 就答不了那个问题** |
| 激励法 | **指数扫频(ESS)**,⛔ 不用气球/掌声 | 冲击源在 <120 Hz 能量与重复性都不够,而 <120 Hz 正是本次要看的段 |

## §10 判据的双极值代入自查(lead 纪律③)

> **规矩**:每条判据,代入"**真该过**"与"**真该不过**"的值各一次,两次答案必须相反。
> **⇒ 今天有一条护栏就是符号写反了,而它只在真正成功的那一刻才误伤。**

| 判据 | 真该过 ⇒ | 真该不过 ⇒ | 相反? |
|---|---|---|---|
| **G-1 素材可复现**:每段 sha256 == MANIFEST | 未改动的段 ⇒ 相同 ⇒ **过** | 被重采样/重归一过的段 ⇒ 不同 ⇒ **不过,且中止** | ✅ |
| **G-2 试次独立**:同类任两试次的样本区间交集 == ∅ | 顺序切分不重叠 ⇒ ∅ ⇒ **过** | 用滑窗切(重叠 50%)⇒ 交集非空 ⇒ **不过** | ✅ |
| **G-3 状态新鲜**:每试次起始 NHS 挂陷数 == 0 ∧ g_duck == 0 | 每试次新建实例 ⇒ 0 ⇒ **过** | 复用实例(r10 之前那种)⇒ >0 ⇒ **不过** | ✅ |
| **G-4 类别不为空**:每类实际入库时长 ≥ N×试次长 | 长笛 8 min ≥ 73×6s=7.3min ⇒ **过** | 长笛只有 2 min ⇒ **不过**(⛔ 不许降 N 凑) | ✅ |
| **G-5 断言强度**:凡报"不误报"必附 Wilson 上界 | 0/73 ⇒ 上界 5.00% ⇒ 报"≤5%" ⇒ **过** | 0/50 报"不误报" ⇒ **不过**(只能说 ≤7.13%) | ✅ |
| **G-6 RIR 低频有效**:每条 RIR 在 20–120 Hz 的带内 SNR ≥ 20 dB | ESS 15 s + 大箱 ⇒ 达标 ⇒ **过** | 气球爆 ⇒ 低频 SNR 不足 ⇒ **不过,该条作废** | ✅ |
| **G-7 归一一致**:每段 RMS 与 −20 dBFS 差 ≤0.1 dB | 归一后 ⇒ **过** | 忘了归一(−35 dBFS)⇒ **不过** | ✅ |

**⇒ 而 G-1/G-3/G-4/G-6 是【中止条件】不是【输出行】**:失败即停,⛔ 不得"记下来继续跑"。
**⇒ 自查一句「这个检查失败时会阻止什么?」——**
```
G-1 阻止:在被悄悄改过的素材上出 ROC 数        G-2 阻止:把相关试次当独立试次做统计
G-3 阻止:r10 那个"计数器饱和"事故原样复发      G-4 阻止:样本不够却照常出断言
G-6 阻止:用一条低频无效的 RIR 去答一个纯低频问题
```
