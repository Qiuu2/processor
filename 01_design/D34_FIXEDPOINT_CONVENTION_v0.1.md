## 1. 记法与参考约定(先钉死,后面所有数才有意义)

### 1.1 Q 记法
写 `Qm.n` = **1 符号位 + m 整数位 + n 小数位**,总位宽 = 1+m+n。
- `Q0.31` = 32 bit,范围 [−1, 1−2⁻³¹],LSB = 2⁻³¹
- `Q4.27` = 32 bit,范围 [−16, 16−2⁻²⁷],LSB = 2⁻²⁷

**异名声明**:常见写法「Q1.31 / Q5.27」(把符号计入整数位)与上表**同物异名**,本项目不用。
单数字写法 `Qn` 一律读作 `Q0.n` ⇒ 库内旧文的「Q31」= 本文 Q0.31,「Q15」= Q0.15。
本节继承 W1-A §3.1-1 的记法统一声明(⚠ W1-A 未过门,此处**只继承记法约定,不继承其数值结论**;
本件的系数格式是独立重推的,结论也与 W1-A 的 Q1.30 不同 —— 见 §3.3)。

### 1.2 dBFS 参考约定 —— **峰值参考**
`dBFS(x) = 20·log₁₀(|x| / 1.0)`,即 **0 dBFS ⇔ 幅值 1.0**。

> **⚠ 这是本项目已栽过的同族二义面(DEC-0010:峰值/RMS)。**
> 对**正弦**而言,「峰值参考」与「满幅正弦 RMS = 0 dBFS」两种约定给出**相同读数**(可证:
> 20log₁₀((A/√2)/(1/√2)) = 20log₁₀(A));对**噪声/节目素材**两者相差 **3.01 dB**。
> ⇒ 本文件所有 dBFS 数一律峰值参考。引用本文数字时**必须连这句一起引**。

### 1.3 电平锚点(⚠ 依赖模拟前端,前端定稿后必须回核)

| 量 | 值 | 来源 |
|---|---|---|
| 标称输入电平 | **+4 dBu ⇔ −20 dBFS**,余量 20 dB | CTO 2026-08-04 拍板 |
| ⇒ 数字满量程对应模拟电平 | **0 dBFS ⇔ +24 dBu = 12.28 V rms** | [L3/上行推算] |
| ADAU1979 满量程差分输入 | **4.5 V rms(typ,min 4.18 / max 4.82)= +15.28 dBu** | [L2/厂家 datasheet Table 1] |
| ⇒ **模拟前端须提供的净衰减** | **−8.72 dB**(15.28 − 24) | [L3/解析] |
| ADAU1962A 满量程差分输出 | **2.00 V rms = +8.24 dBu** | [L2/厂家 datasheet] |
| ⇒ DAC 后须提供的净增益 | **+15.76 dB** | [L3/解析] |

> **⭐ 这是 CTO 那条限定的具体答案,不是重复那条限定**:
> 「+4 dBu ⇔ −20 dBFS」**在 ADAU1979 上不是自动成立的** —— 该 ADC 的满量程只有 +15.28 dBu。
> ⇒ 若前端为单位增益直入,实际是「+4 dBu ⇔ **−11.28 dBFS**」,余量只剩 11.28 dB,
> 则 §6 的余量预算两个数(44.08 / 24.08)须改为 35.36 / 24.08。
> ⇒ **模拟前端选型/增益结构定稿后,本节必须回核**(已列入 §10 待办)。
>
> **⚠ 另记一条给 lead 路由(不在我职责内,但它是我噪声预算的锚)**:
> ADAU1979 动态范围 **min 103 dB / typ 109 dB(A 计权)**[L2/厂家],
> 而 PRD §一.1 要求 **动态范围 > 106 dB**。⇒ **最坏档器件不满足对外规格**。
> 该判断属器件选型(architect / platform-fw),此处只如实记录。

## 2. ① 样本格式与满刻度

### 2.1 两个域,一个参考

```
codec ──► [Q0.31] ──chdsp_io_to_smp──► [Q4.27 链内] ──chdsp_smp_to_io──► [Q0.31] ──► codec
          1.0=0dBFS                     1.0=0dBFS(整数位多 4 bit)          饱和点
```
**两个域用同一个 0 dBFS 参考**,差别只在余量位数。⇒ 「这个节点的 0 dBFS 是多少」全链只有一个答案。

| 节点 | 格式 | 0 dBFS 对应整数 | LSB 的 dBFS 值 |
|---|---|---|---|
| TDM 输入槽 / 输出槽 | Q0.31 | 2³¹ | −186.6 dBFS |
| 链内全部节点(HPF/PEQ/门/压限/分频/延时/限幅) | Q4.27 | 2²⁷ | −162.6 dBFS |
| 累加器 | 见 §5 | — | −325.2 dBFS |

### 2.2 为什么链内右移 4 bit 不丢信息
codec 为 **24-bit**(ADAU1979/1962A)⇒ 输入样本在 Q0.31 里低 8 bit 恒为 0。
右移 4 bit 后仍在 ADC LSB(2⁻²³)之下留 **4 bit**(2⁻²⁷ = 2⁻²³/16)。

**实测**:20 万个 24-bit 左对齐样本,`smp_to_io(io_to_smp(x)) == x` **逐位相同,0 处不等**
[L2/宿主实测 CHK-6]。
**阴性对照(证明该检查不是恒真)**:低 8 bit 非 0 的输入(超 24-bit)确实有损 ⇒ CHK-6n PASS。

## 3. ② 系数格式 —— 与样本不同,而且理由分两类

### 3.1 a 系数的界是**数学界**
任何稳定二阶节的极点在单位圆内 ⇒ **稳定三角**:`|a₂| < 1` 且 `|a₁| < 1 + a₂ < 2`。
⇒ `a₁ ∈ (−2, 2)`、`a₂ ∈ (−1, 1)`,**构造上不可超越**,不依赖任何参数网格。
数值旁证:10⁶ 次随机稳定极点抽样,max|a₁| = 1.999709、max|a₂| = 0.999998 [L2/宿主]。

### 3.2 b 系数的界是**经验扫描界** —— 性质完全不同
> ⚠ 团队纪律 D6-ah:「上界」是需要证明的断言,不是命名选择。此处如实标为**扫描界**。

fs = 48 kHz,参数范围见 §9 台账。全族归一化系数扫描结果:

| 族 | 参数范围 | max\|b\| | 取到最大值的配置 |
|---|---|---|---|
| PEQ 峰型 | f∈[20,20k], Q∈[0.3,20], G∈[−15,+15] | 2.9082 | f=11.9 kHz, Q=0.3, G=+15 dB |
| 低架 | f∈[20,20k], S∈[0.3,1.0], G∈[−15,+15] | 6.2187 | f=20 kHz, S=1.0, G=+15 dB |
| **高架** | f∈[20,20k], S∈[0.3,1.0], G∈[−15,+15] | **11.2148** | **f=20 Hz, S=1.0, G=+15 dB** |
| HPF | f∈[20,20k], Q∈[0.3,20] | 1.9999 | f=20 Hz, Q=20 |
| LPF | f∈[20,20k], Q∈[0.3,20] | 1.8430 | f=20 kHz, Q=20 |

**⇒ 全族 max|b| = 11.2148 @ {高架, f₀=20 Hz, S=1.0, G=+15 dB, fs=48 kHz}** [L2/宿主扫描]

> **⭐ 这一格正是 D-4 的形态**:W1-A 只看陷波(只有 a₁ 要装)⇒ 得出 **Q1.30(±2)**;
> 而 D3/D4 的 **PEQ 峰型就已经 2.91 > 2**,架式滤波器到 11.21。
> **⇒ Q1.30 对 D3/D4 不够用。单族正确 ≠ 全族正确。**

#### 3.2.1 ⚠ 这个界对哪个参数敏感 —— **答案不是我一开始以为的那个**

我最初把 `S ≤ 1.0` 当成保住系数范围的关键限制。**实扫之后不成立**:

| 扫描 | max\|b\|(高架 @20 Hz) | 结论 |
|---|---|---|
| S 从 **1.0 → 2.0**(G 固定 +15 dB) | 11.2148 → **11.2292**(+0.0144) | **S 几乎不影响** |
| G 从 **+15 → +18 dB**(S 固定 1.0) | 11.2148 → **15.8373** | **增益是唯一的驱动量** |

**⇒ Q4.27 的真实有效包络:架式滤波器增益 ≤ +18.089 dB**(该点 max|b| = 16.000,
配置 = {高架, f₀=20 Hz, S=1.0, fs=48 kHz})[L2/宿主二分求解]。

> **⇒ 留痕(为什么值得单写)**:若我把「S ≤ 1.0」写成保护条件,就会**把保护归给一个几乎不起作用的常数**
> —— 而真正的约束(增益 ≤ +18.09 dB)没人守。这与团队纪律 **D6-r「锁错字串的 lint 比没有 lint 更坏」**
> 是同一形态。**⇒ `S ≤ 1.0` 的理由是【音质】(RBJ Cookbook:S > 1 使架式响应产生峰起),
> 不是【系数范围】。两个理由不得互相冒充。**
>
> ⇒ 若 D2 参数字典把增益放宽到 ±18 dB 以上,**Q4.27 立即不够** —— 由 §3.4 的接口硬失败拦截。

### 3.3 裁决:**统一 Q4.27**(±16)
- 覆盖 11.2148,余量 1.43×
- a₁ 精度:半 LSB = 2⁻²⁸ ⇒ 陷波中心频误差 δf = δa₁/(2r·sinω₀)·fs/2π

| 候选格式 | 半 LSB | δf @100 Hz(r=.999346) | δf @20 Hz(r=.99868) | 对 BW/4 = 3.75 Hz 判据 |
|---|---|---|---|---|
| Q1.14(16-bit) | 3.052e−5 | **8.911 Hz** | 44.58 Hz | ✗ 不过 |
| Q1.30 | 4.657e−10 | 1.360e−4 Hz | 6.803e−4 Hz | ✓ 余量 2.8e4 × |
| **Q4.27(本裁决)** | 3.725e−9 | **1.088e−3 Hz** | 5.442e−3 Hz | ✓ **余量 3448 ×** |

> **⚠ 交叉核留痕**:上表 Q1.14@100 Hz 的 **8.911 Hz** 与 W1-A / critic-w1 / lead 三方
> 独立收敛的数**逐位一致**;Q1.30 的 1.360e−4 Hz 亦与其 0.00014 Hz 一致。
> ⇒ 本人第四轨独立复算相符,**该公式可信**。(⚠ W1-A 未过门,此处只作交叉核不作依据)
> **⇒ 从 Q1.30 降到 Q4.27 换来 3 bit 系数精度的代价,在 AFC 判据下仍留 3448 倍余量。**

### 3.4 ⭐ 界失效时靠**接口**拦,不靠文档提醒(D-1)
`chdsp_coef_from_f64()` 对 |x| ≥ 16 **返回非 0(硬失败)**,调用方必须处理。
**实测**:11.2148 → 0(成功);16.0 → −1;−17.5 → −1 [L2/宿主实测 CHK-8]。
⇒ 参数范围一旦放宽到使某个 b 超 16,**系数计算当场失败**,不会静默产出错误滤波器。

## 4. ③ 溢出策略:饱和,禁回绕

### 4.1 为什么这条是灾难级
回绕 = int64→int32 窄化时**正峰翻成大负值** ⇒ 满量程尖峰 ⇒ 爆音 + 后级功放/高音单元风险。
本项目库内已有同型前车:ITC `tree_filterbank` 的 PF-4 缺陷(Σ|h|=1.7309 > 1,
对抗激励下 acc>>15 达 1.73× FS,原无饱和 ⇒ 符号翻转爆音)[L1/ITC 同芯片,PROVENANCE 在案]。

### 4.2 规定
- **每一个** int64/int128 → int32 的窄化点必须饱和到 [INT32_MIN, INT32_MAX]
- 目标侧硬件支持:`MRF = SAT MRF`(两补码分数),溢出可由 `STKY.MOS` 粘滞位读出
  [L2/厂家 SHARC+ Core PR §Multiply Register Instruction Types / Arithmetic Status]
- 每次饱和 ⇒ `sat_count++` 且 `sat_sticky = 1`

**实测**[L2/宿主实测 CHK-1/1n/1z]:
- 好版本:`smp_to_io(0x7FFFFFF0)` → `INT32_MAX`,粘滞位置起 ✓;负向 → `INT32_MIN` ✓
- 坏版本(强制回绕):同输入 → **负值(符号翻转)** ⇒ 该缺陷可被观测
- **反向(护栏会不会挡掉对的)**:未溢出输入**不置**粘滞位 ✓ (CHK-1z)

### 4.3 ⭐ 报警必须接处置(团队纪律 D3)
> 「计数器让人觉得问题被管起来了,实际只是被看见了。」

`chdsp_sat_t` 的**三个消费者已写死在头文件 §7**,D3/D4 落地时逐条接线,**缺任一即视为本机制未闭环**:

| # | 消费者 | 动作 |
|---|---|---|
| C-A | 诊断遥测 | 每统计窗随电平表上报上位机 → CLIP 指示 |
| C-B | Debug 构建 | **链内(非输出端)**饱和直接 assert —— 链内饱和 = 余量策略被突破 = 设计缺陷,不是运行工况 |
| C-C | 输出保护 | 输出端饱和计数进入 D4 音箱保护限幅器输入(持续饱和 ⇒ 降增益) |

> **⚠ 接口只供事实,不供判断**(团队纪律 Interface contract #7):
> 本层只给 `{sat_count, sat_sticky}` 原值,**不给「是否该报警」的阈值判断** —— 阈值属接收方判据层。

## 5. ④⑤ 舍入策略、累加器宽度、在哪一步重新量化

### 5.1 累加器:两个不同的量,不许混
| # | 量 | 值 | 性质 |
|---|---|---|---|
| (a) | **类型范围上界** | \|X\|≤2³¹ ∧ \|C\|≤2³¹ ⇒ 7 项 ⇒ **64.807 bit ⇒ 须 ≥66 bit** | 构造上不可超越 [L2/实测 CHK-3] |
| (b) | **参数范围实测占用** | 最坏合法配置(低架 20 Hz/S=1/+15 dB + 满量程方波)⇒ **58.005 bit** | 经验扫描 [L2/实测 CHK-11] |

> **⭐ 留痕:我第一版写的是「int64 不够 —— 这不是保守,是算出来的」。**
> **r2 实测 58.005 < 63 ⇒ 该说法在真实参数范围内【被证伪】(预注册证伪条件命中)。**
> **已按预注册要求改正被测物,而不是改判据。** 现行正确表述:
> - int64 在 (b) 下够用、在 (a) 下不够;
> - 本项目按 (a) 要求 ≥66 bit,理由**不是**「真实工况会溢出」,而是
>   **(b) 是经验扫描,随参数范围放宽而失效,而 SHARC+ 的 MRF 本来就是 80 bit ⇒ 按 (a) 要求不花任何代价**。

**目标侧**:SHARC+ 定点 MRF = **80 bit(64 bit 结果 + 16 guard bits)**
[L2/厂家:Core PR "a multiplier with an 80-bit fixed-point accumulator";
HW Ref §38 "A 32-bit fixed-point operation generates 80-bit results (64-bit result + 16 guard bits)"]。
**宿主参考实现**:`__int128`。

> ### ⚠⚠ 前提更正:关于「SHARC+ 的 40 bit 扩展精度」
> 派单里写「SHARC+ 有 40 bit 扩展精度 ⇒ 用不用它会改变整个噪声分析」。**在定点口径下这条不成立**:
> - **40-bit 是【扩展精度浮点】格式**(比 IEEE 单精度多 8 bit 尾数)[L2/厂家 Core PR §Dual Processing Elements]
> - **定点数据在 40-bit 寄存器里左对齐占高 32 bit,低 8 bit 读时忽略、写时清零**
>   [L2/厂家 Core PR §Data Registers] ⇒ **定点路径拿不到那 8 bit**
> - 定点的额外精度来自 **80-bit MRF**,不来自寄存器宽度
> ⇒ 本文件按 80-bit MRF 做噪声分析。**该问的问题不是「用不用 40 bit」,而是「重量化点放哪」(§5.3)。**
> ⇒ **同时闭掉 W1-A 的一条 [L4/待核]**:W1-A §3.1-2 写「核心侧指令级确认待 sw_reference 精读 [L4/待核]」
>   —— 已由上述两条厂家原文确认。

### 5.2 舍入:就近舍入(RTN),禁截断
两补码丢弃低位 = 向 −∞ 取整 ⇒ **每次量化引入 −0.5 LSB 的确定性直流偏置**,
该偏置在 DF1 递归里被本节的 |1/A(1)| 放大(20 Hz Butterworth HPF:|1/A(1)| ≈ 1.0e5)。
硬件支持:`MRF = RND MRF` 对 MR1F/MR0F 边界做就近舍入,**是指令修饰符,不额外花周期**
[L2/厂家 Core PR §Round MRx Instruction]。

**实测**[L2/宿主实测 CHK-2b]:
- 好版本(RTN + EF):`mean(y_定点 − y_参照)` = **4.99e−12 满刻度 = 0.001 LSB**
- 坏版本(截断 + 无 EF):|mean| ≥ 1e−5 ⇒ 被杀死

> **⚠ 一条自曝**:我最初的 CHK-2 测的是「输出信号的样本均值」,判据 ≤1e−7。
> r2 用 8 个种子复测,**种子间标准差 s = 1.226e−6** ⇒ **判据落在测量噪声内,该检查没有分辨力**
> (LESSONS C-3:分辨力之下的不等号既不能证真也不能证伪)。
> ⇒ 换被测量为「**算术误差**的均值」(CHK-2b)后才有分辨力。
> ⇒ **原 CHK-2 已退役但未删除**,判据与实测原样留在 results 里(E-2:加标注不删数)。

### 5.3 结构:**DF1**,禁 DF2/DF2T —— 理由是量的
DF2/DF2T 的内部节点 `w` 的传函是 `1/A(z)`,其峰值增益决定所需整数位:

| 算例 | max\|1/A\| | dB | DF2 需额外整数位 |
|---|---|---|---|
| PEQ 20 Hz Q=20 G=+15 dB | 5.711e6 | **135.13** | **23 bit** |
| PEQ 20 Hz Q=20 G=0 dB | 2.789e6 | 128.91 | 22 bit |
| HPF 20 Hz Q=0.7071 | 1.462e5 | 103.30 | 18 bit |
| PEQ 1 kHz Q=20 G=0 dB | 1.178e3 | 61.42 | 11 bit |

**⇒ 32-bit 字长装不下 ⇒ DF2 在本参数范围内不可用。** [L2/宿主]
DF1 的状态是 x 与 y 本身(均受信号电平约束),**每节只有一个量化器,在节输出处**。

### 5.4 ⭐ 二阶误差反馈(EF)—— **必选,不是可选优化**
DF1 的输出量化误差 E 经 `1/A(z)` 到达输出 ⇒ 噪声增益 `NG = Σ|h_{1/A}|²`。
把 `C(z) = A(z)` 的误差反馈加回累加器 ⇒ 噪声传函 `C/A ≡ 1` ⇒ 噪声白化。

**实测(定点仿真,Q4.27,8 个算例)**[L2/宿主实测 CHK-4]:
白噪基准 `q²/12 = −173.35 dBFS`(q = 2⁻²⁷)

### 5.5 重量化点与移位量
```
acc_raw = Σ Xᵢ·Cᵢ              (整数精确,X:Q4.27,C:Q4.27 ⇒ 真值 = acc_raw / 2⁵⁴)
y_raw   = RTN(acc_raw / 2²⁷)   (⇒ 回到 Q4.27),然后饱和到 int32
```
**移位量恒等于 `CHDSP_COEF_FRACBITS`,由格式推出,⛔ 调用方不得自选。**
头文件不提供任何暴露移位量的接口(见 §8 的负向编译测试 N5)。

> **⚠ 目标侧待确认 [L4/待 W1-C 或 CCES 实测]**:SHARC+ 定点乘法的**分数模式**会自动左移 1 位
> 去掉冗余符号位;**整数模式**不会。本文件按**整数模式**语义写(移位 27)。
> 若目标实现用分数模式,移位量改 26 —— **该差异只在 `chdsp_acc_to_smp_r()` 一处**,
> 且由 CHK-9(逐位一致)兜底。⛔ 未在目标板确认前,不得当作已定。

## 6. ⑥ 链内余量策略

### 6.1 余量账
```
链内格式 Q4.27 ⇒ 整数位 4 bit ⇒ 余量 = 4 × 6.0206 = 24.0824 dB
```
| 起点 | 到链内饱和的余量 |
|---|---|
| 标称输入 −20 dBFS | **44.08 dB**(20 dB 信号余量 + 24.08 dB 格式余量) |
| 满量程输入 0 dBFS | **24.08 dB** |

⚠ 上两个数依赖 §1.3 的电平锚点。**若模拟前端为单位增益直入(+4 dBu ⇔ −11.28 dBFS),
第一行改为 35.36 dB。**

### 6.2 规则
1. **链内允许超过 0 dBFS**(这是 Q4.27 存在的理由):PEQ +12 dB 作用在 −20 dBFS 上得 −8 dBFS,
   作用在 −6 dBFS 上得 **+6 dBFS —— 在 Q0.31 下会削,在 Q4.27 下不会**。
2. **链内饱和 = 设计缺陷,不是运行工况** ⇒ Debug 构建下 assert(消费者 C-B)。
3. **全链唯一合法的削波点 = `chdsp_smp_to_io()`**(输出端 Q4.27→Q0.31)。
   在它之前必须由**输出限幅器**把电平压住(D4 职责)。
4. 用户可把 8 段 PEQ 全部 +15 dB 叠在同一频率 ⇒ 链内提升可超 24.08 dB。
   本层**不阻止**,只保证:饱和而非回绕、被计数、被上报。**处置属 D3/D4 的增益结构设计。**

### 6.3 余量的代价 —— 以及为什么它现在是免费的
链内每让出 1 bit 余量,量化噪声底抬高 6.02 dB。Q0.31 → Q4.27 抬高 **24.08 dB**。
**但在 EF 之后,噪声底是 −173.35 dBFS/节**,而设计目标是 ≤ −120 dBFS ⇒ 余量 53 dB。
⇒ **EF 把「余量」与「噪声」这两个原本对立的目标解耦了。** 若无 EF,4 bit 余量会把
最坏算例推到 −84.44 dBFS 量级,完全不可接受。

### 6.4 D-4:整条链的噪声底(⛔ 不许只验单级)
| 链 | 量化器数 | 噪声底 = −173.35 + 10·log₁₀(N) |
|---|---|---|
| 单节 | 1 | −173.35 dBFS |
| 8 段 PEQ | 8 | **−164.32 dBFS** |
| D3 输入链(HPF+8×PEQ+门+压限+延时+限幅 ≈ 12) | 12 | −162.56 dBFS |
| D4 输出链(10×PEQ+LR8 4 节+限幅+延时 ≈ 16) | 16 | −161.31 dBFS |
| D3 + D4 全链 | 28 | **−158.88 dBFS** |

| 对标 | 值 | 余量 |
|---|---|---|
| PRD 动态范围 > 106 dB ⇒ 底噪 ≤ −106 dBFS | −106 | **52.9 dB** |
| 本人设计目标(算术噪声比转换器噪声低 ≥10 dB)⇒ ≤ −120 dBFS | −120 | **38.9 dB** |
| ADAU1979 动态范围 typ 109 dB | −109 | 49.9 dB |

> **⇒ 算术噪声不是本设计的瓶颈,转换器才是。** [L3/解析,基于 §5.4 的 [L2/宿主实测] 单节值]
> ⚠ 上表假设各节量化噪声互不相关(标准假设);相关时最坏可差 10·log₁₀(N) → 20·log₁₀(N),
> 即 8 节最坏 −155.3 dBFS,余量仍 ≥35 dB ⇒ **该假设不影响结论方向**。

## 11. FIRA 定点模式的结构性事实(D4 输出链 FIR 的前置)

**只记厂家原文,⛔ 不估数**(全部 [L2/厂家 HW Ref §38 / EE-408]):

1. **FIRA 支持 32-bit 定点**(`FIR_CTL1.FXD=1`),两补码可选(`TC`),
   舍入模式可选(`RND`:0 = 就近,1 = 截断)。
2. **定点模式下,每个输出样本回写的是完整 80-bit 结果,按 3 × 32-bit 突发**
   (LSW / MSW / 16-bit overflow)⇒ **`WINDOWSIZE = WINDOWSIZE × 3`,且须由核心侧
   「decimate 输出缓冲到目标样本」**。原文:*"A final routine must decimate the output
   buffer to the desired samples."*
3. **定点模式不支持 multi-iteration ⇒ 最大 TAP 长度 = 1024。**
   (与 DEC-0006 风险声明②已记录的「FIRA 定点 ≤1024 taps」一致)
4. **有符号分数格式时输出须 ×2**(硬件不右移去冗余符号位)。
5. **IIRA 没有 FXD 位** —— 其 `FORTYBIT` 选的是 32-bit vs 40-bit **IEEE 浮点**
   ⇒ **IIRA 是浮点专用**,在定点链里使用须做格式转换。
   (与 DEC-0014「IIRA 仅作卸载」不冲突,但**卸载要付格式转换的代价**,此前未记。)

> **⇒ 对 D4 的含义**:0.25 cyc/tap 是 FIRA 的**计算**侧;定点模式另有 **3× 输出 DMA + 核心侧
> decimate** 的代价,短滤波器上可能吃掉优势。**⛔ 本件不给数** —— 属 W1-C / D13。


EE-408 正文亦自陈:*"Core FIR/IIR cycles are measured with the help of the optimized library
functions available with CCES."*

> **⇒ 「SHARC+ 核心 IIR = 2.5 cyc/biquad」是【浮点】数。定点值未测。**
> ⇒ 这是团队纪律 **D6** 的形态(「改这个参数,这个数会变吗?会变就必须在向量里」):
> 定点 biquad 比浮点多出**移位 + 饱和 + 就近舍入**,再加本件强制的 **EF(2 乘 2 移位)**。
> ⇒ **建议给该锚点加限定串**:`2.5 cyc/biquad @ 浮点·CCES biquad()·L1·[L2/厂家]`,
> 并入 D6-x 限定串表。⛔ 我不改台账,报 lead 裁定。
> ⚠ **我没有测过定点 vs 浮点的周期差,不给方向性判断** —— 那是 W1-C 的题。

### 12.2 PRD 与 DEC-0006 在数制上的字面冲突,未见 PRD 偏离留痕
PRD §一.1 原文:「48kHz采样,**24bit/32bit浮点DSP运算**」。

### 12.3 IF-v1.4 回执里一处 dBFS 换算的算术看着不自洽(不在我职责内,只报不改)
