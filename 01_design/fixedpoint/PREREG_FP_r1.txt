§0  本轮之前已经发生的事(诚实分段,防「事后限定」误读 —— 团队纪律 D6-q)
--------------------------------------------------------------------------------
本预注册**之前**已做的是【设计推导】,不是【验证】,其数字来自宿主 numpy/python
探索脚本(scratchpad,非归档件),用于**选定格式**,不作为验收证据:
  E1  系数上界扫描       ⇒ 选定 Q4.27(b 的经验界 11.2148,a 的数学界 <2)
  E2  DF2 内节点峰值增益  ⇒ 否决 DF2,选 DF1(最坏 135.1 dB / 需 23 bit)
  E3  噪声增益闭式 + 定点仿真 ⇒ 选定「二阶 EF 必选」
  E4  dB 表长探索        ⇒ 选定 128+1 项
本轮(r1)要验证的是:**上述设计在 C 实现里是否真的成立**,以及**检查本身能不能失败**。
⇒ 故 §2 各条的「预期值」中,凡来自 E1–E4 的,均在该条内标注 [来自设计推导]。

--------------------------------------------------------------------------------
§1  假设(H)
--------------------------------------------------------------------------------
H1  所有窄化点饱和而非回绕 ⇒ 对抗性满量程输入下不产生符号翻转。
H2  就近舍入使 DF1 递归的量化误差零均值;截断则引入 −0.5 LSB 直流,
    并被该节 |1/A(1)| 放大。
H3  DF1 一节最多 7 个 int32×int32 乘积项 ⇒ 累加器需 66 bit 有符号;
    int64(63 bit 有效)在可构造的输入下会溢出。
H4  二阶误差反馈 C(z)=A(z) 使输出量化噪声白化到 q²/12,与该节 NG 无关。
H5  Q4.27 链内格式在 codec 为 24-bit 时对输入无损(2^−27 < 2^−23)。
H6  8 节级联的量化系数响应与理想响应之差远小于 PRD 的 ±0.3 dB。
H7  dB→线性 在 dB ∈ [−110, +24] 内误差 ≤0.01 dB 且全域单调非降。
H8  强类型开关 CHDSP_STRICT_TYPES 只影响类型检查,不影响数值 ⇒ 0/1 两种构建逐位一致。
H9  量纲混用在 CHDSP_STRICT_TYPES=1 下编译不过。

§2  逐条:预期 / 证伪条件
--------------------------------------------------------------------------------

CHK-0  出货构建的坏版本开关全为 0
  预期    : CHDSP_BROKEN_WRAP==0 && CHDSP_BROKEN_TRUNC==0 && CHDSP_BROKEN_NOEF==0
  证伪条件: 任一非 0 ⇒ 本轮全部结果作废(测的是坏版本)。

CHK-1  饱和 vs 回绕
  预期    : 好版本 chdsp_smp_to_io(0x7FFFFFF0) → INT32_MAX,且 sat_sticky==1;
            坏版本(WRAP)同输入 → 负值(符号翻转)。
  证伪条件: **坏版本与好版本给出相同输出** ⇒ 本检查不依赖被测物,CHK-1 作废并重设计。
            (这是本条存在的唯一理由:能失败的对照才是对照)

CHK-2  就近舍入 vs 截断:直流偏置
  被测量  : 20 Hz Butterworth HPF(Q=0.7071)在零均值随机激励下,DF1 输出的直流分量。
  预期    : 好版本(RTN+EF)|DC| ≤ 1e-7 满刻度;
            坏版本(TRUNC,且关 EF)|DC| ≥ 1e-5 满刻度(即 ≥ −100 dBFS)。
            [来自设计推导:|1/A(1)| ≈ 1.0e5,半 LSB 2^−28 ⇒ 约 3.7e-4]
  证伪条件: 坏版本 |DC| < 1e-6 ⇒ 「截断有害」这一论断在本实现下不成立,须撤回 §舍入 的论证。

CHK-3  累加器位宽
  预期    : 存在可构造的合法输入(|x|<16、|c|<16)使 |acc| > 2^63,
            即 int64 会溢出而 128-bit 不会;且 chdsp_acc_in_range() 仍返回 0。
  证伪条件: 构造不出这样的输入 ⇒ 「int64 不够」的论断不成立,须改写 §累加器。

CHK-4  ⭐ 二阶误差反馈
  被测量  : 8 个算例(见 check_fixed.c 表)定点 DF1 输出 vs 同系数 long-double 递归之差的功率。
  预期    : EF 开 ⇒ 全部落在 −173.35 ± 1.0 dBFS,且**与该节 NG(40–91 dB)无相关**;
            EF 关 ⇒ 每条约等于 −173.35 + NG_dB(±3 dB)。   [来自设计推导 E3]
  证伪条件: (a) EF 开时任一条超出 −173.35 ± 3.0 dBFS;或
            (b) EF 开与 EF 关的差值在任一 NG ≥ 60 dB 的算例上 < 20 dB
            ⇒ EF 的收益不成立,「EF 必选」须撤回,改按无 EF 重做噪声预算。

CHK-5  ⭐ 级联(D-4:单级正确 ≠ 级联正确)
  被测量  : 8 节非平坦 PEQ 级联 + 4 节 LR8 分频级联,量化系数 vs 理想系数的频响之差;
            并单独报 DC 与 Nyquist 增益。
  预期    : 20 Hz–20 kHz 内 max|Δ| ≤ 0.02 dB(规格 ±0.3 dB);
            LR8 高通级联 DC 增益 ≤ −180 dB;LR8 低通级联 Nyquist 增益 ≤ −180 dB。
  证伪条件: 带内 max|Δ| > 0.10 dB,或 DC/Nyquist 泄漏 > −120 dB
            ⇒ 系数格式 Q4.27 对级联不足,须加宽或改用结构约束量化(b1=∓2b0, b2=b0)。

CHK-6  I/O 往返无损(24-bit 输入)
  预期    : 对所有低 8 bit 为 0 的 int32(= 24-bit 左对齐样本),
            chdsp_smp_to_io(chdsp_io_to_smp(x)) == x,逐位相同,且 sat_sticky==0。
  证伪条件: 任一样本不等 ⇒ H5 不成立,Q4.27 对 24-bit codec 有损,须改余量位数。

CHK-7  dB → 线性 精度与单调
  被测量  : dB 从 −144.000 到 +24.000,步进 1/256 dB,共 43009 点。
  预期    : dB ∈ [−110, +24] 内 max|误差| ≤ 0.01 dB;全域单调非降;
            dB == CHDSP_DB_MUTE_Q8 时精确返回 0;dB = +24 时不饱和(raw < INT32_MAX)。
  证伪条件: 带内 max|误差| > 0.02 dB,或出现单调下降,或 +24 dB 触发饱和。

CHK-8  系数范围硬失败(D-1 的执行点)
  预期    : chdsp_coef_from_f64(x) 对 |x| ≥ 16 返回非 0;对 |x| ≤ 11.22 返回 0。
  证伪条件: 超范围输入返回 0(静默接受)⇒ D-1 机制未落地,须重做。

CHK-9  强类型开关的数值中立性
  预期    : STRICT_TYPES=1 与 =0 两次构建,对同一随机激励的 DF1 输出**逐位相同**。
  证伪条件: 任一样本不等 ⇒ 不得使用 =0 构建。

CHK-10 ⭐ 负向编译测试(D-1:靠接口不允许,不靠文档提醒)
  预期    : 下列 5 个片段在 STRICT_TYPES=1 下**全部编译失败**:
            N1 把 io 样本传给收 smp 的函数;      N2 把系数传给收样本的函数;
            N3 两种样本直接相加;                N4 把 dB 当线性增益用;
            N5 绕过接口自己写 (int32_t)(acc>>27)(用 raw 累加器做算术)。
  证伪条件: 任一片段**编译通过** ⇒ 该量纲错误在类型层没被挡住,须补类型。
  ⚠ 反向(团队纪律 D6-y「护栏会不会挡掉对的」):
            另有 3 个**正当**片段必须编译**通过**(P1 同类型赋值 / P2 经函数转换 /
            P3 raw 取值)。任一编译失败 ⇒ 类型过严,挡住了合法用法。

§3  假绿纪律:杀伤矩阵(必须一并报告)
--------------------------------------------------------------------------------
对被测头文件做 3 个坏版本(WRAP / TRUNC / NOEF),报「哪个坏版本被哪条 CHK 杀死」。
  预期    : WRAP → 杀 CHK-1;TRUNC → 杀 CHK-2;NOEF → 杀 CHK-4。
  证伪条件: 任一坏版本**全部 CHK 通过**(存活)⇒ 对应 CHK 不依赖被测物,该条作废。
  ⚠ 变异测试盲区(团队纪律):C 无 .pyc 缓存问题,但**必须清 build 产物后重编**,
    并在结果文件里声明已清。

§4  第二轨(铁律七:关键数字双轨独立工具交叉核)
--------------------------------------------------------------------------------
第一轨 = C 实现(check_fixed.c,#include 被测头文件,不转写其公式)。
第二轨 = ref_fixed.py(numpy/python 整数算术,**独立重写**,不 import C)。
  对表项: CHK-4 的 8 个噪声底、CHK-7 的 dB 表、CHK-5 的级联响应。
  预期    : 两轨差 ≤ 0.5 dB(噪声底,受随机种子与样本数限制)、
            dB 表逐点**整数逐位相同**(两轨同为确定性整数算法)。
  证伪条件: dB 表出现任一点不等 ⇒ 两轨之一有错,本轮 CHK-7 结论作废。
