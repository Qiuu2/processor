§1  r1 的两条不达标(原样记录)
--------------------------------------------------------------------------------
[F-1] CHK-7  预注册判据「dB∈[−110,+24] 内 max|误差| ≤0.01 dB」
      实测 **0.010178 dB @ −109.938 dB** ⇒ **按预注册判据判 FAIL**。
      ⚠ 预注册的【证伪条件】(>0.02 dB)**未触发** ⇒ 设计论断本身未被推翻。
      ⛔ 不移动标杆:不把窗口改成 [−109.5,+24] 然后宣布通过。
      诊断(待 r2 验证):误差来源不是查表,是**输出格式 Q4.27 的 LSB**——
      在 −109.94 dB 处 gain≈3.185e−6 ⇒ raw≈427.5,半 LSB 相对误差
      0.5/427.5 = 0.00117 = 0.0102 dB。若此诊断成立,则该误差在 Q4.27 下**不可约**,
      正确处置 = 把真实包络写进规格,而不是改判据。

[F-2] CHK-2  预注册判据「好版本 |DC| ≤1e-7 满刻度」实测 **−1.473e−6** ⇒ **FAIL**。
      ⚠ 证伪条件(坏版本 |DC|<1e−6)未触发。
      诊断(待 r2 验证):**该检查本身没有分辨力**——被测量取的是
      「输出信号的样本均值」,而输出是随机信号,其均值的标准误差由信号统计决定,
      与算术直流无关。这正是 LESSONS C-3「分辨力之下的不等号既不能证真也不能证伪」。
      ⇒ CHK-2 测的不是它声称的那个东西(D6-b)。

§2  独立再观测(r2 新增,逐条带证伪条件)
--------------------------------------------------------------------------------

CHK-2b  【换被测量】直流偏置改测**算术误差**的均值,而不是输出信号的均值
  被测量  : mean( y_定点 − y_参照 ),参照 = 同量化系数的 long double 递归。
  预期    : 好版本(RTN+EF)|mean| ≤ 2e−9(约 0.3 LSB of Q4.27);
            坏版本(TRUNC+NOEF)|mean| ≥ 1e−5。
  证伪条件: 坏版本 |mean| < 1e−6 ⇒ 「截断有害」论断不成立,须撤回 §舍入 的论证。

CHK-2c  【量分辨力】证明 CHK-2 原判据确实在分辨力之下
  做法    : 用 8 个不同随机种子重复 CHK-2 的原始测量,报 8 个值的标准差 s。
  预期    : s ≫ 1e−7(即原判据落在测量噪声内)。
  证伪条件: s < 1e−7 ⇒ 原测量其实有分辨力,则 F-2 的诊断错误,
            须回头承认好版本真的有 1.5e−6 的直流并找机理。

CHK-7b  【量真实包络】dB→线性 的精度包络与其机理
  做法    : ①报出 max|误差| ≤0.01 dB 成立的**真实 dB 下界**(扫描求得,不预设);
            ②把误差按「查表贡献」与「输出量化贡献」拆开:
              查表贡献 = 用 double 输出重算(不量化到 Q4.27)的误差;
              输出量化贡献 = 总误差 − 查表贡献。
  预期    : 真实下界落在 −110 ± 1 dB;且在下界附近**输出量化贡献占主导**(>80%)。
  证伪条件: 查表贡献 > 0.005 dB ⇒ 诊断错,瓶颈在表而不在输出格式,
            须加长表并重跑(表长是可改的,输出格式不是)。

CHK-5f  【别把巧合当保证】LR 分频的 DC/Nyquist 零点:自由量化 vs 结构约束量化
  缘起    : r1 中自由量化在 fc=80 Hz 恰好给出**精确 0** ⇒ 这是巧合还是保证?
            r1 没有回答,而「巧合被当成保证」正是本项目栽过的形态。
  做法    : fc 从 20 Hz 到 20 kHz 扫 500 点,分别统计两种量化下
            单节 |H(1)|(高通 DC)与 |H(−1)|(低通 Nyquist)**非零的点数**。
  预期    : 自由量化非零点数 > 0(即 r1 的精确 0 是巧合);
            结构约束量化非零点数 == 0(构造保证)。
  证伪条件: 自由量化非零点数 == 0 ⇒ 「自由量化会破坏零点」不成立,
            结构约束量化这条规则失去理由,应按 D4「值不值它的复杂度」删掉。

CHK-11  【累加器实占】DF1 一节在最坏合法输入下累加器的实际位宽占用
  做法    : 用满量程链内样本(±16)与本项目实际参数范围内的最大系数组合,
            跑一遍并记录 max(log2|acc|)。
  预期    : ≤ 66 bit(与 §累加器 声明一致),且 > 63 bit(证明 int64 真的不够)。
  证伪条件: 实占 ≤ 63 bit ⇒ int64 其实够用,§累加器 的论断须改写为
            「理论最坏 66 bit,实际参数范围内 ≤63 bit」并说明二者区别。
