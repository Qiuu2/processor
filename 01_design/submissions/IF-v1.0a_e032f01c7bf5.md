## C1 帧结构与旁链调度
- 音频:48kHz / 64 样本/帧 / 750 fps(平台硬底,DEC-0006 [L1/ITC])。
- 旁链分析槽:每 2ms 一个(系统 500 FFT/s,8 通道错峰,每通道更新周期 16ms)。
- 旁链任务属性:最低优先级、可抢占、非音频 ISR;**错过槽位允许跳帧**(降档,不阻塞音频帧回调)。

## C2 接收方算力包络(判据+状态机)
- ≤ **20,000 cyc/分析槽**,记账口径 = W1-A §0 T3(2.0 cyc/op 计入)。
- 超出须与提供方重议(条款C9),不得静默占用。

## C3 接收方内存包络
- 检测状态机 ≤ **16 KB**(L1)。
- AFC 全模块(双方合计)包络 ≤ 112 KB(W1-A §2.2 承载,此处为知会值)。

## C4 旁链供给数据(提供方产出)
- **主谱**:幅度谱 float32,B3 默认运行点 = 512 有效 bin @ **15.625Hz** 网格,每通道每 **16ms**;B2 备选 = 1024 bin @ 7.8125Hz / 42.7ms。运行点由 `AFC.det.cfg`(factory)选择;**接收方代码禁止硬编码 bin 宽/更新率**,一律读配置。
- **高频看门狗谱**:float32,512 bin @ 46.875Hz(N=1024@48k),每通道 ~1.07s,扫 5.5k-20kHz。
- **候选峰列表** ≤16/通道:{f_interp(Quinn 内插后), P_peak, 全带均值, 邻域均值(定义=C5), 上次配对 id}。
- **可选字段(接收方已点单,2026-07-31 回执)**:候选峰附带 2f 处看门狗 bin 值(供 PHPR 高频上查,f>4kHz 时 2f 超主带 Nyquist 的补偿;接收方口径:仅用于 PERSIST 路否决,秒级陈旧度可接受,GROWTH 不用)。

## C5 PNPR 邻域均值定义(计算=提供方,语义=接收方 W1-B §1.2)
- 排除候选峰主瓣 ±3 bin(Hann 主瓣 4 bin,与 N 无关)。
- 邻域半宽 = max(**187 Hz**, **f·(2^(1/3)−1) ≈ 0.26f**),线性对称(**v1.0a 勘误:v1.0 误写 "±1/6 oct≈0.122f",见头部勘误记录**;以 Hz 表述、与运行点解耦;换算到 bin 由提供方按当前 `AFC.det.cfg` 执行)。
- 值属 [L4/待 ROC 标定];若标定倾向更窄邻域(接收方回执提示强混响场景可能性),走 C9 → IF-v1.1。

## C6 执行器接口(提供方实现,接收方调用)
- API:`notch_request(ch, f0, bw, depth)` / `notch_deepen(ch, slot, Δ)` / `notch_release(ch, slot)` / `g_duck(ch, gain, ramp)`(宽带兜底/PANIC 增益,逐样本斜坡)。
- 系数**双缓冲、帧边界切换**。
- 硬约束:深度斜坡 ≤ **3dB/50ms**(防爆音,D0c §4.4 [L4/厂商佐证]);频率重调迟滞 ≥ **max(0.5Hz, 0.25bin)**(防抖,PX4 惯例 [L4]);陷波系数重算全局 ≤ **1 次/帧**(队列串行;最坏 64 滤波器 85ms 排空)。
- **PANIC / g_duck 旁路系数重算队列**(增益通路,不进队列,帧级生效)。

## C7 陷波中心频精度语义
- Quinn 内插后 **p95 |Δf| ≤ BW/4**(恒带宽下限 15Hz → 3.75Hz)。
- 依据:失谐 BW/4 处陷波仍有 ≈7dB 咬合(窄带近似+精确 RBJ 双轨,W1-A 附录)、BW/2 处仅 3dB;Rane 单陷波环路余量目标 2-3dB [L4/文献]。
- 现状:W1-B selfcheck L2 桌面数据 p95 2.8Hz@1024pt Hann/SNR10dB,满足 [L2/W1-B,待其过门];接收方判据设计不得假设优于此语义。

## C8 判据语义约束
- IMSD 阈值以 **dB/s** 定义(运行点无关,换算行随 `AFC.det.cfg`)。
- IPMP 类"频率稳定性"**不得做唯一主判据**(R-AFC-1 专利 FTO 完成前;DEC-0007)。
