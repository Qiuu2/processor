### 1.2 各判据公式

输入=合同供给(架构侧,**IF-v1.4 条款C4**):**主谱** `M[j]`(全 bin,运行点/网格/更新率以 C4 为准,B3 默认;B2 备选经 `AFC.det.cfg` 适配,**判据代码不得硬编码 bin 宽/更新率**——C4 原文条款)、看门狗谱(§3.6)、候选峰列表 ≤16/通道 {Quinn 内插 f, P_peak, 全带均值, 邻域均值, 上次配对 id}、**分析槽序号 `slot_seq[ch]`**、**GR 遥测 `gr_telemetry`(C11)**。判据组合与阈值逻辑=本文自研层。Quinn 式与 PX4 `GyroFFT.cpp EstimatePeakFrequencyBin` 同构,浮点重写已双验(CHECK B@B3:|f_err| 中值 1.4-1.6Hz、p95 2.8Hz,SNR 30/10dB [L2/桌面数值]);合同精度语义(**C7**)= p95|Δf| ≤ BW/4,CHECK B 为其可实现性旁证(⚠ 余量仅 25%,且纯音+白噪是最友好条件——V-3 正式标定须用劣化素材:AM 展宽+有色干扰,critic INFO③ 已入 §7.3 标定清单),正式标定归架构侧 L2(V-3)。

**A. 供给消费的两条路径(v1.2 新增,CHECK F 依据)**
- **acquisition(获取)**:走 C4 候选峰列表。**注意其 top-N 是"名次容量",本身构成一条随房间变吵而自动抬高的有效准入线**(C4 已写死无绝对电平门,堵的是幅度轴;容量轴另论)。回执 §3 已就此提 v1.5 点单(写明排序度量)。
- **maintenance(维持)**:**已 TRACKED 的轨允许直读主谱**在其已知 bin 上复测 level/PAPR/PNPR,不依赖它进不进 top-N。触发条件:本槽未配对 **∧** 候选表满(np 达 C4 上限);预算上限 **4 轨/槽 [L4/成本约束,与 §8.2 包络联动]**。此时该 hop 记为「**未观测**」而非「**峰消失**」——见 §1.2-D。
  **★ 预算仲裁(v1.3,MAJOR-5;v1.2 未定义 = 实现者自由发挥 = 最坏情形无人负责)**:候选轨按 `last_observed_slot` **升序**(最久未观测者优先)取前 4 条,**轮转**。⇒ 在 NT 条轨全部竞争时,每条轨最迟 `⌈NT/4⌉ = 3` 槽(≈48ms)内必被观测一次,**"未观测"有确定上界**,不依赖实现者的取序习惯。

**PAPR**(结构同 PX4 :514,**度量约定按本文勘正**):
```
PAPR(k) = 20*log10( (Nbins-1) * M[k] / (Σ_j M[j] - M[k]) )   [常规 dB]
```
其中 Σ 在检测频带内取(合同供给的"全带均值"即此式分母的等价原料)。候选门:`PAPR ≥ T_papr`,初值 **T_papr = 15dB [L4/待标定]**(音频域按"语音共振峰帧也可达 10dB+"的保守起点设 15,待 ROC 标定)。
> **⚠ 度量约定勘正(v1.2,同族二义第三例)**:PX4 `GyroFFT.cpp:447` 的 `fft_magnitude = sqrtf(re²+im²)` 是**幅度**,而 `:514` 对该**幅度比**取 `10*log10` ⇒ **PX4 的 SNR 数值 = 常规 dB 的一半**。本文同节的 PNPR 用 `20*log10`(常规 dB),若 PAPR 沿用 PX4 的 10·log10,**同一个 AND 门(§1.3)里两个阈值就用了两套 dB 约定**,且 T_papr=15 的论证原文按常规 dB 推理 ⇒ 实际门会变成常规 30dB(严一倍,偏漏检)。**故本文统一取 20·log10(幅度比)= 常规 dB**;所有 PAPR 类阈值(T_papr / T_papr_high / T_harm)均为此约定。**PX4 的 MIN_SNR 及其参数值不可直接搬**(移植件参数重标定纪律的具体命中)。同族前两例 = C5「每侧/全宽」(B-F2)与 F1「半/满 LSB」,均造成恰好 2× 偏差 [DEC-0010]。

**PNPR**:
```
PNPR(f) = 20*log10( M(f) / mean(M[U(f)]) )   [常规 dB]
U(f) = 峰两侧的邻域窗,**定义(主瓣排除宽度、每侧半宽、线性对称)全部以 IF-v1.4 条款C5 为准**
```

## 2. ★ IMSD 判据自研(帧间幅度斜率)

D0c §1.8 已确认全域无同构实现:振动/工频域的目标全是稳态窄带,从不需要区分"正在长起来的啸叫"与"稳态存在的合法窄带信号"。这是本设计的核心自研件。

### 2.1 物理机理:为什么斜率是啸叫的"身份证"

闭环电声系统在频点 f 处环路增益 G(f)(含相位对齐)超过 1 时,幅度每经一次环路乘 |G|:
```
a(t) = a0 * |G|^(t/τ)  →  L(t)[dB] = L0 + β*t,  β = 20*log10|G| / τ   [dB/s]
```
τ=环路延迟(声程+处理链)。**即:啸叫在 dB 域随时间线性增长,斜率恒定**——这是环路物理决定的签名,人声/乐音没有义务遵守它。
桌面自验(CHECK C,结论域按 B-m5 限定):闭环差分方程仿真(脉冲种子,g=1.05/τ=10ms 与 g=1.02/τ=25ms),用本设计旁链参数(1024 Hann/hop 256)提取 STFT 峰值轨迹,LS 拟合斜率与解析值 20log10(g)/τ 偏差 **0.0% / 0.1%**——证明**轨迹提取管线对指数增长无斜率偏置**(IMSD 的测量链可信);dB 域线性模型本身属反馈物理常识 [L3],不赖此"证明" [L2/桌面数值,`selfcheck_W1B` CHECK C]。**结论限定(critic B-m5)**:CHECK C 的被测物是理想线性差分环路,它只证明"本设计的 STFT 轨迹提取管线能无偏还原 dB 域线性增长",**不证明真实房间的啸叫必呈该形态**——RT60 混响尾、多路径梳状、环内非线性都会给真实斜率叠加噪声与弯折,IMSD 对真实啸叫的判别力由 ROC 素材(§7.3)另证。

量级(会议室,[L3/手算]):τ ≈ 5-50ms(声程 3-30ms + 处理 ~2ms + 换能),超额增益 0.5-3dB/圈 → β ≈ 10-600 dB/s → 每槽(T_hop = IF-v1.4 C1 的每通道更新周期,B3=16ms)**0.16-9.6 dB**。快端由 PANIC 路兜——**仅限输入侧钉住(ADC 满幅)场景有条件担保(IF-v1.4 C12);输出侧限幅器钉住时 tap 电平无下界担保,PANIC 降为机会快路径,覆盖转由 pinned-howl 路径承接(§3.2 三臂 / §3.5-#11,B-F1 修法)**;慢端(<β_min)由 PERSIST 路兜(终将饱和为稳态高峰);IMSD 主攻中段——**在啸叫可闻爆发前抓住它**。
**⚠ "钉住 = 无增长"只对恒定平台成立(v1.2 补,B-F1 深化)**:被**语音间歇打断**的钉住环路会反复"讲话时被 GR 压下 → 停顿时重新指数增长回平台"——这是 PA 实战中"句子之间系统在响铃"的物理成因 [L3/反馈环路物理]。故该场景**存在真实增长段**,只是整段发生在 T_low 之下(仅经 §1.2-C 放宽门可见)。本文据此在 §3.2 增 case (c),并对 IF-v1.4 C11-② 括注"该场景本就不可达"提异议(§8.3-6)。

### 2.2 数学定义

对跟踪峰 k,维护其 **PAPR 轨迹** P_k[n](dB,n = **已交付槽**索引,时间基准 T_hop = IF-v1.4 C1 的每通道更新周期,B3=16ms)长度 W 的环形历史,**并同时存下每个样本的 `slot_seq`**。**用 PAPR(相对量)而非绝对幅度**——这是抗误判设计的核心(§2.4 ①)。

```
窗内 LS 线性拟合:P_k[·] ≈ b_k*x + c_k
  ★ x 轴 = **该样本的 slot_seq 与窗首样本的差值**(= 真实时间轴 / T_hop),不是 0..W-1
  b_k  = 斜率 [dB/槽]
  s_k  = 拟合残差 RMS [dB]           (线性度)

IMSD 命中 ⟺ 轨迹当前为 TRACKED ∧ hist_n ≥ W_used
            (轨迹历史自**诞生**起累积、含 TRACKED 前的槽;算法级参考点 = 轨迹诞生
             ⇒ 该延迟按 IF-v1.4 **C13** 称 **T_decide(判定延迟)**,禁入对外语境)
          ∧ β_min ≤ b_k ≤ β_max
          ∧ s_k ≤ s_max
          ∧ ΔP_k ≥ ΔP_min
          ∧ 窗内空号(跳槽)总数 ≤ W_used/2      (稀疏窗不出判定,见下)
双窗:W_long(主判,预设 §6);W_short=4(快判,仅当 b_k ≥ β_fast)
```

## 4. ★ 深度策略:先浅→复发递进→缓抬试探→宽带兜底

### 4.1 深度可控陷波器(修补 PX4 缺口)

PX4 `NotchFilter::setParameters` 仅三参数、全深无深度控制(D0c §1.6 已核)——**弃其系数公式,保留其 DF1 结构与更新纪律**。系数改用 **RBJ peaking-EQ 负增益式**(RBJ Cookbook [W0 已核])。
> **双轨口径(B-m3,v1.2 关闭方式 = 补跑,不是删宣称)**:v1.0 曾写"pareq.m 交叉核"**实际未跑**(critic B-m3 抓获,本项目记过的虚账)。**现已补做**:`adaptive-dsp-2` 跑通真·异源第二轨(**Orfanidis 系 / Välimäki & Reiss 2016 Table 7.2 的 tan 预畸变式**,与 RBJ 的 sin 映射不同推导、不同带宽映射),本轮集成为 **CHECK A2 并已实跑**(§2.5、§10.1 附命令与输出)。故本设计的双轨现为**三重**:①闭式\\|H\\| vs 复数求值(CHECK A)②半深点带宽功能核(能抓系数公式转写错)③**异源公式轨(CHECK A2)**。**署名保留给 `adaptive-dsp-2`**(DEC-0011 归因更正的落实)。
```
A=10^(G/40)(G<0);alpha=sin(w0)*sinh(ln2/2 * BW_oct * w0/sin(w0))
b=[1+αA, -2cosw0, 1-αA]/(1+α/A);a=[1, -2cosw0, 1-α/A]/(1+α/A)
带宽:BW_hz = max(BW_oct*f, BW_floor);BW_floor 取参数字典默认 15Hz [L4/QSC](量程 5-30,W1-A §5 字典);
      我方原提 12Hz [L4/dbx 8-11Hz 折中] 作 ROC 标定候选,标定后若胜改字典默认值(非结构分歧,双方已确认)
```
桌面核算:①CHECK A —— 闭式 |H| vs 复数求值,5 组 (f0,深度,BW) 两轨差 ≤1e-5dB、@f0 深度=设定值、半深点带宽=设定 BW、极点全稳 [L2/桌面数值];②**CHECK A2 —— 异源第二轨**(RBJ sin 映射 vs Välimäki-Reiss tan 预畸变):5 组规格点 @f0 深度两轨互差**最大 5.31e-12dB**、半深带宽各自 ≈ 设定值(两轨互差最大 1.0e-4 oct = sin/tan 约定差,如实记录)、VR 轨极点全稳 [L2/桌面数值]。**报数一律取实跑最大值**(m-4)。**注:两轨系数本就不同**(带宽映射不同),互核点是**设计规格点**而非系数逐项比。

## 5. 状态机完整定义

### 5.1 每陷波槽:模式 × 状态

**模式**(对齐 PRD §二.5"三种工作模式"与竞品口径 [L4/竞品手册 §2.3],DEC 已确认吻合):
- **AUTO**:参与自动分配/加深/回收/老化/循环复用。
- **MANUAL**:用户直设 f/BW/深度;分配器不可占用、不自动变化。
- **FIXED**:频率钉死(用户手动钉或将 AUTO 陷波"固化"),重启/调预设仍有效,不被新啸叫占用;自动加深仍作用(复发时),LIFT 只回到**固化基线深度**而非 0dB。[L3/产品语义推断:竞品仅明言"不被占用且重启有效",基线深度语义待 host-software/CTO 确认]

**状态**(AUTO 槽;MANUAL/FIXED 仅 ENGAGED 恒驻):
```
        分配(§5.5)                目标深度到达
 FREE ────────────► ENGAGE ────────────────► HOLD ◄──┐
  ▲                (渐深中)                    │      │复发:加深/回挂(§4.2/4.3)
  │                                 静默≥LIFT_AFTER   │
  │ reclaim 窗到期                      ▼             │
  └────────────── STANDBY ◄───────── LIFT ───────────┘
                (0dB 驻留,记频率)   (+3dB/5s 缓抬)
                     │同频复发(≤reclaim 窗)
                     └──────► ENGAGE(直接 -3dB 挂回,不耗新槽)
```
- **STANDBY/reclaim 防抖**:抬到 0dB 后驻留 `reclaim = 30s`(量程 5-120s [L4/QSC Q-SYS]),防"弹进弹出";窗内同频(|Δf|≤BW_hz/2)复发直接回挂;到期 → FREE。
- 系数更新纪律(PX4 防抖思想 + **IF-v1.4 条款C6** 硬约束):重调迟滞 `|Δf| > max(0.25*Δf_bin, 0.01*f)`,须 ≥ C6 规定的下限 [L4/待标定];深度斜坡由执行器保证(C6);**系数重算的全局限流由 C6 规定 → 本层动作进重算队列串行下发,最坏全滤波器更新的排空时间见 C6 [L3/手算],状态机时序对此不敏感(时间常数均 ≥秒级,唯 PANIC 例外——其首动作是宽带回落 g_duck,**增益通路旁路系数重算队列,帧级生效**,C6 已写入)。**

### 5.2 全局语义

- **★ GR 遥测降级的状态机语义(v1.2 新增;IF-v1.4 C11「降级可见性」的接收侧落地,回执使用注记 7)**
  C11 给的是**稳态**语义(`invalid` ⇒ 相关特性自禁用 + 记事件,**禁止静默置零**);**转换瞬间**归本层定案:
```
valid → invalid(遥测源失效/未实现):
   ① **已挂陷波一律不撤** —— 撤陷=环路立刻回啸,危害远大于误挂;存量按正常 LIFT 生命周期走;
   ② 冻结**新的**臂3 豁免与**新的** T_low_gr 放宽准入(门回落 T_low);
   ③ 经放宽门入轨的**存量轨不立即删** —— 删轨会丢掉已累计的 PERSIST 可观测信用,
      那又是一次"降级放大器";改为停止继续放宽、保留至正常老化;
   ④ 上报 host 事件(与 C11 要求的 host 事件同一通道),供 D11 可视化"检测能力已降级"
invalid → valid:不追溯补偿(避免状态回溯),自恢复时刻起正常计
```
  **⚠ 采样率失配(如实)**:`gr_telemetry` 按 C11 规定的帧级更新,而本层每分析槽读一次 ⇒ 帧间的短促限幅可能读不到。对"持续钉住"无害(钉住时 GR 恒 active);对**突发性限幅(音乐)**存在混叠,方向 = 可能高估 active 占比 ⇒ 误豁免面变大。缓解 = N_gr 连续可观测槽 + 仅 PERSIST 路 [L4/待标定]。已提可选 v1.5 点单(读后清零的计数事实字段,回执 §8.2-P7 附注),**不做也可接受**。
- **Lock(锁定)**:通道级开关。冻结所有槽的状态转移与系数变化(演出锁定,竞品同语义);检测旁链继续跑,仅记 log。
- **Clear(清除)**:两级。`Clear-Auto`=复位全部 AUTO 槽(含 STANDBY)→ FREE;`Clear-All`=另含 MANUAL/FIXED(host 二次确认)。[L3/竞品仅"一键复位全部",两级细分为本设计补强,待产品确认]
- 预设切换:AUTO 槽全清;FIXED/MANUAL 随预设文件载入(与 D6 预设模型、参数字典对接)。

### 5.3 分配策略(§5.5 伪代码)与循环复用

新 HOWL 分类到达,按序取槽:
1. **STANDBY 同频槽**(reclaim 命中)→ 直接回挂;
2. **FREE 槽** → ENGAGE;
3. 无 FREE:**round-robin 复用**——候选=全部 AUTO 槽中 `当前深度最浅` 者(损失最小);同深取 `最久未复发` 者(Shure"替换最旧动态"的保守化:替换最旧可能放虎归山,替浅优先把回归风险压到最小 [L3/设计,偏离 Shure 有意为之,留痕]);被复用槽旧频率记入 STANDBY 影子表(仅记频,不占槽),reclaim 窗内旧频复发 → 走宽带兜底而非再抢槽;
4. 3 也无(全部 MANUAL/FIXED 或 LOCK)→ 宽带兜底(§4.4)。

**★ 跟踪轨表的准入优先级(v1.2 新增;D2 扫产出:T_low_gr 放宽 × 轨表容量 NT 的咬合)**
放宽门(§1.2-C)使更多低电平峰有资格入轨,而轨表 NT 有限 ⇒ **放宽档期的轨表压力上升,存在把真啸叫轨挤掉的风险**。定案:
```
轨位竞争时的淘汰序(先淘汰序号小者):
  ① relaxed_entry ∧ 未达 TRACKED ∧ 无 GR 证据
  ② relaxed_entry ∧ 未达 TRACKED
  ③ 常规入轨 ∧ 未达 TRACKED ∧ 最久未命中
  ④ 已 TRACKED 者不被未 TRACKED 者挤掉(硬规则)
即:**常规门入轨者对放宽门入轨者有绝对优先权**,放宽是"额外容量内的机会",不得挤占主路。
```
**★ 僵尸轨防护(v1.3,MAJOR-5;三条各自正确的机制在咬合处产生的第四种行为)**
危害链:①§1.2-D「未观测不计老化」+ ②直读预算 4 轨/槽 + ③本节硬规则「已 TRACKED 不被未 TRACKED 者挤掉」⇒ 忙房间(候选表持续满,正是 CHECK F-2 的形态)下,拿不到直读预算的 TRACKED 轨**既不老化、又不可被挤掉** ⇒ **轨表被僵尸轨长期占满,新的真啸叫连轨都进不去,检测器失能**。**又一次"故障在最需要它工作时才发作"。**
```
三道锁(缺一即复现该失效):
  锁1 仲裁有界:直读预算按"最久未观测"轮转 ⇒ 每轨 ≤⌈NT/4⌉ 槽必被观测(§1.2-B)
  锁2 未观测有上限:unobs_run > U_max ⇒ 强制直读;仍不可判 ⇒ **解除③的保护**,
      降级为可淘汰并转影子表(§1.2-D)
  锁3 硬规则③改为**有条件**:"已 TRACKED 不被挤掉"仅在 `unobs_run ≤ U_max` 时成立
```
**残余**:U_max 与直读预算上限均 [L4/待标定],二者与 NT、候选表容量共同决定最坏占位时长,须在 C 原型上以合成忙房间场景实测(入 §7.3-⑩)。
**影子表继承(§3.2 缓解②③)在轨位被回收时同样生效** —— 被淘汰的 relaxed_entry 轨把 {f, 删除时刻, rapid_onset/t_veto_start, PERSIST 可观测信用} 留在影子表,同频重生时继承(保鲜 T_exempt ∧ GR 仍 active)。

### 5.4 老化超时:§4.3 AutoClear;跟踪表老化:§1.2 IPMP(按**可观测槽**计,§1.2-D)。两者语义不同(陷波器寿命 vs 检测轨寿命),实现分开。

void afc_slot(AfcChannel *c, const SidechainSupply *sp, u32 now_ms) {
  u32 seq = sp->slot_seq;   // ★ 存在性/速率类计数以此为基准(§2.2 三分之一、二类)
  // ★ m-3:墙钟类时长(LIFT_AFTER/reclaim/lift_step/AutoClear/P_persist/T_shadow/T_exempt)
  //   一律用 now_ms(音频帧计数器导出),**不得用 seq 推进** —— 跳槽下二者不等价
  gr_edge_tick(c, sp->gr);                 // §5.2:valid↔invalid 边沿处理(不撤存量陷波)
  // 1) 判据:对 sp->pk 逐个算 PAPR/PNPR/level,过 G0 门(§1.2-C 含 T_low_gr 放宽)
  // 2) 跟踪:按 pair_id 挂到 Track;**三态**记账(命中/未观测/未命中,§1.2-D):
  //      未观测 ⇒ 不计老化、不进滑窗分母;表满且本轨电平低于表内最小 P_peak 时,
  //      走 maintenance 直读主谱复测(上限 4 轨/槽),仍不过门才记未命中
  update_tracks(c->trk, sp, seq);
  // 3) 分类:三路(§3.3),输出至多 1 个非 PANIC 动作;看门狗带走 §3.6 粗判
  Howl h; int nh = classify(c, sp, seq, &h);
  //    classify 内部:PANIC : level>=P.t_panic ∧ 窄带门(C12 措辞:电平∧窄带门,非"仅电平")
  //                          → 断言 NHS_PANIC_ACTIVE,链序 C-4(W1-A §4)
  //                  GROWTH : (imsd_fit(trk) ∨ 臂2 等效命中) ∧ !phpr_veto(trk,sp)
  //                           ∧ !trk->relaxed_entry            (C11-②;异议见 §8.3-6)
  //                  PERSIST: 滑窗命中率 ≥ P.persist_hit_rate(分母=可观测槽,§3.3)
  //                           ∧ 窄带门 = PAPR>=T_papr_high(常规与 relaxed_entry 同,C11-② 字面)
  //                             (PNPR 替代 = 待 v1.5 偏离项,**不实现**,§3.3)
  //                           ∧ !phpr_veto(trk,sp)
  //                  phpr_veto 内含 §3.2 三臂豁免(臂1 IMSD/臂2 RAPID_ONSET/臂3 gr 作用域式,
  //                    臂3 仅 PERSIST;GR 证据另使 P.persist 减半 [L4/待标定],
  //                    但 relaxed_entry 轨**不享减半**——C11-② 两门收紧之一)
  // 4) 状态机 → 动作经执行器 API(notch_request/deepen/release,斜坡归执行器 C6)

  slots_tick(c, seq, now_ms);    // 斜坡按槽推进;LIFT/STANDBY/AutoClear 按 now_ms(m-3)
  duck_tick(c, nh, now_ms);      // §4.4 宽带兜底:attack/hold/recover 全为墙钟量
  publish_dict(c);               // 参数字典回写:每槽 {mode,st,f,bw,depth} → host 频谱图
}

bool imsd_fit(const Track *t, const PresetParams *P, float *b_out) {
  // 预设加载时校验 P->W_used <= W_MAX(B-m2:大房间 W_long=10 恰为上限)
  if (t->hist_n < P->W_used) return false;
  // ★ x 轴 = slot_seq 差值(真实时间轴),不是 0..W-1 —— CHECK E 坐实朴素口径双向失效
  u32 span = t->seq_hist[P->W_used-1] - t->seq_hist[0];
  // m-2 勘正:规范是"空号 ≤ W_used/2" ⟺ span+1 ≤ 1.5·W_used。v1.2 写 `> 2*W_used`
  // (⟺ 空号 ≤ W_used)**比规范松 2×**,而这是 CHECK E 所坐实失效模式的唯一护栏。
  if (2 * (span + 1) > 3 * P->W_used) return false;  // 整数形式,等价于 span+1 > 1.5·W_used
  float b, c0, s;
  ls_fit_x(t->papr_hist, t->seq_hist, P->W_used, &b, &c0, &s);   // O(W) 闭式,x=Δseq
  float dP = t->papr_hist[P->W_used-1] - t->papr_hist[0];
  bool long_ok  = (b>=P->beta_min && b<=P->beta_max && s<=P->s_max && dP>=P->dP_min);
  bool short_ok = imsd_short(t, P);                // W_short=4, b>=beta_fast(同用 Δseq)
  *b_out = b; return long_ok || short_ok;
}

void slots_tick(AfcChannel *c, u32 seq, u32 now_ms) {
  const u32 now = now_ms;   // m-3:本函数内的寿命/驻留判据全部为墙钟量
  for (int i = 0; i < NN; i++) { NotchSlot *s = &c->slot[i];
    if (s->mode == M_MANUAL) { retune_if_needed(s); continue; }  // §5.1:MANUAL 不自动转移
    switch (s->st) {
    case S_ENGAGE: // 斜坡由执行器实施(≤3dB/50ms);本层按时长推进状态
                   if (elapsed(now, s->t_engage) >= ramp_slots(s->target_db))
                     s->st = S_HOLD;                                     break;
    case S_HOLD:   if (elapsed(now, s->t_last_hit) >= c->P.lift_after)
                     { s->st = S_LIFT; s->t_lift_start = now; }          break;
    case S_LIFT: { float floor_db = (s->mode==M_FIXED) ? s->base_db : 0;
                   if (every(now, c->P.lift_step))
                     s->depth_db = fminf(s->depth_db + 3, floor_db); // B-m2:clamp,任意基线不越界
                   if (s->depth_db >= floor_db)
                     s->st = (s->mode==M_AUTO) ? S_STANDBY : S_HOLD; }   break;
    case S_STANDBY:if (elapsed(now, s->t_last_hit) >= c->P.reclaim) free_slot(s); break;
    default: break; }
    retune_if_needed(s);   // Δf 迟滞 §5.1;经执行器 retune,全局 ≤1 次系数重算/帧
  }
}

### 5.6 跨通道协调(自研;多麦系统必需)

同一物理啸叫环路的频点会同时出现在多支开麦上;8 通道各自独立挂陷 = 同频最多 8×深度,音质无谓受损。
```
全局频率登记表(共享,单写者=旁链调度器):
  通道 j 挂入/加深 f 时登记 (j, f, hop)
  通道 i(i≠j)对 |f_i - f| ≤ BW_hz/2 的分类命中:延迟 2 hop(32ms)执行
    → 若 j 的动作已让环路回稳,i 的轨在延迟期内自然衰减,不挂
    → 若仍命中(多麦共环/另一环)→ i 正常挂入
  优先执行者:同 hop 多通道命中同频时,取 level 最高者先动
```

## 7. 验收判据草案(交 verification 共定;本节只定义"怎么测",不承诺任何数字)

### 7.1 它真在工作(正面判据;测量仪器只看**输出信号**,不信内部旗标——假绿纪律)

- **闭环测试床**:实录 RIR(素材工单,与 verification 共立)构成 mic→DSP→spk→RIR→mic 数字闭环 + 语音/音乐源注入;0.5dB 步进抬环路增益。
  - T1 检出:诱发啸叫后,DUT 输出包络在 T_react 内停止增长并回落(T_react 目标值待标定,对标 Sabine 0.4s [L4/仅对标不承诺]);判定用输出信号包络+谱,非内部 log。
  - T2 抑制:挂陷后环路回稳(输出包络 2s 内衰 ≥20dB [L4/判据初值待与 verification 定])。
  - T3 回收:增益回稳后 LIFT 全程无复啸、深度归零。
  - T4 多啸叫:递增增益逐个诱发 ≥8 个频点,验证分配/复用/兜底路径全部走到(含第 9 个啸叫触发宽带兜底)。
  - T5 多麦共环:双通道共环路,验证 §5.6 协调(不出现双通道同频双挂,除非确属双环)。
- **MSG/ΔMSG 测量定义**(唯一合法的"收益"口径):同一 RIR/同一流程下,NHS bypass 与 active 各自的临界增益(判稳标准:单频包络持续增长>1s),差=ΔMSG;跨 ≥N 个 RIR 报分布。**桌面闭环全部 =L2;真房间/真机 =L1(verification 所有)。⚠ D0c §3.1 口径冲突在案(Shure 6-9dB vs Rane 2-3dB),L1 前任何 GBF/ΔMSG 数字不进规格、不对外(C2 红线)。**
