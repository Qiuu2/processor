| PTPR(峰-阈值) | **门**:双阈值(反馈阈值/恐慌阈值,对齐竞品参数体系 [L4/竞品手册 §2.3]) | 阈值语义取竞品,数值自标 |

| PNPR(峰-邻域) | **候选判据**(与 PAPR 与逻辑) | 阈值初值参 zapline-plus 论文数值(EEG 尺度,重标定)[L4] |
| IPMP(帧间持续) | **跟踪机制**(候选→跟踪态的门槛),非分类主判据(专利考量,§2.6) | PX4 近邻豁免+配对+中值+老化(移植重标) |

### 1.2 各判据公式

输入=合同供给(架构侧,**IF-v1.4 条款C4**):**主谱** `M[j]`(全 bin,运行点/网格/更新率以 C4 为准,B3 默认;B2 备选经 `AFC.det.cfg` 适配,**判据代码不得硬编码 bin 宽/更新率**——C4 原文条款)、看门狗谱(§3.6)、候选峰列表 ≤16/通道 {Quinn 内插 f, P_peak, 全带均值, 邻域均值, 上次配对 id}、**分析槽序号 `slot_seq[ch]`**、**GR 遥测 `gr_telemetry`(C11)**。判据组合与阈值逻辑=本文自研层。Quinn 式与 PX4 `GyroFFT.cpp EstimatePeakFrequencyBin` 同构,浮点重写已双验(CHECK B@B3:|f_err| 中值 1.4-1.6Hz、p95 2.8Hz,SNR 30/10dB [L2/桌面数值]);合同精度语义(**C7**)= p95|Δf| ≤ BW/4,CHECK B 为其可实现性旁证(⚠ 余量仅 25%,且纯音+白噪是最友好条件——V-3 正式标定须用劣化素材:AM 展宽+有色干扰,critic INFO③ 已入 §7.3 标定清单),正式标定归架构侧 L2(V-3)。

**A. 供给消费的两条路径(v1.2 新增,CHECK F 依据)**
- **acquisition(获取)**:走 C4 候选峰列表。**注意其 top-N 是"名次容量",本身构成一条随房间变吵而自动抬高的有效准入线**(C4 已写死无绝对电平门,堵的是幅度轴;容量轴另论)。回执 §3 已就此提 v1.5 点单(写明排序度量)。
- **maintenance(维持)**:**已 TRACKED 的轨允许直读主谱**在其已知 bin 上复测 level/PAPR/PNPR,不依赖它进不进 top-N。触发条件:本槽未配对 **∧** 候选表满(np 达 C4 上限);上限 4 轨/槽(包络 §8.2)。此时该 hop 记为「**未观测**」而非「**峰消失**」——见 §1.2-D 可观测性。

**PAPR**(结构同 PX4 :514,**度量约定按本文勘正**):
```
PAPR(k) = 20*log10( (Nbins-1) * M[k] / (Σ_j M[j] - M[k]) )   [常规 dB]
```
其中 Σ 在检测频带内取(合同供给的"全带均值"即此式分母的等价原料)。候选门:`PAPR ≥ T_papr`,初值 **T_papr = 15dB [L4/待标定]**(音频域按"语音共振峰帧也可达 10dB+"的保守起点设 15,待 ROC 标定)。
> **⚠ 度量约定勘正(v1.2,同族二义第三例)**:PX4 `GyroFFT.cpp:447` 的 `fft_magnitude = sqrtf(re²+im²)` 是**幅度**,而 `:514` 对该**幅度比**取 `10*log10` ⇒ **PX4 的 SNR 数值 = 常规 dB 的一半**。本文同节的 PNPR 用 `20*log10`(常规 dB),若 PAPR 沿用 PX4 的 10·log10,**同一个 AND 门(§1.3)里两个阈值就用了两套 dB 约定**,且 T_papr=15 的论证原文按常规 dB 推理 ⇒ 实际门会变成常规 30dB(严一倍,偏漏检)。**故本文统一取 20·log10(幅度比)= 常规 dB**;所有 PAPR 类阈值(T_papr / T_papr_high / T_harm)均为此约定。**PX4 的 MIN_SNR 及其参数值不可直接搬**(移植件参数重标定纪律的具体命中)。同族前两例 = C5「每侧/全宽」(B-F2)与 F1「半/满 LSB」,均造成恰好 2× 偏差 [DEC-0010]。

**PNPR**:
```
PNPR(f) = 20*log10( M(f) / mean(M[U(f)]) )   [常规 dB]
U(f) = 峰两侧的邻域窗,**定义(主瓣排除宽度、每侧半宽、线性对称)全部以 IF-v1.4 条款C5 为准**
```
- **权威方向(B-F2 结构修法,DEC-0010)**:C5 已自足化(定义全文内联 + 显式"每侧" + 删除"语义=接收方"指针),**本文只引用、不定义**;邻域均值由供给侧随候选峰列表交付(C4/C5),本层 maintenance 路径自算时同样按 C5 形态。**本文不复制其数值。**
- 门:`PNPR ≥ T_pnpr`,初值 **T_pnpr = 8dB [L4/待标定]**(zapline-plus 论文 +4dB 为 EEG 尺度 [L4/D0c §1.7];音频动态范围大,取 2 倍起点,待标定)。
- **⚠ PNPR 是局部统计,PAPR 是全带统计** —— 这个差别在掩蔽场景下是决定性的:带外强语音抬高全带均值会使弱峰 PAPR 塌陷,而 PNPR 不受带外影响(CHECK F-2:同一构造谱上 PAPR +10.9dB 不过门 / PNPR +15.1dB 过门 [L2/构造谱])。**故凡"钉住 + 掩蔽"路径的窄带门一律以 PNPR 承重**(§3.2 臂3/放宽门路径)。

**PTPR 双阈值**(语义对齐竞品 [L4/竞品手册 §2.3]):
```
level(k) = 20*log10(M[k])   [dBFS,ADC 参考;**参考化由提供方完成,IF-v1.4 C12(i)**]
反馈阈值 T_low:level < T_low → 绝对不判啸叫(防柔和乐段/低电平嗡声误触发)
  └ GR 条件放宽 T_low_gr(见下 §1.2-C)
恐慌阈值 T_panic:level ≥ T_panic ∧ 窄带门(PAPR≥T_papr)→ 立即判定(§3.4),0=关闭
```
初值:T_low = -45dBFS,T_panic = -6dBFS **[L4/待标定]**(QSC Feedback Threshold 量程 -70~-20dB [L4/QSC 手册] 作 T_low 的可调范围参考;竞品恐慌阈值语义:高于此"绝对是反馈")。
> **⚠ v1.2 删除 `cal_offset`(回执使用注记 6)**:IF-v1.4 **C12(i)** 把 ADC 参考化(数字 trim 折算)的**执行方定为提供方**,本层收到的即 ADC 参考电平。若本层再加一次校准偏移即**二次补偿**。字典内参不跨模块喂判据层。

**⚠ T_panic 有效性前提(critic B-F1;v1.2 按 IF-v1.4 定版收窄)**:"冲顶啸叫必触 PANIC"仅在**增益结构担保**下成立。定版口径 = **IF-v1.4 条款C12 的增益结构二分**:
- **输入侧(ADC 满幅)钉住 = 担保覆盖**,但受 C12 两条件约束((i) ADC→tap 数字增益链为已知量且 trim 补偿由提供方执行;(ii) AEC 参考路径不含本地扩声分量——否则 AEC 会部分抵消 tap 处啸叫分量,平台电平失去 ADC 锚。该项为 A9/D1 定稿显式检查项)。
- **输出侧钉住 = 非担保**(平台电平含 G_声学不可知时变项,静态担保物理上不可能),**PANIC 在该场景降为机会快路径**;覆盖责任转 §3.2 臂2(轨迹历史)+ 臂3(GR 遥测),担保主体 = **C11**。
- **本层表述模板(C12 指定)**:"PANIC 前提担保仅限**输入侧(ADC 满幅)钉住**且受 C12 两条件约束;输出侧钉住检出由 C11(GR 遥测)担保;T_panic 配置合理性由 C12 软校验提示"。

**IPMP(跟踪门)**:帧间关联由合同供给的"上次配对 id"承载(架构侧按最近频率配对,PX4 :525 的 0.25bin 豁免同构);本层在其上维持,**时间基准 = C1 的每通道更新周期 T_hop,计数基准 = C4 的 `slot_seq`(见 §1.2-D)**:
```
连续性:进入"跟踪态"须 命中 ≥3/4 **可观测**槽
中值:首挂用 3 点中值(与跟踪门同步),后续补满 7 点持续精修(受重调迟滞限制)
老化:连续 6 个**可观测且未命中**的槽 → 删轨(PX4 100ms 老化的量级映射 [L3])

```

**C. T_low 的 GR 条件放宽(IF-v1.4 C11「T_low 使用注记」;判据归本层,机制原样落地)**
```

      ∧ 完整 P_persist(不享 GR 减半)∧ PHPR 豁免仍须因果时序

```
**物理理由(本层独立论证,v1.2 补——比"放宽一档"更强)**:T_low 的设计意图是"不对**听不见**的低电平窄带动手",这是关于**输出可闻度**的意图,却用 **tap 电平**实现;二者仅在 tap→输出增益正常时等价。输出侧钉住恰是二者解耦的场景(输出端在天花板、tap 端极弱)⇒ **GR 条件下的放宽不是"松一档凑合",而是把门恢复到它本来的语义** [L3/解析]。
**失效边界(如实)**:放宽门在 `G(tap→限幅点) > (T_low_gr 与天花板之差)` 时仍不及门;该增益全为字典内已知数字量,故失效**由 C11-③ 的软校验事前告警**(与 T_panic 告警同构复用),不是静默失效。残余盲区表述见 §3.2 可达性表 case (b)。

**D. 可观测性(v1.2 新增;C4 `slot_seq` + 候选表容量的联合消费)**
本层对每个跟踪轨、每个交付槽,把结果分三态而非两态——**这是"没发生"与"没观测到"的区分**:
```
命中     :该轨在本槽被配对(或 maintenance 路径直读主谱确认)
未观测   :本槽未交付(slot_seq 出现空号,C1 允许的跳槽降档)
           ∨ 候选表满(np 达 C4 上限)∧ 该轨上次电平 < 表中最小 P_peak ∧ 直读预算已用尽
           → **不计入老化、不计入连续性分母**,记事件
未命中   :该槽已交付 ∧ 该轨确实不在谱上(直读主谱复测亦不过门)→ 正常计老化
```
**为什么必须三态**:C1 的跳槽是**优雅降级**(保音频帧),候选表容量是**成本约束**;若本层把二者一律读成"峰消失",两个各自正确的机制在咬合处就把**降级变成漏检放大器**,而且**发作条件与故障后果正相关**(负载高/房间吵 = 啸叫多发时)。修法范式=让下游能分辨"没发生"与"没观测到"(team_config D2)。

**PHPR(反向否决)**:见 §3.2。
**IMSD(分类主判据)**:见 §2。

### 1.3 组合规则:分级流水线,非"几中几"投票

```
G0 门(全过才进):检测频带 [F_det_lo, F_det_hi] ∧ 通道未 bypass
                 ∧ level ≥ T_low   (GR 条件下放宽为 T_low_gr,§1.2-C;入轨打 relaxed_entry 标)
候选:PAPR≥T_papr ∧ PNPR≥T_pnpr             → 进入/维持跟踪(IPMP 配对)
       └ relaxed_entry 轨:窄带门取 PNPR≥T_pnpr_high(PAPR 在掩蔽下结构性塌陷,§1.2)
跟踪:≥3/4 **可观测**槽命中 → TRACKED;连续 6 个可观测槽未命中 → 删(§1.2-D)
分类(TRACKED 上,三路任一命中 → HOWL,详见 §3):
  PANIC 路:level≥T_panic ∧ 窄带门             (最快,1 槽;前提=条件担保 §1.2/§3.3)
  GROWTH 路:(IMSD 命中 ∨ 等效命中(§3.2 臂2))∧ 非谐波族(PHPR 否决,削波豁免 §3.2)
             └ relaxed_entry 轨不走本路(IF-v1.4 C11-② 规定;异议见 §8.3-6)
  PERSIST 路:长时驻留(滑窗命中率口径,§3.3)∧ 高窄带门 ∧ 非谐波族(同受 §3.2 豁免)
```
**不做扁平"几中几"的理由**:六判据信息维度不同(电平/形状/时间),扁平投票会让三个"形状类"判据(PAPR/PNPR/PHPR)在一帧内互相凑票,把持续元音投成啸叫;分级流水线强制"先是窄带峰、再是持续峰、最后才谈是不是啸叫",每级淘汰各自的假阳性(设计论证 [L3])。检测频带初值 `F_det_lo=120Hz`(可调 30-500Hz,对齐 dbx 检测 HPF [L4/dbx AFS2])、`F_det_hi=8kHz`(主旁链 Nyquist 上限);**8-20kHz 由合同看门狗谱补盲,仅粗判(§3.6)**。

## 2. ★ IMSD 判据自研(帧间幅度斜率)

D0c §1.8 已确认全域无同构实现:振动/工频域的目标全是稳态窄带,从不需要区分"正在长起来的啸叫"与"稳态存在的合法窄带信号"。这是本设计的核心自研件。

### 2.1 物理机理:为什么斜率是啸叫的"身份证"

闭环电声系统在频点 f 处环路增益 G(f)(含相位对齐)超过 1 时,幅度每经一次环路乘 |G|:
```
a(t) = a0 * |G|^(t/τ)  →  L(t)[dB] = L0 + β*t,  β = 20*log10|G| / τ   [dB/s]
```
τ=环路延迟(声程+处理链)。**即:啸叫在 dB 域随时间线性增长,斜率恒定**——这是环路物理决定的签名,人声/乐音没有义务遵守它。
桌面自验(CHECK C,结论域按 B-m5 限定):闭环差分方程仿真(脉冲种子,g=1.05/τ=10ms 与 g=1.02/τ=25ms),用本设计旁链参数(1024 Hann/hop 256)提取 STFT 峰值轨迹,LS 拟合斜率与解析值 20log10(g)/τ 偏差 **0.0% / 0.1%**——证明**轨迹提取管线对指数增长无斜率偏置**(IMSD 的测量链可信);dB 域线性模型本身属反馈物理常识 [L3],不赖此"证明" [L2/桌面数值,`selfcheck_W1B` CHECK C]。**结论限定(critic B-m5)**:CHECK C 的被测物是理想线性差分环路,它只证明"本设计的 STFT 轨迹提取管线能无偏还原 dB 域线性增长",**不证明真实房间的啸叫必呈该形态**——RT60 混响尾、多路径梳状、环内非线性都会给真实斜率叠加噪声与弯折,IMSD 对真实啸叫的判别力由 ROC 素材(§7.3)另证。

量级(会议室,[L3/手算]):τ ≈ 5-50ms(声程 3-30ms + 处理 ~2ms + 换能),超额增益 0.5-3dB/圈 → β ≈ 10-600 dB/s → 每槽(T_hop = IF-v1.4 C1 的每通道更新周期,B3=16ms)**0.16-9.6 dB**。快端由 PANIC 路兜——**仅限输入侧钉住(ADC 满幅)场景有条件担保(IF-v1.4 C12);输出侧限幅器钉住时 tap 电平无下界担保,PANIC 降为机会快路径,覆盖转由 pinned-howl 路径承接(§3.2 三臂 / §3.5-#11,B-F1 修法)**;慢端(<β_min)由 PERSIST 路兜(终将饱和为稳态高峰);IMSD 主攻中段——**在啸叫可闻爆发前抓住它**。
**⚠ "钉住 = 无增长"只对恒定平台成立(v1.2 补,B-F1 深化)**:被**语音间歇打断**的钉住环路会反复"讲话时被 GR 压下 → 停顿时重新指数增长回平台"——这是 PA 实战中"句子之间系统在响铃"的物理成因 [L3/反馈环路物理]。故该场景**存在真实增长段**,只是整段发生在 T_low 之下(仅经 §1.2-C 放宽门可见)。本文据此在 §3.2 增 case (c),并对 IF-v1.4 C11-② 括注"该场景本就不可达"提异议(§8.3-6)。

### 2.2 数学定义

对跟踪峰 k,维护其 **PAPR 轨迹** P_k[n](dB,n = **已交付槽**索引,时间基准 T_hop = IF-v1.4 C1 的每通道更新周期,B3=16ms)长度 W 的环形历史,**并同时存下每个样本的 `slot_seq`**。**用 PAPR(相对量)而非绝对幅度**——这是抗误判设计的核心(§2.4 ①)。

```
窗内 LS 线性拟合:P_k[·] ≈ b_k*x + c_k
  ★ x 轴 = **该样本的 slot_seq 与窗首样本的差值**(= 真实时间轴 / T_hop),不是 0..W-1
  b_k  = 斜率 [dB/槽]
  s_k  = 拟合残差 RMS [dB]           (线性度)
  ΔP_k = P_k[末] - P_k[首] [dB]      (总升幅)

IMSD 命中 ⟺ 轨迹当前为 TRACKED ∧ hist_n ≥ W_used
            (轨迹历史自**诞生**起累积、含 TRACKED 前的槽;算法级参考点 = 轨迹诞生
             ⇒ 该延迟按 IF-v1.4 **C13** 称 **T_decide(判定延迟)**,禁入对外语境)
          ∧ β_min ≤ b_k ≤ β_max
          ∧ s_k ≤ s_max
          ∧ ΔP_k ≥ ΔP_min
          ∧ 窗内空号(跳槽)总数 ≤ W_used/2      (稀疏窗不出判定,见下)
双窗:W_long(主判,预设 §6);W_short=4(快判,仅当 b_k ≥ β_fast)
```

> **★ 计数语义二分(v1.2 新增,IF-v1.4 C4 `slot_seq` 的使用注记;回执使用注记 3)**
> C4 原文要求「全部连续性/老化/驻留计数按**已交付分析槽**计」。**该规则对"存在性计数"正确,对"速率估计"有害**:
> - **存在性**(连续性 / 老化 / reclaim / PERSIST 驻留)→ 按已交付(且可观测)槽计 ✓ —— 正是本款要防的"伪峰消失";
> - **速率**(IMSD 的 b、s)→ **x 轴必须用 slot_seq 差值**。照字面把跳槽窗压成连续 x,窗内真实时间跨度被系统性低估,**斜率与线性度残差同时失真**。
>
> **数值坐实(CHECK E,`selfcheck_W1B`,构造轨迹 [L2/桌面数值])——双向都错**:

### 2.4 抗误判设计(四条,全部自研)

1. **相对量抵共模**:P_k 用 PAPR(峰对谱均值)而非绝对电平 → 推子/AGC/整体渐强(crescendo)是共模,斜率≈0(CHECK D:crescendo 例 b=0.14dB/hop 被拒)。⚠ 出生先验"共模抵消只抵消共模":**独奏乐器单线渐强不是共模**——由 PHPR 否决与预设收紧兜(§3.2/§6),残余风险如实列入 §3.5。

3. **跟踪连续性前置**:斜率只在 TRACKED(已连续 ≥3/4 hop 的窄带峰)上计算;缺帧即中止,防瞬态(掌声/敲击)的谱溅射伪装成"增长"。

**诚实注**:第四/五种中**臂3 均可达**(限幅器持续出力,GR active),不扩大"无 GR 时代"的洞;但重生轨即使继承信用,**检出仍有延迟叠加**(最坏 ≈ 中断时长 + 剩余 P_persist)。**影子机制未仿真,不声称已闭环**(入 §3.5-#11 残余行与 §9)。

**残余误豁免面(如实)**:①臂2+正因果的等效命中对"延迟谐波+极陡起音入台"的合成器/电子音色存在误触发面——音乐预设抬 R_RISE/收 S_PLAT,ROC 标定;②臂3 的"音乐过限幅器"误豁免由 PERSIST 秒级驻留+浅陷 -3dB 起步+LIFT 快回收把损伤钉在有界范围;③臂3 作用域式的电学/声学过包含(见上)。三者并入 §3.5-#11。
**高频限制**:f>4kHz 时 2f 超出主旁链上限(C4 主谱带宽),及时上查不可用 → 该区间否决实际靠下查(f/2)+ 预设收紧;诚实记为盲区之一。**增强(已入 IF-v1.4 C4)**:候选峰附带 **2f 看门狗 bin 值**——**仅用于 PERSIST 路**否决(秒级时标下陈旧度可接受,C4 明写"秒级陈旧度可接受"),不用于 GROWTH 路因果时序判定(削波例外须及时数据)。

### 3.3 三路分类的分工(§1.3 的展开)

- **PANIC 路**(1 槽判定延迟 T_decide):level≥T_panic ∧ 窄带门(PAPR≥T_papr)的峰,**不经 PHPR/持续性判据**(措辞按合同 C12 勘正:PANIC = 电平 ∧ 窄带门,**不是"仅电平"**;钉住啸叫天然满足窄带门,担保范围不变)。**覆盖 = 条件担保,仅输入侧(ADC 满幅)钉住且受 IF-v1.4 C12 两条件约束;输出侧钉住时为机会快路径,不承诺覆盖**(C12 明文:两侧文档中"快端由 PANIC 兜"的无条件旧表述一律按该款收窄)。响应:①挂陷波 -9dB(经执行器斜坡,C6 硬约束)②通道宽带临时回落(§4.4)**先行兜住斜坡期间的增长** ③临时提升检测灵敏度(T_papr/T_pnpr 各降 3dB,持续 5s)④断言 `NHS_PANIC_ACTIVE` → AGC hold(链序 C-4(W1-A §4),防 AGC 把回落的增益拉回来)。①-③对齐竞品恐慌阈值语义 [L4/竞品手册 §2.3] 与 Espressif 全局增益回落结构 [L4/README_HOWL]。
- **GROWTH 路**:IMSD(或臂2 等效命中)∧ PHPR 非否决。抓"正在长"的啸叫,主力路。T_decide 见 §2.3 表。
- **PERSIST 路**(秒级):驻留 ≥ P_persist ∧ 高窄带门 ∧ PHPR 非否决。兜"已饱和/缓慢爬升"啸叫。P_persist 初值:语音预设 1.0s、音乐预设 2.5s [L4/待标定]。
  - **★ 驻留语义(v1.2 改,B-F1 深化;关键修法,不是放宽豁免条件)**:由**严格连续**改为 **滑窗命中率**——`在长度 P_persist 的滑窗内,命中槽 / 可观测槽 ≥ 70%`,**分母只计可观测槽**(§1.2-D),[L4/待标定]。
    **为什么必须改**:钉住啸叫在真实会议里**必然**与交谈共存;讲话期啸叫被 GR 压下、停顿期重新长回平台(§2.1)。严格连续下,一段 1-3s 的讲话就会触发老化删轨 ⇒ **PERSIST 计时永远重置 ⇒ 稳态啸叫伴交谈时 PERSIST 恒不触发**。这与 B-F1 是同一病型(条件在目标场景恒假),只是藏在连续性语义里。滑窗命中率 + 影子表继承 PERSIST 信用(§3.2 缓解③)共同跨过讲话段。
    **代价(如实)**:容忍中断 ⇒ 间歇性合法窄带(反复出现的乐音)更易累积 ⇒ 误触发面变大。三重收紧对冲:同频绑定(|Δf| ≤ BW/2)、高窄带门、PHPR 否决;ROC 标定命中率门限(§7.3-⑦)。
  - **窄带门取值(v1.2 勘正)**:常规路径用 `PAPR ≥ T_papr_high(=T_papr+6dB)`;**`relaxed_entry` 轨(经 T_low_gr 入轨)改用 `PNPR ≥ T_pnpr_high`** —— 因 PAPR 是全带统计,在掩蔽/钉住场景结构性塌陷(CHECK F-2)。IF-v1.4 C11-② 原文写的是 PAPR,已提 v1.5 点单 P6(回执 §8.2);在其定版前,本文**显式声明本处偏离合同字面并给出物理理由**,不静默执行。
  - **已知代价**:超过 P_persist 的合法纯音(测试信号/HVAC 风鸣/提示音)会被浅陷(-3dB)——列入误触发清单 §3.5,由浅起步+快回收把损伤控制在轻微。

### 3.4 分类输出

`HOWL(ch, f_median, class∈{PANIC,GROWTH,PERSIST}, PAPR, level)` → 交状态机(§5)。同 hop 多峰命中按 (PANIC 优先, 次按 b_k 降序) 排序,每 hop 每通道**至多执行 1 个新挂/加深动作**(防一帧内连锁误动作;PANIC 不受限)[L3/设计]。

### 3.6 高频看门狗带(消费 IF-v1.4 C4 的高频看门狗谱)

主旁链上限(C4 主谱带宽)以上的盲区由看门狗谱补,但其网格粗、更新慢(C4 规定的每通道扫描周期),**IMSD/GROWTH 不适用**(采样周期 ≫ 啸叫增长时标)。处理规则:
- 仅两路:**PANIC**(level≥T_panic 的窄带峰,单次确认即动作)与 **PERSIST-粗**(连续 ≥3 个看门狗周期的高窄带门峰)。
- 挂陷用**宽档**(≥1/5 oct;该带宽 ≫ 看门狗网格,定频精度要求天然放松 [L3/手算]);占用同一 8 槽池。

- 预期负担极低:会议场景高频啸叫罕见(GN 专利典型带 1-6.5kHz 旁证 [L4]),看门狗是保险不是主战场。
- **⚠ 反应时间(v1.2 按 IF-v1.4 C13 箍② 重算,联动 W1-A verdict F4/DEC-0008)**:C13 只对主带写了 Δfill;本带的同位概念是**扫描周期上界**——onset 可能恰在一次扫描完成后发生,最坏须等满一个周期。按同一保守口径 [L3/手算]:

| 本带路径 | 组成 | **T_react(对外)** |
|---|---|---|

## 4. ★ 深度策略:先浅→复发递进→缓抬试探→宽带兜底

### 4.1 深度可控陷波器(修补 PX4 缺口)

PX4 `NotchFilter::setParameters` 仅三参数、全深无深度控制(D0c §1.6 已核)——**弃其系数公式,保留其 DF1 结构与更新纪律**。系数改用 **RBJ peaking-EQ 负增益式**(RBJ Cookbook [W0 已核])。
> **双轨口径(B-m3,v1.2 关闭方式 = 补跑,不是删宣称)**:v1.0 曾写"pareq.m 交叉核"**实际未跑**(critic B-m3 抓获,本项目记过的虚账)。**现已补做**:`adaptive-dsp-2` 跑通真·异源第二轨(**Orfanidis 系 / Välimäki & Reiss 2016 Table 7.2 的 tan 预畸变式**,与 RBJ 的 sin 映射不同推导、不同带宽映射),本轮集成为 **CHECK A2 并已实跑**(§2.5、§10.1 附命令与输出)。故本设计的双轨现为**三重**:①闭式\\|H\\| vs 复数求值(CHECK A)②半深点带宽功能核(能抓系数公式转写错)③**异源公式轨(CHECK A2)**。**署名保留给 `adaptive-dsp-2`**(DEC-0011 归因更正的落实)。
```
A=10^(G/40)(G<0);alpha=sin(w0)*sinh(ln2/2 * BW_oct * w0/sin(w0))
b=[1+αA, -2cosw0, 1-αA]/(1+α/A);a=[1, -2cosw0, 1-α/A]/(1+α/A)
带宽:BW_hz = max(BW_oct*f, BW_floor);BW_floor 取参数字典默认 15Hz [L4/QSC](量程 5-30,W1-A §5 字典);
      我方原提 12Hz [L4/dbx 8-11Hz 折中] 作 ROC 标定候选,标定后若胜改字典默认值(非结构分歧,双方已确认)
```
桌面核算:①CHECK A —— 闭式 |H| vs 复数求值,5 组 (f0,深度,BW) 两轨差 ≤1e-5dB、@f0 深度=设定值、半深点带宽=设定 BW、极点全稳 [L2/桌面数值];②**CHECK A2 —— 异源第二轨**(RBJ sin 映射 vs Välimäki-Reiss tan 预畸变):5 组规格点 @f0 深度两轨互差 ≤1e-12dB、半深带宽各自 ≈ 设定值(两轨互差 ≤1e-4 oct = sin/tan 约定差,如实记录)、VR 轨极点全稳 [L2/桌面数值]。**注:两轨系数本就不同**(带宽映射不同),互核点是**设计规格点**而非系数逐项比。

```
HOLD 中静默(该轨无任何再命中)≥ LIFT_AFTER(预设,§6)→ 进 LIFT:
      +3dB / lift_step(5s)[L4/dbx 3dB 步进;dbx LIFT AFTER 量程 5s-60min]
      抬升中复发 → 立即回挂 pre-lift 深度并重置计时(dbx 语义);若复发为 PANIC 级 → 回挂并再加深 -3dB
      抬至 0dB 无复发 → STANDBY(§5.3)
老化:AUTO 陷波连续挂 ≥ AutoClear(默认 OFF,量程 1-99h [L4/Shure DFR22])→ 强制进 LIFT
```

### 4.4 宽带减益兜底(8 点耗尽/陷波不足;Rane + 乐鑫结构佐证 [L4])

```
触发:①分类命中但无可分配陷波(§5.5 分配失败) ②NOTCH_INSUFFICIENT ③PANIC 路(临时回落)
动作(作用于本通道 AFC 模块出口的宽带增益 g_duck):
  attack:-1dB/100ms 递减,直到该通道无 HOWL 分类,下限 -6dB [L4/待标定]
  PANIC 变体:一步 -6dB(5ms 斜坡),恐慌解除后并入通用恢复
  hold:静默 10s 后 recover:+1dB/s 回 0dB;恢复中复发 → 回落并重置
  互斥:g_duck 生效期间断言 NHS_PANIC_ACTIVE / NHS_DUCK_ACTIVE → AGC hold(链序 C-4(W1-A §4),
        否则 AGC 会把回落增益拉回,两环对打)
  事件:FILTERS_EXHAUSTED / PANIC_DUCK 上报 host(PRD §六 可视化)
```
执行侧需求:g_duck 是 AFC 出口的宽带增益节点,须支持逐样本斜坡(已列 §8.3-④,执行器归架构侧)。
兜底放通道内不放主输出:只降罪魁通道,不伤全系统(与 automixer NOM 限制天然叠加)[L3/设计]。

## 5. 状态机完整定义

### 5.1 每陷波槽:模式 × 状态

**模式**(对齐 PRD §二.5"三种工作模式"与竞品口径 [L4/竞品手册 §2.3],DEC 已确认吻合):
- **AUTO**:参与自动分配/加深/回收/老化/循环复用。
- **MANUAL**:用户直设 f/BW/深度;分配器不可占用、不自动变化。
- **FIXED**:频率钉死(用户手动钉或将 AUTO 陷波"固化"),重启/调预设仍有效,不被新啸叫占用;自动加深仍作用(复发时),LIFT 只回到**固化基线深度**而非 0dB。[L3/产品语义推断:竞品仅明言"不被占用且重启有效",基线深度语义待 host-software/CTO 确认]

**状态**(AUTO 槽;MANUAL/FIXED 仅 ENGAGED 恒驻):
```
        分配(§5.5)                目标深度到达
 FREE ────────────► ENGAGE ────────────────► HOLD ◄──┐
  ▲                (渐深中)                    │      │复发:加深/回挂(§4.2/4.3)
  │                                 静默≥LIFT_AFTER   │
  │ reclaim 窗到期                      ▼             │
  └────────────── STANDBY ◄───────── LIFT ───────────┘
                (0dB 驻留,记频率)   (+3dB/5s 缓抬)
                     │同频复发(≤reclaim 窗)
                     └──────► ENGAGE(直接 -3dB 挂回,不耗新槽)
```
- **STANDBY/reclaim 防抖**:抬到 0dB 后驻留 `reclaim = 30s`(量程 5-120s [L4/QSC Q-SYS]),防"弹进弹出";窗内同频(|Δf|≤BW_hz/2)复发直接回挂;到期 → FREE。
- 系数更新纪律(PX4 防抖思想 + **IF-v1.4 条款C6** 硬约束):重调迟滞 `|Δf| > max(0.25*Δf_bin, 0.01*f)`,须 ≥ C6 规定的下限 [L4/待标定];深度斜坡由执行器保证(C6);**系数重算的全局限流由 C6 规定 → 本层动作进重算队列串行下发,最坏全滤波器更新的排空时间见 C6 [L3/手算],状态机时序对此不敏感(时间常数均 ≥秒级,唯 PANIC 例外——其首动作是宽带回落 g_duck,**增益通路旁路系数重算队列,帧级生效**,C6 已写入)。**

### 5.2 全局语义

- **★ GR 遥测降级的状态机语义(v1.2 新增;IF-v1.4 C11「降级可见性」的接收侧落地,回执使用注记 7)**
  C11 给的是**稳态**语义(`invalid` ⇒ 相关特性自禁用 + 记事件,**禁止静默置零**);**转换瞬间**归本层定案:
```
valid → invalid(遥测源失效/未实现):
   ① **已挂陷波一律不撤** —— 撤陷=环路立刻回啸,危害远大于误挂;存量按正常 LIFT 生命周期走;
   ② 冻结**新的**臂3 豁免与**新的** T_low_gr 放宽准入(门回落 T_low);
   ③ 经放宽门入轨的**存量轨不立即删** —— 删轨会丢掉已累计的 PERSIST 可观测信用,
      那又是一次"降级放大器";改为停止继续放宽、保留至正常老化;
   ④ 上报 host 事件(与 C11 要求的 host 事件同一通道),供 D11 可视化"检测能力已降级"
invalid → valid:不追溯补偿(避免状态回溯),自恢复时刻起正常计
```
  **⚠ 采样率失配(如实)**:`gr_telemetry` 按 C11 规定的帧级更新,而本层每分析槽读一次 ⇒ 帧间的短促限幅可能读不到。对"持续钉住"无害(钉住时 GR 恒 active);对**突发性限幅(音乐)**存在混叠,方向 = 可能高估 active 占比 ⇒ 误豁免面变大。缓解 = N_gr 连续可观测槽 + 仅 PERSIST 路 [L4/待标定]。已提可选 v1.5 点单(读后清零的计数事实字段,回执 §8.2-P7 附注),**不做也可接受**。
- **Lock(锁定)**:通道级开关。冻结所有槽的状态转移与系数变化(演出锁定,竞品同语义);检测旁链继续跑,仅记 log。
- **Clear(清除)**:两级。`Clear-Auto`=复位全部 AUTO 槽(含 STANDBY)→ FREE;`Clear-All`=另含 MANUAL/FIXED(host 二次确认)。[L3/竞品仅"一键复位全部",两级细分为本设计补强,待产品确认]
- 预设切换:AUTO 槽全清;FIXED/MANUAL 随预设文件载入(与 D6 预设模型、参数字典对接)。

### 5.3 分配策略(§5.5 伪代码)与循环复用

新 HOWL 分类到达,按序取槽:
1. **STANDBY 同频槽**(reclaim 命中)→ 直接回挂;
2. **FREE 槽** → ENGAGE;
3. 无 FREE:**round-robin 复用**——候选=全部 AUTO 槽中 `当前深度最浅` 者(损失最小);同深取 `最久未复发` 者(Shure"替换最旧动态"的保守化:替换最旧可能放虎归山,替浅优先把回归风险压到最小 [L3/设计,偏离 Shure 有意为之,留痕]);被复用槽旧频率记入 STANDBY 影子表(仅记频,不占槽),reclaim 窗内旧频复发 → 走宽带兜底而非再抢槽;
4. 3 也无(全部 MANUAL/FIXED 或 LOCK)→ 宽带兜底(§4.4)。

**★ 跟踪轨表的准入优先级(v1.2 新增;D2 扫产出:T_low_gr 放宽 × 轨表容量 NT 的咬合)**
放宽门(§1.2-C)使更多低电平峰有资格入轨,而轨表 NT 有限 ⇒ **放宽档期的轨表压力上升,存在把真啸叫轨挤掉的风险**。定案:
```
轨位竞争时的淘汰序(先淘汰序号小者):
  ① relaxed_entry ∧ 未达 TRACKED ∧ 无 GR 证据
  ② relaxed_entry ∧ 未达 TRACKED
  ③ 常规入轨 ∧ 未达 TRACKED ∧ 最久未命中
  ④ 已 TRACKED 者不被未 TRACKED 者挤掉(硬规则)
即:**常规门入轨者对放宽门入轨者有绝对优先权**,放宽是"额外容量内的机会",不得挤占主路。
```
**影子表继承(§3.2 缓解②③)在轨位被回收时同样生效** —— 被淘汰的 relaxed_entry 轨把 {f, 删除时刻, rapid_onset/t_veto_start, PERSIST 可观测信用} 留在影子表,同频重生时继承(保鲜 T_exempt ∧ GR 仍 active)。

### 5.4 老化超时:§4.3 AutoClear;跟踪表老化:§1.2 IPMP(按**可观测槽**计,§1.2-D)。两者语义不同(陷波器寿命 vs 检测轨寿命),实现分开。

```c
  u8    exec_id;            // 执行器滤波器句柄(notch_request 返回)

typedef struct {            // 检测轨
  bool  active; float f_hz; medfilt7_t fmed;        // 首挂 3 点、补满 7 点(§1.2)
  u16   pair_id;            // 合同供给的帧间配对 id(关联归架构侧)
  float papr_hist[W_MAX]; u32 seq_hist[W_MAX];      // ★ 值 + 其 slot_seq(LS 的真实 x 轴,§2.2)
  u8    hist_n; u32 t_born, t_last_seen;            // t_born ≡ t_onset(C13 算法级参考点)
  u8    hits4;              // 近 4 个**可观测**槽的命中位图(§1.2-D)
  u16   obs_n, hit_n;       // PERSIST 滑窗:可观测槽数 / 命中槽数(命中率口径,§3.3)
  u32   t_veto_start;       // PHPR 否决条件首次成立时刻(§3.2 因果时序另一端)
  bool  rapid_onset;        // 臂2 sticky 签名(保鲜期以 t_born 起算,T_exempt)
  bool  relaxed_entry;      // ★ 经 T_low_gr 放宽门入轨(§1.2-C);限最严 PERSIST 变体
} Track;                    // B-m2 增量按 3 字段口径:{rapid_onset, t_onset(复用 t_born), t_veto_start}
typedef struct {            // ★ 影子表项(§3.2 缓解②③ / §5.3):删轨后保鲜,同频重生时继承
  float f_hz; u32 t_removed; bool rapid_onset; u32 t_veto_start;
  u16   persist_credit;     // 已累计的 PERSIST 可观测驻留信用(v1.2 扩展)

typedef struct {
  NotchSlot slot[NN]; Track trk[NT];
  float g_duck_db; u32 t_duck_quiet;      // 宽带兜底
  StandbyShadow shadow[NN];               // 复用槽/删轨的影子表
  bool  gr_valid_prev;                    // GR 有效位边沿(§5.2 降级瞬变)

} AfcChannel;

  float wd_2f;                              // 2f 看门狗 bin 值(C4;仅 PERSIST 路否决用)

} PeakInfo;

  struct { bool active; float gr_db; } comp_in[8];     // 输入链 COMP/限幅
  struct { bool active; float gr_db; } dynEQ_in[8];    // 8 段动态 PEQ(各频段最大)
  float route_gain_db[8];   // 本通道 → 各输出母线的路由增益(矩阵状态原值)

                                            //  判据代码不得硬编码 bin 宽/更新率——C4

// ===== 每通道分析槽(周期见 IF-v1.4 C1)一次;包络 C2(对账 §8.2)=====
void afc_slot(AfcChannel *c, const SidechainSupply *sp) {
  u32 seq = sp->slot_seq;                  // ★ 一切计数以此为基准,不用墙钟/名义 hop
  gr_edge_tick(c, sp->gr);                 // §5.2:valid↔invalid 边沿处理(不撤存量陷波)
  // 1) 判据:对 sp->pk 逐个算 PAPR/PNPR/level,过 G0 门(§1.2-C 含 T_low_gr 放宽)
  // 2) 跟踪:按 pair_id 挂到 Track;**三态**记账(命中/未观测/未命中,§1.2-D):
  //      未观测 ⇒ 不计老化、不进滑窗分母;表满且本轨电平低于表内最小 P_peak 时,
  //      走 maintenance 直读主谱复测(上限 4 轨/槽),仍不过门才记未命中
  update_tracks(c->trk, sp, seq);
  // 3) 分类:三路(§3.3),输出至多 1 个非 PANIC 动作;看门狗带走 §3.6 粗判
  Howl h; int nh = classify(c, sp, seq, &h);
  //    classify 内部:PANIC : level>=P.t_panic ∧ 窄带门(C12 措辞:电平∧窄带门,非"仅电平")
  //                          → 断言 NHS_PANIC_ACTIVE,链序 C-4(W1-A §4)
  //                  GROWTH : (imsd_fit(trk) ∨ 臂2 等效命中) ∧ !phpr_veto(trk,sp)
  //                           ∧ !trk->relaxed_entry            (C11-②;异议见 §8.3-6)
  //                  PERSIST: 滑窗命中率 ≥ P.persist_hit_rate(分母=可观测槽,§3.3)
  //                           ∧ 窄带门(常规=PAPR≥T_papr_high;relaxed_entry=PNPR≥T_pnpr_high)
  //                           ∧ !phpr_veto(trk,sp)
  //                  phpr_veto 内含 §3.2 三臂豁免(臂1 IMSD/臂2 RAPID_ONSET/臂3 gr 作用域式,
  //                    臂3 仅 PERSIST;GR 证据另使 P.persist 减半 [L4/待标定],
  //                    但 relaxed_entry 轨**不享减半**——C11-② 两门收紧之一)
  // 4) 状态机 → 动作经执行器 API(notch_request/deepen/release,斜坡归执行器 C6)
  if (!c->lock && nh) allocate_or_deepen(c, &h, seq);  // §5.3/§4.2
  slots_tick(c, seq);            // ENGAGE 等斜坡 / LIFT 缓抬 / STANDBY 到期 / 老化
  duck_tick(c, nh, seq);         // §4.4 宽带兜底攻击/保持/恢复
  publish_dict(c);               // 参数字典回写:每槽 {mode,st,f,bw,depth} → host 频谱图
}

bool imsd_fit(const Track *t, const PresetParams *P, float *b_out) {
  // 预设加载时校验 P->W_used <= W_MAX(B-m2:大房间 W_long=10 恰为上限)
  if (t->hist_n < P->W_used) return false;
  // ★ x 轴 = slot_seq 差值(真实时间轴),不是 0..W-1 —— CHECK E 坐实朴素口径双向失效
  u32 span = t->seq_hist[P->W_used-1] - t->seq_hist[0];
  if (span + 1 > 2 * P->W_used) return false;       // 窗内空号 > W_used/2:不出判定(§2.2)
  float b, c0, s;
  ls_fit_x(t->papr_hist, t->seq_hist, P->W_used, &b, &c0, &s);   // O(W) 闭式,x=Δseq
  float dP = t->papr_hist[P->W_used-1] - t->papr_hist[0];
  bool long_ok  = (b>=P->beta_min && b<=P->beta_max && s<=P->s_max && dP>=P->dP_min);
  bool short_ok = imsd_short(t, P);                // W_short=4, b>=beta_fast(同用 Δseq)
  *b_out = b; return long_ok || short_ok;
}

void slots_tick(AfcChannel *c, u32 now) {
  for (int i = 0; i < NN; i++) { NotchSlot *s = &c->slot[i];
    if (s->mode == M_MANUAL) { retune_if_needed(s); continue; }  // §5.1:MANUAL 不自动转移
    switch (s->st) {
    case S_ENGAGE: // 斜坡由执行器实施(≤3dB/50ms);本层按时长推进状态
                   if (elapsed(now, s->t_engage) >= ramp_slots(s->target_db))
                     s->st = S_HOLD;                                     break;
    case S_HOLD:   if (elapsed(now, s->t_last_hit) >= c->P.lift_after)
                     { s->st = S_LIFT; s->t_lift_start = now; }          break;
    case S_LIFT: { float floor_db = (s->mode==M_FIXED) ? s->base_db : 0;
                   if (every(now, c->P.lift_step))
                     s->depth_db = fminf(s->depth_db + 3, floor_db); // B-m2:clamp,任意基线不越界
                   if (s->depth_db >= floor_db)
                     s->st = (s->mode==M_AUTO) ? S_STANDBY : S_HOLD; }   break;
    case S_STANDBY:if (elapsed(now, s->t_last_hit) >= c->P.reclaim) free_slot(s); break;
    default: break; }
    retune_if_needed(s);   // Δf 迟滞 §5.1;经执行器 retune,全局 ≤1 次系数重算/帧
  }
}
```

音频通路侧(每 64 样本帧最坏 8 级 DF1 串联)与系数斜坡/双缓冲**归执行器(架构侧,合同)**;本层不触碰样本域,只发 notch_request/deepen/release 与 retune。

### 5.6 跨通道协调(自研;多麦系统必需)

同一物理啸叫环路的频点会同时出现在多支开麦上;8 通道各自独立挂陷 = 同频最多 8×深度,音质无谓受损。
```
全局频率登记表(共享,单写者=旁链调度器):
  通道 j 挂入/加深 f 时登记 (j, f, hop)
  通道 i(i≠j)对 |f_i - f| ≤ BW_hz/2 的分类命中:延迟 2 hop(32ms)执行
    → 若 j 的动作已让环路回稳,i 的轨在延迟期内自然衰减,不挂
    → 若仍命中(多麦共环/另一环)→ i 正常挂入
  优先执行者:同 hop 多通道命中同频时,取 level 最高者先动
```
[L3/设计,待闭环多麦仿真验证;PANIC 不延迟。]

## 7. 验收判据草案(交 verification 共定;本节只定义"怎么测",不承诺任何数字)

### 7.1 它真在工作(正面判据;测量仪器只看**输出信号**,不信内部旗标——假绿纪律)

- **闭环测试床**:实录 RIR(素材工单,与 verification 共立)构成 mic→DSP→spk→RIR→mic 数字闭环 + 语音/音乐源注入;0.5dB 步进抬环路增益。
  - T1 检出:诱发啸叫后,DUT 输出包络在 T_react 内停止增长并回落(T_react 目标值待标定,对标 Sabine 0.4s [L4/仅对标不承诺]);判定用输出信号包络+谱,非内部 log。
  - T2 抑制:挂陷后环路回稳(输出包络 2s 内衰 ≥20dB [L4/判据初值待与 verification 定])。
  - T3 回收:增益回稳后 LIFT 全程无复啸、深度归零。
  - T4 多啸叫:递增增益逐个诱发 ≥8 个频点,验证分配/复用/兜底路径全部走到(含第 9 个啸叫触发宽带兜底)。
  - T5 多麦共环:双通道共环路,验证 §5.6 协调(不出现双通道同频双挂,除非确属双环)。
- **MSG/ΔMSG 测量定义**(唯一合法的"收益"口径):同一 RIR/同一流程下,NHS bypass 与 active 各自的临界增益(判稳标准:单频包络持续增长>1s),差=ΔMSG;跨 ≥N 个 RIR 报分布。**桌面闭环全部 =L2;真房间/真机 =L1(verification 所有)。⚠ D0c §3.1 口径冲突在案(Shure 6-9dB vs Rane 2-3dB),L1 前任何 GBF/ΔMSG 数字不进规格、不对外(C2 红线)。**

### 7.3 误触发套件与阈值标定(素材工单前置)
