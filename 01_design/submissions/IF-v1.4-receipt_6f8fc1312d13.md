## 1. C13 两箍(T_react/T_decide 命名垄断 + Δfill=64ms 保守上界)

**独立推导**
- Δfill 物理量 = 分析窗能量爬升时间 = N/fs_sc。由 C1/C4 的 B3 运行点:1024/16000 = **64.0ms**,与箍②取值逐位相符 [L3/解析,本回执复算]。
- 箍②的机制正确性:verdict B-m4 打击的危害是"下游拿到两个数"。Δfill 的**真实值在 0~64ms 间取决于啸叫 onset 与窗边界的相位**,是一个分布而非定值;对外账取满窗上界是**唯一不需要实测就成立**的保守选择,且与"L1 实测后方可按实报"配套——**机制无懈可击,我确认**。
- 箍①的机制正确性:两个参考点(轨迹诞生 / onset)是**不同物理量**,硬合并会损失精度;命名垄断+语境禁令堵的是**泄漏口**而非量本身。我确认该结构优于硬合并。

**⚠ 使用注记 1(数值作用域,须两侧同步)**:C13 给出的对外主路数 **242ms = 64+128+50 以 W_long=8 为前提**,而 **C10 自身明写 `W_long_max × hop = 10×16ms = 160ms`(大房间档)**。同一份合同内,C13 的示例数与 C10 的窗上界不同参。按箍②"保守"的立意逐档复算 [L3/解析]:

| 路径 | T_decide | T_react = Δfill + T_decide + 斜坡 |
|---|---|---|
| 快路 W_short=4 | 64ms | **178ms** |
| 主路 W_long=8(语音/音乐·小房间) | 128ms | **242ms**(= C13 示例数,critic i2 已证) |
| **主路 W_long=10(语音/音乐·大房间)** | **160ms** | **274ms** |
| PANIC(1 hop + g_duck 5ms 斜坡) | 16ms | 85ms |
| PANIC(1 hop + 陷波 −9dB 150ms 斜坡) | 16ms | 230ms |

⇒ **242ms 不是预设空间的上界**。我方 W1-B v1.2 按上表逐档写,并显式标注档位;**请 v1.5 把 C13 的示例数改为"随 W_long 档位,242ms@W_long=8 / 274ms@W_long=10"**,否则 D14/宣传引 242ms 而设备跑大房间预设即违反 C13 末行自己立的规矩("任何总反应数字若未含满窗 Δfill 且未标 L1 实测即违反本条款"——现在要加一句"且未含所在预设的 W_long")。**这不是异议,是同一箍②立意的贯彻。**

**⚠ 使用注记 2(箍②在看门狗带的贯彻)**:C13 只对主带写了 Δfill。高频看门狗带(C4:N=1024@48k、每通道 ~1.07s)的同位概念是**扫描周期上界**——onset 可能恰在一次扫描完成后发生,最坏须等满一个周期。故按箍②口径 [L3/解析]:看门狗 PANIC 路 T_react ≈ 1070 + 21.3(窗填充)+ 150(−9dB 斜坡)= **≈1.24s**;PERSIST-粗(3 周期)≈ **3.3s**。我方 v1.1 写的"≈1.1-1.2s"**未含满窗与斜坡,按 C13 口径属偏乐观,v1.2 已改**。此数进 CTO 第三关议程第 3 项(F4 残余风险)时应用 1.24s,不用 1.1s。

**结论:确认。** 命名垄断与保守上界两箍我方全文遵从;T_decide 不出现在 §7 验收章与任何对外语境。

## 2. C11 T_low 使用注记(T_low_gr 放宽 + 最严 PERSIST 变体 + 软校验扩展)

**独立推导(先复算漏点本身)**
输出侧钉住的 tap 电平:环路稳态条件 = 前向增益 + 声学回程 = 0dB;钉住点在输出限幅器,故
`tap = L_天花板 − G(tap→限幅点)`。取合同算例(天花板 −6dBFS、前向 +50dB)⇒ **tap = −56dBFS**,低于 T_low(−45dBFS)**11dB** [L3/解析,复算相符]。**漏点属实**:候选被 G0 门挡掉,三臂全不可达——这比 tap<T_panic 更深一档,攻击的是修法的前置门。

**机制评估(我独立给出的接受理由,比"放宽 20dB"更强)**
T_low 的**设计意图**是"不对听不见的低电平窄带动手"(§1.2 原文:防柔和乐段/低电平嗡声)。这是一个**关于输出可闻度**的意图,却用 **tap 电平**实现——两者只在 tap→输出增益已知且正常时等价。输出侧钉住恰是二者解耦的场景:**输出端在天花板(极响),tap 端在 −56dBFS(极弱)**。因此 GR 条件下的放宽**不是"松一档凑合",而是把门恢复到它本来的语义**。基于这一论证我接受 ①,并认为它比原文给的理由更能抵御"为什么不干脆删了 T_low"的追问。

**数值边界(如实)**:T_low_gr = −65dBFS;算例的 −56dBFS 有 **9dB 余量**;**放宽门的失效临界 = G(tap→限幅点) > 59dB**。该增益是**已知数字量**(动态PEQ/COMP补偿/ANS/AGC/矩阵路由/输出增益,全在字典内),故失效场景**可由 ③ 的软校验事前告警**,不是静默失效 —— ③ 因此不是附属条款,是 ① 的可用性前提,我确认其必要。

**⚠ 实质异议 1(唯一一条;针对 ② 的括注论证,不针对 ② 的机制)**

C11-② 原文:「PANIC/GROWTH 维持原门(**该场景本就不可达**,不放,免扩误伤面)」。

**括注的物理论断不成立**,反例是钉住啸叫最常见的现实形态——**语音间歇下的钉住啸叫**:
1. 钉住的平衡靠限幅器 GR 维持环路增益 = 1。本地讲话人一开口,同一母线电平抬高 ⇒ **GR 加深** ⇒ 该通道环路增益跌破 1 ⇒ **啸叫按环路时间常数衰减**;
2. 讲话停顿 ⇒ GR 释放 ⇒ 环路增益回到 1+ ⇒ **啸叫重新指数增长**回钉住平台。这正是 PA 实战中"句子之间系统在响铃"的物理成因 [L3/反馈环路物理];
3. ⇒ 该场景**存在真实的增长段**,IMSD 并非"结构性不中"——不中的是**恒定平台**,不是**被语音打断的钉住环路**;
4. 而这些增长段**整段发生在 T_low 之下**(从 −76dBFS 附近升回 −56dBFS),**只有经放宽门才看得见**;放宽门却恰恰禁止它们进 GROWTH。

⇒ **② 的括注复现了 B-F1 的病型**:用一个在目标场景里为假的前提,论证"这条路不用留"。critic 通则原文是"豁免条件在目标场景恒 False = 写了等于没写";这里是它的镜像——**"该场景本就不可达"的判断在目标场景恒假,于是一条真实可达的路被无据关闭**。

**为什么仍不阻塞**:该场景的覆盖**不必**经 GROWTH。语音间歇同时打断 PERSIST 的严格连续性(6 槽老化 = 96ms ≪ 语音段 1-3s ⇒ 轨必被删),所以 ② 指定的"最严 PERSIST 变体"**在同一场景下同样不可达**——真正要修的是 **PERSIST 的连续性语义**,而那是 C11 明文划归我方的判据层("定案机制:判据归接收方,本条款载使用注记")。我方 v1.2 的修法(§3.2/§5.3,不需改约):
- PERSIST 连续性由**严格连续**改为**滑窗命中率 ≥70%@2s,且只在"可观测 hop"上计率**(可观测性判定见使用注记 4);
- **影子表继承扩展**:同频(|Δf| ≤ BW/2)重生轨除继承 -2 提出的豁免签名外,**继承已累计的 PERSIST 可观测驻留信用**,保鲜期 T_exempt;继承须 GR 仍 active 为条件。频率刚性(房间几何决定)使同频关联可靠 [L3]。
- 两项都在"一门放宽、两门收紧"的结构内:**没有缩短 P_persist 的墙钟时长,只是容忍观测中断**,与 ②"完整 P_persist 不享 GR 减半"的立意一致。

**点单(v1.5)**:请把 ② 的括注改为事实陈述(如"GROWTH 维持原门系误伤面控制的取舍,非因该场景无增长"),或按上述允许"经放宽门 ∧ GR 持续 active ∧ PAPR≥T_papr_high ∧ 完整 W_long ∧ PHPR 非否决"的收紧型 GROWTH。**理由不能留错的**——错的理由会让下游(尤其零上下文的新 critic)以为这条路已被物理排除,从而不再检查它。

**结论:确认 ①②③④ 的机制与数值;对 ② 的括注论证提异议(非阻塞),并已在我方层给出补偿设计。**

## 3. C4 候选提取无绝对电平门(唯一物理下限 = 谱域数值底噪)

**独立推导(数值底噪 −128dBFS 复算)**
Q15 量化步长 q = 2⁻¹⁵,量化噪声 RMS = q/√12 ⇒ 相对满幅幅度 **−101.10dBFS**;N=1024 实 FFT 相干处理增益 = 10·log₁₀(512) = **27.09dB** ⇒ **每 bin 底噪 = −128.19dBFS** [L3/解析]。**与合同 −128dBFS 逐位相符**,且我确认其 dBFS 约定 = **峰值参考**(与我方 §1.2 `level` 定义同约定;若换"满幅正弦 RMS = 0dBFS"约定则为 −119.2dBFS)。**建议 v1.5 在该数后加"(峰值参考约定)"** —— 本项目已两次因"每侧/全宽、半/满 LSB"同族二义吃 2× 亏,dBFS 参考约定是同族第三个高发面。

**关键关系复核**:−128.2dBFS ≪ T_low_gr(−65dBFS),低 **63dB** ⇒ **数值底噪不可能成为判据门的藏身处**,C4 写死"无绝对电平门"确实堵死了"洞搬进供给层(绝对门形态)"这一路。**条款文本我确认。**

**⚠ 实质保留(不确认前任附带的推论"洞无处可搬")**
`top-N 相对选择` **不含绝对阈值,但它是一个信号相关的有效电平门**:实际准入线 = 当前谱中第 N 名局部峰的电平,**在房间吵时自动抬高**。前任的端到端自查只比了"数值底噪 vs T_low_gr"(**幅度轴**),没有比"名次容量"(**容量轴**)。我**不接受**该推论,理由与算例:

- **可实现的排挤场景(与 GR 抑制不同源,故不能用"响的东西会加深 GR 把啸叫压住"消解)**:C10/C11 作用域内的 **8 段动态 PEQ 是频段选择性**的。语音能量集中在 A 频段 ⇒ 动态 PEQ 只在 A 段加深 GR;B 段的钉住啸叫**未被抑制**,却仍要与 A 段的几十条语音谐波争 ≤16 个候选名额。**幅度排序下它出局,而它并没有变弱。**

**数值坐实(`selfcheck_W1B` CHECK F,两子场景并列,[L2/构造谱])——含一条推翻我方事前预期的结果**:

| 子场景 | 幅度 top-16 含啸叫线 | 有效准入线(第 16 名) | 已知 bin 直读 PAPR(门 15) | PNPR(门 8) |
|---|---|---|---|---|
| **F-1 宽带限幅钉住稳态(语音间歇)** | **True** | −92.3dBFS | **+38.9dB ✓** | +38.9dB ✓ |
| **F-2 频段选择性钉住 + 带外强语音** | **False** | **−53.5dBFS** | **+10.9dB ✗** | **+15.1dB ✓** |

**必须并列跑两个子场景**,只跑其一都会得出错的一般结论:
- **F-1 = 主场景,前置门全可达** —— 宽带限幅钉住的稳态平衡里,啸叫**必然**是本通道 tap 上的主导分量(啸叫与本通道其余内容共用同一条 tap→母线增益;啸叫在母线上顶到天花板 ⇒ 它在 tap 上也是最大的)。**这一条我先前差点漏掉,它把本保留的适用面收窄了一个量级——如实记,不夸大成普遍洞。**
- **F-2 = 真实残余**:啸叫线被挤出候选表,**且我事前预期的"改按 PAPR 排序即可救回"被本检查证伪** —— PAPR 是**全带**统计,带外语音抬高全带均值,弱峰 PAPR 随之塌陷(+10.9dB < 门 15)。**掩蔽下唯一存活的窄带证据是 PNPR(局部统计,+15.1dB)。**

**由此产生的两个后果(均已落 v1.2)**:
1. **我方层的"维持侧"补偿**:C4 供的是**主谱全 512 bin**,不只是候选表 ⇒ 已 TRACKED 的轨可由我方**在已知 bin 上直接读主谱复测**,不依赖它进不进 top-16。仅对"本槽未配对 ∧ 候选表满(np=16)"的轨走此路径,上限 4 轨/槽(包络对账见 W1-B §8.2)。**获取(acquisition)侧仍受容量限制 —— 残余,如实入可达性表 case (c)。**
2. **GR 放宽路径的窄带门改以 PNPR 承重**(见下方点单 P6),因为 PAPR 在该子场景结构性不可达。

**点单(v1.5,非阻塞但须在 D3/D4 实现派单前定)**:**C4 请写明 top-N 的排序度量**(P_peak 降序 / PNPR 降序 / 混合配额)。条款现在对此沉默 ⇒ 实现相关,且不同选择对 F-2 子场景的获取侧覆盖率不同。**我方倾向(按 CHECK F 修正后的依据):保留 ≥4 个名额按 PNPR(局部)降序分配**——**不是 PAPR**,PAPR 已被证伪;其余按 P_peak。供给侧已在算邻域均值(C5),增量成本可忽略。

**结论:条款文本确认(含 −128dBFS 复算相符);其附带推论"洞无处可搬"我不确认,已给容量轴反例、并把该反例的适用面如实收窄到 F-2 子场景。**

## 4. C4 `slot_seq[ch]`(跳帧降档可见性)

**独立推导**:C1 允许旁链跳槽(最低优先级、可抢占)。若我方按**名义 hop/墙钟**计数,跳槽 = 伪"峰消失" ⇒ 断轨重置 ⇒ **优雅降级机制变成漏检放大器**,且故障触发条件(高负载)与故障后果(漏检)**正相关**——负载高恰是全通道活跃、啸叫多发时。字段必要性我独立确认,**u32 单调 + 空号**的形态足够(不需要额外的"跳了几槽"字段,差值自明)。

**⚠ 使用注记 3(本轮新发现,计数语义必须二分 —— 这是 D2 咬合扫的产出)**
C4 原文:「接收方**全部**连续性/老化/驻留计数**按已交付分析槽计**」。**这条规则对"存在性计数"正确,对"速率估计"有害**,而 IMSD 的 LS 拟合恰是速率估计:
- 存在性(连续性/老化/reclaim/P_persist 驻留)→ 按**已交付槽**计 ✓(正是本条款要防的伪消失);
- **速率(IMSD 的 b=dB/hop、s=线性度残差)→ x 轴必须用 `slot_seq` 差值(真实时间轴)**。若照字面把跳槽窗压缩成连续 x,窗内的时间跨度被系统性低估,斜率与残差同时失真。

**数值坐实(CHECK E,`selfcheck_W1B`,构造轨迹 [L2/桌面数值])——双向都错**:

| 构造 | 朴素 x=0..7(按已交付槽序) | 正确 x=Δslot_seq |
|---|---|---|
| 真啸叫 250dB/s,窗中跳 6 槽 | b=+8.57(536dB/s) s=5.86 → **not**(s_max 拒 ⇒ **漏检真啸叫**) | b=+4.00(250dB/s) s=0.00 → GROWTH ✓ |
| 真啸叫 400dB/s,窗中跳 4 槽 | b=+10.97(686dB/s) s=6.62 → **not**(**漏检**) | b=+6.40(400dB/s) s=0.00 → GROWTH ✓ |

## 6. C12 ADC 参考电平担保双条件(+ trim 补偿执行方 = 提供方)

### 8.5 ⚠ 交底期新发现:同族二义第三例 —— PAPR 的 dB 约定(我方文档缺陷,含跨文档暴露面)

**事实**:我方 §1.2 的 PAPR 式 `10·log10((Nb−1)·M[k]/(ΣM−M[k]))` 与 PX4 `GyroFFT.cpp:514` 逐符号同构(我已核 vendor 件:`:447 fft_magnitude = sqrtf(re²+im²)` ⇒ **M 是幅度不是功率**,`:514` 对该**幅度比**取 **10·log10**)。故:

- 该式给出的数值 = **常规 dB 的一半**(幅度比的常规 dB = 20·log10);
- 而同一节的 PNPR 式写的是 `20·log10(...)` = **常规 dB**;
- ⇒ **同一个 AND 门(§1.3 候选门:PAPR≥15 ∧ PNPR≥8)里的两个阈值用了两套 dB 约定**,并列书写,任何读者/实现者都会按同一约定理解;

**这是本项目第三次同族二义,前两次各造成恰好 2× 偏差**:C5「每侧/全宽」(B-F2)、F1「半/满 LSB」(W1-A)。**通则(DEC-0010)"规范值必须带明确度量约定"此前列了每侧/全宽、半步/满步、峰值/RMS、单边/双边 —— 建议补入第五项:「幅度比 10·log10 / 20·log10」**,并入 team_config 同族二义清单。

**处置(v1.2 已落,不需改约——PAPR 的定义在我方层,合同只供原料 P_peak/全带均值)**:
1. §1.2 PAPR 改为 **20·log10(幅度比)= 常规 dB**,与 PNPR 同约定;所有 PAPR 类阈值(T_papr/T_papr_high/T_harm)显式标注"常规 dB(20·log10 幅度比)";
2. 显式警示 **PX4 :514 的 MIN_SNR/参数值不可直接搬**(其为半 dB 约定),移植时必须换算 —— 这是"移植件参数重标定"纪律的一个具体命中;
